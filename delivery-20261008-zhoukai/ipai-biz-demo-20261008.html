🚀 新手上手
三步闭环：① 回执（增长台手填当天数据）→ ② AI 诊断出行动清单 → ③ 一键派活给数字高管，产出物直接复制使用，效果回填再迭代。
建议顺序：先找沈定做 IP 定位（打地基）→ 何策出选题池 → 秦文写第一批文案。定位没定之前，不建议急着发内容。
30 秒自动走完「填数据 → 诊断 → 派单 → 生成全案」全流程，方便你看系统怎么运转。演示数据不影响你的真实记录。
现阶段手动填写（私信/到店/成交等），客单价由流水÷单数自动算出，不用填。后期接入平台 API 后自动同步，只填线下才能确认的字段。
⚡ 算力计费
1 元 = 10 算力 · 0 元开通。按次扣费：文案 15、诊断/直播/投流 50、定位全案 99（各高管卡片上有标）。生成成功才扣，失败不扣。
邀请等活动赠送的算力，仅可用于文字类智能体（定位/选题/文案/私域/成交话术等），视频生成、投流等消耗型功能不适用。
「我的 → 算力余额 → 充值」，支持单次充值与年卡（含专属权益）。本演示页不产生真实扣费。
🗂️ 派单与工作台
三个入口都可以：① 增长台任务卡点「派活」；② 数字高管页点高管卡片；③ 左侧功能栏（选题/文案/成交…）直接选。进入工作台后按引导填简报即可。
生成过的全案自动归档到「我的 → 增长档案 → 最近产出物」，支持随时回看全文、复制、下载，最多保留最近 12 份。
三级联动流水线：每天 09:00 生成 10 条选题 → 20:00 按重要性取前 N 条写文案 → 21:00 按文案取前 N 条生成视频。每一环的条数都可在「任务 → 定时任务」里用 ± 按钮调整；上游没生成，下游当天自动跳过。
回工作台改访谈简报（客群/亮点/语气等），高管会按新简报重新生成；也可以直接在对话里补充要求。
📈 内容与流量
获客是闭环不是单发：把数据丢给江流诊断 → 按建议调整 → 何策换选题 → 秦文重写。迭代三轮，比单发一条有效得多。
用定时任务：选题/文案/视频每天自动按计划生成，你只负责挑满意的发。投放加热找窦加（DOU+）或陶邻（本地推）。
