📜 文案铁律 每条都过
✓
一句话一个意思

每条 100-200 字，短句，口语，像手机打出来的

✓
从具体场景出发

不说「今天感悟很深」，说「今天帮一个火锅品牌跑通了AI获客」

✓
专业感用行为证明

不说「我很专业」，说「今天帮客户排查了一个AI流程卡点」

✓
软 CTA，不硬推

不说「私信我」，说「有类似问题可以交流」

✓
保护客户隐私

隐去人名、公司名、具体金额、可辨认截图

✓
不编造

不发明案例、不夸大数据、不造假客户聊天

✓
缺真实数字只留占位

正文缺数字时插入【这里补一个真实数字】，老板亲补（例：护理 40 分钟），补完检查项才变绿 —— 系统不替你编

🖼️ 配图规则 真实感优先 · 能不生成就不生成
📷
实拍图为主（信任来源）

工作现场、交付过程最值钱的是真实感：从素材箱一键挂图，AI 只修不造——客户隐私打码（人脸 / 车牌 / 联系方式），门头、logo、位置等你的品牌信息原样保留，与文案隐私泛化同一条流水线
