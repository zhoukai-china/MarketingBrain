## 二、部署步骤（api.lcppch.top:3007）

1. **同步代码**：把上述文件同步到服务器仓库（main/config 有改动，注意别覆盖服务器 .env；首次部署含 `gu_models.py`，`init_db()` 自动建 `gu_quotas` 表，无迁移脚本）。
2. **.env 新增**（可全部不填，默认即限时免费期）：
   ```ini
   GU_POINTS_PER_CALL=0      # 0=免费体验期；按次计费改 10-30（10积分=1元）
   GU_DAILY_FREE_CALLS=10    # 免费期每用户每日对话次数；0=不限次
   GU_CONV_TTL_HOURS=6
   GU_MAX_CONTEXT_MESSAGES=16
   GU_TIMEOUT=90
   GU_MAX_MESSAGE_CHARS=500
   ```
3. **重启服务**（systemd 同款命令即可），确认启动日志出现 `[gu] 已加载 6 位顾问配置`。
4. **nginx 两处**：
   - SSE 必须关缓冲，`/os-v2/api/skills/gu/`（或整个 skills 反代块）内加：
     ```nginx
     proxy_buffering off;
     proxy_cache off;
     proxy_read_timeout 120s;
     ```
     （后端已带 `X-Accel-Buffering: no` 响应头，双保险）
   - 前端页面：`web/gu-ren-app-20261006.html` 放到 nginx 静态目录即可，前端自动识别 lcppch.top 域名走 `/os-v2/api/skills` 反代通道（与微信回调同一前缀）；其他域名部署需改文件头部 `API_HOST / API_PREFIX` 两个常量（文件内有注释标明）。
5. **真模型冒烟**（服务器上有 DEEPSEEK_API_KEY）：浏览器打开页面即进大厅（体验期免注册：前端静默发游客 Key，全程**无任何 Key 弹层**；Key 弹层页面已按产品拍板整体移除，游客 Key 失败时发送会自动重连）→ 问孙子「对面全场五折跟不跟」→ 确认流式打字 + 四段卡片 + 引文出处标签 + 顶栏「今日剩 N 次」逐次递减；再发一句「谢谢先生」→ 应得到一句正常短回复（不出四段卡）。顶栏最左有「‹」返回商城按钮（`MALL_URL` 常量可指定商城地址，留空则浏览器历史返回）。
