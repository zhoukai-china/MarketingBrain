# 思潼品牌获客智能体：四场景内测手册

## 一、当前内测范围

品牌获客智能体当前按四个业务场景验收，不要求客户先提供完整经营数据：

| 场景 | 默认联合能力 | 第一版主要交付 |
|---|---|---|
| 外卖订单增长 | 行业热点＋文案创作＋直播话术 | 待验证热点、7天内容、60分钟外卖直播与平台下单承接 |
| 美业到店增长 | 选题灵感＋文案创作＋朋友圈私域 | TOP10选题、7天内容、消费者咨询、预约、实际到店与复购承接 |
| 餐饮招商加盟 | 招商获客＋直播话术＋朋友圈私域 | 餐饮招商内容、60分钟招商直播、线索筛选、考察承接与30天计划 |
| 美业招商加盟 | 招商获客＋直播话术＋朋友圈私域 | 美业门店模型、招商内容、加盟线索、到店考察、签约跟进与30天计划 |

## 二、客户资料不阻塞原则

客户暂时没有提供菜品、项目、价格、地址、案例、门店模型、招商政策或经营数据时，系统必须继续交付第一版：

1. 已确认信息按客户事实写入。
2. 未确认信息统一标记为【待补】。
3. 不借用思潼自己的城市、行业、产品和案例填空。
4. 不编造销量、效果、收益、回本、客流、预约、到店、签约或复购结果。
5. 客户以后补数据时，只升级对应占位和复盘结论，不推倒现有结构。

## 四、内部操作步骤

1. 打开最新版“思潼·品牌获客智能体”。
2. 新建任务，不复用其他客户任务。
3. 打开“当前客户资料”，填写客户名称、行业、城市、门店规模、经营问题、增长目标和主要平台。
4. 选择对应业务场景，让系统自动指定3个技能。
5. 在输入框补充本轮需求；没有的数据明确写“暂未提供”。
6. 发送后检查“3项联合任务已完成”。
7. 检查右侧是否生成3个独立智能文件。
8. 打开完整交付物，重点检查事实、行业、转化路径和可执行性。

## 五、每份结果必须检查什么

### 共同检查

- 客户名称、城市、门店规模和经营问题是否正确。
- 是否混入思潼企业资料或上一个客户资料。
- 3个技能是否全部显示已完成。
- 是否有短结论、完整交付、可直接使用内容和复盘指标。
- 缺失事实是否写【待补】，而不是被模型自行补齐。
- 版面是否按章节折叠，是否方便老板和员工阅读。

### 场景专项检查

- 外卖订单：成交必须回到美团、饿了么、淘宝闪购，不默认写抖音团购和到店核销。
- 美业到店：必须走“内容/朋友圈—消费者私信—预约—实际到店—成交与复购”。
- 餐饮招商加盟：必须有线索筛选、考察预约、风险提示和30天计划；禁止收益与回本承诺。
- 美业招商加盟：必须围绕加盟商、门店模型、考察和签约跟进；不得转成培训招生、招店长合伙人或合伙人培养。

## 六、发给客户的反馈话术

可以直接复制下面这段：

> 我们正在内测思潼AI增长智能体，我先根据目前了解的情况，为你的业务生成了一版增长方案。现在缺少的真实项目、价格和经营数据都标了“待补”，没有把不确定内容当成事实。你不用一次提供全部资料，先帮我看5件事：第一，客户情况有没有写错；第二，方案里哪一部分最有用；第三，哪一部分太空或不符合实际；第四，员工能不能直接照着执行；第五，如果下一版只补一组真实数据，你愿意先补什么。你直接语音回复就可以。

## 八、自动验收命令

本地接口运行后执行：

```bash
pnpm acceptance:acquisition-scenarios
```

验收线上或独立测试环境时：

```bash
pnpm acceptance:acquisition-scenarios -- --base "https://你的接口地址" --token "测试账号令牌"
```

脚本必须同时通过四个场景、12个技能步骤、客户资料隔离、必需交付和禁用项检查。任何一个场景出现部分交付，都不能进入客户内测。

## 九、上线前放行条件

- 四场景自动验收全部PASS。
- 最新工作台四个场景按钮可见、能力数量正确。
- 每个场景至少完成一次页面真实发送。
- 3个智能文件能打开、预览和下载Word。
- 任务客户资料不会覆盖企业资料，不会串到其他任务。
- 客户未提供数据时不会阻塞第一版生成。
- 生产环境登录、邀请、积分、数据库和数据隔离检查通过。
