# LQ-01 / LQ-02 受控知识授权与版本底座

状态：已完成

## 归属

- 产品：兰琪美业经营增长智能体
- 层级：产品任务含平台子改动
- 风险：高
- 预计修改热点：`packages/db/prisma`、`apps/api/src/services`、`scripts`
- 是否允许并行：否；该任务定义后续兰琪知识和诊断模块的基础边界。

## 用户结果

平台可以把兰琪提供的方法论、内部定价和业务资料登记为可追溯、可授权、可失效的知识版本，后续智能体只能读取当前租户有权使用的版本。

## 本次范围

- 建立 K1 至 K4 的受控知识版本数据结构与迁移。
- 建立服务端“默认拒绝”的知识版本校验和访问判定规则。
- 为激活的 K1 核心知识强制要求来源、版本、审核、适用范围和有效期。
- 建立脱敏确定性回归，覆盖正常授权、过期、无授权、跨租户、总部私密、门店私有和会话临时资料。

## 本次不做

- 不导入兰琪真实方法论、内部定价、客户资料或案例。
- 不创建加盟商推荐/开通流程（后续 LQ-03）。
- 不暴露后台录入页面或正式面向加盟商的 Agent 页面。
- 不启用真实充值、支付或退款。

## 验收条件

1. 正常路径：已审核、在生效期内、适用于当前角色和租户的 K1 版本可被判定为可用。
2. 失败路径：缺少来源/审核/版本/适用范围的 K1 版本不可激活；过期或未开始生效的版本不可用。
3. 不应发生：未授权租户读取 K1、加盟商读取总部 K2、推荐方读取门店 K3、其他会话读取 K4、任何知识反馈自动激活。
4. 可观测结果事件：访问判定产生允许/拒绝及明确原因，供后续 AgentRun 审计接入。
