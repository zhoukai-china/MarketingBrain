# LQ-24 私域营销结果动作补齐：「素材信息不够」分支也要能重新生成

状态：**已完成并上测试实例 + 生产**（2026-09-12）

## 归属

- 产品：兰琪美业经营增长智能体平台（`docs/agents/lanqi-beauty/`）
- 层级：产品专用（前端结果面板）
- 风险：低（只加一个按钮，不改生成逻辑、不改计价、不改接口）
- 预计修改热点：`apps/web/src/pages/LanqiMomentsPage.tsx`、`apps/web/src/pages/LanqiMomentsWechatGroupPage.tsx`
- 是否允许并行：是（与平台侧 PLAT-* 工作线无文件重叠）

## 用户结果

老板填的素材被判定「还不够具体」时，结果面板不再是一条死路——他补完信息后能直接在原地点「重新生成」，不用重新找按钮或刷新页面。

## 来源

WorkBuddy《兰琪私域营销页回归复测报告（第3轮）》建议「结果卡片底部补一键复制 + 重新生成」。
复核结论：报告的 P2-1/P2-2 在 2026-09-11 已修并已上线（内测实例真实浏览器 11/11 通过），
但**报告现象仍有可复现的残留**——当 `result.needsInput` 为真时，结果面板走的是另一个分支，
该分支**只有提示文案、没有任何操作按钮**，此时「结果卡片没有按钮」确实成立。
本轮按报告建议把这个分支补齐。

## 本次范围

- 「朋友圈获客」快速模式/专业模式：`result.needsInput` 分支补「🔄 重新生成」按钮（`data-lanqi-moments-regen`）。
- 「微信群话术」：同一分支补同样按钮（`data-lanqi-wechat-regen`）。
- 该分支**不**放「📋 复制文案」——这里没有正文可复制，放上去只会让人复制到一句提示。

## 本次不做

- **不做「多版本切换」——用户 2026-09-12 明确拍板：「不要多版本切换，如果不满意，支持用户重新生成就可以了。」** 该口径与现状一致：结果卡片（含「信息不足」分支）已有「🔄 重新生成」，且后端 `POST /lanqi/moments/upgrade` **每次调用都真实重跑一次生成**（`momentRequestKey` 的 upsert 只用于记账，`update: {}` 不返回旧结果），因此「不满意就再点一次」本次已由既有能力满足，无需新增版本列表或多版并存。
- 不改 `isInputRich` 判定规则、不改提示文案、不改接口与积分。
- 不动服务端：`needsInput` 由 `apps/api/src/products/beauty-industry/moments-service.ts` 决定，本轮不碰。

## 验收条件

1. 正常路径：素材信息充足时，结果卡片仍有「复制文案 + 重新生成」（不回归）。
2. 失败路径：素材信息不足（`needsInput`）时，面板除提示外给出可点的「重新生成」；点击后按钮进入「重新生成中…」禁用态，再次生成后仍按原规则判定。
3. 不应发生：信息不足分支不出现「复制文案」；不因新增按钮伪造正文、不修改提示文案、不新增扣费或任务。
4. 可观测结果事件：DOM 上 `[data-lanqi-moments-regen]` / `[data-lanqi-wechat-regen]` 在信息不足分支内存在且可点。
5. 桌面 1280 与移动 390 视口都可见可点，控制台 0 错误。

- 基线命令：`node scripts/lanqi-moments-ui-contract-smoke.mjs` → **PASS 19/0**（改动前全绿，说明本轮新增断言是唯一红灯来源）。
