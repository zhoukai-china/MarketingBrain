# LQ-28 兰琪爆款复刻：取消「搜索爆款」，改为「贴抖音链接 / 上传参考视频」自备素材

状态：已上线（2026-09-14，测试实例 + 生产）

## 归属与口径

- 产品：兰琪（`docs/agents/lanqi-beauty/`），公域获客 → 视频获客 → 爆款复刻。
- 用户口径（2026-09-14，原「兰琪-公域获客-页面开发」任务末轮反馈）：
  1. 页面上的「AI 去抖音/视频号搜爆款」结果不可用：抓到的不是爆款（点赞很少）、要求皮肤管理却给沐足、还混入图文；
  2. **取消爆款复刻里的「搜索爆款」功能**，改为**用户自己添加抖音链接或者上传视频文件**，再给要替换的人物形象（换脸 / 换人），由智能体做爆款复刻（参考用户提供的两张原型截图）。
- 由此本卡同时**下线 LQ-25 的「爆款检索」能力**（页面入口、API 路由、配置项、专项冒烟）。LQ-25 的历史证据保留在 `tasks/LQ-25-爆款复刻真实检索源接通.md` 与 `docs/BUG_REGRESSIONS.md`，不再作为在跑能力。

## 只读取证（2026-09-14，生产机真实调用，不含密钥输出）

| 探针 | 结论 |
|---|---|
| `site:channels.weixin.qq.com 皮肤管理门店获客` | `search_results=0` —— **视频号侧根本没有可检索的站内视频页**，与用户「抓不到视频号视频」一致 |
| `抖音 皮肤管理门店获客 皮肤管理 爆款视频 site:douyin.com/video` | 10 条里 **0 条 `/video/`**，3 条 `/note/`（图文）、3 条 `/user/` 主页、其余第三方站点；其中一条正是用户投诉的「楠枫沐足保健服务馆」——**检索词带行业词也挡不住无关赛道** |
| 检索返回字段 | 每条只有 `icon / site_name / index / title / url`，**没有 snippet、没有点赞/播放字段** → 服务端无法证明「是不是爆款」 |
| 抖音视频页 `www.douyin.com/video/{id}` | HTTP 200 / 72914 B，`<body></body>` 空壳，无 `playAddr` / `RENDER_DATA` |
| `iesdouyin iteminfo` / `aweme detail` | HTTP 200 / **0 字节** |
| `iesdouyin share` / `m.douyin share` 分享页 | HTTP 200 / 32KB JS 空壳，无视频直链、无 `digg_count` |

**结论**：公开检索既拿不到真爆款证据（无热度字段），也拿不到视频号视频，更拿不到抖音视频文件。
继续硬做「搜爆款」只会给出门店无法信赖的结果，因此按用户口径**下线检索**，改为自备素材。

- `apps/web/src/pages/LanqiAcquireVideoPage.tsx`（`ReplicateMode`）改为三段式：
  1. **第 1 步 参考素材**：两个页签「参考抖音链接」「上传参考视频」；
     - 抖音链接：本地校验（必须 `https`、必须是抖音域、`/video/` `POST /note/` 或分享短链），识别后登记为参考来源，并**明确说明平台不提供站内视频文件下载**、给出「存原片再上传」的步骤；**链接本身不出片**（fail closed）；
     - 上传参考视频：`MP4 / MOV ≤200MB`，上传到 `/files` 拿 `fileId`，并读取真实时长回显；
  2. **第 2 步 人物形象**：换脸（头部照片）/ 换人（全身画面）二选一 + 真实上传 `fileId`；
  3. **第 3 步 授权 → 报价 → 确认 → 轮询 → 播放/下载**（沿用 LQ-27 既有链路，不改计费与幂等）。
- 页面副标题、右侧摘要面板、枢纽卡片文案同步去掉「搜爆款 / 关键词」口径。
- 回归：更新页面契约冒烟与测试实例验收脚本（断言不再出现检索入口、必须出现两个参考素材页签、链接路径不出片、未上传原片时不出片）。
- **不做**：不新建后端链路、不改计费口径、不接第三方付费数据服务、不做产品替换 / 视频比例 / 模型版本等本项目未具备的控件。

## 验收条件

1. 页面上**不再出现**任何「搜索爆款 / 平台筛选 / 行业领域 / AI 去抖音搜爆款」入口，且不再请求 `/lanqi/acquire/video/viral-search`（接口已下线）。
2. 「参考抖音链接」页签：填非抖音链接 → 本地拦截并说明原因；填抖音链接 → 识别成功并登记参考来源，同时**明说拿不到视频文件**、引导去上传；未上传原片时**不能**报价 / 出片。
3. 「上传参考视频」页签：非 MP4/MOV 或 >200MB → 本地拦截、不发请求；上传成功 → 显示文件名与时长。
4. 未上传原视频 / 未上传人物形象 / 未勾齐四项授权 → 点「看报价」不发任何请求并说明缺什么；确认按钮在此之前保持禁用。
5. `gaps` 非空 → 照实展示缺口，不创建任务、不扣积分；确认成功 → 进入轮询、成片可播放下载。
6. 界面不出现模型 / 厂商名；租户隔离沿用既有 RBAC（单店角色看不到别的门店任务）。
7. 页面在桌面 1440 与移动 390 下无横向溢出、无 console / page 错误。

## 已知边界（必须对用户讲清，不得含糊）

- 抖音 / 视频号**不开放站内视频文件下载**，服务端也无法把分享链接解析成视频（上表 5 条路径全部实测为空或 JS 空壳）。
  所以「参考抖音链接」只用于登记参考来源与引导，**真正出片必须有用户上传的原片文件**。
- 出片时长上限沿用后端策略（`maxOutputSeconds:30`），对外定价仍为 ¥1.2/秒 = 24 积分/秒（LQ-27 已拍板）。
- 若门店需要「平台真爆款 + 点赞/播放数据」，唯一可行路径是接第三方数据服务，属**独立采购决定**，本卡不做。
