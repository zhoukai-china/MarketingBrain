# 兰琪任务卡

开始一个兰琪开发结果时，从 `../../_templates/TASK_TEMPLATE.md` 复制任务卡到本目录，文件名使用：

```text
LQ-编号-简短结果.md
```

例如 `LQ-01-定义知识授权契约.md`。同一时间只允许一张兰琪编码任务卡处于“开发中”；知识盘点或 Eval 设计可以作为非编码准备任务并行。
