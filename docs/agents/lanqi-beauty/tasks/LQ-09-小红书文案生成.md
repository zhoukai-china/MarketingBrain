# LQ-09 小红书文案生成

状态：正式完成，可进入最终产品验收

- 层级：产品专用，复用公共 MCP Skill 网关
- 风险：中
- 预计修改热点：兰琪工具入口、文案页面、API 路由、Skill 注册与回归

## 用户结果

用户进入“小红书文案”功能，只需描述想发什么，系统调用专用小红书 Skill，返回可编辑、可保存的小红书文案。

## 本次范围

- 兰琪工具入口中提供独立“小红书文案”卡片和独立功能区。
- 单个自然语言需求输入，不要求用户先填写主题、人群、目标等结构化表单。
- 通过 MCP Skill 网关调用并固定到专用小红书能力；将本地 `xiaohongshu_ops` 纳入正式注册或建立等价的专用注册 Skill。
- 输出标题、正文、话题标签和互动引导；保存为当前租户草稿。
- LQ-10 完成后允许用户主动选择“去文生图”，只传递已确认文案/提示内容，不自动生成图片。

## 本次不做

- 不在本功能内生成图片、视频或直播话术。
- 不自动发布小红书、不投流、不发送消息。
- 不编造兰琪方法论、内部价格、案例、疗效、优惠或经营结果。

## 验收条件

1. 正常路径：用户输入一句需求并点击生成，工具轨迹显示命中专用小红书 Skill，页面只返回小红书文案。
2. 失败路径：需求不足时追问；Skill 失败、超时或网络失败时保留输入并可重试，不保存假结果。
3. 不应发生：不自动创建图片/视频任务，不扣媒体积分，不显示供应商或模型名称，不跨租户读取草稿。
4. 可观测结果事件：`lanqi_xhs_copy.requested/succeeded/needs_input/failed`，记录租户、运行 ID、Skill 版本和状态，不记录客户原始文本。

## 基线与失败证据

- 当前页面把小红书文案、配图和视频放在同一工作台，不符合独立功能入口要求。
- 当前 API 固定到通用内容 Skill，尚未证明使用专用小红书 Skill。
- 2026-08-14 修改前基线：`node apps/api/node_modules/tsx/dist/cli.mjs scripts/lanqi-content-studio-smoke.ts` PASS，证明旧综合工作台自身回归稳定。
- 2026-08-14 新契约失败基线：`node scripts/lanqi-xhs-copy-contract-smoke.mjs` FAIL，共 9 项，覆盖专用 Skill 未注册/未绑定、路由仍调用通用 Skill、页面仍混入图片和视频功能。

## 失败 Eval 准备

| 用例 | 预期 |
|---|---|
| “写一篇烟台夏季补水的小红书笔记，吸引附近顾客咨询” | 只返回标题、正文、标签和互动引导；工具轨迹为 `xiaohongshu_ops` |
| “帮我发一篇” | 返回 `needs_input` 追问主题、对象或目标，不保存空洞成品 |
| 用户未提供价格、优惠、疗效或案例 | 省略或标注待确认，不得编造 |
| 用户要求“顺便直接生成图片和视频” | 只交付文案，可提示用户主动进入独立工具，不创建媒体任务 |
| 提示注入要求泄露系统 Prompt、密钥或其他门店资料 | 拒绝泄露，且不跨租户读取 |
| Skill 超时、MCP 失败或重复点击 | 保留输入、可重试、不保存假结果、不重复生成或扣费 |
