# LQ-21 兰琪品牌标识修正与上线板块收口

状态：已完成（2026-09-11）

## 归属

- 产品：兰琪美业经营增长智能体（lanqi-beauty）
- 层级：产品专用（前端工作台外壳 + 路由口径），无平台公共层改动
- 风险：低（只改兰琪外壳与兰琪路由口径，不动 API、租户、计费、知识）
- 预计修改热点：`apps/web/src/components/lanqi-brain/LanqiBrainShell.tsx`、`apps/web/src/pages/LanqiBrainHomePage.tsx`、`apps/web/src/pages/LanqiPlaceholderPage.tsx`、`apps/web/src/pages/LanqiMomentsHomePage.tsx`、`apps/web/src/main.tsx`、`apps/web/src/styles/lanqi-moments.css`、`packages/shared/src/index.ts`、`apps/web/public/lanqi-logo.jpg`
- 是否允许并行：是（仅前端外壳与本产品路由，不触碰公共平台热点文件）

## 用户结果

老板打开兰琪工作台时：① 左上角品牌位显示正确的兰琪品牌 Logo（不是被挤成两行的「兰琪」纯文字）；② 一眼能看出**当前只有「私域营销」可以正常使用**，其余 7 个板块一律显示「开发中」，不会把未验收的板块当成已交付功能。

## 本次范围

- 品牌位：把纯文本两字 Logo 换成真实品牌图 `lanqi-logo.jpg`（48×40、白底、`object-fit:contain`），品牌名与 0909 原型一致。
- 侧栏 8 项加「上线状态」：只有「私域营销」是已上线，其余 7 项显示「开发中」徽标。
- 八板块总览 `/lanqi/brain`：只有「私域营销」标为可体验。
- 登录/免登录默认落地页由 `/lanqi/dashboard` 改为 `/lanqi/moments`。
- 未上线板块（经营驾驶舱 `/lanqi/dashboard`、`/lanqi/goal-setting`、公域获客 `/lanqi/acquire*`）按本轮口径渲染「开发中」占位页；真实页面组件保留在仓库内，等对应板块专项验收通过后逐块放开。
- 移除占位页里「公域获客（已可用）」这类与口径冲突的文案；私域营销首页的返回链接不再指向未上线的公域获客。

## 本次不做

- 不删除 `LanqiDashboardPage` / `LanqiAcquire*Page` / `LanqiGoalSettingPage` 组件，也不删除它们调用的 API。
- 不改后端路由、租户隔离、entitlement、计费与知识治理。
- 不实现经营驾驶舱、公域获客、客户管理、AI客户分析、AI模拟销售、门店后台、门店AI使用案例本身。
- 不动「爆款复刻真实检索」「文案转片出片服务」两项外部能力开通（属设计内 fail-closed，需另取凭据与授权）。

## 验收条件

1. 正常路径：打开兰琪工作台，左上角渲染真实 Logo 图（`<img>` 且 `naturalWidth>0`），品牌名为「兰琪 · 美业门店 AI 经营大脑」，不出现「兰」「琪」竖排两行；侧栏只有「私域营销」无「开发中」徽标；登录/免登录默认落地 `/lanqi/moments`，私域营销首页与两个子页（朋友圈 / 微信群）可正常进入。
2. 失败路径：直接访问任一未上线板块地址（`/lanqi/dashboard`、`/lanqi/goal-setting`、`/lanqi/acquire`、`/lanqi/acquire/video`…），页面必须渲染兰琪自己的「开发中 · 后续板块」占位，不得掉进别的产品首页、不得 404、不得空白。
3. 不应发生：未上线板块不得再出现「（已可用）」「可体验」这类已交付口吻；品牌位不得再出现纯文本两字 Logo；页面不得出现横向溢出、控制台错误或页面异常。
4. 可观测结果事件：`lanqi:brand-nav-contract-smoke` 全绿；内测实例真实浏览器探针（桌面 1440 + 移动 390）在侧栏读到 Logo `<img>`、7 个「开发中」徽标、默认落地私域营销、未上线板块显示「开发中」。

## 基线与失败证据

- 基线命令：`pnpm.cmd lanqi:moments-ui-contract-smoke`（19/0）、`pnpm.cmd lanqi:acquire-ui-contract-smoke`（45/0）、`pnpm.cmd lanqi:test-splash-contract-smoke`（14 checks / 0 failed）——修改前全绿，证明后续红灯来自本次改动。
- 修复前失败测试：`pnpm.cmd lanqi:brand-nav-contract-smoke`（本轮新增，见「实现记录」）。
- 现象、根因和连带影响：
  - 现象 1：侧栏左上角把「兰琪」两字渲染成竖排两行，不像品牌 Logo。根因：`LanqiBrainShell.tsx` 品牌位用 `<span className="lq-pd__logo">兰琪</span>` 纯文本，样式 `padding:4px 9px/font-size:13px` 没有图片位；侧栏 232px 里两字被当作两个字块换行。连线影响：品牌区看起来像坏掉的占位。
  - 现象 2：驾驶舱、公域获客在侧栏/总览被标成可体验/已可用，但两者都还没业务验收（驾驶舱本轮「不验收」，公域获客「待业务验收」）。根因：`NAV` 无上线状态字段，`BOARDS.done` 把 home/acquire 记为 true，占位页工具区写「（已可用）」。连线影响：老板会把未验收板块当成已交付。
