## 归属

- 产品：兰琪美业经营增长智能体平台（`docs/agents/lanqi-beauty/`），公域获客 → 视频获客 → 爆款复刻。
- 层级：产品专用。检索规则、服务、路由都落在兰琪目录（`apps/api/src/products/lanqi/`、`apps/api/src/routes/lanqi-viral-search.ts`），
  只在 `server.ts` 的兰琪作用域注册；美业单品侧不挂这条路由。
- 风险：**中**——真实外发检索（每次检索会真实调用一次联网检索能力）、结果真实性、租户隔离、条目不得编造。
- 是否允许并行：可以与其它产品任务并行，但 `apps/web/src/pages/LanqiAcquireVideoPage.tsx` 是兰琪视频页唯一热点，同文件改动必须串行。

## 用户结果

门店在「公域获客 → 视频获客 → 爆款复刻」里填关键词（可选平台筛选：抖音 / 视频号 / 抖音+视频号，行业领域：美容皮肤管理 / 美甲美睫 / SPA养生 / 综合生活美容），
点「AI 去抖音/视频号搜爆款」后拿到**真实可点开的条目**：每条显示平台、真实类型（抖音视频 / 抖音图文 / 视频号页 / 微信图文）、标题、站点与摘要，
可以「打开原页面」核对，也可以「选它复刻」进入下一步补素材。检索不到有效条目时页面照实说明，**不编造条目、链接和播放量**。

## 口径来源（用户 2026-09-12）

## 本次不做

- **不接第三方数据服务**（新榜 / 蝉妈妈 / 飞瓜 / 灰豚等）与抖音开放平台企业接口：需要另取账号、资质与费用授权，属独立决定。
- **不做服务端爬虫抓抖音搜索接口**：实测 `www.douyin.com/search/*` 是 JS 空壳（73KB 空 body）、
  站内搜索 API 未签名直接返回 `blocked`、`v.douyin.com` 短链只回一段混淆 JS、`iteminfo` / `aweme detail` 均返回 0 字节 ——
  没有签名与登录态拿不到真实条目，硬做就是伪造结果。
- **不改变爆款复刻出片能力**：生成按钮仍是 `VIDEO_RENDERING_READY=false` 的 fail-closed 提示，OSS/STS 与预算闸属 LQ-23/演示 4 的另一条线。
- 不动计费口径、不动租户隔离、不动美业单品的爆款复刻链路、不动 `main.tsx` 上线开关。

## 实测证据（2026-09-12）

- 真实检索（用生产同一把凭据、跑真实服务代码）：关键词「皮肤管理门店获客」+ 领域皮肤管理 →
  `platform=dy` **3 条抖音站内页**、`platform=sph` **6 条微信生态页**、`platform=all` **6 条合并结果（抖音在前）**；
  全部 URL 均为 `https://www.douyin.com/{video|note}/...` 或 `https://mp.weixin.qq.com/s?...`，无第三方站点、无编造字段。
- 检索词选择有实测依据：抖音站内视频页几乎不被公开索引，带「爆款视频 + `site:douyin.com/video`」写法后有效条目由 3 条升到 5 条，故固定采用该写法。

## 已知边界与后续

- **检索源口径（用户 2026-09-12 拍板：先走 A）**：本期不接第三方数据服务（新榜 / 蝉妈妈 / 飞瓜 / 豚豚这类付费作品库），继续用公开网页检索 ——
  抖音给站内真实页（多为 `/note/` 图文，少量 `/video/`），视频号给微信生态公开图文并按真实类型标注。
  **重提 B 的触发点**：等**爆款复刻真正出片跑通**（需要用户侧的 OSS/STS 凭据 + 生产付费上限）之后，由我核对这条链路的实际价值，再回来讨论要不要为“视频号视频条目 + 播放点赞数据”付费。
  在此期间**不得**擅自采购、开户或引入任何外部付费数据源。
- **视频号站内视频页没有公开索引**（`site:channels.weixin.qq.com` 实测 0 条），所以「视频号」这一档当前给的是**微信生态公开图文页**，
  页面上按真实类型标注为「微信图文」，不冒充视频号视频。要拿真正的视频号视频条目，只有两条路：第三方数据服务，或微信侧官方能力 —— 都需要用户另行决定与授权。
- 抖音侧命中的多是 `/note/`（图文）页，`/video/` 页被公开索引的很少；条目卡片按真实类型标注，不把图文当视频。
- 检索为一次同步外发请求（默认 25s 超时），当前未做结果缓存与频控；门店连续点击会重复计费给上游（对门店免费）。若后续使用量上来，需要补缓存 / 频控。

## 2026-09-14 收口：本能力已由 LQ-28 整体下线

- 用户 2026-09-14 口径：「**取消爆款复刻里面的搜索爆款功能，让用户自己添加链接或者上传视频文件**」。
- 下线原因（生产机只读取证，6 条探针）：① 检索接口只回 `icon / site_name / index / title / url`，**没有点赞 / 播放字段**——服务端证明不了「是不是爆款」；② `site:channels.weixin.qq.com` **0 条**，视频号侧根本没有可检索的站内视频页；③ 抖音那组 10 条里 **0 条 `/video/`**、3 条 `/note/` 图文、3 条 `/user/` 主页，且含用户点名的「楠枫沐足保健服务馆」——规则层挡不住无关赛道与图文混入；④ 抖音视频页 / `iesdouyin iteminfo` / `aweme detail` / 分享页**四条路径全部为空壳或 0 字节**，服务端拿不到视频文件，「选它复刻」实际接不上。
