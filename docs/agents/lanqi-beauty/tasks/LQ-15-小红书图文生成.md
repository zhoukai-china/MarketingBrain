# LQ-15 小红书图文生成

状态：开发完成，零付费统一页面链路已达到本地验收线

## 归属

- 产品：兰琪美业经营增长智能体
- 层级：产品任务含现有平台媒体/积分能力复用
- 风险：高
- 预计修改热点：兰琪内容工作台页面、兰琪专属组合工作流、现有媒体下载响应、兰琪专项测试与产品文档
- 是否允许并行：否；暂停尚未启动的美业问答 MCP 和其他兰琪编码任务

## 用户结果

用户在 `/lanqi/content-studio` 一次输入并确认页面已展示的积分报价后，在同一页面获得可复制的小红书文案与可下载的真实图片，刷新后恢复同一图文作品。

## 本次范围

- 一个主按钮完成文案、专业图片提示词、图片任务创建和统一保存。
- 输出三个标题候选、选中标题、正文、标签、互动承接、图片、保存状态、时间和实际积分。
- 提示词只放在高级详情；复用既有草稿、预览、媒体任务、租户资产和积分事务。
- 图片失败时保留文案并允许只重试图片；重复请求复用同一作品/任务。
- `/lanqi/image-studio` 只保留兼容/内部调试路由，不进入用户主导航。

## 本次不做

- 不开发美业问答 MCP、视频、直播话术、自动发布、投流、充值或生产部署。
- 不新增产品专属钱包，不复制媒体 Provider、提示词或积分账本逻辑。
- 未获得新费用授权前不创建第四个真实图片 Provider 任务。

## 验收条件

1. 正常路径：一次输入、一次报价确认，在同页得到标题/正文/标签/互动、真实图片、复制和下载；刷新恢复完整作品。
2. 失败路径：文案失败不创建图片；图片失败保留文案并释放图片预留；只重试图片不重复文案计费；余额不足、取消、断网、超时和下载失败有明确终态。
3. 不应发生：跨租户、重复生成/扣费、A/B/tenant 测试标签、编造疗效/价格/案例、供应商临时 URL 暴露、从用户导航进入独立图片工作室。
4. 可观测结果事件：`lanqi_xhs_package.quoted/requested/text_ready/image_requested/partial_success/succeeded/restored/canceled/failed/copied/downloaded`。

## 基线与失败证据

- 基线命令：`node scripts/lanqi-xhs-package-contract-smoke.mjs`
- 修复前失败测试/Eval：FAIL；旧页面只有“生成小红书文案”并要求跳转 `/lanqi/image-studio`，没有统一 package API、同一作品关联、图片下载和部分成功恢复能力。
- 现象、根因和连带影响：LQ-09/LQ-10/LQ-14 以内部阶段分别交付，用户必须手工搬运内容且文案/图片无法作为同一作品恢复。
- 浏览器修复前证据：正常 HTTP 请求被 `request.raw.destroyed` 误判为取消并返回 499；文本 Provider 安全降级会把无关固定内容当作小红书文案；受保护资产直接作为 `<img src>` 时被浏览器 ORB 阻断。三项均先在真实页面复现后建立合同断言或专项路径。
