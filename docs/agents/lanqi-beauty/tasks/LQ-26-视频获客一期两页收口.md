# LQ-26 视频获客一期收口（爆款复刻单模式 + 一键成片 6 步）

状态：**开发完成、已上测试实例并实测通过；生产已发布**（2026-09-12）

## 归属与口径来源

- 产品：兰琪（`docs/agents/lanqi-beauty/`），公域获客 → 视频获客。
- 参考文档（用户 2026-09-12 指定入口）：`CODEX-START-HERE.md` → `CODEX-开发总纲-20260909.md` → **`2026-09-12-视频获客一期最终范围-Codex交接.md`（本期以此为准）**；
  Demo 对照 = 本地工作副本 `beauty-xhs-prototype-20260827\video.html` / `video-copy.html`（线上冻结版不含本次改动）。
- 用户口径：一期**只做 2 页** —— `video.html` = 🔥爆款复刻（单模式）、`video-copy.html` = 一键成片（原「文案转片」，**删手动贴文案**）；
  **撤门店素材成片 / AI 剪辑**（代码保留、不挂入口、不交付）；两页任务页**互不显示对方跨页入口**。

## 用户结果

1. 视频获客只剩两个入口：**爆款复刻**（关键词/赛道 → 抖音·视频号真实检索 → 选一条 → 换脸/换人/换产品 → 复刻方案[画质档位 480p/720p/1080p + 肖像授权] → 生成）；
2. **一键成片**：一句话说需求 → AI 写 **3 版**候选文案（每版标字数 + 预估口播时长，第 1 版 = 用户选的风格，可「换一批」且保留第 1 版）→「用这版」**直接进分镜** → 传素材卡 → 积分预算 → 成片；
3. 全流程**没有「手动贴文案」入口**，也没有门店素材成片 / AI 剪辑入口。
