# LQ-10 文生图

状态：专业提示词增强零付费版本已完成并通过本地放行门禁；真实图片生成待预算与账号确认

## 归属

- 产品：兰琪美业经营增长智能体平台
- 层级：兰琪独立入口，复用公共媒体生成、钱包与审计底座
- 风险：高
- 是否允许并行：否

## 用户结果

用户从兰琪小红书文案页主动进入独立“文生图”工具，填写画面需求、用途、比例、视觉方向和文字方式，在确认素材权利后获得可保存、可恢复的最终提示词、事实边界、能力依赖和费用预览。本阶段不生成图片、不扣积分。

## 本次范围

- 独立入口、独立页面和按租户隔离的预览历史。
- 支持自然语言需求、用途、1:1/3:4/9:16/16:9 比例、视觉方向、画面文字方式和素材权利确认。
- 使用专用 `lanqi-image-prompt-enhancer` 将普通需求转换成可编辑意图理解、真正影响成图的待补问题、三个不同变量的视觉方向、正向提示词、负向提示词、后期叠字和供应商无关模型参数。
- 只注入门店档案中的已确认门店名称、城市和服务；无激活知识版本时显式说明未引用兰琪专属方法论。
- 生成供应商无关的 `media.image.generate` capability、提示词预览、100 积分产品预估和永久存储/计费依赖。
- 可从小红书文案页主动跳转；不会自动把文案变成图片。

## 当前零付费阶段

- 已完成独立页面、输入契约、提示词预览、比例/用途选择、授权确认、多轮调整、草稿保存恢复、网络失败和 240 秒文本增强超时降级；未提交任何外部图片任务。
- “确认并生成图片”作为第二步主按钮已在同页展示；当前明确禁用并说明真实生成授权、永久存储和图片模型尚未放行，不要求用户复制提示词去其他页面。
- 报价只展示 `billable=false` 的产品积分预估，不扣积分、不创建媒体任务、不调用图片模型。
- 已覆盖模糊需求、夸大疗效、未授权真人、内部信息诱导、网络失败、重复点击、刷新恢复和租户隔离。
- 只有上述零付费链路与质量门禁通过后，才回总调度申请一次受控真实图片调用；充值、生产配置和发布同样单独确认。

## 本次不做

- 不自动接在小红书文案后生成；不生成文案或视频。
- 不向用户展示供应商、模型、API 密钥或内部成本。
- 不自动发布、投流或付款。

## 验收条件

1. 正常路径：当前租户可创建一项提示词与费用预览，并在刷新后恢复；相同输入重复点击只恢复同一记录。
2. 失败路径：模糊需求、缺少授权、夸大疗效或未授权真人请求返回 422；网络失败与 240 秒超时保留输入并允许重试；运行时 Skill 结果不满足结构契约时安全降级，仍不创建图片任务。
3. 不应发生：不调用 `/lanqi/media/quote|confirm|jobs`，不创建 `LanqiMediaJob`，不读取或修改积分账户，不暴露供应商、模型或密钥；租户 A 无法读取租户 B 预览。
4. 事实边界：只使用门店已确认事实，不编造价格、优惠、疗效、案例、评价、销量、门店环境或兰琪方法论。
5. 页面：兰琪小红书页可进入独立文生图；桌面与 390px 移动端覆盖保存、重复点击、刷新恢复、422、网络失败、返回和控制台。
