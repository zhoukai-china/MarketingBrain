# LQ-06：项目、获客与成交草案

## 目标

为兰琪授权门店提供执行方案的准备页：先展示门店资料齐备度与所需授权知识，再形成仅供确认的方案草案框架。

## 范围

- 新增当前租户的执行方案草案接口和页面入口。
- 复用门店画像与经营诊断的已确认、估算和待补信息。
- 明确区分“资料待补”和“兰琪授权方法论/内部定价待接入”。
- 所有输出均为草案，不触发投放、发消息、付款、发布或其他外部动作。

## 不在本任务范围

- 录入、推断或展示兰琪项目名称、内部定价、获客话术、成交 SOP 或案例。
- 将推荐关系视为数据访问权。
- 自动执行任何对外动作。

## 验收条件

1. 当前登录租户可打开执行方案草案页，看到来源、资料待补项、授权知识待补项与阶段状态。
2. 门店资料不足时，接口和页面返回“待补门店资料”，而不是编造方案。
3. 即使门店资料完整，未接入经授权的兰琪执行方法论与内部定价时，项目、获客、成交阶段仍为锁定状态。
4. 响应不包含项目名称、价格、推荐关系带来的任何其他门店数据，也不提供外部执行入口。
5. 接口只从服务端登录上下文取得租户；不接受客户端租户标识。
