## 验收条件

1. 正常路径：选类型/阵地 → 填原话（快速 ≥15 字）/七柱必填 → 点生成 → AI 升级流水线出稿 → 结果含诊断/对比/发布前检查 → 可复制、可下载配图 → 主流程不断。
2. 失败路径：原话不足/必填缺失给出精确提示并高亮定位，不静默卡死；生成失败给出可恢复状态（资料保留 + 重试）；网络失败保留输入。
3. 不应发生：编造具体数字/效果/客人姓名；暴露模型名/厂商名；跨门店串数据；`keepMine=true` 时改写原句；生成文案含 ban 词（私信/加我/找我/留个/扫码/进群）或 abs 词（根治/永久/最好/100%/特效）；配图未经授权使用真人肖像。
4. 可观测结果事件：升级任务成功/失败/取消、发布前检查 warn/ok、配图生成成功/失败，均落库可按门店查询。

### 用户报障与根因

1. **「微信群营销话术生成不了」**（`docs/BUG_REGRESSIONS.md` QA-20260910-020，P1）：三层根因缺一仍会复现——① 前端把「主题」当必填（`disabled={loading || !storeId || !topic || !detail}`），老板只填「具体内容」时按钮永远灰着；② 灰着不说明原因（与 QA-014 Bug9 同类）；③ 后端也把主题当必填，且 Provider 侧错误串（`deepseek_provider_http_error` 等）会直接渲染到页面，违反本卡验收条件 3。
2. **「AI 配图没有正常生成」**（QA-20260910-021，P1）：`moments-image.ts` 的 `DEFAULT_ASSET_BASE_PATH = "/beauty-industry"` 把 `asset.url` 硬编码到美业单品作用域，兰琪租户取图必然 403；前端 `fetch(...).blob()` 不看状态码，把 JSON 错误体塞进 `<img>`，于是表现为破图。**生图是好的，取图作用域错了。**
