## 基线与失败证据

- 基线：`pnpm.cmd qa:fast`（在板块4 收口时全绿）。
- 红灯 1（成稿空白，P1）：真实浏览器走查中 `.lq-cw__draft` 成稿编辑框为空，但检查项正常渲染；接口级断言看不到。根因是 `setStep(3)` 与 `editorRef.current.textContent` 同步写入竞态。
- 红灯 2（合规误拦，P1）：真实大模型 `acquire/live/segments` HTTP 422「绝对化/疗效词（第一）」；`acquire/advisor` 返回「命中特效；命中私信」。抓原始模型输出确认是序数用法（第一部分）、劝阻复述（不引导加微信／不用特效）与渠道名词（回复评论和私信）三类误判。

## 实现记录

- 板块枢纽 `/lanqi/acquire` + 子页 `video` / `copywriter` / `live` / `methods` 全部落地；`?state=`、`.reviewer`、手机外壳、设备切换器均未工程化。
- 文案改稿：真实大模型产 3 个开头 + 正文 + 3 个标题 + 封面 + 发布前检查项；成稿回填改受控（`applyDraft` + `useEffect`），修复空白 Bug。
- AI 运营顾问：平台识别（抖音/视频号/美团，识别不出先反问）→ 动作清单（summary/steps/followUps/sources/needInfo）；被门禁拦一次回灌重写，再不过 fail closed。
- 直播话术：规则定 5 轮 23 段 120 分钟骨架 → 分批（19 批，≤2 段/批）→ 模型填正文 → 合规硬门禁（违规引导词 / 绝对化疗效词 / 价格口径 / 编造数字）。
- 视频获客：四模式页签（爆款复刻 / 门店素材成片 / AI 剪辑 / 文案转片）；爆款复刻无真实检索源，明确「不做假数据」；生成侧肖像授权未勾选禁止提交，Provider 未开通 fail closed；画质档位只有 480p/720p/1080p。
- 合规规则层（`moments-rules.ts`）：`第一` 序数豁免改完整量词表；新增语境判定 `hasRiskyUsage`（劝阻复述、平台内渠道名词不误伤，真导流仍拦）。四条提示词的「第一」口径同步改为「仅排名宣称」。
- 发现并修复「点开测试要先登录」：`apps/web/.env.development.local` 的 `VITE_DIRECT_TEST_LOGIN=true` 未被早期启动的 dev server 加载，重启 `pnpm dev:web` 后本机直达不再跳登录。
