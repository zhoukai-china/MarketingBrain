# LQ-13 直播话术

状态：待开发

## 归属

- 产品：兰琪美业经营增长智能体平台
- 层级：产品专用，复用公共 MCP Skill 网关
- 风险：中
- 是否允许并行：否

## 用户结果

用户进入“直播话术”功能，只需描述直播目标、产品和已确认活动，系统调用 `live_script_planner` Skill，返回可编辑、可保存的完整直播话术。

## 本次范围

- 兰琪工具入口中的独立卡片和独立功能区。
- 自然语言输入；通过 MCP Skill 网关固定调用 `live_script_planner`，能力锁定为 `live_script`。
- 生成开场留人、产品讲解、互动、异议处理、转化承接、风险提示和下播跟进；保存为当前租户草稿。

## 本次不做

- 不生成小红书文案、图片或视频。
- 不自动开播、发布、发送消息、投流或改活动配置。
- 不编造产品、价格、优惠、疗效、库存、案例、成交或兰琪方法论。

## 验收条件

1. 正常路径：用户输入需求后，工具轨迹命中 `live_script_planner`，页面只返回直播话术。
2. 失败路径：直播时长、产品、目标等关键信息不足时追问；Skill 失败或超时时保留输入并可重试。
3. 不应发生：不调用媒体生成、不发布、不扣媒体积分、不读取其他租户资料。
4. 可观测事件：`lanqi_live_script.requested/succeeded/needs_input/failed`，记录运行与 Skill 版本，不记录客户原始文本。

## 基线与实现记录

- 运行时已有 `live_script_planner`，`agent_store_acquisition.live_script` 已绑定该 Skill；兰琪尚无独立入口和租户草稿接口。

## 验证

- 新增兰琪直播话术专项 smoke/Eval；同一高风险样例重复 3 次。
- 运行 `pnpm.cmd qa:fast`、`pnpm.cmd qa:regression`，并完成桌面/移动端输入、追问、失败、重试、保存和刷新 E2E。
