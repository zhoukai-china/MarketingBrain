## 归属与口径

- 产品：兰琪（`docs/agents/lanqi-beauty/`），公域获客 → 视频获客 → 爆款复刻。
- 用户口径（2026-09-12）：**在兰琪复刻页补上「上传原视频（必填，校验 mp4 与大小）→ 肖像授权勾选 → 报价（积分+画质档位）→ 确认 → 出片轮询 → 成片播放/下载」；
  后端直接复用已有的授权 / 暂存 / 许可 / 计费链路，不新建一套。**
- 前置事实（本轮只读核实，生产 env）：OSS 暂存（桶/区域/前缀/结果域名 + STS + 自动续期）已就位；出片端点已修正为 `image2video/video-synthesis`；
  执行授权 key 已配置；**待开**=`ALIYUN_VIDEO_REPLICATION_MAX_COST_FEN`（默认 0=禁止付费）与 `BEAUTY_VIDEO_EXECUTION_MODE`（默认 disabled）；
  另 `ALIYUN_VIDEO_REPLICATION_CREDITS=0` 不满足报价校验（要求 `creditCost > 0`），样片需要临时给一个正数。
- **产品事实（不可绕过）**：复刻必须有**原视频文件**。抖音 / 视频号站内视频流抓不到（实测：搜索页是 JS 空壳、站内接口未签名返回 `blocked`、视频号是登录墙），
  所以门店必须把那条爆款**下载后上传**，平台不做抓取；`validateDirectAssetUrl` 已明确拒绝平台播放页链接。

## 已核实的既有契约（直接复用，不新写后端）

| 步骤 | 调用 | 关键点 |
|---|---|---|
| 上传素材 | `POST /files`（multipart `file`）→ `{ file: { id } }` | 原视频与人物照片都走这个接口拿 `fileId` |
| 素材授权 | `POST /viral-video-replication/material-authorizations` | 记录授权声明与依据引用；不代表已获生成权限 |
| 报价 | `POST /viral-video-replication/quote` | 入参：`referenceFileId / portraitFileId`（或 HTTPS 直链）+ `requestKey` + `model` + 四项授权布尔；返回 `canConfirm / creditCost / gaps[]` |
| 确认出片 | `POST /viral-video-replication/confirm` | 同一入参；`gaps` 非空则 422（未创建任务、未扣费）；成功 202 + `job` |
| 轮询 | `GET /viral-video-replication/jobs`、`POST /jobs/:id/refresh` | **美业工作台当前没有轮询**，兰琪要自己补 |
| 取成片 | `GET /viral-video-replication/jobs/:id/content` | 需带登录态，前端按 LQ-23 同款做法取 blob 再播放/下载 |

四项授权布尔（与美业同一口径）：`visualRightsConfirmed`（原视频画面/改编权）、`audioRightsConfirmed`（原音频）、
`performerConsentConfirmed`（原主角同意被替换）、`portraitConsentConfirmed`（替换照片本人/已授权）。
注意：**既有 payload 不含 `storeId`**，门店归属由素材授权链路推导。

## 验收条件

1. 未上传原视频 / 未勾齐四项授权 → 「报价」与「确认」按钮禁用，点击不发请求。
2. 上传非 mp4（或超大）→ 本地拦截并明确提示，不发请求。
3. 报价成功 → 页面显示积分与档位，且写明「确认后才扣减」。
4. `gaps` 非空 → 页面照实展示缺口，不创建任务、不扣费。
5. 确认成功 → 任务进入轮询，状态变化可见；出片后可在页面播放并下载。
6. 上游失败 / 超时 → 明确失败文案，**不谎报成功**、不重复提交（同一 `requestKey` 幂等）。
7. 界面不出现任何模型 / 厂商名；租户隔离沿用既有 RBAC。

## 样片跑通清单（用户已授权：首次联调上限 ¥10、一次不重试、失败即止）

1. 开两个开关：`ALIYUN_VIDEO_REPLICATION_MAX_COST_FEN=1000`、`BEAUTY_VIDEO_EXECUTION_MODE=controlled`；
2. 临时给正数 `ALIYUN_VIDEO_REPLICATION_CREDITS`（样片后按真实成本重定，并向用户出示价格算式）；
3. 为本次请求单独签发执行许可（`provider_https`，成本上限 ≤¥10，一次一批）；
4. 用仓库自带合成素材（不涉客户数据）跑一条真样片，记录：请求参数、真实成本、成片、失败码（如有）；
5. 跑完按结果决定是否保持开关（默认回落到关闭）。
