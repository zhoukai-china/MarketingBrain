## 一、用户需求

用户 2026-09-11 提问：「`https://api.lcppch.top/lanqi-test/` 一级导航页的字体从黑色改成白色会好看些吗？」

## 二、验收条件

1. 侧栏底色仍是兰琪品牌橙 `#F37021`（不改品牌观感）。
2. 导航项、品牌名、10px「开发中」徽标文字改为白色。
3. 导航悬停反馈由深棕蒙层改白色蒙层，与白字一致。
4. 「开发中」徽标在白字后仍**比改前更清晰**（改前深棕字 2.71:1，改后不得低于 4.5:1）。
5. 不产生横向溢出、不新增 console 错误、已上线「私域营销」与 7 个「开发中」占位页行为不变。
6. 不改变任何非配色行为（路由、「开发中」开关、计费、租户隔离）。

## 三、实现（最小、可回滚）

仅动 `apps/web/src/styles/lanqi-moments.css` 4 条规则：

| 选择器 | 改前 | 改后 |
| --- | --- | --- |
| `.lq-pd__brand` / `.lq-pd__brand-name` | 字色 `#2D1A10`，分隔线 `rgba(45,26,16,.18)` | 字色 `#fff`，分隔线 `rgba(255,255,255,.28)` |
| `.lq-pd__item` | `color:#2D1A10` | `color:#fff` |
| `.lq-pd__item:hover` | `rgba(45,26,16,.10)` | `rgba(255,255,255,.18)` |
| `.lq-pd__badge`（含 `--dev`） | 底 `rgba(45,26,16,.14/.10)` + 深棕字 | 底 `rgba(45,26,16,.30)` + `#fff` 字 |

`.lq-pd__item.on`（激活项白底橙字）与 `.lq-pd__side` 底色**未动**。

## 四、对比度口径与 AA 例外（写在前面）

- 品牌橙 `#F37021` 上：纯白字 **2.94:1**，原深棕字 `#2D1A10` 为 5.64:1。也就是说**白字实际上降低了 WCAG AA 达标度**——这是用户明确选择的品牌观感优先项，登记为**已声明的 AA 例外**，并在契约 smoke 里用 2.9:1 下限守住，防止有人把底色改浅导致白字继续变差。
- 10px「开发中」徽标：改前深棕字只有 **2.71:1**（本来就不达标），改后白字在加深底色 `rgba(45,26,16,.30)` 上为 **4.79:1**，**比改前更好且达标**。徽标是本轮唯一同时「满足用户要求」且「抬高合规下限」的地方。

## 五、验证证据（红 → 绿）

1. 基线（改前）：`pnpm.cmd lanqi:brand-nav-contract-smoke` → PASS 35/0。
2. 红灯（只加断言、不改样式）：同命令 → **FAIL 37 passed / 5 failed**，失败明细正是 `color=#2D1A10`、徽标 `3.44:1`、hover 仍为深棕蒙层。
3. 绿灯（改样式后）：→ **PASS 42 passed / 0 failed**，其中导航白字 `2.94:1`、徽标白字 `4.79:1`（`chip=rgb(184,86,28)`）。
4. `pnpm.cmd qa:fast` → **PASS**（含 `lanqi:brand-nav-contract-smoke` 42/0、7 包 `typecheck` 全绿）。
5. `pnpm.cmd --filter @baolu/web build` → **PASS**。
6. 测试实例真实浏览器：`node scripts/lanqi-brand-nav-browser-e2e.mjs --base https://api.lcppch.top/lanqi-test` → **PASS 0 failed**（桌面 1440 + 移动 390；`nav=rgb(255,255,255)`、`bg=rgb(243,112,33)`、白字 2.94:1、徽标 4.79:1、横向溢出 0、console/page 错误 0）。
7. 生产产物断言：线上 `assets/index-C-muJ3eY.css` 实测含 `.lq-pd__item{…color:#fff}`、`.lq-pd__brand-name{…color:#fff}`、`.lq-pd__item:hover{background:#ffffff2e}`、`.lq-pd__badge{background:#2d1a104d;color:#fff}`、`.lq-pd__side{background:#f37021}`。

## 六、刻意不做

- **不登记 `docs/BUG_REGRESSIONS.md`**：这是用户主动要求的视觉调整，不是 Bug 修复；但对比度已固化为常驻回归断言（谁把底色改浅 / 徽标改回浅棕就会红灯），符合「防回归」目的。
- 不改品牌橙底色、不改激活项反白样式、不动路由与「开发中」开关、不动计费。
- 不为追求 AA 全绿而放弃用户要的品牌观感；AA 例外已明示，不做无说明的静默降级。
