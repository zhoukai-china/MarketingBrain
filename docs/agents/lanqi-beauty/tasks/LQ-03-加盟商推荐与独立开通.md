# LQ-03 加盟商推荐与独立开通

状态：已完成

## 归属

- 产品：兰琪美业经营增长智能体
- 层级：产品任务含平台子改动
- 风险：高
- 预计修改热点：`packages/db/prisma`、`apps/api/src/routes`、`apps/api/src/services`、`scripts`
- 是否允许并行：否；涉及租户创建与邀请码归因。

## 用户结果

兰琪加盟商能创建一次性推荐开通码；被推荐门店用码完成独立工作区开通，系统记录渠道归因，而推荐方不能查看门店任何私有数据。

## 本次范围

- 创建受服务端身份约束的兰琪推荐码。
- 复用既有邀请码开通路径创建独立租户，并将推荐关系原子化绑定到新租户。
- 推荐方仅能查看本人的推荐记录与领取状态，不返回被推荐门店名称、ID、档案、会话、运行或钱包信息。
- 覆盖一次性领取、重复领取、跨租户读取、无管理员角色和自我推荐拒绝。

## 本次不做

- 不自动结算佣金、不创建代理层级或真实支付。
- 不提供兰琪真实加盟商账号与门店资料。
- 不授予被推荐门店任何未验证的兰琪知识访问权限；后续由授权开通流程发放。
- 不新增用户页面；首版通过受保护 API 支持后台/运营开通，页面任务随后补充。

## 验收条件

1. 正常路径：加盟商管理员创建一次性推荐码；新门店以该码开通独立租户；推荐记录显示已领取。
2. 失败路径：已领取/已撤销推荐码不可再次使用；非管理员不能生成推荐码。
3. 不应发生：推荐方获得门店名称、门店 ID、档案、会话、诊断、钱包或知识访问权；不同推荐方不能互查记录；同一门店不能被重复归因。
4. 可观测结果事件：创建、领取、撤销均有创建时间、状态和推荐/被推荐租户内部关联，可供后续审计使用。
