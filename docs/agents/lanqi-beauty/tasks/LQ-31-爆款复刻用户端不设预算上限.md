# LQ-31 兰琪爆款复刻：用户端不设单条预算上限（有积分即可出片）

## 归属

- 产品：兰琪（`docs/agents/lanqi-beauty/`），公域获客 → 视频获客 → 爆款复刻。
- 层级：产品口径 + 公共出片链路配置（env）。
- 风险：中（计费口径相关的"限制"移除，但付费（积分）与模型硬上限不变）。
- 允许并行：否（独占出片链路配置口径）。

## 用户结果

门店上传 2–30 秒原片、勾选授权、有足够积分时，就能报价并出片；页面不再出现"时长超出当前单条预算上限"这类内部口径外溢的拦截。片长超过 30 秒时明确告诉用户"超过模型支持的时长上限（2–30 秒）"。

## 本次范围

- `ALIYUN_VIDEO_REPLICATION_MAX_COST_FEN` 1000 → 3000（生产 + 测试实例，含 env 备份与重启）。
- 页面缺口文案：`provider_budget_exceeded` → 「超过模型支持的时长上限（2–30 秒）」；`execution_budget_too_small` → 「服务端出片额度未配置，请联系思潼服务团队」。
- 页面声明去重：按素材各自记账（只声明新素材）+ 授权依据文件整场会话只上传一次，消除换素材时的 409。
- 回归：20 秒夹具 + 浏览器验收新增断言。

## 本次不做

- 不改对客价（24 积分/秒已拍板）；不放宽积分门槛（有积分才能出片）；不越过模型 2–30 秒硬上限；不接第三方视频解析。

## 验收条件

1. 正常路径：20 秒原片 + 四项授权 + 有积分 → 报价 `canConfirm=true`，积分 = 480（20×24）。
2. 失败路径：原片 <2 秒或 >30 秒 → 本地与服务端都拦下，提示指向"模型支持的 2–30 秒"。
3. 不应发生：报价缺口里不再出现 `provider_budget_exceeded`（用户端无内部预算卡点）；换素材/重传时不产生 409 等无意义失败请求；未确认前不建任务、不扣积分。
4. 可观测结果事件：`data-lq-vd-gaps` 内容、`data-lq-vd-primary` 状态迁移、quote 请求次数。
