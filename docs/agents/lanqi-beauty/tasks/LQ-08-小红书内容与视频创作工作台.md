# LQ-08：内容与媒体创作工作台（历史总卡）

## 状态

已拆分，不再作为编码任务。2026-08-14 按用户确认拆为五个独立功能卡：LQ-09 至 LQ-13。

## 拆分后的产品边界

- `LQ-09-小红书文案生成.md`：只生成小红书文案，不自动生成图片或视频。
- `LQ-10-文生图.md`：独立输入文字生成图片，也可由用户主动带入已保存文案。
- `LQ-11-文生视频.md`：独立输入文字生成视频。
- `LQ-12-图生视频.md`：独立选择有权使用的图片生成视频。
- `LQ-13-直播话术.md`：只生成直播话术，不混入小红书或媒体生成。

用户在兰琪工具入口点击哪个功能，就进入哪个独立功能区。跨功能传递必须由用户主动选择，不进行一键串联生成。

## 用户结果

兰琪授权门店可以基于本店事实、经授权的兰琪方法论和已确认的营销目标，生成可审核的小红书图文草案、营销文案、配图草案与视频创作草案；任何发布、投放或付费生成均保留确认与审计边界。

## 能力范围与开发顺序

### 第一批：小红书图文与视频创作

- 内容 Brief：门店、目标人群、营销目标、平台、小红书笔记类型和事实依据。
- 营销文案草案：标题、正文、标签、行动引导、风险提示与事实来源。
- 配图生成：封面与图文配图的生成任务、预览、失败重试和素材隔离。
- 文生视频与图生视频：任务创建、状态追踪、失败处理、素材隔离和结果下载。
- 生成前显示预估算力消耗；请求、扣费、取消和重试须幂等且可审计。
- 默认只保存草案；不自动发布、不自动投放。

### 第二批：爆款视频复刻接入

- 复用既有阿里云换人/换头复刻能力，而不是另建供应商链路。
- 既有能力已经具备：源视频与肖像图输入、视觉/音频/表演者/肖像授权确认、报价确认、租户隔离、幂等扣费、失败退款与回调状态处理。
- 兰琪侧只增加独立入口、素材归属和内容审核边界；仅接受用户拥有、获得授权或可合法使用的源视频/图片/脚本。

## 前置条件

1. 图文与视频创作可先以门店自身提供的事实和素材启动；兰琪资料未到位时，必须明确标为通用草案，不能编造兰琪案例、效果、价格或话术。
2. 取得兰琪品牌资料、方法论、案例边界、禁用表达及审核规则后，再把它们以授权知识版本接入，解锁兰琪品牌化内容。
3. 正式项目与内部定价知识完成版本、适用范围和审批接入后，才能把相关内容用于营销文案。
4. 视频生成实施前复核现有供应商、模型、素材存储、版权/肖像授权、算力计费与取消退款配置；不得绕开既有审计链路。
5. 小红书发布或投流如需接入，另建任务，默认只生成预览/草稿，需逐次确认后执行。

## 每批验收重点

- 事实与授权来源可追溯；资料不足时明确待补，不编造内容。
- 门店 A 不能读取、下载或引用门店 B 的素材、任务、文案或视频。
- 生成失败、超时、取消、重复提交与扣费可正确处理并可审计。
- 发布、投流、发送消息和付款没有用户确认不得执行。
- 图文和视频在桌面、移动端完成创建、加载、失败重试、刷新恢复与下载验收。
