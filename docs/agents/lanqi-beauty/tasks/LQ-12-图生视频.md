# LQ-12 图生视频

状态：阻塞（当前百炼账号未返回可用图生视频模型）

## 归属

- 产品：兰琪美业经营增长智能体平台
- 层级：兰琪独立入口，复用公共素材、媒体生成、钱包与审计底座
- 风险：高
- 是否允许并行：否

## 用户结果

用户进入“图生视频”功能，上传或选择一张自己有权使用的图片，填写运动/镜头需求，选择规格并在确认积分后生成视频。

## 本次范围

- 独立入口、图片选择/上传、授权确认、生成参数、报价、任务进度、失败退款和下载。
- 可主动选择文生图生成的图片，但不自动串联。

## 本次不做

- 不生成小红书文案、图片或直播话术；不包含换人换头/爆款复刻。
- 不接受无法确认权利来源的图片；不显示供应商、模型、密钥或内部成本。

## 验收条件

1. 正常路径：授权确认和报价确认后创建单一任务，成功视频可播放和下载。
2. 失败路径：无图片、格式不支持、无授权确认、模型未开通、余额不足、超时或供应商失败均不产生错误扣费。
3. 不应发生：未确认素材权利即提交、跨租户访问素材、自动使用小红书配图、重复扣费。
4. 可观测事件：素材选择、授权确认、报价、提交、成功、失败、退款和下载。

## 基线与阻塞证据
