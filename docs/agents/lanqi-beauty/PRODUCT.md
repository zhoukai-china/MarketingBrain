# 蓝旗美业经营增长智能体产品定义

## 产品定位

这不是去掉品牌知识的“通用美业智能体”，也不是给每家门店复制一套代码。它是由蓝旗方法论驱动的一套统一产品，由思潼维护平台能力，供蓝旗总部、蓝旗加盟商，以及经蓝旗渠道授权的其他美业门店使用。

核心卖点必须始终是蓝旗的知识方法论、项目经营经验和内部定价体系。通用大模型能力只是载体，不能替代蓝旗价值，也不能把蓝旗内容降级成无品牌的通用建议。

## 参与角色

- 蓝旗总部：知识所有者和业务授权方，维护方法论、内部定价与适用范围。
- 蓝旗加盟商：获授权使用产品，也可以推荐其他美业门店开通。
- 被推荐门店：独立租户，在授权范围内使用蓝旗产品，不读取推荐方的门店数据。
- 思潼平台：提供账号、租户、知识权限、Agent 运行、算力钱包、审计和运维。
- 门店用户：提交本店资料、执行建议并回填结果。

## 商业边界

- 所有获授权用户使用同一套蓝旗产品，不另造“无蓝旗方法论的通用版”。
- 蓝旗知识的可见范围、使用期限、门店范围和版本由授权决定。
- 推荐关系只用于渠道归因、授权和结算依据；不能因此共享两家门店的私有经营数据。
- 算力充值可以作为平台收入来源，但余额、扣费、退款和重复请求必须有可审计流水。
- 内部定价属于受控知识；输出时必须携带版本、适用条件和依据，不能由模型自由编造。

## 首期用户结果

门店录入基本经营信息后，能够基于已授权的蓝旗知识获得：经营诊断、适合的项目与内部定价建议、获客与成交动作、执行清单和复盘建议，并且所有关键结论可追溯到知识版本或明确标注“资料不足”。

## 首期任务地图

| 编号 | 模块 | 用户结果 |
|---|---|---|
| LQ-01 | 产品与授权契约 | 明确谁可以使用哪一版蓝旗知识 |
| LQ-02 | 知识结构与版本 | 蓝旗方法论和内部定价可治理、可追溯 |
| LQ-03 | 租户、推荐与开通 | 加盟商可推荐门店，门店独立开通且不串数据 |
| LQ-04 | 门店经营档案 | 建立可更新、可校验的门店真实档案 |
| LQ-05 | 蓝旗经营诊断 | 给出有依据、有缺口标记的诊断与优先级 |
| LQ-06 | 项目、获客与成交 | 生成符合蓝旗方法论的经营执行方案 |
| LQ-07 | 算力钱包与复盘 | 可审计扣费，并用执行结果持续复盘 |
