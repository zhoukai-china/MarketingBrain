# 兰琪美业经营增长智能体产品定义

## 产品定位

这不是去掉品牌知识的“通用美业智能体”，也不是给每家门店复制一套代码。它是由兰琪方法论驱动的一套统一产品，由思潼维护平台能力，供兰琪总部、兰琪加盟商，以及经兰琪渠道授权的其他美业门店使用。

核心卖点必须始终是兰琪的知识方法论、项目经营经验和内部定价体系。通用大模型能力只是载体，不能替代兰琪价值，也不能把兰琪内容降级成无品牌的通用建议。

## 参与角色

- 兰琪总部：知识所有者和业务授权方，维护方法论、内部定价与适用范围。
- 兰琪加盟商：获授权使用产品，也可以推荐其他美业门店开通。
- 被推荐门店：独立租户，在授权范围内使用兰琪产品，不读取推荐方的门店数据。
- 思潼平台：提供账号、租户、知识权限、Agent 运行、统一积分账户与 usage ledger、审计和运维。
- 门店用户：提交本店资料、执行建议并回填结果。

## 商业边界

- 所有获授权用户使用同一套兰琪产品，不另造“无兰琪方法论的通用版”。
- 兰琪知识的可见范围、使用期限、门店范围和版本由授权决定。
- 推荐关系只用于渠道归因、授权和结算依据；不能因此共享两家门店的私有经营数据。
- 算力充值可以作为平台收入来源，但余额、扣费、退款和重复请求必须有可审计流水。
- 兰琪独立网页与 WorkBuddy MCP 是同一兰琪后端能力的两种入口，共用 Agent、Skill、知识、权限、积分账户、usage ledger 和质量门禁；不得复制两套提示词或账本。
- MCP 连接凭据由兰琪用户端连接管理页生成、撤销和轮换，绑定 `product=lanqi`、租户、用户和最小权限；推荐关系不产生数据访问权，也不能看到其他产品。
- 内部定价属于受控知识；输出时必须携带版本、适用条件和依据，不能由模型自由编造。

## 正式版品牌入口路线（2026-08-24 已确认，尚未实施）

- 兰琪品牌版复用美业智能体正式版的同一入口与账号链路：品牌产品介绍页 → 微信扫码或手机号验证码登录/注册 → 首次邀请码或体验码验证 → 门店开通向导 → 兰琪经营工作台；老用户保持会话并直接进入工作台。
- 兰琪品牌层只替换产品名称、Logo、品牌色、独立入口和获授权专属知识，不复制另一套登录、权限、Agent、Skill、计费或数据逻辑。通用美业用户不得读取兰琪专属智库和门店数据。
- 品牌专属邀请链接可以自动带入体验码；体验码只在首次开通时验证一次，不作为老用户日常登录步骤。
- 兰琪视觉与介绍页应体现其品牌调性；底层模板默认采用米白、暖金、墨绿的美业高级感设计 tokens，再由兰琪品牌配置覆盖。错误提示或邀请码表单不得作为正式品牌入口的第一印象。
- 当前不改造兰琪或美业内测登录页。正式版开发时另立任务卡、先做原型并完成桌面/移动端 E2E 后再实施。

## 首期用户结果

门店录入基本经营信息后，能够基于已授权的兰琪知识获得：经营诊断、适合的项目与内部定价建议、获客与成交动作、执行清单和复盘建议，并且所有关键结论可追溯到知识版本或明确标注“资料不足”。

## 产品内智能体群

兰琪是一个美业 AI 经营系统，不限制为单一智能体。后续可以在统一兰琪入口下逐步增加经营诊断、项目与内部定价、获客内容、销售成交、员工培训和经营复盘等专业智能体。用户默认使用统一助手入口，由系统按任务路由；专项用户也可以直接进入已授权模块。

初期统一运行在思潼 AI 智能 OS，使用思潼现有域名与账号基础能力，不单独建设兰琪域名。若未来成立新公司，优先赋予其兰琪产品独立运营权并继续租用思潼 OS；仅按合同和合规范围导出兰琪产品用户/门店业务数据，不迁走底层代码或其他租户数据。

## 双入口产品路线（2026-09-03 更新）

1. LQ-15 已把现有小红书文案、专业图片提示词和图片任务合并到 `/lanqi/content-studio` 的一个用户任务“兰琪小红书图文生成”。用户只输入一次并确认按钮旁报价；后端顺序完成文案、内部图片提示词、图片任务和统一保存。
2. 用户已要求暂停小红书图文继续开发，当前先交付“兰琪美业经营问答”独立网页；固定复用美业通用核心 `beauty_business_qa -> general_qa@0.2.0`，兰琪只提供产品入口、品牌和已授权租户事实。
3. WorkBuddy MCP 已薄适配同一问答 capability、会话和账本；后续外部 Connector/OAuth 验收不得复制页面提示词、Skill 或历史存储。
4. 文生视频、图生视频仍为后续独立媒体能力，不并入图文任务。

网页与 MCP 必须共享同一兰琪积分账户和 usage ledger。余额不足时两入口都在 Provider 调用前拒绝，并引导到兰琪品牌充值页；兰琪只消费底层统一 billing/MCP credential 能力，不建立产品专属钱包。

经营问答当前零费用验收阶段只要求用户填写至少 2 个字的问题；经营档案是可选的已确认背景。资料不足不阻断通用起步建议，但必须在回答中指出最关键的待补资料，不得把估算或缺失字段写成事实。
