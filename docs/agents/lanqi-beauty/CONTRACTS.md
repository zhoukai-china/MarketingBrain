# 蓝旗智能体业务契约

## 输入契约

- 当前租户、用户、角色和蓝旗授权必须由服务端可信身份确定，不能采用模型生成或前端自报值。
- 门店档案至少区分已确认事实、用户估计、知识推断和待补资料。
- 使用内部定价时必须确定知识版本、适用区域、项目、门店类型和生效时间；资料不足时先追问或给出待确认项。

## 输出契约

- 经营结论必须说明依据、适用条件、优先级和下一步动作。
- 项目与内部定价建议必须携带蓝旗知识版本；版本过期或无权限时拒绝展示。
- 不能编造门店业绩、蓝旗案例、价格、效果、授权关系或已经执行的动作。
- 关键字段缺失时明确标记“待补”，不能用行业常识伪装成门店事实。

## 权限契约

- 蓝旗授权核心方法：仅向有效授权范围内的租户开放。
- 蓝旗总部管理资料：只供总部角色使用，不因“使用同一智能体”向加盟商或外部门店开放。
- 门店私有资料：只属于该门店租户；推荐方、其他加盟商和其他门店不可读取。
- 任务临时资料：只用于本次授权会话，按平台数据规则到期清理。
- 推荐关系不等于数据访问权。

## 算力与外部动作契约

- 每次计费都要有租户、运行、金额、状态和幂等键，失败或取消按实际消耗规则处理。
- 同一请求重试不得重复扣费。
- 内容发布、客户消息、广告投放、付款和真实业务配置默认只生成草稿或预览；按外部动作授权流程确认后才执行。

## 硬失败

以下任意一项发生即判定失败，不能被其他评分抵消：跨租户泄露、总部私密知识越权、内部定价编造、无授权使用蓝旗知识、重复扣费、伪造已执行动作、把门店原始数据写入全局知识。
