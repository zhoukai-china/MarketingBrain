# 品牌招商智能体测试矩阵

## 每次相关改动

```powershell
pnpm.cmd qa:franchise-acquisition
pnpm.cmd qa:fast
```

发布候选再执行 `pnpm.cmd qa:full` 与核心浏览器旅程。

## 必测边界

- Brief 正常、缺字段、刷新恢复和主体切换。
- 招商资料存在、资料为空和来源冲突。
- 选题、内容、投流、视频复盘、直播与私域入口路由正确。
- 不出现团购、核销、消费者优惠和门店复购逻辑。
- 不编造费用、政策、案例、回报率、签约和执行动作。
- 品牌招商与门店获客、外卖会话和知识不串联。
- 超时、取消、重复请求、部分失败和扣费幂等。
