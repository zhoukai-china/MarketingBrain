# 品牌招商智能体契约

| 模块 | 必要输入 | 主要输出 | 禁止结果 |
|---|---|---|---|
| 招商 Brief | 品牌/项目、行业、目标加盟商、本轮目标、承接动作 | 可保存、可恢复的任务 Brief | 用泛行业信息替代本轮目标 |
| 招商选题 | Brief，选用的授权资料 | 10条有来源或待核验标记的选题 | 门店团购/到店消费者选题 |
| 招商内容 | 选中的选题与真实政策 | 可拍内容和加盟咨询承接 | 编造费用、案例、收益 |
| 投流预览 | 素材、地域、预算上限、线索定义 | PREVIEW_ONLY 计划、监控、止损 | 声称已创建或启动计划 |
| 咨询/考察 | 真实线索状态 | 筛选、跟进和考察动作 | 把播放或私信直接写成签约 |
| 复盘 | 真实内容、直播与线索数据 | 证据、规律、下轮调整 | 无归因数据时宣称成交效果 |
