# 品牌招商智能体产品定义

## 用户与结果

服务连锁品牌总部、招商团队和加盟业务负责人，通过招商 Brief、选题、内容、投流预览、咨询筛选、考察承接、直播与复盘获得合格加盟线索。

## 硬边界

- 目标对象是潜在加盟商，不是门店消费者。
- 不生成团购券、核销、消费者优惠、菜品促销或门店复购方案。
- 未提供加盟政策、费用、案例和回报数据时必须标记待补。
- 不承诺收益、回本周期或已执行投流。
- 内容平台指标不能直接写成加盟线索或签约结果。
