# 创始人 IP 获客系统工作流

```text
进入创始人 IP 选题系统
→ 选择本轮获客目标
→ 填写创始人身份/项目、目标人群、线索目标与真实承接条件
→ 汇总行业热点、对标账号、AI 录音卡、自己账号真实数据复盘
→ 选题 Skill 分析并生成选题
→ 内容生产
→ 生成渠道/投流预览
→ 进入目标专属承接状态机
→ 回填真实业务结果
→ 按目标口径复盘下一轮
```

已有稳定 IP 表达或录音时自动复用，不强迫用户进入企业知识库或重复完成 IP 定位；资料不足只追问影响本轮结果的字段。每个任务先固定一个主要目标，混合目标要分别记录内容、承接和结果。

用户在开始选题、内容或复盘前遇到新媒体与创始人 IP 决策疑问时，可进入“问问保禄”对话：提出问题 → 保禄能力分身给出判断、依据、今天动作与待验证项 → 用户按需要进入选题、内容或复盘模块。该入口不代替四目标获客目标简报，也不写入四目标的线索、承接或结果指标。

开发迁移顺序：先建立四目标枚举与 Brief 契约，再复用现有选题/内容能力，然后接入四套承接状态和复盘。旧 `agent_acquisition`、`agent_store_acquisition` 及其授权在迁移验收完成前保持兼容。
