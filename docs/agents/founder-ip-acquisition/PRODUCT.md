# 创始人 IP 获客系统产品定义

## 用户与定位

服务思潼老客户中的企业创始人、老板和内容/获客团队。用户以创始人 IP 作为长期信任资产，再按本轮业务目标选择不同获客路径。它不是只做加盟招商，也不是四套互不相干的智能体。

## 四种获客目标

| 目标 | 对象 | 典型承接 | 核心结果 |
|---|---|---|---|
| 招商加盟 | 潜在加盟商 | 咨询、筛选、考察、签约 | 合格加盟线索与真实进展 |
| C 端团购到店 | 本地消费者 | 团购商品、预约、到店、核销、复购 | 有效到店、核销与复购 |
| 学员招募 | 目标学员 | 咨询、试听/说明会、报名、交付 | 合格咨询与真实报名 |
| 合作方招募 | 联营、渠道、城市合伙人或其他合作方 | 资格判断、方案沟通、洽谈、合作 | 合格合作线索与真实合作进展 |

四种目标共享创始人 IP 表达、内容资产和通用创作能力，但获客目标简报、承接动作、线索状态、转化口径和复盘指标必须分开。一次任务可以组合目标，但必须拆成可区分的活动与结果，不能混用指标。

## 当前优先入口：选题系统

当前阶段不把企业知识库或资料库作为创始人 IP 获客的用户主流程。用户先选择一个获客目标，并填写创始人身份/项目、目标人群和本轮线索目标；再由选题系统汇总以下四类证据，固定调用选题 Skill 输出可测试选题：

1. 近期行业热点：必须保留可回溯来源、URL 与日期；无法核验时标记待核验。
2. 近期对标账号内容：只分析可确认归属的公开内容；没有互动证据不能称为爆款。
3. AI 录音卡：只使用当前主体可访问的真实近期工作表达与转写。
4. 自己账号真实数据复盘：用真实账号数据识别应继续测试的爆款方向，以及应放弃或降频的方向。

四类来源可以缺失，首用时仍可生成第一版；缺失来源必须明确标记，不能由模型补造。底层历史资料和连接不删除，仅不作为当前入口或必填步骤展示。

## 问问保禄

“问问保禄”是创始人 IP 获客系统内的独立对话入口。它调用“保禄的新媒体与创始人 IP 能力分身”，为新媒体内容、创始人 IP 定位与表达、账号经营、选题、内容结构、自然获客和内容承接提供专业判断；它不是保禄本人，不得虚构保禄经历、客户案例、账号数据或平台实时规则。固定先给直接判断、判断依据、今天可执行的一步和待确认/待验证项；发布、投放、发消息和账号修改只可给建议或草案。

## 兼容迁移

当前生产仍使用原品牌招商与门店获客的部分 Agent、路由和页面。产品方向已经合并，但不得只改外显名称就宣称完成；必须按 `FIP-01` 迁移任务先建立目标路由和历史回归，再逐步收敛旧实现。
