# 美业智能体产品定义

## BY54 受控Seedance执行边界（未对外开放）

BY53协议已接现有持久许可、原积分与用量、私有MP4及恢复，但默认关闭且没有公开Seedance入口。首profile只接两份经人工控制台核对/签名并被Ark接收的授权图片；测试100积分不是商业定价，真实非生产账号/素材/预算未验。继续同一美业核心和品牌配置，不复制兰琪页面或知识，不复用wan许可。详细已实现/未验部分见[SEEDANCE_EXECUTION](SEEDANCE_EXECUTION.md)；下方BY53仅协议准备属于历史阶段。

## BY53 Seedance协议准备，不等于功能开放

多参考人物/场景方向仍用同一美业核心。Seedance2.0独立adapter仅零调用准备、默认关闭；不把已有wan换人入口改成Seedance，也不宣称人物授权、实际质量或费用已通过。首profile两图/5秒720p的schema不产生任务权限，后续必须接服务端审核素材与持久许可；见[合同](SEEDANCE_ADAPTER.md)。品牌配置/知识/公开入口不变。

## BY52 返回“我的AI”的目录边界

`/my-ai`展示当前已开通产品，而不是公开推荐。美业品牌与旧lanqi产品权限分别判定：品牌租户进入同一`/agents/beauty-industry`核心，旧`/lanqi/store-profile`只显示给具备独立lanqi产品权限的租户。公共推荐/购买目录不因本项隐藏；未开通/过期、加载/失败不显示专属卡，余额未知为—。不新开购买或充值，不恢复暂停能力。

## BY51 用量不等于客户定价

已批准先行计量与商业定价隔离。当前只为默认关闭的视频执行补持久调用审计，token/image/video_second合同离线验证，不开放新页面/消费/订阅/额度接口。未知用量不是0、失败释放积分不是Provider退款；跨模型/单位/币种不能盲加。A3改价数字不采纳，AI剪辑仅后续需求登记。详见[计量合同](USAGE_METERING.md)与[候选矩阵](PRE_FINAL_FOUNDATIONS.md)。

## BY-50 默认关闭的受控视频执行（本地工程完成）

BY49下述“execution未安装”为历史状态；BY50已在同一通用核心route安装显式受控factory与签名单批许可/人民币预算/请求次数持久门禁。没有公共签发入口或客户端预算覆盖；真实素材授权、非生产OSS/凭据和独立视频费用仍未验收，默认disabled，不开放页面或新业务。品牌/Skill/商业积分不变，详见[受控执行边界](VIDEO_CONTROLLED_EXECUTION.md)。

## BY-49 私有OSS暂存工程接线（未开放）

北京专用私有OSS技术适配已在通用美业核心独立实现，复用BY45/46授权、lease与账本；不是新增品牌或视频页面。正式默认disabled，只有存储配置也不能生成视频：付费execution与服务端一次性预算通道尚未安装。用户声明非法律核验，临时文件TTL≤15分钟，清理失败可恢复但不能承诺外部副本已追回。详见[私有暂存合同](VIDEO_PRIVATE_OSS_STAGING.md)。本轮只用合成注入协议，真实云/视频未验收，不建邀请、不恢复暂停产品。

## BY-46 门店素材授权与私有暂存（本地基础，未开放真实视频）

- 复用现有登录、产品权限、门店、上传文件和账本。声明只绑定本人上传且同租户/当前门店的文件与依据文件，固定文件hash、参考视频/老板/达人角色、用途、到期和版本；客户端不能选择其他tenant/store/brand。当前无门店绑定的多门店成员须先明确服务端门店上下文，不自动选第一家店。
- `declaration_recorded`只表示已记录用户授权声明与依据引用；不代表独立法律审查通过，不以勾选框宣称肖像或音频权利真实有效。未取得真实素材/云端接入授权前不传真实客户内容。
- 私有暂存可替换适配层与15分钟TTL、本地签名访问、撤销再核验和可恢复清理已实现。BY46当时仅本地HTTP+隔离数据库；BY49补OSS实际driver与注入协议验证，但真实云/视频仍未验收，默认缺执行前置拒绝生成。不是用户可验收的视频生成功能。
- 同租户其他用户/门店的任务不会进入本人历史；已撤销素材的历史记录保留于审计数据库，但不再提供生成/下载，不阻断其他有效历史。XHS、经营问答、BY-19/BY-20等暂停状态不变。

## BY-45 授权素材视频换人（底层实现，未开放）

- 当前支持方向仅为已授权参考视频与已授权人物照片进行换人，保留参考背景、动作和光照。`owner_promo`与`kol_visit`共用核心但分别要求老板/达人肖像授权，不能混用。
- 不承诺换门店背景、新台词、声音克隆、字幕或任意风格；不改变任何现有Skill/导航开放状态。UI仍待定稿，不复制WorkBuddy假结果。
- 缺服务端素材归属/授权记录或安全暂存时，报价不可确认且不创建任务、不扣积分。BY-45不构成真实视频能力已放行；XHS及其他既有暂停项不恢复。

## 可配置品牌包

- 产品只维护一套 `beauty-industry` 核心能力、稳定路由、正式 Skill、MCP、账本、权限和历史合同。品牌包不能复制或覆盖核心业务实现。
- 默认显示品牌为“美业智能体｜门店 AI 经营大脑”。首个实例 `lanqi` 显示“兰琪”，使用纯文字标识和版本化 `lanqi-orange` 主题；不使用第三方商标名、不生成假 Logo，暂时复用当前入口和域名。
- 品牌配置固定包含 `brandCode/displayName/theme/logo/domain/pageCopy/knowledgePackRef/featureFlags`；只能由服务端租户与产品授权推导，不能由页面请求、query/header或WorkBuddy参数自报。
- 品牌显示与品牌知识严格分离。兰琪在没有已授权来源时只显示 `awaiting_authorized_sources`，不得写入16年、35项、两万学员、9800、价格、疗效、案例或其他候选陈述，也不得把测试资料提升为品牌知识。
- WorkBuddy或其他开发来源的品牌材料只可进入 candidates/intake/quarantine；经provenance、授权、脱敏Eval和正式版本流程后，才可成为当前租户的独立知识包。默认租户永远不加载兰琪知识。

## 产品定位

美业智能体是品牌中立的行业 AI 产品，不包含兰琪名称、视觉、验收门店标签、兰琪方法论、内部定价或租户资料。正式产品代码固定为 `beauty-industry`。

交付形态是一套“美业行业 MCP 产品包”：用户购买或由后台受控开通后，只需配置一个 server URL 和一次显示的 secret，即可在 WorkBuddy 中发现其已获授权的多个工具。用户不会获得 Skill 源文件或内部 Prompt。

兰琪美业是该通用内核的品牌版本之一，后续以品牌配置、独立入口、功能开关和专属知识叠加；现有 `/lanqi` 路由与数据继续兼容，不破坏性迁移。

## 正式版入口路线（2026-08-24 已确认，尚未实施）

- 当前 `/beauty-beta/` 邀请码页面只作为邀请制内测入口，保持可用，不再投入视觉重构；它不代表正式版第一印象。
- 正式版入口链路为：产品介绍页 → 微信扫码或手机号验证码登录/注册 → 首次开通验证邀请码或体验码 → 首次开通向导 → 美业经营工作台。老用户保持会话，日常登录直接进入工作台。
- 产品介绍页重点展示获客、销售、知识问答和经营诊断等产品价值，并提供“立即体验”和“已有账号登录”；未开放能力仍须明确标注状态，不能冒充已完成。
- 首次开通向导只采集门店名称、城市、细分赛道、经营类型和核心项目；邀请码或体验码只在首次开通时验证一次。支持带邀请码的专属邀请链接自动带入体验码，避免用户复制粘贴。
- 通用产品用户可见名称固定为“美业智能体”。视觉方向采用米白、暖金、墨绿，强调美业高级感；错误提示或邀请码表单不得作为正式产品首页主体。
- 正式版开发时另立单一任务卡，先完成可点击原型，再做桌面端与移动端真实 E2E；当前仅记录路线，不修改现有入口、鉴权或生产环境。

## 首个可销售 MVP

美业获客只按三个用户可理解的一级分支呈现：

1. 图文获客：只有“小红书图文生成”一个完整任务，文字与图片保存在同一运行记录。文字成品交付3个标题候选、正文和话题；用户选择的标题决定客户复制稿，图片安全计划仍按同一已保存任务与持久化plan版本生成封面/内容/互动三角色，不因客户端选择覆盖服务端事实或版本。真实 AI 图片必须经过积分预览与明确确认，未获授权时禁用并解释原因。Provider 技术成功不等于客户可用，逐图通过本地质量风险筛查后才进入客户图库；证据不足显示“需人工复核、当前不可交付”，而不是伪称确定违规或自动放行。三图承诺不足三张自动合格时整批失败关闭，不以部分技术成功冒充完整交付。
2. 视频获客一级页固定为六张独立卡：选题系统、内容系统、复盘系统、爆款复刻（规划中）、文生视频（规划中）、图生视频（规划中）。内容系统当前按正式 V5 十件套合同一次交付，不拆成十个一级入口；复盘系统的独立页面再进入视频数据复盘或视频内容复盘。
3. 直播获客：`直播话术 → 直播复盘`；策划要素属于话术内部，不另设直播策划任务。直播复盘是数据/转写/原计划分阶段核验后的综合八模块复盘，证据不足时按模块降级，不等同于视频复盘、直播生成或投流。

不存在“获客问答”入口。爆款复刻、文生视频、图生视频保持“规划中/暂未开放”，仅有稳定说明页；爆款复刻未来只处理已授权参考素材和可核验证据，不抓取、复制或绕过平台。视频内容复盘允许上传并在服务端读取格式、时长和分辨率，上传原件请求后删除；BY-15 准入证明模型链能够真实取得视觉与 ASR 证据，不等于系统自动读取后续每个业务视频。正式运行只接受当前租户可核验的转写与画面证据，未就绪时失败关闭，不声称看过视频。

网页和 WorkBuddy MCP 调用同一 Agent、Skill、知识、entitlement、产品钱包与 usage ledger。MCP 只是薄适配，不能复制第二套 Prompt 或知识。

## 美业经营工作台 MVP

- 经营档案只保存当前租户用户确认的门店级资料：细分赛道、单店/连锁、经营阶段、核心项目、目标顾客、渠道、本次目标和事实边界；不采集或推断顾客级真实数据。
- 首页依据档案和最近运行展示最多 3 项“今日经营动作”、上次进度、最近结果和下一步。所有动作仅为建议、草稿或预览。
- 快速模式默认“一句话 + 已确认档案”；专业模式只展开当前工具真正需要的字段，两种模式共用同一 Agent/Skill/事实/账本。美业销售快速模式优先给一条可立即发送且不虚构事实的初步回复，再询问主要顾虑；专业模式需要项目、已确认价格/优惠边界、顾客原话或主要顾虑、沟通阶段和允许下一步动作，缺失时在积分前阻断。完整策略与质量审核默认折叠，复制默认只复制顾客可见回复。
- 获客任务按三条锁定分支保存在统一运行历史中；视频分支允许 `选题 → 内容十件套 → 视频复盘` 携带上一步结果生成，直播分支允许话术与直播复盘互相承接。网页与 WorkBuddy MCP 在同租户、同产品授权下恢复。
- 产品地图固定展示当前模块；美业获客与美业销售按真实权限可执行，其余模块进入独立规划页并真实标注规划中或暂未开放。

## 美业 AI 日报第一阶段

- 面向所有获权美业租户提供同一份产品级公开资讯快照，不读取或混入租户经营档案、顾客、账号或其他私有数据；访问仍须通过 `beauty-industry` entitlement。
- 正式业务时区固定 `Asia/Shanghai`，每天 09:00 生成；服务跨 09:00 离线时恢复后只补跑一次。正常任务、补跑和受权人工重试共享产品+业务日期+合同版本唯一键、租约、幂等和单日调用/结算上限。
- 固定 15 条、5 版块、每版块 3 条、3 条趋势和 1 个今日动作。每条保留来源 URL、发布日期、来源标签、核验状态和可核验的美业细分类标签；页面显示业务日期、09:00 截止时间、触发类型、来源窗口、最后成功、失败原因和下次计划时间。
- 产品采用两层事实：来源层可收录六域内通用 AI、模型、产品、监管、产业与企业改造真新闻，逐条保留核心事实与原行业；美业解释层再由正式 `ai_daily_brief@1.0.0` 标明“思潼点评、对门店的可能影响、适用条件、建议验证”。推断不得冒充来源事实。
- 资讯优先取截至当日 09:00 的最近 24 小时，合格条目不足才扩至 72 小时；仍不足则明确来源不足，不使用旧闻、静态 fallback 或模型常识凑满。
- 当前已完成 controlled mock、六域公平/跳转与两层事实的零网络验收；既有两次真实来源终验均在模型前来源不足。新的真实来源读取/模型终验、scheduler、导航/WorkBuddy 正式开放与生产部署仍须按当前任务门禁继续 fail-closed。

## 产品分层

- 通用获客内核：跨行业稳定任务契约、幂等、计费、失败路径和运行事件。
- 美业行业 Skill 包：行业术语、服务流程、合规、获客差异和脱敏 Eval，不复制整套获客 Prompt。
- 品牌专属层：品牌外观、入口、功能开关、专属知识和必要定制。
- 租户数据层：当前经营主体的已确认门店资料、会话、资产和用量；推荐关系不产生访问权。
