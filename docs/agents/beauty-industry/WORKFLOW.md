# 美业智能体开发流程

## BY54 持久执行顺序（默认disabled）

服务端actor→独立签名permit→人工审核版本/素材实字节与依据hash→积分/submit claim/usage started同事务→单次POST→有限GET→token及费用观察门禁→单次下载/原子MP4+恢复回执→原finish结算/释放。未知POST不重放，缺usage不免费，落盘后DB失败在lease过期后恢复同一回执、不重新下载；下一次refresh推进，不新造后台队列。真实许可/账号/素材缺失时云前停止，未接公开route或客户按钮；见[执行合同](SEEDANCE_EXECUTION.md)。下方BY53未持久接线描述为历史。

## BY53 独立协议验证顺序

固定2.0输入→服务端resolver授权证据→两图首profile→原子claim→单次POST→id关联GET→精确状态/结果URL/用量回执。当前只注入合成transport/journal，不接任务/积分/真实网路；POST未知不可重新创建，GET可在20次/1小时/退避下恢复，unknown不等于退款。正式执行需先把该port接现有持久许可/账本事务及Ark素材审核和安全暂存，见[SEEDANCE_ADAPTER](SEEDANCE_ADAPTER.md)。

## BY52 目录返回流程

美业Shell返回我的AI（本机apiBase保留）→签名会话/当前membership→已拥有Agent与产品entitlement→服务端品牌显示/独立旧产品入口→目标页原授权重验。加载/错误显示未知余额与状态，不渲染专属入口；没有生成任务、扣费、重新开通或品牌知识注入。

## BY51 视频调用审计流程

原签名scope/授权→同事务提交次数及started事件→单次提交→Provider关联hash/观察事件追加→原quality/持久化/账本。缺usage/断流/DB中断保留unknown，迟到usage只补审计，不重发/追扣。内部门店/用户月视图按Asia/Shanghai调用开始月与独立单位分组。无新HTTP/页面/队列，正式业务报价不变，见[USAGE_METERING](USAGE_METERING.md)。

## BY-50 受控执行当前流程

服务端配置（默认disabled）→原身份/素材授权→签名许可与整个请求/hash/版本校验→额度与余额预检→事务唯一claim→暂存逐请求持久计数→原job/积分预留→提交计数先落库再单次Provider提交→有界poll/下载→MP4原子保存/原积分结算→暂存清理。未知终态不重发；中断恢复也清理；退款不重置外部承诺额度。历史按保存request/permit恢复并保留原权限。BY49“无execution”历史限制已被本地接线取代，但真实访问未开放，见VIDEO_CONTROLLED_EXECUTION。

## BY-49 云暂存配置与同链恢复

服务端默认disabled → 独立配置/STS格式与到期检查（无网络）→ 只有已装受控execution及预算才可confirm → BY46用户/租户/门店/素材hash授权 → 持久lease → OSS桶只读安全预检 → 单次PUT/HEAD → V4短期GET → 再授权/既有job与账本/执行 → release删除并HEAD404；未知终态不重发。当前正式route仍无execution/预算0，故流程停在安全准入而非假装已上线。

撤权还须清理尚未创建job的lease；部分上传或删除失败保留cleanup_failed并显式sweep，不另造队列。云URL是短时bearer，删除失败时≤15分钟仍可能可读；生命周期1天仅备援。详见[配置、最小权限、观测及未验项](VIDEO_PRIVATE_OSS_STAGING.md)。

## BY-47 音视频转写未授权的安全停点

共享上传 → multipart/格式检查 → 音视频命中后服务端503停止（不转码/不外发/不预留）；用户可改为提供已有合法转写文本，不能盲目重试或勾选“同意”绕过。CSV/Excel等零费用数据解析继续原流程。美业现有视频/直播复盘不因本项新增录音分析、客户记忆或ASR任务页面。需要自动转写时先补正式用途/权限/预算/存储合同；不存在任务不制造“恢复成功”。

## BY-46 声明、暂存与撤销流程

本人上传文件及声明依据 → 服务端由Membership/entitlement派生tenant/store → 实际本地bytes/hash/MIME/尺寸/时长核验 → 幂等保存`user_declared_not_independently_verified`声明及AuditLog → 逐请求重验角色/用途/版本/expiry → 持久暂存lease后复制已核验bytes → 在预留前、submit前再次核验 → 复用BY-45单任务/账本 → 终态撤销暂存访问并清理。

撤销声明先落库/version递增，再对未结算关联任务停止后续本地动作、CAS等额释放一次和清理暂存。已提交外部的任务记`terminal_unknown`而非声称外部已取消；不能追回已被外部读取的副本。成功历史不倒改、不伪造Provider退款，后续文件访问重新检查声明。清理失败持久为`cleanup_failed`且访问立即拒绝，可由显式维护sweep恢复（每次最多100条）；不另建后台队列/定时器。

当前缺真实HTTPS私有driver/执行权限/视频预算，默认停在创建任务前。本地`local_only`不得组装真实`provider_https`执行器；无环境开关或客户端字段可绕过。没有新增页面/导航或WorkBuddy公开工具，后续多端只能复用此服务端合同。

## BY-45 视频底层（未正式开放）

## BY-25 美业销售两阶段流程

```text
快速模式 + 最短有效异议
→ reservation 前基础事实/高风险边界检查
→ quick_response：可发送初步回复 + 为什么这样回 + 顾客可能下一句 + 下一步提问
→ 完整策略与质量审核默认折叠，复制只包含初步回复

专业模式
→ reservation 前校验项目/价格或优惠边界/顾客顾虑/沟通阶段/允许动作
→ 缺任一项：精确 422，不创建 AgentRun、不预留积分
→ 全部具备：professional_advice 完整异议策略 → 同租户保存/历史恢复/一次结算
```

医疗适用性、疗效、诊断、具体顾客是否适合以及未确认价格/案例/名额/优惠不能由快速回复推断；必须澄清或标待核实。Web 与 WorkBuddy 复用同一 preflight、结果类型、账本和幂等合同。
