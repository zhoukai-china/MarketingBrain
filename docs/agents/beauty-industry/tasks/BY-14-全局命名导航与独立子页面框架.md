# BY-14 全局命名、导航与独立子页面框架

状态：已完成

## 归属

- 产品：美业智能体（`productCode=beauty-industry`）
- 层级：产品专用信息架构，复用现有鉴权、租户、权限、经营档案、历史、WorkBuddy 与固定业务路由
- 风险：高（全局产品识别、全部可见导航、旧深链、刷新/浏览器历史、权限与移动焦点）
- 预计修改热点：美业共享壳层、现有美业页面路由/独立页面渲染、WorkBuddy 页面接线、样式、确定性导航回归与产品文档
- 是否允许并行：否；同一美业智能体当前只有本编码任务

## 用户结果

用户在“美业智能体｜门店 AI 经营大脑”中点击任一可见导航，都进入唯一稳定 URL 和独立页面；已开放能力真实可用，规划中能力只说明边界，且桌面、390px、刷新和浏览器历史始终恢复正确状态。

## 本次范围

- 统一侧栏、顶部、页面和浏览器标题的主名称“美业智能体”与副标题“门店 AI 经营大脑”；租户、城市和本机验收标识独立显示。
- 为工作台、日报、知识问题、获客、销售、专属交付、专属经营诊断、任务中心、经营档案、WorkBuddy 建立唯一稳定页面路由和准确选中态。
- 建立美业获客模块首页，以及图文、视频、直播分支稳定页；保留已开放 Skill 工作区旧深链。
- 规划中页面只展示用途、状态、前置条件和未来边界；无假按钮、假数据、Provider 调用或 AgentRun。
- 权限不足时仍可进入模块说明页，但不得显示可执行表单或伪开放状态。
- 支持直接深链、刷新、前进/后退、返回、404、加载错误/重试、桌面和 390px 导航展开/关闭/Escape/焦点恢复。

## 本次不做

- 不实现视频内容复盘、直播复盘的新业务页面或任何后续业务能力。
- 不改变 capability/Skill/tool 映射、产品 scope、entitlement、账本、租户、档案或数据合同。
- 不调用文本、图片、视频或 ASR Provider，不部署生产。
- 不重构其他产品路由，不整体格式化或提交既有工作树。

## 验收条件

1. 正常路径：每个可见主导航有唯一 URL、独立标题/主内容和正确选中态；获客首页、三分支及所有既有正式工作区可深链、刷新和返回。
2. 失败路径：接口失败显示安全错误与重试；未知美业路径显示产品内 404；无权限模块显示真实未开通状态；移动菜单可展开、关闭、Escape 并管理焦点。
3. 不应发生：规划中项不得 disabled/无效、锚点滚动或局部临时卡片；不得出现旧产品总名称、假数据、伪功能、跨租户内容、Provider/账本副作用或 capability 映射变化。
4. 可观测结果事件：导航只改变 URL/页面和浏览器标题；规划页、404、前进/后退与刷新不创建 AgentRun、媒体任务或积分流水。
