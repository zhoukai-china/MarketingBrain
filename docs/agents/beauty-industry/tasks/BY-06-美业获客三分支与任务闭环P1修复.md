# BY-06 美业获客三分支与任务闭环 P1 修复

状态：已完成（content skill V5 十件套契约、页面与全量门禁均已收口）

## 归属

- 产品：美业智能体
- 层级：产品专用，复用现有 Agent/Skill/MCP/账本与 TenantProfile
- 风险：高（错误路由、任务上下文、积分幂等、租户隔离）
- 预计修改热点：美业产品路由/适配器/页面/连接页、产品专项与 E2E；不新增 Schema，不改媒体 Provider
- 是否允许并行：否

## 用户结果

用户只在“图文获客、视频获客、直播获客”三条锁定分支中工作；每个任务显示正确表单，下一步继承当前结果并真实生成，刷新可恢复，美业 WorkBuddy 连接留在产品内。

## 本次范围

- 删除“获客问答”用户入口和 `beauty.acquisition_plan` 产品工具；美业获客首页仅保留图文、视频、直播三张一级入口卡。
- 图文：小红书完整文字包，按 1/3 张契约返回配图方向/专业提示词；真实图片未获本轮费用授权，生成入口禁用且不拆图片工作室。
- 视频：选题 → 内容十件套（content skill V5）→ 投流预览 → 视频复盘；视频数据复盘与视频内容复盘明确分离，后者因受控上传未接通而禁用；文生视频/图生视频按数字人方向仅规划且禁用。
- 直播：直播话术（含策划要素） → 直播复盘；无独立直播策划层。
- 每个任务独立输入 Schema；显式选择锁定 capability/Skill，自由文本不改分支。
- 下一步继承门店档案、当前结果、目标和 conversationId；生成按钮明确预计积分，重复 requestId 幂等。
- 自动保存当前分支、模式、草稿、当前阶段和 sourceRunId；刷新恢复。任务临时资料不写入经营档案，只有用户明确保存才进入档案。
- WorkBuddy 进入美业专属连接页，展示产品 MCP 地址、工具、余额/用量、最近调用、一次性 secret 领取、轮换/撤销，不输出 secret。

## 本次不做

- 不调用图片/视频媒体 Provider；不开放文生视频/图生视频真实执行。
- 不开发销售、交付、诊断、兰琪品牌或其他行业。
- 不接顾客级真实数据、企微、订单、会员、聊天；不自动发布、投流、付款或发消息。
- 不新增 Schema；不复制创始人 IP Prompt 或其他行业内容。

## 验收条件

1. 正常路径：三分支及内部流程正确；图文无 EDL/复盘字段，视频任务各用独立表单，直播话术/复盘互不串线；下一步真实生成并继承上下文；刷新恢复当前任务与历史。
2. 失败路径：空输入、错误数据、断网、取消、超时、余额不足、Provider 失败、重复点击均有终态；复盘缺数据明确待补，不能自动切到其他工具。
3. 不应发生：内容需求进入直播/视频复盘；自由文本改变显式工具；任务临时资料静默写入经营档案；跨租户/跨行业污染；重复调用/扣费；媒体调用或外部动作。
4. 可观测事件：运行记录保留 tenant/product/channel/capability/skill/conversation/request/积分；页面显示保存时间、任务阶段和来源，不记录 secret。
