## 基线与失败证据

- 零费用基线：正式美业 8 类×3 policy Eval、产品 MCP contract、全仓 Skill contract、`baolu_content_creator` 同步回归均 PASS。
- 真实输出 Eval：8 个场景中 5 个使用 `deepseek-v4-pro`，另 3 个使用受控零费用生产 fallback；Provider 调用 10 次（每个真实场景规划+成稿两阶段，不是自动重试），估算费用 ¥0.2765，媒体调用 0。
- 失败证据：选题返回通用连接失败模板；小红书缺三张配图提示词并编造个人体验；短视频把生活美容改成美甲；投流输出被截断；直播混入带货/美甲/餐饮字段；视频复盘丢失已提供的 3 秒留存和私信字段。
- 根因：`finish_reason=length`/结构不完整没有在所有美业工具 fail closed；通用美容拍剪 fallback 把美容/皮肤管理/护肤与美甲放在同一默认分支；直播正式 Skill 只覆盖带货/招商模板；视频 CSV 字段映射未覆盖当前字段名。
- 连带影响：确定性 contract PASS 不能证明最终业务输出可售；当前美业产品不能以“全部工具可直接用”对外宣称。
