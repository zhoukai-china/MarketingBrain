## 验收条件

1. 正常路径：同一 XHS run 返回 `beauty-xhs-image-plan-v1` 安全摘要；三张图片分别绑定封面/内容/互动角色和同一文字任务，全部合格后才显示与下载，刷新/历史恢复不重复调用。
