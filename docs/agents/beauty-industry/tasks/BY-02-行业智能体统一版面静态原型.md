# BY-02 行业智能体统一版面静态原型

状态：已完成（静态原型版面已确认；功能接入需另立任务）

## 归属

- 产品：行业智能体通用页面模板（美业为首个合成演示行业）
- 层级：产品专用前端原型
- 风险：低
- 预计修改热点：`apps/web` 独立原型页面、样式、路由和原型专项；美业产品文档
- 是否允许并行：否

## 用户结果

用户可以在不接后端的前提下，点击查看企业经营工作台首页、获客首页和小红书图文页三张统一版面原型，并判断其信息架构与视觉是否适合作为所有行业智能体模板。

## 本次范围

- 三个独立可点击路由：工作台首页、获客首页、小红书图文页。
- 顶部企业/门店、积分、WorkBuddy、用户中心；左侧九项固定导航。
- 获客六阶段和小红书左右任务布局；合成示例与纯前端本地交互。
- 可配置 design tokens，演示为品牌中立美业配色。
- 用户可见产品名为“美业智能体”；导航采用“美业知识问题 / 美业专属交付 / 美业专属经营诊断”。
- 导航进一步采用美业语义：“美业AI改造日报 / 美业获客 / 美业销售”。
- “数据复盘”保留为获客第六阶段，阶段内并列“视频数据复盘”和“直播数据复盘”，不增加一级流程长度。
- 小红书图文结果支持 1 张或 3 张合成配图；默认三张分别为封面图、内容图和互动承接图，可在同页切换查看。

## 本次不做

- 不恢复 BY-01 功能开发，不接 API/MCP/Agent/Skill/计费/数据库。
- 不调用模型或媒体 Provider，不扣积分、不迁移、不部署。
- 不开放销售、交付、诊断、视频等未实现能力。

## 验收条件

1. 正常路径：三个页面可通过左侧导航和页面按钮切换；小红书页能用本地状态演示输入、标题选择、复制/下载/保存反馈。
2. 失败路径：未开放模块明确显示“规划中/暂未开放”且不可点击；空输入不会伪造生成结果。
3. 不应发生：任何 fetch/API 请求、真实扣费、模型调用、兰琪/A-B店/tenant 测试标签、把合成内容冒充 AI 结果。
4. 可观测结果事件：本轮无后端事件；仅通过 URL、DOM 状态和浏览器控制台验收。
5. 文案与层级：页面不得再出现“通用美业智能体 / 行业知识问答 / 行业专属交付 / 行业专属经营诊断”；桌面端两个复盘卡片并列，390px 自动堆叠且无横向溢出。
