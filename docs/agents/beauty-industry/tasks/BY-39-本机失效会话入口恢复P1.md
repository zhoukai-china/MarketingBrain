## 验收条件

1. 正常路径：无 token 或旧 token 直接打开 XHS 深链，均可进入美业登录并在本机开通后返回原 URL，工作台主内容可交互。
2. 失败路径：只有 401 触发会话恢复；403/404/500、网络错误和跨租户拒绝不得被伪装成重新登录成功。
3. 不应发生：不得丢失 `apiBase`、循环重定向、匿名绕过、自动调用 Provider、跨租户恢复旧数据或把旧 token 留在浏览器。
4. 可观测结果：source/runtime fresh、ready/database、首开和刷新 console0；失败请求可定位到鉴权阶段，登录后请求无新增 4xx/5xx。

## 基线与失败证据

- 环境基线：PostgreSQL 55434、API 3016、Web 5176 在线；source/runtime=`89E2FD86`、`source_fresh=true`、ready/database=true、Web=200。
- 无会话基线：真实 Chromium 能进入 `/login/beauty-industry`，点击“本机直接开通”后回到 XHS 深链并显示工作台。
- 修复前红灯：`scripts/beauty-industry-local-entry-auth-browser-e2e.mjs` 稳定复现失效 token 停在原XHS页，DOM为“当前页面暂时没有加载成功/请先完成微信登录和账号绑定”；静态`auth:product-login-smoke`同步FAIL。
- 根因：页面只识别token缺失，不识别token失效；四个启动请求并行发出，401被当作普通加载错误渲染，旧token和原深链均未进入恢复流程。此前浏览器smoke预注入有效token，因此没有覆盖真实首开状态。
