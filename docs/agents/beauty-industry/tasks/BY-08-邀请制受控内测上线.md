- 产品：美业智能体
- 层级：产品专用，复用现有公共邀请、积分、MCP 凭据和发布能力
- 风险：高（公开入口、权限、积分、Provider 与生产发布边界）

## 本次范围

- 开放：美业经营档案、小红书图文、视频选题、内容十件套、视频数据复盘、直播话术、直播复盘、美业销售，以及对应稳定 MCP 工具。
- 小红书图文沿用同一任务内标题、正文、标签、真实历史图片、复制、下载和明确图片费用确认。
- 产品明确标识“邀请制内测”；只允许后台人工邀请和人工发放测试积分。
- 现有凭据和新凭据只获得当前 7 个开放 scope；网页和 MCP 共用工作流、档案、账本、历史与幂等。

## 本次不做

- 不开放视频内容复盘；只从网页入口、下一步、Web API、MCP tools/list 和 credential scopes 下架，保留底层 workflow、媒体解析实现和回归资产。
- 不开放文生视频、图生视频、日报、知识问答、投流、正式支付、充值、退款、自动充值或生产支付订单。
- 不调用任何文本、图片、视频或 ASR Provider，不产生新费用；不做真实发布、投流或其他产品开发。

## 验收条件

1. 正常路径：受邀且有 `beauty-industry` entitlement 的用户可保存经营档案，并在网页/MCP发现并使用 7 个开放能力；小红书历史图文可复制、下载、刷新恢复。
2. 失败路径：无邀请码/授权、余额不足、重复请求、网络失败和已退役 tool/scope 均 fail closed；图片只有用户显式确认且余额/额度允许时才可创建任务。
3. 不应发生：`beauty.video_content_review`、`acquisition:video-content-review`、视频上传入口、文生/图生视频执行入口、投流、开发登录、mock pay/mock Provider、真实支付订单或未经确认的 Provider 调用不得在内测生产路径出现。
4. 可观测结果事件：邀请兑换、entitlement、credential 创建/轮换/撤销、tools/list、AgentRun、积分预留/结算/释放和失败码可审计；不记录密钥、客户原文或跨租户资料。
