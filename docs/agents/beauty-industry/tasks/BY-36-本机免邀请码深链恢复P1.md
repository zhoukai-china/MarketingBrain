- 环境红灯：55434/3016/5176 均未监听，HTTP 与 `/ready` 连接拒绝；正式 status 报 API/Web offline。

- 根因：美业页先保存原路径，但 `LoginPage` 挂载时无条件用产品默认首页覆盖该值；旧保存值也未包含 query/hash。
