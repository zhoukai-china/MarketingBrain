# 外卖增长智能体工作流

```text
上传经营资料并填写经营阶段
→ 自动核验数据质量与可判断边界
→ 生成完整经营诊断和原因扫描
→ 每轮选择一个候选问题验证
→ 成立后生成单变量增长方案
→ 经确认后执行并回填真实动作
→ 同口径评估效果与副作用
→ 周期复盘，继续/调整/停止
```

状态只能向前推进或明确返回补数/重做验证；可能原因不能跳过验证直接成为增长方案。页面按钮、API 和 Agent 输出必须服从同一状态机。

## 单人开发切片

每个任务只改变一个模块里的一个用户结果，例如“用户可从诊断候选选择一个问题并看到对应核查蓝图”。不要用一个任务同时重写诊断、验证和复盘。
