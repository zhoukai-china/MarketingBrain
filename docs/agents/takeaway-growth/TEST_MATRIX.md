# 外卖增长智能体测试矩阵

## 每次相关改动

```powershell
pnpm.cmd qa:takeaway
pnpm.cmd qa:fast
```

发布候选再执行 `pnpm.cmd qa:full` 和浏览器核心旅程。

## 必测路径

- 正常资料：上传到复盘完整闭环。
- 缺字段、重复、日期异常、口径冲突、漏斗倒挂。
- 空输入、重复点击、刷新、返回、超时、取消、部分失败。
- 同一 requestId 不重复执行或扣费。
- 租户 A 无法读取或影响租户 B。
- 模拟回填不能产生真实增长结论。
- 未经确认不执行改价、上下架、活动或投放。
- 每个历史外卖 P1 Bug 保留自动回归。
