# 外卖增长智能体产品定义

## 用户与结果

服务餐饮品牌总部、外卖运营和门店负责人，以真实外卖平台与经营数据完成：数据核验、经营诊断、问题验证、增长方案、真实执行回填、效果评估和周期复盘。

## 产品边界

- 核心结果是有效完成单与贡献利润的可验证改善，不把曝光或单日波动直接当增长。
- 所有结论区分已确认事实、分析假设、待补信息和行动建议。
- 改价、上下架、活动和投放默认只生成待审批草案。
- 不使用其他门店或租户数据，不把模拟回填判定为真实增长。
- 不混入品牌招商、消费者团购内容生产或无证据的经营承诺。
