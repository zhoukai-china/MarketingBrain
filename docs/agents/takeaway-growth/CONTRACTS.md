# 外卖增长智能体契约

每个模块必须稳定输出：当前结论、证据、待补、下一步、完成标准和禁止动作。

| 模块 | 必要输入 | 主要输出 | 硬失败 |
|---|---|---|---|
| 数据基础 | 门店、平台、周期、经营阶段、文件 | 可用性、质量、口径风险、可判断边界 | 串租户、把缺失写成已确认 |
| 经营诊断 | 已通过核验的数据版本 | 完整原因扫描、优先候选、证据链 | 单点异常直接写根因 |
| 问题验证 | 一个候选问题 | 去哪里看、记录什么、比较方法、成立规则 | 不同问题套同一模板 |
| 增长方案 | 已验证结论 | 单变量动作、基线、护栏、止损、负责人 | 未验证直接执行、未经确认外部动作 |
| 执行回填 | 已批准方案、真实动作 | 执行事实、偏差、数据性质 | 模拟数据冒充真实执行 |
| 效果评估 | 同口径基线与测试期 | 增长/无增长/负增长/证据不足 | 忽略退款、节假日或并发活动 |
| 复盘 | 完整周期证据 | 继续/调整/停止、下一轮待审批动作 | 编造效果或自动扩大投入 |
