## 1. 这个 demo 是什么

把宠物门店「获客 → 接待 → 跟进 → 成交 → 售后 → 复购」整条链路，变成老板每天打开手机就能**执行、追踪、复盘**的 AI 工作台。不是记账系统，也不是文案工具——核心价值是 AI 把门店经验变成「今天该干什么、跟谁、说什么」。

- **样板门店人设**：毛孩子宠物生活馆（虚构样板名，洗护+商品均衡的个体单店，对应优先客群 20%，定价锚点 500-1000 元/月）。
- **AI 角色**：AI 店长「汪小助」（24h 企微接待 + 经营诊断 + 话术生成的统一人格）。
- **设计基准**：手机端为主（老板在店里用手机，底部微信式 4 Tab），电脑端 ≥960px 自动增强（左侧导航 + 多列网格）。
- 顶栏保留产品线惯例：**思潼AI商城**品牌 + 算力积分入口（演示口径：文字 10/条 · 图片 40/张 · 视频 120/条）+ 充值。

## 2. demo 结构（4 Tab · 手机底部导航 / 电脑左侧导航）

### 🏠 Tab 1 经营驾驶舱（老板第一屏）
1. **今日结论 AI 诊断**：自然预测 ¥7.9 万（93%）→ 执行到期提醒+M1 唤醒后冲 ¥8.68 万（102%），并给出"今天最该盯 15:00 前发 M1 私信"。
2. **目标达成四卡**：业绩 / 新客 / 复购率（已达成态）/ 沉睡唤醒，带进度条与日均缺口。
3. **沉睡会员分档**：M1（30-44 天·75%）/ M2（45-89 天·67%）/ M3（≥90 天·20%），阈值说明洗护周期 30-45 天，可点击直达唤醒。
4. **今天干什么**：P0×2（M1 一键唤醒、大额未耗储值电话）、P1（国庆寄养逼单）、P2（朋友圈）+ 例行清单（回访/打卡/好评/档案）。可勾选，进度条联动。
5. **储值·次卡耗卡**：预收未耗 ¥43,200 + 3 张 90 天未用次卡预警（宠物店版"预收负债"）。

### 💬 Tab 2 私域自动化引擎（核心差异化，5 个子模块）
1. **24h 企微自动接待**：4 组实景会话——预约报价 / **猫腹泻问药（触发红线：不诊不开药→引导就医）** / 寄养收费 / 议价自动转人工；顶部统计条（接待 17 · 转化 5 · 转人工 2 · 响应 3 秒）。
2. **到期提醒引擎（最强留存武器）**：5 张可操作卡——疫苗到期（豆豆）/ 粮食耗尽预测（咪咪，按购买周期推算）/ 洗护超期（汤圆 32 天）/ 驱虫满 90 天（团子）/ 猫砂将耗尽（煤球）。每卡含个性化 AI 话术，可单条私发或"17 条一键发送"。
3. **回访·寄养打卡**：洗护后第 2 天自动回访 + 复购券/好评引导；寄养每日照片视频打卡；商品适口性回访；**自动打标签云**（猫狗/幼老年宠/高价值/周期客等 11 类）。
4. **唤醒·分层**：M1 具体理由私信 / M2 券+关心 / M3 电话+回归礼包，各档成功率与策略明示。
5. **评价管理**：差评预警（吹干问题，AI 归因 + 48h 处理话术 + 补洗动作）、好评自动感谢/沉淀素材。
- Tab 顶部固定**产品红线横幅**。

### 🎬 Tab 3 内容营销工场（最高频·付费感知最强，5 个子模块）
1. **每日文案**：朋友圈种草/活动/科普 3 条 + 社群逼单 1 条，均带发布时间建议、复制、配图/发社群/转数字人等动作（复制按钮真实可用）。
2. **短视频脚本**：《新手养猫 3 笔冤枉钱》《猫罐头看 3 行字》分镜脚本，可一键转数字人；驱虫话题刻意只讲渠道风险、不讲剂量。
3. **AI 数字人口播（会议定的王牌卖点，完整生成器三步）**：
   - 选形象（小林店长/阿哲主播/汪管家卡通/专业顾问 4 选 1）→ 贴文案（预填换毛季口播稿，实时字数/成片秒数）→ 生成预览（扣 120 积分，约 4 秒分步进度）；
   - 成片为 9:16 竖屏播放器：店名角标 + 形象说话动画 + 声波 + 逐句字幕 + 进度条 + 暂停/重播 + 下载/一键发布；
   - 形象区注明"仅护理/经营口播，不输出诊疗内容"，并预留"老板本人形象克隆（正式版）"。
4. **节日活动方案**：国庆宠物节——3 个套餐组合（洗护次卡/洗护+临期零食搭售/充 500 送 80）+ 9/28 预热到 10/7 收网时间轴 + 海报主文案。
5. **美团点评**：店铺简介、问答区自动回复（接送/猫应激）模板。

### 🏪 Tab 4 门店后台（P1 简示，一屏带过）
- **宠物档案**：豆豆完整档案（品种/疫苗/过敏/习惯/毛质美容档案/前后对比位）+ 高风险宠物红色提醒（贝贝暴躁应激，两人操作 + 已签免责）。
- **库存临期**：临期 2 品（34/42 天）、滞销 1 品、补货提醒 1 条，可生成临期捆绑方案。
- **产品知识库问答**：可提问/快捷问题，只答本店在售品；肾病罐头回答带"以兽医诊断为准"红线注脚。
- **店员培训**：AI 扮客户异议演练 3 剧本（嫌贵/自己网购驱虫/拒办卡），点击后逐条对话并给评分。
- **日报/客诉分析**：当日经营摘要 + 本周客诉 AI 归因（2/3 吹干应激→改 SOP）。

## 3. 可点的真实交互（给老板演示时走这条线）

1. 驾驶舱勾选 P0 → 进度条走；点任务上的"去私域引擎"自动跳 Tab 并高亮第一张提醒卡。
2. 到期提醒逐条/全部"一键发送" → 变"✓ 已发送"。
3. 进私域 Tab 时接待会话自动逐条浮现（演示 24h 值守感）。
4. 内容工场复制文案真实进剪贴板；数字人完整走一遍选形象→生成→播放（积分实时扣减）。
5. 门店后台点培训剧本，看 AI 顾客陪练对话与评分。
6. 店头右上「**▶ 一键演示**」：约 28 秒自动走完全流程（驾驶舱诊断→任务→私域发送→红线接待→数字人成片→高风险档案→回驾驶舱），可随时停止。

## 4. 工程/产品要点（正式开发时对齐）

- **数据模型先行**：宠物档案（品种/生日/疫苗驱虫日期/过敏/毛质）+ 消费记录是所有自动化的燃料；到期引擎依赖"购买日期+规格+宠物体重/食量"的消耗推算（30 磅犬粮 5-7 周、猫砂 3-4 周、驱虫 90 天、洗护 30-45 天，阈值按品类可配）。
- **红线要做成系统拦截而不是提示词约定**：健康类意图识别 → 固定话术兜底（拒诊拒药+引导就医），数字人与知识库同样走该拦截；知识库只索引本店在售商品库。
- **轻量接入**：企微（接待/私信/打卡）+ 网页工作台，店员零提示词学习；所有 AI 产物都带"复制/一键发送"而不是让店员自己改写。
- **计费**：按文字/图片/视频分档算力积分（demo 已演示数字人扣 120），B 端商城上架与合伙人分佣见需求文档第 3 节。
- **演示数据全部虚构**：门店名、宠物名、客户姓氏均为样板数据，不指代真实门店或个人。

## 7. 待确认问题（体验会前/中收集）

1. 到期提醒的发送时间窗与频控：一天几条？客户多久没响应停止自动追？
2. 企微接入形态：现有门店有多少在用企业微信？个体店是否需要"客服号/网页 H5"兜底？
3. 数字人形象：4 个预置形象是否够？老板本人克隆形象是否进第一期（成本与合规）？
4. 储值/次卡数据从哪来：手工录入还是接现有收银/会员系统？
5. 纯洗护店低价档（≤200 元/月）第一版是否只做驾驶舱+文案的阉割包？
6. 多店连锁（商品为主头部店）的多门店对比/汇总本版未做，排期确认。
