**三、访谈话术**

【问·情境式】假设一位老板做到8家店，营收不错，但店长一换就掉业绩，他第一步该动哪里？
【答】先别急着招人，先看三件事：他的股权结构能不能支撑扩张、店长岗位有没有可复制的动作清单、利润是不是真的留在总部。多数情况是第二件事没做，换谁都会掉。

【问·情感式】很多老板说自己是"被生意绑住的人"，一年到头不敢离开门店，这种状态你理解吗？
【答】理解，而且这通常不是能力问题，是结构问题。老板把自己变成了最大的瓶颈，公司没有沉淀出体系，人一走事就停。

【问·转折式】有人说连锁扩张的关键是选址和流量，你说不是，那到底卡在哪？
【答】选址和流量决定单店能不能活，体系决定能不能复制。开到第3家之后，卡点基本都在顶层设计：股权怎么分、标准怎么定、合伙人怎么进怎么退。

【问·引导式】如果一个品牌想拿天使轮，你建议他提前多久开始整理股权和架构？
【答】不是提前多久的问题，是顺序问题。融资之前股权必须干净、决策必须清晰，否则尽调阶段就会被反复追问，进度会被拖住。

【问·回顾式】你服务过连锁企业做体系导入，回头看，老板最容易忽略的一步是什么？
【答】最容易忽略的是"把老板脑子里的东西写下来"。标准化的提炼导入，本质是把个人经验变成组织能力。（具体服务案例：待补充）

【问·引导式】什么样的连锁企业适合来找你做诊断？
【答】年营收千万级、已经跑通单店模型、正在开第3家到第20家之间、准备走融资或合伙人路线的连锁品牌，不限行业。

**四、拍摄脚本**

【固定场景】
- 场景A：办公室／书架前，中景机位，画面留白在右侧供字幕使用。用于0-3秒钩子与45-60秒收尾。
- 场景B：会议桌／白板前，中景偏侧45度，配合手部动作做"三步法"讲解。
- 场景C：门店内靠窗位置，自然光，用于人设感片段（可与获客型成片交替发布）。

【移动场景】
- 跟拍老板走进门店、与店长交接、翻看运营台账，用于3-15秒的节奏垫片。
- 手持轻微晃动的走廊镜头，用于15-30秒的"问题暴露"段落。

【B-roll清单】
1. 门店门头与排队人流（店面信息待补充）
2. 员工晨会、带训、交接班
3. SOP手册／运营台账翻页特写
4. 组织架构图、股权架构示意图（画面内容为示意，不出现真实品牌名）
5. 白板写"股权—标准—合伙人"三步
6. 深夜办公室台灯、电脑屏幕
7. 评论区引导浮层素材

**五、拍摄注意事项**

| 类别 | 要求 |
|---|---|
| 着装 | 商务休闲为主，深色纯色上装，避免细条纹与大面积logo；配饰从简 |
| 场景 | 背景干净、纵深清晰，避免杂乱办公桌；不出现真实客户品牌、合同、公章、门店招牌 |
| 收音 | 领夹麦为主，手机备份录音；关闭空调与门缝噪音源，录制前试听10秒 |
| 灯光 | 主光在镜头侧前方45度，人物与背景分离；避免顶光造成眼窝阴影 |
| 状态 | 用提词器时保持眼神落点在镜头附近，语速比日常慢半拍，句子之间留半口气 |
| 禁忌 | 不出现收益承诺与绝对化表述；不使用"一定能落地""结果必然"这类表达；不做医疗、金融收益类承诺；不诱导用户脱离平台、不要求观众留下联系方式、不引导站外交易；不使用"某连锁品牌"这类易被指向真实企业的模糊指代，改用"很多连锁"这类泛化表述；数据与案例未经确认一律不出镜 |

**九、评论区引导**

- 置顶评论：连锁的第3家到第10家，是最容易出问题的阶段。你最卡的是股权、标准，还是合伙人？在评论区说一句，我按顺序往下拆。
- 前10条回复风格：
 1. 认同型：一句话接住情绪＋追问一个具体场景。
 2. 提问型：先给判断方向，再邀请补充背景信息。
 3. 抬杠型：不辩论，复述对方观点后给一个可自查的问题。
 4. 同行型：肯定身份，引导分享自己遇到的阶段性问题。
 5. 泛泛型：把话题收窄到"第几家店""哪个环节"。
 6. 求方案型：说明哪些信息还不够，请对方补充行业与门店数量。
 7. 讲故事型：接住故事，提炼一句共性结论。
 8. 情绪型：先共情，再给一个当下能做的动作。
 9. 咨询型：确认人群匹配度（营收量级、门店阶段），提示主页有内容可先看。
 10. 离题型：礼貌拉回主线，不做长篇解释。
- 意向转化话术：
 1. "你现在的门店数量和阶段是哪种？说清楚我再给你具体建议。"
 2. "这种情况一般要先看股权，再看标准，顺序别反。"
 3. "你把行业、门店数、当前卡点写全，我按你的情况拆一版思路。"
 4. "主页有同样阶段的拆解，可以先对照自查。"
 5. "适合做体系导入的是已经跑通单店模型、正在扩张的品牌，你可以先自查这一条。"
