**三、访谈话术**

【问·情境式】很多年轻女孩想学皮肤管理，最怕学完用不上，你怎么看这个问题？
【答】这个担心很真实。我们的做法是把技术拆成可以照着走的步骤，从问诊到手法都带练，学完能直接回到自己门店用。

【问·情感式】你在美业待了20年，为什么一直只做皮肤管理这一件事？
【答】因为这一件事就没做透。手法、产品、话术，每一环都在变。我见过太多门店什么都做，最后什么都没做深。

【问·转折式】市面上的课程不少，你们的区别在哪？
【答】区别在于落地。我们不是只讲理论，是把门店真实的接待流程搬出来，连顾客会问什么问题都一起过一遍。

【问·引导式】学完之后，怎么落到自己的门店里？
【答】先按你门店现有的项目做适配，再定服务流程。具体排期和适配方案，要看你的门店情况，这块可以待补充。

【问·回顾式】这20年里，有没有让你印象特别深的学员案例？
【答】有，但涉及学员门店信息，我不方便公开。案例数量和门店名单，我统一标了待补充，不想拿数字说事。

【问·情境式】新手基础比较弱，多久能上手？
【答】节奏因人而异。有人快有人慢，我们不承诺固定周期。具体的学习周期和费用，可以看主页说明或待补充。

**四、拍摄脚本**

固定场景（门店内，机位A）
- 主播正面半身，居于画面中偏右，背景为护理区或产品墙，景深虚化。
- 桌面放置案例册、皮肤档案本、流程卡，方便随时拿起。
- 主灯在主播斜前方45度，避免顶光造成眼下阴影。

移动场景（穿插实拍）
- 手法演示位：护理床旁近景，拍手部动作与产品涂抹过程，不拍顾客正脸。
- 培训位：白板前中景，拍学员围站、记录、互相练习。
- 前台与走廊：拍门店日常客流，画面中不出现真实客户人像，可用背影或虚化处理。

B-roll 清单
1. 门店招牌与门头（门店名：待补充）
2. 护理床、仪器、产品陈列
3. 手法特写：清洁、按摩、导入等步骤
4. 案例册翻页（案例数量：待补充，对比图需打码）
5. 学员练习与笔记
6. 顾客咨询与档案填写
7. 主页界面、关键词评论区示意
8. 片尾品牌卡：「兰琪」+ 待补充门店信息

**五、拍摄注意事项**

着装清单
- 主播着浅色或品牌色工作服，领口整洁，不戴夸张饰品。
- 美甲干净，长度适中，手部入镜前确认无破损。
- 头发扎起或收拢，避免遮挡面部与镜头。

场景清单
- 背景整洁，护理车、毛巾、瓶罐按统一方向摆放。
- 画面内不出现无关人员走动，不出现真实顾客正脸。
- 门店内的宣传物料需提前检查，避免出现过期或不实内容。

收音清单
- 使用领夹麦，麦克风藏于衣领内侧，避开衣物摩擦。
- 关闭空调外机、吹风机等持续噪音源。
- 拍摄前录10秒环境音，确认无回声与电流杂音。

灯光清单
- 主灯+补光灯组合，色温统一为暖白，避免冷暖混用。
- 面部光比控制在柔和范围，不要出现明显阴阳脸。
- 仪器特写与案例册翻页处补一盏小灯，保证画面通透。

状态清单
- 开口前深呼吸，语速比日常略慢半拍。
- 每条内容拍3遍，第1遍找感觉，第2遍求完整，第3遍留最佳。
- 眼神盯镜头而非屏幕，避免眼神飘移。

禁忌清单
- 禁忌：不得使用绝对化用语，不得对服务效果做承诺性表述。
- 禁忌：不得涉及医疗功效描述，不得暗示可替代医疗手段。
- 禁忌：不得诱导用户转入站外一对一沟通，不得出现站外引流信息。
- 禁忌：不得展示未经授权的顾客肖像与个人信息。
- 禁忌：不得使用「最」「第一」等排名性表述。
- 禁忌：不得对收益、回本周期做出承诺。
- 禁忌：不得编造门店数量、案例数据与资质信息，未提供的统一标「待补充」。

**九、评论区引导**

置顶评论
「20年只做皮肤管理这一件事，案例和流程我都放在主页了，想了解的先点主页看置顶。门店信息与价格：待补充。」

前10条回复风格
1. 疑问型：先肯定对方的问题，再给一句可执行的建议，不评价对方门店。
2. 同行型：用「我们门店也是这么做的」这类共情句式，回一句流程要点。
3. 新手型：强调节奏因人而异，不承诺固定周期，引导看主页说明。
4. 抬杠型：不争辩，只回一句「你的角度我记下了」，不与用户对线。
5. 询价型：统一回复「价格在主页说明里，按门店情况有差异」，不做区间报价。
6. 案例型：回复案例已做脱敏处理，数量标「待补充」，不展示顾客信息。
7. 地域型：回复覆盖城市待补充，请对方先看主页说明。
8. 质疑型：只讲自己的20年经历，不做效果对比。
9. 求资料型：引导对方在评论区发关键词「皮肤管理」，按顺序公开回复。
10. 情绪型：先用一句共情接住，再给一条流程建议，不追问个人情况。

意向转化话术
- 「在评论区发关键词『皮肤管理』，我按顺序回复，主页置顶有完整流程。」
