附录 · 实际代码落点（图中各块对应文件）

后端入口：apps/api/src/routes/chat.ts（基础问答 /chat）、marketplace.ts（货架文案）、agent-runtime.ts（数字员工运行时）。多轮历史由 buildInputWithConversationHistory 从 DB 拼入。

后端写死闸门：apps/api/src/products/beauty-industry/advisor-rules.ts 的 advisorGate() / platformAskBack()（空/太短/平台未识别 → 固定反问，不调模型）。

模型生成追问：写在提示词指令里——copy-ten-contract.ts 的 COPY_TEN_SYSTEM_PROMPT（信息不够→【需补充信息】）；advisor 的 prompt.md 也含 followUps 生成指令。

A 路 prompt.md：packages/skills/src/index.ts 的 loadSkillPrompt(skillId) = readFile('packages/skills/skills/<id>/prompt.md')；共 54 个 skill 目录。

B 路内联契约：marketplace.ts 的 marketplaceSkillSystemPrompt(sku) → 返回 COPY_TEN_SYSTEM_PROMPT（写死 TS 常量，不走 loadSkillPrompt）；同文件的 parseCopyTenContract 做死规则校验。

知识库：routes/knowledge-base.ts 的 subjects/documents/industry supplements；经 agent-runtime.ts 的 RuntimeKnowledgeAction（knowledgeAction 开关）按需注入，不进 prompt.md。

大模型：services/domestic-chat-provider.ts 调 DeepSeek（api.deepseek.com/v1）；日志只打 responseHash/responseBytes/usage，不打印正文。

落库：通过→MarketplaceDeliverable.answer / LanqiContentDraft.copyDraft / AgentRunStep.output；不通过→422 不落库不扣积分。
