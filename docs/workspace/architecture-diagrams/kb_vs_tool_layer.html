知识库 vs 工具调用：层次区别

两者都扩展 LLM 能力，但处于不同层 —— 一个增强「输入」（让它知道更多），一个增强「行动」（让它做成更多）。中间的大模型是共同核心。
维度① 知识库（输入侧）② 工具调用（输出侧）
所处层上下文组装层（prompt 拼装前）推理行动层（生成过程中的 loop）
模型角色被动消费文本主动决策「调不调、调哪个、传什么」
对外部世界只读（不改变任何东西）可读写 / 执行（查实时、发消息、生成文件）
触发方用户挂文档 / 系统按主题注入模型在推理中自主决定
调用形态单次生成（文本拼进去就完）多步循环（调→执行→回喂→再调）
扩展的是「模型知道什么」「模型能做什么」
组合关系：两者不互斥。工具调用可以是「去检索知识库」的那个工具 —— 模型先决定调检索工具，工具把文档取回，再注入上下文。此时「知识库」是工具的一种具体能力，落在工具调用这一层之内。简单说：工具调用是更上层的「行动框架」，知识库注入可以是它的一个子场景。
