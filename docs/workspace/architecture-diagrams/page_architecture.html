你在页面上点什么，背后就走哪条路

不堆名词，只讲你眼睛看到的页面，以及你在框里打字后发生了什么。

一句话先讲透：「聊天框」是同一个长相的壳子，但它有两种身份——你从「商城」点进来的走货架后端（提示词写死在代码里）；你从「数字员工工作台」点进来的走另一条后端（提示词存在数据库里）。你之前分不清，就是因为这两个框长得一模一样。
你看到的页面 / 聊天框壳子 货架能力（商城路径） 数字员工（工作台路径） 大模型（共用）

你之前那几个困惑，对着图就清楚了

Q：为什么「对话业务流程」和「货架文案路径」像是两回事？
A：它们不是两回事——「对话」只是聊天框这个壳子。你从商城点进来的那个框（ipzone__copy、meiye__copy、ipzone__livescript）就是图上橙色那条；数字员工工作台里的框是绿色那条。壳子一样，后端不同。
Q：那「skill 在哪起作用」为什么我看不到？
A：因为你一直看的是橙色那条。橙色这条路压根不用 skill 文件，提示词是写死在代码里的常量。skill 文件只在绿色那条（数字员工）和少数高级工作流里才被加载。
Q：我发的消息、追问、收集信息，是谁在问？
A：橙色路里，「你没填全/说清楚点」这类通用反问是后端写的；「请补充行业/卖点/人群」这种看人下菜碟的追问，是模型按提示词自己问的。绿色路同理。
附录：图上每块对应的真实代码位置（给以后改代码用，平时不用看）
  • 商城首页 = /agents 路由，列卡片用接口 /market/zones + /market/skus
