商城 · 直播话术生成运行流程

仅这一条线：商城聊天页 → 后端 /run → 分段生成 → 落库返回（代码已逐项核实）

无 schema 校验、无自动重试（仅文案/选题有） 扣积分（或包月覆盖）+ 写 MarketplaceDeliverable + 返回 200 ⑤ 前端收尾 200 且 settled → 渲染 answer、显示消耗积分、停计时器 502/504 → 提示网关超时、继续 30秒轮询找回后台成品 25分钟兜底文案是前端假状态，不代表后端还在跑 模型：deepseek-v4-pro ｜ 单次输出上限 16384 tokens ｜ 正常约 6–7 分钟 ｜ nginx 等待上限 30 分钟 ｜ 前端兜底 25 分钟

关键点：整单是一次 HTTP 长连接等后端跑完 10 段再回 200； 前端有两条独立保险——25 分钟兜底文案（纯前端定时器，会存 localStorage，重开页面还在）和 30 秒找回轮询（502/504 后后台跑完也能取回）。所以"一直不返回"通常是请求没真正到后端 / 连接被中断， 而不是后端在慢慢生成。
