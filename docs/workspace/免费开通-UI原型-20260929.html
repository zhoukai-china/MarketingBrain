交互规则（给前端实现的约束）

点规则
环境判断复用 wechatInAppBrowser()：微信内 → 直跳 oauth2；否则 → 拉二维码（与登录同一组件、同一接口，只换文案与回调后的动作）
微信未配置/auth/wechat-config 返回 503（或 demo 模式）→ 隐藏微信按钮，只留「手机号验证码开通」
state走 /auth/wechat-state 签发（带签名、10 分钟），回调页交后端验签；不依赖浏览器存储
二维码/auth/wechat-bridge/qrcode 生成（指向本站 /wechat-bridge），轮询 /auth/wechat-bridge/status；5 分钟过期，过期保留块 + 「刷新二维码」
到账动作拿到登录结果后立刻调 POST /market/activate（幂等）→ 返回 gift/expiresAt → 渲染成功态
文案一致性权益三条、到期日、余额条构成，必须与 HANDOFF §7 一致（90 天 / 限文字类 / 不计佣金）
兜底微信与验证码都失败 → 文案「联系服务团队开通」，不静默吞错
