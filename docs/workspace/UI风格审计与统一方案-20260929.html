一句话结论：现在系统里其实跑着三套视觉语言——① 商城链路（扁平白卡 + 橙系）② 工作台/详情页里的 Hero 与瓷贴（轻拟物：大渐变、内阴影、光晕、旋转虚线环）③ 更早的深色拟物体系（sitong-design / agent-products，128 处阴影、84 处渐变）。 建议不消灭轻拟物，而是给它划边界：运营位（Hero、金刚瓷贴、主 CTA）允许轻拟物，内容区（列表、卡片正文、表单、表格、弹层）一律扁平，并用一套 Token 收口。

1.1 具体混搭点（同一屏里能同时看到的）

#现象证据影响
1轻拟物 vs 扁平同屏金刚瓷贴（渐变+内阴影+呼吸光晕+外发光环）紧挨着扁平白卡商品卡；数字人卡带旋转虚线环，详情页卡不带同一栅格里两种质感，视觉噪音强
2按钮家族五套橙渐变+流光（旧充值/主 CTA）／橙描边（新返回）／白底描边（商品卡加购）／深底白字（Hero 内）／微信绿（登录）主次不分，主 CTA 被稀释
3顶栏两套并存MallTopbar（新）与 Topbar（旧，带主题切换/退出/💎横幅）同时被 /chat、/mine、/recharge 等引用页面间跳一次换一次头
4圆角无梯度6/8/9/10/12/14/15/16/18/20/99px 混用，同类卡片也不一致整体"凑出来"的观感
5阴影无档位0 到 0 16px 40px rgba(120,50,0,.14) 之间任意取值层级关系读不出来
6边框色多套#F0EBE3 / #E5DDD1 / #d5e3da / #e3e9f2（不同页面各一套）跨页拼接有色差
7字号基线不一商城 .eh 14px、Topic 工作台 15px、cpw 默认 16px同字号不同观感
8图标三种来源emoji／SVG／位图混用（金刚区 emoji、商品封面前阵才换图）精细度不一致
9弹层/空态两套商城浅色橙系 eco-modal vs 其它页深色 sheet vs 充值页纯扁平弹层出现时像另一个产品
10动效无统一规则扫描线、顶部流光、呼吸、旋环、流光按钮、打字机各自为政，无"何时动"的约定页面"一直在动"，干扰阅读
