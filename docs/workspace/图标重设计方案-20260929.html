风格 A · 釉面线性（推荐）

品牌渐变瓷贴 + 白色 2px 圆头线性图标 + 顶部高光。精致、有质感，和 Hero 渐变同一血缘；线性笔画显得「贵」。

金刚区七格推荐
瓷贴渐变逐格用现有 tint 色（内容获客橙 / 私域玫红 / 咨询师金 / 硬件绿 / 课程紫 / OPC 深橙 / 行业粉），与现状色板一致，只换「图案」不换「配色」。

风格 B · 暖白浮雕

暖白瓷底 + 橙色图标 + 细边框轻投影。更素、更「苹果设置页」，牺牲一点活泼换高级感。

风格 C · 双色几何

浅色底 + 双色面性图标（主色块 + 深色细节）。扁平干净、信息感强，但和 Hero 的拟物氛围略有割裂。
