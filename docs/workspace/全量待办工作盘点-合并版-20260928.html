三、各工作线明细

A · 算力计费与增长体系 8–12 人日 P0

业务逻辑：docs/HANDOFF-compute-pricing-20260926.md（v1.0 已定稿，经营方逐条确认）。核心口径：全站「积分→算力」改名；汇率 COMPUTE_RATE=10（1 元=10 算力，上线后不调）；智能体 0 元开通按固定目录价扣费；失败/重试不扣费；赠送算力 90 天有效、先扣、不进佣金基数、限文字类任务。

P0 主链路：全站改名+汇率常量+整数记账 / 余额分账（充值+赠送）+逐笔账单+扣减顺序 / 目录价扣费+失败不扣+使用前明示 / 八人价目表+视频生成两档 SKU 落库 / 充值三档（100/300/1000 + 加赠）/ 存量迁移脚本（价格÷2、余额1:1、幂等+对账，已有真实付费用户）。

P0 佣金：SKU 首充/后续佣金率两字段、首充期 30 天口径、佣金 ≤ 毛利 80% 系统校验、月结+退款扣回+自买判定。

P1 增长：邀请裂变（立得 100 / 满 50 得 100，风控前置+追回）、签到（5/天、第7天+30、周封顶 60）、余额预警、合伙人/邀请看板。

验收抽测：充 ¥300 到账 3600 构成可查 / 先扣赠送后切充值 / 失败余额不变 / 第 31 天按后续率 / 同设备互邀不触发 / 迁移脚本幂等 / 全站搜「积分」0 结果。

代码落点：apps/api 计费层（marketplace.ts 计费段、billing-consume.ts、credit-reservations.ts 三段式可复用）+ 前端余额/充值/账单页。
