一、端到端主流程

门店从一句话到成片的完整链路。橙色 = 门店要动手的点；每一笔费用都在创建任务前先报价确认，失败自动退回。

门店操作 后端服务 模型 / 存储 计费点
  • ⑧ 我的生成：出片后进「我的生成」列表，可预览 / 下载 / 重新生成；每镜的成片也可在分镜卡里直接播放。
  • 整片 = 各镜单独出片后由「合成成片」拼成；没出成的镜预留算力自动退回，同一镜重试不会重复扣费。

二、首帧一致性机制（为什么人物不再跑偏）

每镜第一画面决定整条片的"脸"。这套机制保证：每个镜出来都是同一个人、背景忠实于文案。

  • 历史教训已修：提示词截断丢地标（"长江大桥"）→ 已交大模型全句理解；参考图 OSS 缺对象 → 现在先确保上传再签名。
  • LLM 被禁止指定人物性别/年龄/长相——人物长什么样只由你上传的照片决定。

三、真实出片 · 计费与失败处理

当前所有生成都走真实模型。规则只有三条：先报价再扣费、没出成自动退、重试不重复扣。

配套开关：LANQI_MEDIA_EXECUTION_MODE=real（视频与图片均真实生成）· 模型：分镜/文案 = DeepSeek（真实 LLM）· 生图 = 万相 2.7 参考生图 · 视频 = 万相图生视频 · 合成 = 本机 ffmpeg。 生成失败不打扰流程：单镜重试不影响其他镜。
