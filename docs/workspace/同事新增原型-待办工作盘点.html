验收抽测用例（§12）

  • 充 ¥300 → 到账 3600（3000 充值 + 600 赠送，账单构成可查）
  • 消耗顺序：先扣赠送、不足自动切充值
  • 任务失败 → 余额不变、账单无扣费记录
  • 推荐客户首充后第 31 天消耗按后续率计提；纯赠送消耗佣金为 0
  • 同设备两账号互邀 → 奖励不触发
  • 迁移脚本重复执行 → 余额与价格无二次变化
  • 全站搜索「积分」关键词 → 0 结果
