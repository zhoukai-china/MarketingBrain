## 2. 产品一句话

私有知识库 + 行业热点 + 对标账号 + 数据复盘 → 四大来源三关筛选出 10 条。

## 3. 已定稿的产品决策（用户确认，勿改口径）

1. **四大来源**：
   - ① 私有知识库 —— 大脑笔记自动同步（记录工作生活日常：客户往来 / 成交案例 / 心得灵感 / 评论私信 / 销售客服记录）
   - ② 行业热点 —— 按行业 / 产品 / 地区自动组合关键词检索，逐条核验来源。**后台只抓抖音平台数据**；前端/文案不得出现「只抓抖音」字样
   - ③ 同行与对标内容 —— 用户粘贴抖音**主页链接或某条视频链接**；视频链接由 AI 自动定位所属账号并抓取整个账号主页与内容。产出**对标账号分析**：该号近期在讲哪些选题（归类 + 频次）、哪些选题流量好 / 有爆款潜质（带互动数据）、哪些角度可借鉴出题 → 可借鉴角度自动入候选池
   - ④ 自身账号数据复盘 —— 用户上传**抖音 / 视频号**视频数据，由「视频数据复盘智能体」分析，**本模块只显示推荐选题**，不显示复盘报告等其他内容
2. **三关筛选**：一票否决 → 共识层级（**前两关自动完成**）→ 阶段配比（**用户自选**起号 / 增长 / 变现三档，页面上按钮切换）
   - 第一关证据**只来自四大来源既有资料**（私有知识库的评论/私信/客户原话、数据复盘上传数据、对标账号检索结果），**不做账号数据自动抓取**（抖音无公开 API，自动抓取不可行）；无证据标「待验证」+ 给最小验证动作
   - 第三关界面**不出现具体数字**（粉丝数区间、条数配比都不出现），配比只显示侧重（主打 / 主力 / 辅助 / 少量 / 看时机）
   - 第三关**初始不默认选中任何阶段**：进入时配比区显示虚线引导提示「先点上方选择阶段」，三按钮带呼吸光圈动画；用户点选后才显示配比条
3. **缺源降级不阻塞**：任一来源缺失或关闭 → 配额自动重分配到其余来源 → 照常出 10 条，缺口如实标注（demo 来源③卡片有开关可直接演示，黄色降级提示条会弹出）
4. **对外命名统一**：私有知识库 / 行业热点 / 对标账号 / 数据复盘。全文不出现「baolu_topics」「大脑笔记」以外的旧称（大脑笔记仅作为来源①的同步载体名称保留）
5. **头像**：选题策略官用真人头像（平台 `/avatars/topic.png`；demo 内嵌的是同一张图的 base64）
6. 流程口径：配置四大来源 → 候选池涌现 16–20 条 → 三关筛选 → 交付 10 条（带证据状态 + 创作建议 + 适用阶段）

## 4. demo 内可点交互（开发时需真实实现）

| 交互 | demo 行为 | 正式版 |

| 运行实况面板 | 自动播放演示（约 20s） | 真实运行日志流 + 右侧实时指标 |

## 5. 后端 / 数据需求

- 大脑笔记同步接口（来源①）
- 行业热点检索 + 来源核验：抖音热榜 / 巨量算数等公开数据可行（已验证结论）
- 对标账号取数：抖音官方无主页 API，需第三方数据服务（飞瓜/新抖类，按账号付费）或用户自助粘贴链接解析——**开发前先做可行性验证**，这是本需求唯一的重大技术风险点
- 数据复盘选题读取：复用视频数据复盘智能体的产出，只取选题字段
