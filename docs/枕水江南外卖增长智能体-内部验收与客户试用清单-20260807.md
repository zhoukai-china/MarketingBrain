# 枕水江南外卖增长智能体｜内部验收与客户试用清单

日期：2026-08-07

## 一、产品定位

- 客户进入后直接看到“枕水江南外卖增长智能体”，不再选择“枕水江南客户项目”。
- 同一套外卖增长能力可配置不同企业名称、Logo、主色和登录文案；不同企业资料按租户隔离。
- 餐饮增长智能体继续复用同一外卖增长 Skill，但枕水的主入口是独立外卖增长智能体。

## 二、枕水实际使用闭环

1. 数据建档：录入门店阶段、目标、平台、周期、订单与利润口径，并选择授权经营资料。
2. 原因诊断：区分已确认事实、方向性信号、分析假设和待补数据，不把时间先后写成因果。
3. 方案实验：每轮只提出一个主要变量，写清基线期、测试期、不变项、利润护栏、止损线、审批人和复盘日。
4. 人工执行：改价、上下架、投放、活动和预算动作只能作为待审批草案，由枕水确认后在平台执行。
5. 结果回传：回传有效完成单、实付、补贴、退款、贡献毛利、履约和新老客结果。
6. 复盘复制：判断继续、停止或调整；样板店有效后，再到1至2家可比门店复验，不能直接把相关性当成因果。

## 三、老店与新店的不同方法

### 老店增长

- 使用本店近90天历史基线、动作日志和同口径兄弟门店找瓶颈。
- 保护已验证有效的商品、价格和活动，不一次改多个变量。
- 优先输出一个可审批的增量实验。

### 新店业绩突破

- 先确认开业日、平台上线日、商圈、配送半径和首月目标。
- 从可比成熟门店提取商品、价格带、活动和履约经验，但必须在新商圈重新验证。
- 输出7天、14天、30天冷启动计划和第一轮实验。

- 指定运营负责人、动作审批人和数据回传人。
