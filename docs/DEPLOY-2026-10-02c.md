## 一、本次改动与原因

**问题**：安卓微信内置浏览器（WebView）不允许网页触发文件下载，原海报"下载"走 `canvas.toBlob → <a download>.click()`，被微信拦截并弹出系统提示「可在浏览器打开此网页来下载文件。」盖在海报中间；且预览用 `<canvas>`，微信长按存不了图。结果：微信里根本存不下海报。

**修复**（`InvitePoster.tsx` + `eco-mall.css`，仅改 2 个文件）：
1. 预览改为真正的 `<img>`（离屏 canvas 渲染后转 `data:image/png`），微信长按即可"保存图片"。
2. 微信环境（UA 含 `MicroMessenger`）按钮文案变「查看大图 · 长按保存到相册」，点击打开全屏大图并提示"长按图片 → 保存到相册"，右下角浮「长按保存 ↙」徽标。
3. 非微信浏览器保持原"下载海报图片"不变。
4. 修一处隐患：原按钮靠"邀请链接"才可用（链接未加载完为灰、点击无反应）；微信下"查看大图"不需要链接，已改恒可点。

**提交**：本地 commit `next`（见第四节），未合并远端（git push 走 443 单独跑，本次未做）。
