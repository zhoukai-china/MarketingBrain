# 四版本 SKU 能力

## 本地商家标准版

定位：老板/小团队的日常获客与成交助手。

包含：

- 思潼分身
- IP定位
- 选题策划
- 内容创作
- 朋友圈生成
- 小红书运营
- 直播话术
- 销售话术
- 投流指导
- AI日报
- 基础自动化推送

不包含：

- 视频复盘
- 直播复盘
- 文件分析
- 报告导出
- 录音卡分析
- 多账号深度协作
- 电脑端 Web 工作台

## 本地商家高级版

定位：一个本地商家的完整经营增长系统。

包含标准版全部能力，额外包含：

- 视频复盘
- 直播复盘
- 销售增长顾问
- 交付标准化
- 财务咨询
- 人事咨询
- 行政咨询
- 电脑端 Web 工作台
- Excel / Word / PDF / CSV 文件分析
- Word / PDF 经营报告导出
- 录音卡分析
- 多账号协作
- 高级自动化推送

## 连锁品牌标准版

定位：连锁/加盟品牌的招商获客与品牌内容助手。

包含：

- 思潼分身
- IP定位
- 招商/品牌选题策划
- 招商/品牌内容创作
- 招商朋友圈
- 小红书品牌种草
- 招商直播话术
- 招商销售话术
- 招商投流基础建议
- AI日报
- 商学院基础能力
- 基础自动化推送

## 连锁品牌高级版

定位：总部级增长、招商、交付、管理系统。

包含连锁标准版全部能力，额外包含：

- 招商视频复盘
- 招商/培训直播复盘
- 销售增长顾问
- 总部到门店交付标准化
- 商学院高级能力
- 财务咨询
- 人事咨询
- 行政咨询
- 电脑端 Web 工作台
- 招商/门店/财务/运营文件分析
- 多门店经营报告导出
- 招商团队/督导团队/门店员工录音卡分析
- 多门店、多角色、多账号权限
- 高级自动化推送
- 总部质量看板
