## 三、执行过程

1. `git` 同步本地 → 远程（`export GIT_SSH_COMMAND="ssh -o HostName=ssh.github.com -p 443 ..."` 走 443）
2. 服务器先备份三套产物（上表）
3. 本地 `tar` 同步 `apps/web/src` + `apps/web/public` + `apps/api/src` + `packages` 到远程，md5 逐文件比对 **全部一致（0 mismatch）**
4. 远程依次构建：
   - `scripts/build-os-v2-web.sh` → `dist/`
   - `scripts/build-ai-root.sh` → `dist-ai-root/`
   - `pnpm --filter @baolu/api build` → `apps/api/dist`
5. `systemctl restart baolu-os-v2`（服务 active，3002 监听正常）
6. **首轮验证发现页脚「思潼AI商城」未进产物** —— 原因：`index.html` 是仓库根文件，`tar` 只同步了 `src`/`public` 漏了它。补 `scp` 根 `index.html` 到远程后**二次重建两套前端**，页脚文案已进产物。
