# 开发说明 · 周域私域引擎工作台（朋友圈+社群）MVP

> **交互基线**：`docs/prototypes/moments-workbench-demo-20261014.html`（v12，纯静态原型，**原型即交互规格**，提交 16f8cd8）
> **目标**：按原型把「对话式内容工作台」做成真实功能，接入后端能力后上线（前端归属 `apps/web`）
> 原型内数据均为虚构演示数据；右上角「一键演示」≈40 秒跑完标准用户旅程，即验收基线

## 1. 原型怎么看

- 本地预览：`python -m http.server 8922 -d docs/prototypes` → `http://127.0.0.1:8922/moments-workbench-demo-20261014.html?v=12`
- 手机端优先（390 视口），桌面 ≥960px 双栏为辅；所有交互点按钮均可点，全流程可走通

## 2. 页面结构（原型即规格）

- **桌面双栏**：左 390px 对话流 + 右工作台卡片列（各自独立滚动）；**移动端**上下单栏 + 底部「对话 / 工作台」双 tab（safe-area 适配，交付红点提示）
- **对话区**：任务入口菜单（6 任务）、选项气泡（含推荐项自动点选）、自由输入路由、AI 打字中三点动画、生成中流水线进度卡（gen-wrap）
- **工作台**：
  - 发圈简报：7 字段（角色/任务/目标/口吻/强度/保留原话/配图）随对话实时填充
  - 素材箱：五路进一个箱（打字 / 语音转写 / 图片视频 / 文件解析 / 微信转发），状态标签（✓ 已提炼 / ⏳ 待提炼 / 📷 可挂图）
  - 交付区：各任务交付卡（对比稿 / 3 条候选 / 拆条 / 周历 / 档案 / 五级信号）
- **红点机制**：对话视图收到交付 → 亮；进入工作台 → 清

## 3. 六个任务流（扣费点已定）

| 任务 | 交互路径 | 算力 |
|---|---|---|
| 快速升级 | 原稿 → 目标/口吻/强度 → AI 诊断升级 → 补数字（用户确认，AI 不编） | 5/条 |
| 七柱从零写 | 喂素材 → 信号 → 分柱 → 3 条候选+配图 | 15/次 |
| 群消息拆条 | 4 目的选一 → 拆 3 条+节奏建议 | 15/次 |
| 周计划 | 本周重点 → 7 日周历+每日配图建议 | 50/次 |
| 人设建档 | 4 问 → 档案长期复用（决定金句卡落款/口吻/配图风格） | 正式 20 |
| 发后复盘 | 已发记录五级信号 → 下一条调法 | 免费 |

- **失败不扣费**；「保留原话」模式正文一字不改，只附发布建议
- 诊断升级若缺具体数字：提示用户补录（如「护理 40 分钟」），补完检查项才变绿

## 4. 配图双轨（红线，必须原样实现）

- **实拍线**：素材箱挂真实图，AI **只修不造**——打码对象仅限客户隐私（人脸 / 车牌 / 联系方式 / 聊天内容）；**门头、logo、位置等品牌信息原样保留**；挂图后自动带「隐私已打码」标记
- **生成线**：仅限装饰性文字排版卡（金句卡 / 节气海报 / 知识卡片），风格跟人设档案走，可换样式 / 换一句 / **保存 PNG 到手机相册**（正式版行为，原型为 toast 演示）
- **绝不生成**：客户照片、聊天记录截图、案例效果图——AI 直接拒绝并给替代方案
- 文案同规：数字必须来自用户补录或素材原文，AI 不编造；证据不足不占位

## 5. 后端能力依赖

1. 对话流式输出（SSE/WS）+ 任务状态机（对齐原型 step：raw→goal→tone→level→keep→diag→patch→done）
2. 内容生成（分柱模板）、素材提炼、**图片脱敏打码服务**、金句卡渲染出图（PNG）
3. 算力账户：扣费（5/15/50/20 档）、充值、失败回滚
4. 素材箱五路入库统一模型（文字/语音转写/图片/文件解析/微信转发）

## 6. 验收标准

- 「一键演示」的完整旅程在真实产品中可走通（任务选择 → 生成 → 补数字 → 配图 → 交付 → 复盘）
- 移动端 390 宽无横向滚动；触控目标 ≥44px；红点时机、脱敏口径、补数字流程与原型逐字一致
