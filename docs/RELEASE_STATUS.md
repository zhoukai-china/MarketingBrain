# 当前上线状态

更新时间：2026-06-28

## 结论

当前代码已经进入“可部署到阿里云测试环境”的阶段。第一版给 3-5 个老客户内测，不建议再等所有功能完美后才上线。

## 时间判断

### 真实部署

如果服务器登录、RDS、域名/nginx、DeepSeek、微信登录、微信支付资料都齐，预计 0.5-1 天可以完成阿里云 v2 测试环境部署。

如果微信支付证书、网页授权域名、RDS 白名单或 nginx 旧配置需要现场排查，预计 1-2 天。

### 第一版老客户内测

部署完成后，再用 0.5-1 天跑通：

- 微信登录
- 邀请码入驻
- DeepSeek 真实模型输出
- 微信支付预下单和回调
- database 模式数据隔离冒烟
- 运营后台巡检

因此，顺利情况下 1-2 天可以给 3-5 个老客户内测；如果微信/支付联调卡住，预计 2-4 天。

## 不阻塞第一版内测

- 小程序
- 真正桌面端安装包

- Word/PDF 完整排版导出

这些可以在 v2.1/v2.2 做。第一版先保证老客户能登录、能用、能付费、数据不串、输出专业。

旧版继续给老客户兜底，不要停。v2 先挂 `/os-v2/`，只发邀请码给 3-5 个熟悉客户。内测 3-7 天后，根据质量反馈和数据隔离审计结果，再扩大到 20-30 个客户。
