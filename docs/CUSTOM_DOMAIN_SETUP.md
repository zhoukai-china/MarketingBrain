# 企业专属域名上线说明

企业管理员可以在“账号中心 → 企业专属访问域名”绑定一个完整主机名，例如 `ai.example.com`。系统会保存该域名、给出 DNS 验证记录，并在访问请求的 Host 与已验证域名匹配时返回对应企业的品牌信息。

## 1. 设置平台 CNAME 目标

生产环境在 API 的环境文件中设置平台统一入口：

```text
TENANT_CNAME_TARGET=custom.your-domain.com
```

`custom.your-domain.com` 必须解析到承载本系统前端和 API 网关的入口。不要使用示例值作为正式生产目标。

## 2. 客户在域名服务商配置 DNS

管理员在后台保存域名后，任选一种方式完成归属验证：

- CNAME：将客户域名（例如 `ai.example.com`）指向页面显示的 `TENANT_CNAME_TARGET`。
- TXT：按页面显示的记录名和值添加 TXT 记录。

DNS 生效后，在页面点击“检查 DNS 并验证”。未验证的域名不会用于公开品牌匹配。

## 3. 网关与 HTTPS 是上线前置条件

DNS 验证不等于网站已可访问。每个客户域名还必须在边缘网关或 Nginx 中完成以下配置：

1. 接收该 Host 并将 Web 静态资源和 `/api/` 请求转发到本系统。
2. 为该域名签发和续期 HTTPS 证书；不能用平台域名的普通证书替代客户域名证书。
3. 将 `Host`、`X-Forwarded-Host`、`X-Forwarded-Proto` 原样转给 API。

推荐通过支持“自定义域名 + 托管证书”的 CDN / WAF / 负载均衡处理多客户域名；若使用 Nginx + ACME，需要在域名验证成功后将该 Host 纳入配置并为其申请证书。网关层只应接入状态为 `verified` 的域名。

## 4. 验收

完成配置后，以客户域名打开登录页，并确认：

- 登录页显示该企业的名称、Logo、主色和登录文案；
- 登录后工作台与导出报告使用相同品牌；
- 其他客户域名不会显示该企业品牌；
- 使用未验证或已解绑域名时回退为平台默认品牌。
