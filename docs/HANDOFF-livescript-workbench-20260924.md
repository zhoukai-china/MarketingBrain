## 一、背景与目标

直播话术智能体（`ipzone__livescript`，数字员工「罗盘」）当前入口是纯对话逻辑：
`https://ai.lcppch.top/agent/ipzone__livescript/chat`

问题与文案智能体改造前一致：信息收集靠用户自己组织、等待黑盒、结果是一条 Markdown 长文（逐字稿 / 节奏表 / 场控清单挤在一起，直播执行时翻找困难）、迭代要重新开对话描述。

目标：参考**文案工作台**（`docs/prototypes/copy-workbench-demo-20260922.html`，已认可的设计思路）把 chat 升级为工作台（workbench）。

## 三、设计要点（相对文案工作台的复用与差异）

### 复用（三段式结构不变）

1. **左：对话式分流引导**——一次只问一个问题、带快捷选项，答案自动点亮右侧简报字段；
2. **右：开播简报（6 字段）+ 交付区**——占位 / 生成中 / 已交付三态画布，逐件点亮 + 生成日志；
3. **双轨输入**——老手可跳过引导直接填简报、输入框自由打字（如「改成 90 分钟」→ 简报自动更新）；
4. 现有 `/chat` 路由保留兜底，工作台为新路由 `/agent/ipzone__livescript/workbench`。

### 差异（直播话术特有）

1. **按场次类型分流引导**：第一问定模式（带货 / 招商 / 知识付费），后续问题按 `when` 条件切换对应问题集——与现有 `chat-flows.ts` 的 slots `when` 分支逻辑一致，问题模板可直接平移。
2. **开播简报 6 字段**：场次类型 / 品牌主推 / 目标人群 / 转化动作 / 场次时长 / 交付深度。
3. **交付物 = 整场话术十件套**（对应 `live_script_planner` V3 固定输出八大件，四套轮播话术拆成独立件支持单件重生成）：
   - 🧭 策划区：① 直播总览
   - 🎤 话术区：② 开场话术 ③④⑤⑥ 轮播话术 A痛点 / B实力 / C模型边界 / D扶持筛选（= V3 第三大件）⑧ 收尾话术
   - 🪝 承接区：⑦ 承接钩子×3 + 高频应答×5（合规安全版）
   - 🛠️ 执行区：⑨ 轮播节奏表（0→下播分钟连续覆盖、20 分钟一浪）⑩ 场控执行清单（开播前/中/后）
4. **合规内建**（本工作台重点卖点）：生成日志含「合规预审：扫描违禁词库」步骤；逐字稿中「投资有风险，入伙需谨慎」强制嵌入（场控贴片同步）；缺真实数据一律标【待补】不瞎编（对齐 V3 事实安全）。
5. **计费口径**：轻量（单段话术）沿用现有 SKU **200 积分/次**；完整十件套按件计费（待拍板，见第六节）。

### demo 演示数据说明

- 自动演示走「招商加盟 · 思潼AI增长OS 招城市合伙人 · 120 分钟整场」示例（与文案工作台自指示例风格一致）；
- 手动选「带货」时：问题会正确切换到带货分支，但**交付数据仍为招商示例**（demo 限制，交付区有黄条提示）；真实版按带货打法输出（FABE 塑品 + 团购逼单 + 核销路径）；
- 未确认数据（投资口径、分成比例、客户案例、操盘履历）均以【待补】标示——这是刻意演示 V3 事实安全机制，不是遗漏。

## 四、工程落地建议

1. **前端**：新增路由 `/agent/:sku/workbench`（AgentChatPage 保留兜底）。工作台 = 分流引导组件 + 开播简报状态 + 话术包渲染三块。分流问题模板平移 `apps/web/src/marketplace/chat-flows.ts` 现有 livescript slots 的 `when` 分支。
2. **后端 / 接口**：run 接口不变（`POST /api/market/skus/:skuId/run`）；交付轮询复用 `/market/me/deliverables`（30s 轮询 + 25 分钟超时已在生产验证）。answer 由纯 Markdown 升级为按 V3 八大件分块的**结构化输出**，前端按标记渲染卡片；四套轮播话术各自独立分块。
3. **计费**：轻量单段沿用 200 积分；整场十件套新 SKU / 变体；单件重生成需 run 接口加 piece 白名单。

## 五、demo 验收（已自测通过）

- 双击本地打开：正常渲染，console 无报错；
- 自动演示：6 题引导 → 简报 6/6 → 生成日志（含场景识别、合规预审）→ 十件套交付卡片 + 分区 tab；
- 手动模式：重置、逐题作答、复制单件（toast 确认）均正常；
- 分支逻辑：选「带货」后简报点亮 + 问题切换到带货分支，验证通过。
