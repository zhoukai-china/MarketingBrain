## 部署过程说明

生产切换前，预发布构建先后发现开发依赖被跳过和服务器并发构建内存不足。处理方式为非交互安装完整依赖、服务器串行构建，以及在同一锁定源码上本机构建 API 产物并校验 SHA256 后上传。

首次两次切换后的自动业务门禁因验收脚本误读公开接口字段而触发回滚：公开套餐接口不返回 `status`，公开 Agent 能力不返回内部 `skillId`。两次均成功恢复旧版本，线上 SHA256 与备份记录一致。修正为按公开接口契约验收，并在生产编译定义中单独验证 Skill 绑定后，第三次切换和完整验收通过。
