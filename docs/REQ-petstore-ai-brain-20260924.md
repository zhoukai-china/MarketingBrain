## 2. 产品定位（一句话）

不是记账系统，也不是文案工具——把宠物门店「获客 → 接待 → 跟进 → 成交 → 售后 → 复购」整条链路，变成老板每天打开就能**执行、追踪、复盘**的 AI 工作台。

PetPulse 复盘结论与会议纪要一致：AI 的价值不是替代人，是把门店经验变成每天可执行、可追踪、可复盘的动作。

## 3. 目标客群与定价锚点

| 门店类型 | 占比 | 策略 | 定价锚点 |
|---|---|---|---|
| 洗护+商品均衡店 | 20% | ★ 优先拓展 | 500-1000 元/月 |
| 商品为主头部店 | 10% | ★ 优先拓展 | 1000+ 元/月 |
| 纯洗护店 | 60% | 暂缓（老板累、接受度低，后续低价档切入） | ≤200 元/月 |
| 活体售卖为主 | 10% | 暂不拓展 | — |
| 宠物医院 | — | 不碰（专业性/合规风险） | — |

商业配套：B 端 AI 商城上架、市场合伙人分佣（专属链接注册永久归属）、宠多格等赋能机构合作、区域代理渠道；算力积分计费（文字最低/图片居中/视频最高）。

## 4. 核心差异化：四件传统系统干不了的事

现有系统 = 静态记账（客户登记、消费扣款、会员打折、基础支付统计）。AI 经营大脑必须做到：

1. **24h AI 自动接待**咨询预约（企微）
2. **自动生成推广内容**（文案 / 短视频脚本 / 数字人口播）
3. **自动回访**售后（洗护后 / 寄养接宠后）
4. **客户分析 + 跟进提醒**——算出"今天该跟谁"

打消"和现有系统重复"顾虑的关键：价值要大到门店愿意替换现有系统。

## 5. 功能需求清单（四大模块 + Demo 优先级）

### A. 经营驾驶舱（P0 · Demo 主屏）—— 老板每天第一屏

- 今日结论：AI 一句话诊断 + 月末业绩预测 + 今天最该盯什么
- 目标达成四卡：业绩 / 新客 / 复购 / 唤醒
- 沉睡会员分档：M1（1 个月没来·黄金期）/ M2（关键期）/ M3（≥90 天·重症期），优先唤醒 M1；宠物洗护周期约 30-45 天，分档阈值按品类调整
- 今天干什么：P0/P1/P2 要救的事 + 例行清单（触达 / 回访 / 内容 / 复盘）
- 储值卡·次卡余额与耗卡提醒（宠物店版"预收负债"）

### B. 私域自动化引擎（P0 · 核心差异化）

- 24h 企微自动接待：营业时间 / 洗护价格 / 寄养收费 / 疫苗咨询（边界：不答诊疗）
- **到期提醒引擎**（宠物店最强留存武器）：疫苗 · 驱虫 · 洗护周期 · **粮食耗尽预测**（30 磅犬粮≈5-7 周、猫砂≈3-4 周、驱虫≈90 天）→ 自动生成私信话术
- 消费后自动回访（洗护后 / 寄养接宠后）+ 寄养每日打卡发给主人
- 沉睡唤醒 + 会员分层：批量唤醒话术、高价值客专属活动
- 自动打标签：新老客 / 猫狗 / 幼宠·老年宠 / 消费偏好
- 好评引导 + 差评预警（美团 / 点评）

### C. 内容营销工场（P0 · 最高频使用 + 付费感知最强）

- 朋友圈 / 社群每日文案：产品种草 / 洗护活动 / 寄养优惠 / 养宠科普
- 短视频脚本：新手养猫避坑、罐头怎么挑（好拍好剪）
- **AI 数字人口播视频**：老板给图片 + 文案 → 自动成片（会议明确的新卖点，解决老板不出镜、不会拍视频）
- 节日活动方案：618 / 周年庆 / 宠物节 → 方案 + 海报文案 + 套餐组合（洗护+零食、储值方案）
- 美团 / 点评店铺文案 + 问答区自动回复 + 买家秀回复模板

### D. 数据与门店支撑（P1 · Demo 做后台简示）

- 宠物档案：品种 / 年龄 / 疫苗 / 过敏 / 用药 / 习惯 + 美容档案（毛质 / 修剪样式 / 前后对比）
- 库存进销存：临期零食罐头预警（食品保质期痛点）、滞销识别、补货提醒、下周销量预测
- 产品知识库问答：卖点 / 成分 / 禁忌（如肾病猫罐头、幼犬零食），店员随问随答
- 店员培训：标准接待话术生成 + AI 扮演客户异议演练（嫌贵 / 抗拒驱虫 / 不愿办卡）
- 洗护 / 寄养 SOP 生成；日报周报自动生成（营收 / 洗护单 / 零售 / 新客）+ 客流规律排班推荐
- 客诉分析：差评归因（应激 / 价格 / 态度）+ 安抚模板 + 高风险宠物识别（皮肤病 / 心脏病 / 暴躁）→ 提前告知签免责

## 6. 产品红线（必须内建进产品，不是文档约定）

- AI **不做疾病诊断、不开药、不判断重症** → 一律引导就医或到店
- 知识库限定本店在售产品，不推竞品、不乱说话
- 轻量接入：企微 / 网页即用，店员零提示词学习成本

## 8. 第一版 Demo 方案决议（2026-09-24 已确认）

| 决策项 | 结论 |
|---|---|
| 样板门店人设 | **均衡店·单店**（洗护+商品均衡的个体店，最贴合优先客群 20%，故事线聚焦私域复购与到期提醒） |
| 数字人模块 | **完整生成器界面**（选形象 → 贴文案 → 生成预览，作为内容工场王牌卖点） |
| Demo 范围 | 做深：驾驶舱 + 私域引擎 + 内容工场；简示：门店后台（库存临期/知识库/培训一屏带过）；不做：多门店对比、排班报表细节 |
| 交付形态 | 自包含单文件 HTML Demo（双击可开、可微信发送）+ 交接说明，沿用产品线惯例含算力积分入口 |

## 9. 案例与数据交叉验证

- **PetPulse**（视频①）：痛点"老板不知道今天推什么、销售不知道跟谁、复购全靠人记" → 印证工作台 + 链路方向
- **16W 案例**（视频②）：AI 宠物短视频引流 + 私域二转已跑通 → 内容工场是门店"看得见"的付费理由
- **美国宠物零售**：到期复购提醒是对抗电商订阅（Chewy 型）的核武器；宠物零售客户终身价值比普通零售高 43%
- **行业面**：3126 亿市场、线上吃掉 67.6% 标品、线下靠洗护/寄养/专业服务立足、"专业 > 便宜"、宠物生命周期（疫苗/驱虫/绝育/老年护理）= 天然触达理由
