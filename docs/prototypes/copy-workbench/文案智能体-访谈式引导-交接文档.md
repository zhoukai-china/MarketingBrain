# 文案智能体 · 访谈式引导填写 — 交接文档

> 交付对象：Trae 工程化
> 版本：v1.0 ｜ 日期：2026-09-22 ｜ 来源：WorkBuddy 原型设计（思潼 AI 增长 OS）
> 配套原型：`文案需求问诊单.html` / `文案需求问诊单_填空版.html`

---

## 0. 一句话任务（直接粘给 Trae）

> 把本文档实现为「文案智能体」的对话流程：用户进入后，智能体**一次只问一个问题**，按第 4 节的逐句话术引导用户填写 7 项信息（含追问与兜底），用户答完后**复述汇总并请其确认**，再把结构化答案（第 2 节 JSON 契约）交给现有内容生成引擎，产出"十件套"。7 项中未填的，按第 5 节分档规则处理。第 6 节验收标准为验收依据。

---

## 1. 背景与目标

**现状问题**：现有文案引擎（`baolu-content-creator` V5）默认是"用户丢一句需求 → 直接输出十件套"。好处是快，坏处是——用户没说清"谁、对谁、要干啥、有啥真实素材"时，出来的是**通用模板稿**，谁用都行，等于没写这个客户。

**本次目标**：新增一个「**访谈式引导模式**」。智能体先通过 7 轮对话把"料"问齐，再出稿。

**双模式并存**：
- **直接模式**（保留）：一句话 → 直接出十件套。
- **引导模式**（本次新增）：逐条访谈 → 答完出十件套。
- **切换规则**：用户明说"直接写/别问了"→ 走直接模式；否则默认进入引导模式。

## 2. 字段定义与数据契约

### 2.1 七个字段

| # | 字段 key | 问题 | 必填级 | 示例答案 | 供给十件套的哪部分 |
|---|----------|------|--------|----------|-------------------|
| 1 | `q1_who` | 谁出镜？本地生意还是全国招商？ | ★必填 | 我本人出镜，做全国招商加盟，餐饮，12 家直营店 | 角色适配 → 口吻 / 投流渠道 / 讲不讲招商 |
| 2 | `q2_goal` | 这条视频想干啥？（可多选） | ★必填 | 主要招商留资，顺便立信任 | 选题策划（漏斗层级）+ 投流主渠道 |
| 3 | `q3_audience` | 说给谁听？啥身份、啥痛点？ | ★必填 | 想加盟的老板，30-45 岁，怕不懂获客、怕被割韭菜 | 选题策划"目标人群" + 钩子角度 |
| 4 | `q4_material` | 最想讲的一个真实素材是啥？ | ★必填 | 一个老客户做 IP 三年只有两条客资，改一个动作后每天 20+ 条，半年开 40 家店 | 口播逐字稿 + 访谈话术的血肉 |
| 5 | `q5_redline` | 有啥绝对不能说的？ | △重要 | 不承诺收益、不用极限词、品牌写"XX" | 评论引导 + 投流合规 + 禁用词 |
| 6 | `q6_region` | 想投哪？单城/多城/全国？ | ○选填 | 全国，重点山东、河南 | 投流建议·投放地域 |
| 7 | `q7_budget` | 投流预算每月多少？ | ○选填 | 每月 5000 左右测试 | 投流建议·预算分配 |

> 必填级说明：**★** 缺了只能出空壳；**△** 不填按通用兜底；**○** 不投流可空。

### 2.2 输出 JSON 契约

```json
{
  "mode": "guided",
  "answers": {
    "q1_who": { "creator": "本人|代运营|团队", "business_type": "本地门店|全国招商|OPC", "industry": "餐饮" },
    "q2_goal": ["招商留资", "立信任"],
    "q3_audience": { "identity": "想加盟的老板", "age": "30-45", "pain_points": ["不会获客", "怕被割韭菜"] },
    "q4_material": { "type": "case|story|data|method", "content": "……具体素材……" },
    "q5_redline": ["不承诺收益", "不用极限词"],
    "q6_region": "全国（重点山东、河南）| 暂不投",
    "q7_budget": "5000元/月 | 暂不投"
  },
  "completeness": { "level": "full|standard|generic", "missing": [] }
}
```

> `completeness.level` 由智能体按第 5 节规则自动计算。生成引擎据此决定输出精度。

## 3. 对话状态机

| 状态 | 智能体动作 | 进入下一状态的条件 |
|------|-----------|-------------------|
| `GREETING` | 说明引导模式 + 征得同意（一次说清 7 个问题、可跳可停） | 用户表示开始 / 未反对 |
| `Q1` | 主问 + 追问 + 打样 | 拿到「出镜人 + 生意类型」两项 |
| `Q2` | 主问（给 A/B/C/D 选项）+ 追问"最想要哪个" | 至少识别到 1 个目标 |
| `Q3` | 主问 + 追问"最头疼啥" | 拿到「人群身份 + ≥1 个痛点」 |
| `Q4` | 主问 + 追问"有具体人/数字吗" + 兜底转换 | 拿到一个**可拍的、足够具体**的素材 |
| `Q5` | 主问 + 兜底默认红线 | 用户给红线，或说"没有"→套默认 |
| `Q6` | 主问 | 拿到地域范围，或"暂不投" |
| `Q7` | 主问 | 拿到预算，或"暂不投" |
| `CONFIRM` | **复述汇总**全部答案，请用户确认/修改 | 用户确认 |
| `GENERATE` | 调内容引擎，产出十件套 | 输出完成 |
| `DONE` | 交付，提示缺项（如有） | — |

**全局异常处理：**
1. **答非所问** → 换句话重问一次 → 还不行 → 给打样让其选。
2. **用户跳过** → 允许，字段留空，按第 5 节兜底。
3. **一次答了多个问题** → 按字段归位，已答的题直接跳过。
4. **用户说"别问了，直接写"** → 中途切「直接模式」，用已收字段出稿。
5. **每题最多追问 2 次**，避免"审问感"。

## 4. 逐句引导话术（智能体实际说的话）

### 开场（GREETING）

> "老板，为了给你写出**真能变现**的文案、不是套模板的空话，我先用 7 个问题把你这条视频的'料'备齐。你答多少算多少，答不上来的我按常规兜底——但答得越具体，文案越像你本人。咱们一条一条来，开始？"

---

### Q1 — 出镜人 + 生意类型

- **【主问】** "第一个问题：这条视频**谁出镜**？你自己上，还是团队/代运营在拍？"
- **【追问】** "另外，你做的是**本地门店生意**，还是**全国招商加盟**？做哪个行业的？"
- **【打样】** "比如这么答：我本人出镜，做全国招商加盟，餐饮行业，现在 12 家直营店。"
- **【完成判据】** 识别到「出镜人」+「本地/招商」+（最好有）行业。
- **【过渡】** "好，记下了。"

### Q2 — 视频目标

- **【主问】** "第二个：这条视频你最想达到啥效果？给你四个选项，可以多选——
  A 让更多人认识你；B 显得你专业、立信任；C 直接带来咨询或成交；D 招加盟商。"
- **【追问】** "如果只能选一个最想要的，选哪个？"
- **【打样】** "比如：主要想招商留资，顺便立信任。"
- **【完成判据】** 至少命中 A/B/C/D 之一（或等价意图）。
- **【过渡】** "明白。"

### Q3 — 目标人群

- **【主问】** "第三个：这条视频是**说给谁听**的？你的客户、或者想加盟的人，大概是啥样的人？多大年纪、干啥的？"
- **【追问】** "他们**最头疼、最怕**的是什么？"
- **【打样】** "比如：想加盟的老板，30-45 岁，自己做过小生意或上班想创业，怕不懂获客、怕被割韭菜。"
- **【完成判据】** 拿到「人群身份」+「≥1 个痛点」。
- **【过渡】** "好。"

### Q4 — 核心素材（最关键）

- **【主问】** "第四个，也是**最关键**的一题：你有没有一个**真实的故事、案例或者数字**想讲？比如某个客户、某家店，之前啥样、后来改了什么、最后结果是啥。"
- **【追问】** "有没有**具体的人和数字**？比如'多少条客资''开了几家店''几个月见效'这种。"
- **【兜底转换】**（用户答不出时）"没关系。那换个角度——这条视频你想**讲个观点**，还是**教观众一个方法**？挑一个也行。"
- **【打样】** "比如：一个老客户做 IP 三年只有两条客资，改了一个动作，现在每天稳定 20+ 条客资，半年新开了 40 家店。"
- **【完成判据】** 拿到一个"**可拍的具体素材**"（案例/故事/数字/方法论任一种，且细节够撑起一条视频）。
- **【过渡】** "这个料很实，够了。"

### Q5 — 合规红线

- **【主问】** "第五个：有没有啥话是**绝对不能说的**？比如不能承诺收益、不能出现'最''第一''稳赚'这类词。你的品牌名、产品，有没有要避开的？"
- **【兜底默认】**（用户说没有）"那行，我就按通用红线来——不承诺收益、不用极限词、评论区不出现'私信/加微信'这类引导词。"
- **【完成判据】** 拿到自定义红线，或确认走默认红线。
- **【过渡】** "收到。"

### Q6 — 投放地域（选填）

- **【主问】** "第六个，如果之后要**投流**，你打算投哪些地方？就一个城市、几个城市，还是全国？"
- **【跳过条件】** 若 Q2 明确是纯拉新/自然流量 → 可问："这条先不投流的话，这题跳过也行，要跳过吗？"
- **【打样】** "比如：全国招商，重点投山东、河南。"
- **【完成判据】** 地域范围，或"暂不投"。

### Q7 — 投放预算（选填）

- **【主问】** "最后一个：如果投流，你一个月大概能拿出多少**预算**？"
- **【打样】** "比如一个月 5000 左右测试。不投的话直接说'暂不投'就行。"
- **【完成判据】** 预算数字，或"暂不投"。

### 收尾（CONFIRM → GENERATE）

- **【汇总复述】** "好，老板，我复述一遍确认下：**[出镜人+生意类型]；想[目标]；说给[人群]，他们最怕[痛点]；素材讲[素材概要]；红线是[红线]；投[地域]，预算[预算]。** 有没有要改的？"
- **【进入生成】** "行，没问题。我现在按你的情况出一整套——选题、口播稿、访谈、拍摄、剪辑、标题、发布时间、评论引导，还有投流建议。稍等。"
- **【缺项提示】**（若有非必填空着）"有[地域/预算]没填，我先按常规给你，之后要投再补。"

## 5. 缺项兜底与分档输出逻辑

智能体在生成前，按已收字段计算 `completeness.level`：

| 已收情况 | level | 输出 | 处理 |
|----------|-------|------|------|
| Q1-Q4 全齐 | `full` | 可直接拍 + 可投流版 | 正常出十件套 |
| Q1-Q4 齐但 Q5-Q7 空 | `standard` | 完整版（投流按常规参数补） | 出稿后提示可补 |
| **缺 Q4**（有 Q1-Q3） | `generic` | 通用模板版 | **先追问一次**："素材没给，文案会偏通用，要不要再补一个真实案例？"；用户坚持 → 照出，并在稿子开头标注"素材待补" |
| 缺 Q1-Q3 中任意一项 | — | **不出稿** | 连调性都定不了，必须追齐 |
| 用户中途切直接模式 | `direct` | 用已收字段出稿 | 缺项按默认值 |

**默认值兜底规则：**
- Q5 空 → 套通用红线（不承诺收益 / 不用极限词 / 评论区禁"私信·加微信·电话·找我·留个"）。
- Q6/Q7 空 → 投流建议给标准参数表，不指定地域与预算。
- 平台/时长不填 → 默认"抖音 + 视频号"、60 秒。

## 6. 验收标准（可测试）

| # | 验收点 | 判据 |
|---|--------|------|
| 1 | 进入即说明并征得同意 | 开场白出现"7 个问题 + 可跳可停 + 越具体越像你" |
| 2 | 一次只问一题 | 不出现一次性甩 7 题 |
| 3 | 每题含追问 | 用户答得含糊时，智能体发起追问 |
| 4 | Q4 有兜底转换 | 用户答不出时，能自动切"讲观点/讲方法" |
| 5 | 每题追问 ≤2 次 | 不无限循环 |
| 6 | 答完复述汇总 | CONFIRM 状态有完整复述 |
| 7 | 缺项按分档处理 | 缺 Q4 先追问再兜底；缺 Q1-Q3 不出稿 |
| 8 | 可中途切直接模式 | 用户说"别问了"能立刻切 |
| 9 | 输出结构正确 | 生成引擎收到第 2.2 节 JSON 契约 |
| 10 | 无违规引导词 | 全程不出现"私信/加微信/电话/找我/留个" |

## 7. 语言风格与红线

- **风格**：大白话、短句、口语、不 AI 腔、不客服腔（参照保禄本人说话方式）。
- **节奏**：一次一题，不连问；给选项降低回答门槛；答完给正反馈（"好""明白""这个料很实"）。
- **红线**：不诱导、不承诺收益、不承诺回本；不出现违规引导词；不出现竞品名称。
- **署名**：若输出文档，标题下与落款统一用「思潼·行业智能体」。

## 8. 附：给 Trae 的补充说明

- 本逻辑**不替代**现有内容生成引擎，只在其前面加一层"访谈采集前置层"。
- 采集结果 → 第 2.2 节 JSON → 注入现有十件套生成流程。
- 「问诊单 HTML」是同一逻辑的**静态呈现版**（客户可离线填），对话流程是它的**交互版**，两者字段必须一致，后续改字段要同步改。
- 建议把第 4 节话术做成**可配置文案**（而非硬编码），方便后续按行业/客户调整语气。
