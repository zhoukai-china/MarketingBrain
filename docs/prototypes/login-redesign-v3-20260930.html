登录页重设计 v3 · 4 套方向

本轮修正：不再出现任何内部数据（价目 / 算力数字）与内部界面截图；不再用会折行的清单。视觉分量改由「图形构成 + 排版」承担——全部是纯 CSS / SVG 绘制。

这次改了什么
  • 去掉了价目数字与产品截图 —— 登录页是对外门面，不暴露内部信息。
  • 去掉了会折行的清单（上一版「选题策略官 · 每日选 / 题」两行确实难看）。
  • 改用 圆弧轨道 / 网点织纹 / 巨大字标 / 抽象层叠 四种纯图形语言撑住版面。
  • 依然不用渐变文字、不用 emoji、不用纯 #fff/#000；橙色只做点睛。
方向 A轨道 · 纸底 + 圆弧构成

暖纸底 + 一组同心圆弧与刻度点，像品牌手册的扉页。衬线标题压住画面，克制、安静、有出身感。

适合：想显得「有专业门槛、稳定可靠」；与内容/出版调性接近。

方向 B织纹 · 深墨 + 网点 + 暖光

近黑暖墨 + 细网点织纹 + 左上角一抹暖光。冷静、精密、有仪器感；没有大色块，只有密度。

适合：想传达「技术可靠、按量计费、可追溯」。

方向 C字标 · 排版主导

以超大字号、紧字距、强对比的排版当主视觉；右下角一枚极简印记。最「设计驱动」，几乎不靠颜色。

适合：品牌自信、想一眼记住；移动端天然好适配。

方向 D层叠 · 抽象纵深

右侧一组微微错角叠放的纸片（纯 CSS 形状，不含任何内容），柔影制造纵深。安静但有体量感。

适合：想暗示「交付物 / 文档」这件事，又不想露真图。

4 套均为静态设计稿（表单不可提交），全部图形由 CSS / SVG 现场绘制。
本版不含任何内部数据（价目 / 算力数字）与内部界面截图；两处硬约束仍保留：带微信版本没有企业/品牌名称输入框、隐私条款始终在。
