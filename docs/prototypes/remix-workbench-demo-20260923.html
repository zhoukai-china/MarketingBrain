🔧 复刻流水线 · 四步把爆款变成你的成片

全程工作台内完成 · 每一步产出都可见可改
① 投喂与解析
  • 抖音链接 / 视频文件 双入口
  • 自动下载原片 → ASR 逐字转写
  • 产出：拆解报告 + 口播逐字稿
② 形象与音色
  • 上传头像 / 半身照 / 全身照 → 训练数字人形象
  • 音色三选：克隆原声风格 / 克隆我的声音 / 平台音色库
  • 形象一次训练，跨任务反复复用
③ 文案与结构
  • 三种复刻深度：像素级 / 结构复刻·文案换血 / 灵感复刻
  • 逐字稿带时间轴，逐段可编辑
  • 保留爆款节奏，替换成你的产品口径
④ 一键合成
  • 数字人口型驱动 + 字幕烧制 + BGM 混音
  • 9:16 竖版 1080P 成片，可下载可重渲
  • 质检：口型同步 / 时长偏差 / 画面规范

💡 设计说明 · 复刻工作台补齐内容生产最后一环

🎬选题、文案都齐了，卡在「拍」

选题工作台给出 10 条可开拍选题，文案工作台给出可照读逐字稿——但老板还是不想面对镜头、不想约拍摄、不想学剪辑。

复刻工作台把「拍出来」也接了：爆款结构 + 数字人形象 = 不出镜、不拍摄、不剪辑，10 分钟拿到能发的成片。

🔗双入口投喂，降低使用门槛

看到好视频，复制链接粘贴进来即可——系统自动解析、转写、拆结构；手里有文件就直接上传，不逼用户「先搞到链接」。

解析结果先出（拆解报告 + 逐字稿），用户确认后续环节——先看到价值，再等待合成。

🧑‍💼形象是资产，复用是复利

形象照一次上传训练，后续所有复刻任务直接选用，不用每次重传；音色克隆同样沉淀为个人资产。

换形象 / 换音色 / 改文案段落 → 局部重渲，不用整条重来。

🔧 工程落地要点 · 给技术合伙人

1️⃣前端

复用文案工作台骨架：/agent/:sku/workbench 路由 + 引导问答 + 简报 + 交付渲染三块结构不变。

新增组件：视频 / 链接投喂、形象照上传与授权勾选、逐字稿时间轴编辑器、成片播放器与下载、形象库选择器。

2️⃣后端 / 第三方能力

链接解析与 ASR 转写可复用 vidrev 智能体既有链路（视频下载 + 语音转写已在生产验证）。

数字人合成是唯一新增的重资产能力：需接第三方合成 API（候选：硅基智能 / 闪剪开放平台 / 即创等，选型见待确认）；建议先出供应商对比与报价再立项。

3️⃣计费与合规

按条计费两段点：解析（低成本）+ 合成（高成本，对应第三方渲染费用）；形象训练建议免费沉淀，合成时收费。

合规三条红线：形象照必须本人授权勾选；成片不复用原片画面素材（只借结构文案）；数字人内容需加AI 生成标识符合平台规范。

❓ 待确认问题（建议合伙人拍板）

1. 数字人合成供应商选型：口型质量、API 稳定性、单条渲染成本、竖版 1080P 支持——建议拿 2-3 家做横向对比再定。

2. 单条定价：解析 + 合成一口价，还是分段计费（提案：解析 10 + 合成 60 积分）？改文案段落局部重渲怎么计费？

3. 形象库与音色库：是否做成租户级资产跨任务复用？音色克隆（需录音授权）第一期是否上线，还是先上平台音色库？

4. 商城上架：新增第 9 个数字员工（提案：能力核 remix，人名建议「唐刻」，头像待生成），上架位置与详情页文案待定。

5. 抖音链接解析的失败兜底：风控 / 地域限制导致下载失败时，是否引导用户改传本地文件（本 demo 已按双入口设计）。
