## 一、这是什么

FDE 专区 6 张卡片的封面配图，替代原 CSS 渐变背景（`.fc-store` 等六色）+ 内联 SVG 线稿图标。

**统一风格**：深蓝底 + 橙色光 + 玻璃质感，与已上线的思潼AI商城（ai.lcppch.top/agents）视觉一致。

## 三、替换步骤（周凯）

1. 在 `fde-industry-expansion-demo-20261001.html` 中，将 6 个卡片容器的背景从 CSS 渐变改为新图：
   - 方案 A（推荐）：`.fc-store / .fc-chain / .fc-logi / .fc-bank / .fc-ins / .fc-ecom` 的 `background` 改为 `url(图片路径) center/cover no-repeat`；保留 `.fc-name` 标题层（已预留左下留白，文字直接压图可读）。
   - 方案 B：在卡片内加一层 `<img class="fc-img" src="...">` 绝对定位铺底，`z-index` 低于 `.fc-name`、高于原 `.fc-svg`（或移除 `.fc-svg`）。
2. 图片路径：随 demo 同源放置（如 `assets/fde-store.jpg` 或直接内联引用本包 `new/` 目录）。
3. 本地浏览器打开 demo 核对 6 张卡片封面与标题压图效果正常。
