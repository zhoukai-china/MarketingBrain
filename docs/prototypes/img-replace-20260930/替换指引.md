## 一、替换清单

页面图片以 base64 内嵌在 JS 对象 `IMG_ASSETS` 中（`palu` 同时是保禄数字分身头像）。把下表 key 对应的 base64 字符串整体替换为新值即可：

|-----|---------|---------|------------|
| palu | 保禄数字分身头像（1:1） | new_jpg/palu.jpg | base64/palu.b64.txt |

| opcComic | AIGC 漫剧创作工作台 | new_jpg/opcComic.jpg | base64/opcComic.b64.txt |

注意：`hwRec` / `hwRobot` / `opcLlm` / `opcComic` 四个 key 在源码里**没有引号**（形如 `hwRec:"/9j/..."`），检索时别漏；`palu` / `courseAgent` / `courseWb` 是带引号的 `"palu":"..."`。

## 二、替换方法（二选一）

方法 A（手工）：在 HTML 里搜 `key":"` 或 `key:"`，把引号内的旧 base64（`/9j/` 开头）整体换成 `base64/<key>.b64.txt` 的内容。

方法 B（脚本）：`python3 replace_imgs.py <页面文件>` —— 本目录附带脚本，自动完成 7 个 key 的查找替换并备份原文件。
