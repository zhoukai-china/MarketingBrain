短视频文案需求问诊单

老板，为了给你写出真能变现的文案（不是套模板的空话），先跟你确认 7 件事。照着每题下面的【参考回复】格式回我，5 分钟填完，我直接出全套：口播脚本 + 拍摄方案 + 剪辑指令 + 标题话题 + 投流建议。

填得越具体，文案越像你的人、越能打

第一步 · 定调（不出就别写）

先搞清楚"谁、对谁、干啥"，角色和主线全在这三步。
1这条视频谁出镜？您本人，还是团队/代运营？
顺便说下：您做的是本地门店生意，还是全国招商加盟？（行业也报一下）
参考回复：我本人出镜，做的是全国招商加盟，餐饮行业，目前有 12 家直营店。/ 或：我不开店，是代运营，帮客户做本地生活账号。
2这条视频主要想达到啥目的？（可多选）
A 让更多人认识你（拉新）｜ B 立信任、显得你专业 ｜ C 直接促成交/留资 ｜ D 招加盟商
参考回复：主要想招商留资（D），顺便立信任（B）。/ 或：纯拉新（A），新号起量阶段。
3说给谁听？你的客户或加盟商大概是啥人？
什么行业、什么身份、年纪、最痛的点是啥？
参考回复：想加盟的老板，30-45 岁，自己做过小生意或上班想创业，痛点是不会获客、怕被割韭菜、怕总部不扶持。

第二步 · 填肉（决定文案质量）

没有真实素材，文案就是空话。这步必须问到具体的人、事、数。
4这条视频你最想讲的一个真实素材是啥？
一个真实案例 / 故事 / 数字 / 结果都行。越具体越好（谁、做了啥、前后对比）。
参考回复：讲我一个老客户：做 IP 三年只有两条客资，后来改了一个动作，现在每天稳定 20+ 条客资，半年新开 40 家店。/ 或：教知识，讲"门店获客三道门"的方法论。
5有啥绝对不能说的？红线先锁死。
比如不能承诺收益、不能用"最/第一/稳赚"这类词；品牌名、产品有啥要避开的？
参考回复：不能承诺收益，不用极限词，品牌名写"XX"就行，别提竞品名字，招商不写具体回本周期。

第三步 · 投放闭环（不投可空）

只有内容定稿且要走投流才填这两题。
6如果想投流，想投哪？单城 / 多城 / 全国？
招商类一般投全国，本地门店投周边 3-5 公里。
参考回复：全国招商，投全国，但重点看山东、河南、河北。/ 或：本地门店，投门店周边 5 公里。
7投流预算大概每月多少？（不投写"暂不投"）
先给个上限，我按内容类型排分配。
参考回复：每月 5000 左右测试。/ 或：暂不投，先把自然流量跑起来。
