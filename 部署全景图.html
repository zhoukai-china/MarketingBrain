思潼 AI 增长 OS v2 · 部署全景图

同一份源码靠 VITE_BASE_PATH 打出多套包；两大环境（生产 / 内测）共用同一台机器、同一个 PostgreSQL 实例，仅用 schema 隔离

先记住两件事（这是你之前绕晕的根）：
① ai.lcppch.top/os-v2/ 和 api.lcppch.top/ 是「同一套前端包 + 同一个后端」——nginx 都指向 /opt/baolu-os-v2/apps/web/dist 这同一份文件，API 都反代到 :3002 同一个 node 进程。区别只是 api 域还多了几条指向 :3001 的老路由（已挂起）。
② 生产库和内测库不是两台机器，是同一库的两个 schema：PostgreSQL 只有一个实例、一个业务库 baolu_os_v2，生产用 public schema、内测用 lanqi_test schema。（修正上次图写的"独立库"，那是错误的）

两区怎么分：
🔵 生产（蓝框）= 真实客户。入口：ai.lcppch.top/（新平台根）、ai.lcppch.top/os-v2/（老路径）、api.lcppch.top/（旧前端域）。后端 :3002 共用。
🟢 内测（绿框）= 随便折腾。入口：api.lcppch.top/lanqi-test/（免登录）、api.lcppch.top/sitong-test/。后端 :3010 独立进程但连同一个库的另一 schema。
入口 URL nginx 路由 前端静态包 后端 / 微服务 数据库 挂起 / 隔离 ⚠ 同一套包
