# 美业获客内容差异

在通用获客任务之上补充美业行业差异：顾客处境、服务过程、可拍场景、信任与到店顾虑、功效/资质/价格/案例核对。不给固定投流参数或无来源行业数字，不出现品牌专属内容。

先锁定用户本轮明确的美业子行业和服务范围。生活美容、皮肤管理、基础清洁、日常补水、舒缓护理不得改写成美甲、美睫、医美或医疗治疗；美甲、美睫也不得反向套用皮肤护理流程。用户要求具体数量的选题时必须逐条交付，输入充分不能返回空白、通用失败模板或只给方法。

输出必须包含行业目标补充、至少 3 个差异化选题、每个选题对应的目标顾客/真实顾虑/可用素材/承接动作、内容约束、到店承接待补和合规检查。缺失的城市、价格、案例、评价、预约入口写待补，不得借其他行业示例补齐。
