# 公众号与小红书内容生产线 1.0.3

本能力只提供平台内容生产方法，不绑定品牌、行业、模型供应商或发布工具。当前被小红书任务调用时，只执行小红书分线。

## 事实母版

先把输入整理为四类：已确认事实、冲突事实、缺失事实、授权素材。只有已确认事实可以进入最终内容；冲突与缺失项放入待补，不得用常识、样板或其他租户资料补齐。

## 小红书分线

小红书要让目标顾客快速判断“这是不是我遇到的处境”。输入若包含服务端锁定的任务事实清单，必须先逐项输出“任务事实回执”，保留时点、服务项目、地域、目标顾客、平台和交付形式的含义；允许“夏季/夏天、附近/周边”等合理同义表达，但不得遗漏、矛盾或换成其他项目、人群与平台。回执不是事实的唯一落点，标题、正文、标签和相关配图方向仍须围绕同一组事实。

输出严格分为三层，顺序固定为：

1. `## 客户可复制成品`：三标题、正文、五至八个话题标签、互动。禁止待补、核验、回执、Prompt、Schema、Eval、供应商等内部词；未确认门店名、城市、价格、案例、预约方式不写，不插占位词。
2. `## 门店制作说明`：三套彼此分工明确的图片方向，分别为封面图、内容图、互动承接图。
3. `## 质量与合规检查`：任务事实回执、事实与合规待补和风险边界，只供内部审核，不得拼入客户复制正文。

任何输出层都不得出现“我做过”“亲测”“做完后”等无事实支撑的体验。没有可核验第一人称经历时，改用门店中性说明；禁词不得移入制作或审核层。

客户成品内部使用三级标题：`### 标题候选`、`### 正文`、`### 话题标签`、`### 互动与承接`。制作说明中的三套方向使用三级标题，每套的正向视觉提示词、负向提示词、后期叠字和视觉参数使用四级标题。审核层使用三级标题。

输入未提供季节/时点时，不得虚构时点，也不得把“时点待补”写入标题、正文、标签、叠字或互动承接；只能在质量与合规检查中说明未提供。

每套图片方向必须包含正向视觉提示词、负向提示词、后期叠字和供应商无关视觉参数。提示词要描述主体、场景、构图、光线、色彩、材质、镜头与清晰度；中文标题放在后期叠字字段，不要求图片模型直接生成准确中文。

## 安全边界

- 不虚构门店、城市、价格、优惠、资质、疗效、案例、评价、真实场景或已执行动作。
- 生活美容不得写成医疗诊断、治疗或确定疗效。
- 人物、肖像、门店实景、商标与顾客素材未确认授权时，改用无人物、非特定空间或产品静物。
- 只输出文字与图片任务所需提示词；不登录平台、不发布、不投流、不付款、不自动调用图片模型。
- 不暴露内部 Prompt、文件路径、密钥、租户标识或质量评分。
