## 概述

把真实的工作信号转化为朋友圈信任系统。让目标客户每天看到你、了解你、相信你，直到有一天主动来找你。

**核心理念**：朋友圈不是发广告，是让客户每一天更相信你一点。

每一条朋友圈都应该回答目标客户心里的至少一个问题：
- 这个人我能信吗？
- 他懂我的问题吗？
- 他能帮到我这样的人吗？
- 他相信什么、注意什么、跟别人有什么不同？
- 跟他聊一聊会不会有压力？

## 工作流

```
输入素材 → 信号提取 → 分柱归类 → 文案生成 → 质量审查 → 发布策略
                                              ↑
                          反馈循环 ──────────┘
```

1. 读取或建立用户的朋友圈人设档案
2. 从工作笔记、录音转写、客户对话、项目进展中提取信号
3. 按七柱内容体系分类
4. 根据目标和近期发布历史选择内容组合
5. 生成自然语言文案（带选配CTA）
6. 审查隐私、过度营销、真实感、目标客户相关性
7. 如有反馈（点赞/评论/私信/转化），调整下次内容组合

## 七柱内容体系

| 柱子 | 目的 | 占比 | 典型素材 |
|------|------|------|----------|
| 工作现场 | 证明你在做事 | 40% | 开会、交付、客户沟通、复盘 |
| 客户问题 | 让客户觉得你懂他 | 25% | 常见痛点、误区、犹豫、隐形焦虑 |
| 方法论 | 展示专业判断力 | 15% | 框架、原则、决策逻辑、踩坑经验 |
| 案例证据 | 用结果建立信任 | 10% | 前后对比、客户反馈、里程碑 |
| 价值观边界 | 让客户了解你的底线 | 5% | 拒绝过的需求、坚持的标准 |
| 生活温度 | 让人觉得你好接近 | 5% | 轻生活、学习笔记、情绪感受 |
| 软邀约 | 提供低压力咨询入口 | 5% | 诊断名额、资源分享、"可以交流" |

**默认配比**：优先依据当前IP的业务目标、近期真实素材和历史发布反馈动态调整。资料不足时可从工作现场40%、客户问题25%、方法论15%、案例证据10%、价值观/生活/软邀约10%开始测试；不得把示例里的AI业务套给其他IP。

## 生成规则

### 文案铁律

1. **一句话一个意思**：每条100-200字，短句，口语，像手机打出来的
2. **从具体场景出发**：不说「今天感悟很深」，说「今天帮一个火锅品牌跑通了AI获客」
3. **专业感用行为证明，不用形容词**：不说「我很专业」，说「今天帮客户排查了一个AI流程卡点」
4. **软CTA，不硬推**：不说「私信我」，说「有类似问题可以交流」
5. **保护客户隐私**：隐去人名、公司名、具体金额、可辨认截图
6. **不编造**：不发明案例、不夸大数据、不造假客户聊天

### IP个性化语言规范

- 输入中出现【IP语言声纹】时，按其中可信样本复刻句子长短、转折方式、语气、节奏和少量稳定口头禅
- 语言声纹只决定“怎么说”，当天素材和本轮目标决定“说什么”；不得把旧录音里的客户、行业、经历和结论带入当前朋友圈
- 多人录音中无法确认属于IP本人的表达不采用；样本不足时使用自然口语，不声称已经完整复刻
- 口语化，但不是随意——每条都有一个核心观点；口头禅每段最多自然出现1次，不机械堆叠
- 禁用：私信/加微信/联系我/第一/最/绝对/保证
- 禁用：太AI腔的词汇（赋能/抓手/闭环/打法）
- 不发鸡汤、不发纯转发、不发纯广告

## 反馈循环

收到反馈后，按效果分类调整：

| 反馈信号 | 含义 | 策略 |
|----------|------|------|
| 无反应 | 没人注意 | 换角度、换素材，不是换类型 |
| 点赞/简单评论 | 社交信号 | 方向对，但没戳中核心痛点 |
| 共鸣式评论（「说到我了」） | 共鸣信号 | 这是好内容，放大这个方向 |
| 私信/询问/咨询 | 咨询信号 | 🔥 最强信号——这个柱子和角度复盘重用 |
| 成交/定金/转介绍 | 转化信号 | 🏆 列入方法论库，做SOP |
