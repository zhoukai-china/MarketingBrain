# WorkBuddy 样板库：内容十件套 / 拍剪优化

## 输入样例 A：内容十件套
我是杭州做中医体质调理的，主推 199 元初筛体验，想吸引 30-45 岁长期熬夜、湿气重、睡不好的女性，发小红书和抖音，目标是私信预约。

## 样板输出骨架 A
短结论：不要拍“中医调理多专业”，要拍“熬夜后身体给你的三个信号”。目标不是科普热闹，而是让用户私信做初筛。

选题：给 3 个选题，每个包含标题、用户痛点、开头钩子、转化入口。

可直接发布的文案：写成用户能看懂的生活场景，避免夸大疗效；结尾引导“私信发你初筛表”。

访谈话术：按一问一答补充顾客决策问题；访谈对象、经历、疗效与案例未确认时必须待补，不得伪造采访。

可直接拍摄的脚本：按镜头1-4写，每个镜头包含画面、口播、字幕。

拍摄注意事项：包括光线、服化道、证据素材、不能说的夸大词。

剪辑EDL：按 0-3 秒、3-8 秒、8-15 秒、15-25 秒拆时间线。

发布标题话题、发布时间、评论区引导话术、投流建议：必须给可复制文本和复盘指标。

## 输入样例 B：拍剪优化
我上传了一条门店探店视频，想发抖音，画面有环境、产品、老板口播，但是节奏慢，想让附近客户私信预约。

## 样板输出骨架 B
短结论：这条不要重新写内容十件套，先把“开头留人、画面证据、转化入口”改顺。

镜头结构：按保留、删掉、补拍三类给建议。

分镜优化表：镜头顺序 / 画面内容 / 字幕 / 口播 / 时长 / 目的。

剪辑EDL：必须给秒级时间线，标明哪里加速、哪里切特写、哪里放转化字幕。

发布前检查：封面标题、首屏字幕、评论置顶、私信入口、复盘指标。

## 评分标准
- 场景命中：内容十件套就输出十件套；拍剪优化就输出镜头结构和 EDL，不互相串。
- 事实保真：用户没说城市、价格、疗效、数据，就不编。
- 老板可用：文案能复制，镜头能拍，剪辑师能照 EDL 剪。

## 失败案例
- 用户点拍剪优化，却输出“完整内容执行包”。
- 只有原则：“提升节奏、突出卖点”，没有镜头、字幕、秒级剪辑。
- 把样板里的行业、城市、价格照搬给新用户。

## IP语言声纹适配样例

输入附带语言声纹：本人常说“我跟你说”“你看”，习惯用“不是……而是……”做观点转折。本轮要求是替一家连锁美业客户写招商口播。

合格表达：“我跟你说，加盟这件事，不是先听对方讲多少支持，而是先看这套门店模型有没有真实样板。你看三个地方……”

边界：可以借用句式和少量口头禅；不能把IP自己的AI业务、旧客户和旧录音结论写进美业客户的招商内容。
