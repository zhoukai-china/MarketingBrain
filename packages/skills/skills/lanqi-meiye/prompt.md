# 兰琪（蓝琪）美业专属方法论

> **边界说明**：本 skill 只放**兰琪这一家问题肌美业品牌**的独有实战打法，来自保禄 2026-08-03 至 08-06 的录音，是服务兰琪过程中沉淀的具体数据和方法，**不是美业通用方法论**。通用获客/成交/门店/服务见对应 `meiye-*` skill。兰琪的方法论会随保禄服务推进持续更新。

## 一、兰琪获客（三网获客 + 一元引流 + 9.9 团购）

### 1.1 三网获客框架

| 网 | 渠道 | 打法 |
|----|------|------|
| **天网**（线上） | 抖音团购 + 小红书种草 + 点评搜索 | 引流款 + 内容 + 好评排名 |
| **地网**（线下） | 门口低价拓客 + 异业联盟 + 社区地推 | 门口小推车 1 元拓客、周边商户互导 |
| **人网**（裂变） | 老带新 + 转介绍 + 会员裂变 | 带新客送产品、闺蜜卡、转介绍激励 |

### 1.2 一元地网拓客（门口截流）

门店门口放小推车，针对**带孩子的妈妈**：

| 步骤 | 动作 |
|------|------|
| 1 | 扫码付 **1 元**送小礼品（吸引停下） |
| 2 | 扫码进群送价值 **98 元**的水（进群沉淀） |
| 3 | 付 1 元领 **800 元**体验卡（到店钩子） |

**效果**：一个月积累 **500 个顾客**。

### 1.3 9.9 天网团购（抖音冲量 + 好评）

引导顾客团购 **9.9 元体验** + 写好评 → 一个月做到抖音评分 **4.7 分**、**120 个好评**，成为商圈「好评 + 人气」**双第一**，之后靠抖音自然流量持续获客。

### 1.4 头脸组合项目

兰琪创新推出的「**头脸**」组合项目（洗头 / 补水 / 艾灸），性价比高、决策成本低、自带流量——作为通用引流款。

### 1.5 裂变

- 带新客送**水乳霜、精华、眼霜**等礼品，**60% 以上**新客会进群，最高单个顾客能邀请**七八十人**进群。
- 老客带新客到店送产品、免费用项目。

### 1.6 获客成本投产（兰琪实战数据）

| 场景 | 数据 |
|------|------|
| 抖音投流（祛痘） | 一天 300 元获 13 个咨询，单个成本约 23 元 |
| 引流成交率 | 标准化接待流程下，成交率可达 50% |
| 客单价 | 980–990 元 |
| 前端拓客 | 亏钱拉新，**二转（高阶项目）盈利** |

## 二、兰琪成交（产销分离 + 365 会员 + 中台技师）

### 2.1 产销分离（服务与销售分工）

- **服务的美容师不做销售，专门的销售负责成交**——弱化美容师销售压力，成交率更高。
- 标准配置：**7 张美容床 + 7 个美容师**（服务）+ 专职销售（成交）。
- **顾问式成交**：先解决客户具体问题（获客），客户认可后再推高阶项目（盈利）。前端低价获客，后端高阶项目赚回来。

### 2.2 365 元年费会员

**365 元年费会员**（类似山姆会员店）：每次到店仅 **9.9 元**（5 元为美容师手工费，剩余覆盖产品成本），核心目的是**引流 + 转化高阶卡项**（3000 / 6900 元）。

### 2.3 中台技师专场成交（连锁模式）

连锁采用「中台技师专场成交」：**店主负责引流到店，品牌方中台技师团队全国巡回集中成交**——当店主积累够 298 元体验客后，技师上门做集中转化。

### 2.4 成交模型

低价引流项目到店后，**免费给顾客升级为符合皮肤状态的高阶项目，用王牌项目成交**——留客率比直接用引流项目成交更高。

## 三、兰琪门店（7 床 7 师单店模型）

- **7 张美容床 + 7 个美容师**（服务）+ 专职销售（成交），产销分离。
- 单店月业绩可达**十几万**，7 床 7 师是单店产能的合理上限（再多接待能力就饱和了）。
- 用**小型仪器替代人工手法**，避免不同美容师手法差异带来的效果不稳定。

| 加盟等级 | 定价 | 定位 |
|---------|------|------|
| 技术培训 | 9800 元 | 仅学习技术 |
| 店中店 | 10000 元 | 导入院线项目技术 |
