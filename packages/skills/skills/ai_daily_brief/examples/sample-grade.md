# Codex 正式样板库：行业热点获客

> 来源：仓库正式 `ai_daily_brief@1.0.0` 的脱敏样板；不依赖 WorkBuddy 候选原件。

## 用户输入：

我是做少儿口才培训的，想知道近期有什么行业热点能转成短视频和朋友圈。

## 样板输出：

短结论

少儿口才近期不要蹭泛教育新闻，要蹭家长正在问的真实问题：孩子不敢表达、上台紧张、开学适应、面试表达、亲子沟通。

公开实时数据待补。建议用这些关键词验证：少儿口才 家长 焦虑、孩子 不敢表达、开学 表达能力、儿童 面试 表达。

一、行业热点速览

热点1：孩子会背稿，但一到陌生场合就不敢说。

热点2：开学后老师反馈孩子表达不主动。

热点3：家长开始比较口才课到底是不是智商税。

二、热点来源/线索

当前没有用户提供截图、链接或平台热榜，所以不编造具体排名。

可验证线索：
小红书搜“孩子不敢表达”。
抖音搜“少儿口才有没有用”。
微信搜“开学表达能力”。

三、热点判断

适合蹭的是家长已经在焦虑的问题。

不适合蹭的是和报名无关的泛教育争议。

四、IP获客机会

老板不要讲“我们课程多专业”，要讲“什么孩子适合练表达，什么孩子先不用报课”。

五、可蹭选题

选题1：孩子不是不会说，是一到陌生场合就卡住。

开头：如果你家孩子在家话很多，一上台就不说话，先别急着批评。

转化入口：评论区发孩子年龄，我帮你判断先练表达还是先练胆量。

六、短视频切入

开头3秒：
“孩子不敢表达，不一定是胆小。”

主体：
讲三个判断点：敢不敢看人、能不能说完整句、遇到陌生人会不会沉默。

结尾：
让家长把孩子年龄和表现发私信。

七、朋友圈切入

最近很多家长问我，孩子不敢上台是不是一定要报口才课。

我的判断不是先看课程，而是先看孩子卡在哪一步。

有的孩子是胆量问题，有的是表达结构问题，还有的是不习惯陌生场合。

想先判断的，可以把孩子年龄和最近一次不敢表达的场景发我。

八、直播切入

直播主题：
孩子不敢表达，家长先别急着报班，先看三个判断点。

开场问题：
你家孩子是在家能说，还是在哪都不愿意说？

互动方式：
评论区打年龄，我按年龄段讲训练重点。

九、风险提醒

不要承诺几节课变自信。

不要制造家长焦虑。

不要编造升学政策和学校要求。

十、今日动作

今天先发一条短视频。

下午发一条朋友圈。

晚上统计评论区和私信里家长问得最多的 3 个问题，明天继续拍。
