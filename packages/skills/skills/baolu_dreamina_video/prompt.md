## 完整方法论：Prompt写法与质量提升技巧

> ⚠️ 好prompt不是"说好看就好看"。Seedance 2.0支持结构化控制——镜头、运镜、时间线、节奏，用对了能拍电影级画面。

### Seedance 2.0 结构化Prompt公式

```
[风格定义] + [场景描述] + [镜头/运镜] + [时间线] + [画面细节] + [约束条件]
```

**六个要素缺一不可**：

| 要素 | 作用 | 示例 |
|------|------|------|
| **风格** | 定调，写在最前面 | "电影级品牌概念视频"、"人文纪录片风格"、"美食广告质感" |
| **场景** | 描述画面内容 | "沸腾的重庆火锅，红油翻滚，热气升腾" |
| **镜头/运镜** | 控制画面动态 | "微距特写、慢推镜头、固定机位、手持跟拍、俯拍" |
| **时间线** | 精确控制节奏 | "0～3秒：火锅沸腾特写；4～8秒：筷子夹起毛肚慢动作" |
| **细节** | 画质/光影/质感的精确描述 | "浅景深、金色侧光打在食材表面、水珠凝结、4K画质" |
| **约束** | 告诉AI不要什么 | "无人物出镜、无字幕、无LOGO、人物比例符合现实" |

---

### 提升画质的关键技巧

#### 1. 用专业镜头语言替代形容词
```
❌ "画面好看" 
✅ "微距特写，浅景深f2.8，金色侧光，前景虚化，商品位于画面黄金分割点"
```

#### 2. 时间线分段控制节奏
```
✅ "0～3秒：静止特写；3～8秒：慢推镜头靠近；8～10秒：突然加速，产品出场"
```

#### 3. 用具体运镜替代笼统描述
```
❌ "镜头移动"  
✅ "稳定器低角度跟拍，从左向右缓慢摇移，速度均匀"
```

#### 4. 叠加质感关键词
```
✅ 食物："油光质感、蒸汽升腾、酱汁滴落慢动作"
✅ 空间："空气中有微尘漂浮、光斑轻轻晃动、柔光穿透薄纱"
✅ 产品："玻璃瓶身水珠凝结、金属表面冷光反射、皮革纹理微距"
```

#### 5. 用负向约束控制翻车
```
✅ "无人物出镜、无字幕、无品牌LOGO、运镜速度均匀不卡顿、人物比例符合现实"
```

### 生成策略：多版本筛选

**一次生成多条，选最好的一条，才是保障质量的正确做法。**

| 策略 | 做法 | 适用场景 |
|------|------|----------|
| **同prompt多刷** | 同一个prompt生成3次，选画面最自然的 | 场景简单、变量少时 |
| **变体A/B测试** | 同一场景，改运镜方式（微距vs广角、慢推vs固定）各生成1次 | 不确定哪种镜头语言更好时 |
| **分段生成** | 复杂视频拆成多个5秒片段分别生成，后期拼接 | 多场景、长视频 |
| **图生视频** | 先用Midjourney/即梦文生图出高质量静帧，再拿这张图去生成视频 | 对画面精度要求极高时 |

> ⚠️ **默认行为**：生成视频时至少同prompt跑2次，给用户选最佳版本。不指望一次成功。

### Prompt生成的Checklist

每条prompt发出前自查：

```
□ 风格写在最前面了吗？（电影级/广告质感/纪录片）
□ 有具体的镜头描述吗？（微距/推拉/跟拍/俯拍）不只是"好看"
□ 时间线分段了吗？（复杂场景用0～X秒标记）
□ 有质感关键词吗？（水珠/光斑/蒸汽/纹理/反光）
□ 有约束条件吗？（无人物/无字幕/无LOGO）
□ 单条prompt场景不超过3个吗？（超过就拆成多条）
```
