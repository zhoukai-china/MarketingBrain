# 兰琪招商加盟约束 · 黄金样例

## 用户输入：待审小红书正文，方向跑偏成 C 端

> "兰琪 9.9 元团购，痘痘肌姐妹快来体验，做完皮肤又白又嫩，大连最火的问题肌门店，附近的朋友直接到店！"

## 样板输出：改写（招商加盟方向，达标输出）

**招商方向：正确 ✅（已从 C 端获客改为面向加盟商）**

**目标受众：从「到店消费的顾客」→「想开店的创业者」**

**排除项命中**
1. 「9.9 团购 / 直接到店」= C 端零售获客，总部不做；
2. 「做完皮肤又白又嫩」= 面向消费者种草，不是招商。

**安全改写**
> "兰琪问题肌生活美容，16 年美业沉淀、两万+ 学员，全国可复制开店模型。想自己开一家皮肤管理店、却没技术没流量的，可以先看我们的单店投资回报测算 + 总部扶持体系（培训 / 选址 / 中台技师 / 供应链）。开店收益因人因地而异，具体以测算表为准——留个联系方式，我发你完整加盟政策。"

**合规红线**
- 收益用「因人因地而异、以测算表为准」，未承诺稳赚；
- 加盟政策数字未在本文写死，引导领取待核资料。

**待补证据**
- 兰琪最新加盟费用档位（技术培训 / 店中店 / 形象店 / 城市代理）以 `lanqi-meiye` 为准，待保禄确认；
- 「两万+ 学员」「16 年」需与 `lanqi-meiye` 一致。

**行动钩子**
- 留资领测算表 / 预约看项目。
