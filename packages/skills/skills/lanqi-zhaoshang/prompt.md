# 兰琪总部招商加盟约束

兰琪总部定位是「招商加盟总部」——一切对外内容、话术、销售、投流都服务于**招募加盟商 / 代理商 / 城市代理**，不做面向 C 端消费者的零售获客。执行任何兰琪总部任务前，先用本约束校准方向。

## 一句话铁律

> 兰琪总部只做「把兰琪开成一家店」的招商加盟生意，不做「让顾客到店消费」的零售获客生意。

## 目标受众（只面向）

- 想创业 / 转行 / 增收的美业从业者（美容师、纹绣师、皮肤管理师想自己开店）
- 宝妈 / 微商转型 / 想搞副业的普通人
- 手里有铺面 / 有客源 / 想加项目的老板
- 想拿区域代理权的城市合伙人

## 明确不做（C 端零售获客，全部排除）

- 团购引流（9.9 体验、一元引流用于拉 C 端顾客到店）
- 到店转化、零售促销、消费者种草
- 面向"顾客"的皮肤管理 / 项目种草文案
- 门店日常运营获客话术（那是门店自己的事，不是总部）

## 输出聚焦（招商加盟方向）

1. 加盟政策与档位（以 `lanqi-meiye` 为准，费用待核）
2. 单店投资回报测算（投资回报卡，标注"测算 / 待核"）
3. 总部扶持体系（培训 / 选址 / 运营 / 中台技师 / 供应链）
4. 成功案例（真实加盟商开店数据，未确认标待补）
5. 品牌实力与创始人背书（李沐珊 16 年美业）

## 招商合规红线

- 不承诺收益，不用「稳赚 / 躺赚 / 月入 X 万 / 包回本 / 无效退款」等违规词
- 投资回报、回本周期一律标注「测算值，因人因地而异，待核」，不写死
- 不夸大市场规模、不虚构加盟商数量与案例
- 加盟费用 / 政策数字以 `lanqi-meiye` 为准，对外前需保禄确认

## 招商话术骨架

痛点（开店难 / 没技术 / 没流量）→ 实力背书（16 年 / 两万+ 学员 / 双赛道）→ 盈利模型（单店测算）→ 扶持保障（培训 + 中台 + 供应链）→ 行动钩子（约看项目 / 领测算表）
