## 一、核心认知（先统一认知再谈方法）[·1912419525 ·1911215243 ·1912420527]

1. **AI不是工具，是重构企业工作流**——嵌入工作流后降本增效、重构增收（课程原话："AI不是工具，是载体；真正值钱的是你自己的方法论"）。
2. **AI不是降本，是增收**：中小企业最大痛是流量不够、转化不行，AI先解决增收（同 `knowledge-base.md` 第一章）。
3. **AI时代三层级**（不可混淆）：知识层（会被替代）→ 解决问题层（半替代）→ 体系层（不可替代，保禄价值在这层）。
4. **国家叙事（说服用）**：国务院要求2027年70%企业完成AI化，晚做一天多落后一天；没完成AI改造的企业会被淘汰。[·1912419525]
5. **最大敌人是拖延**：AI改造最大阻力不是技术，是"等想清楚再动"。培训后当晚一对一梳理优先改造板块，先动起来。

## 二、AI改造三步骤（保禄方法论骨架）[·1912419525 ·1911215243]

| 步骤 | 做什么 | 关键判断 | 常见坑 |
|------|--------|----------|--------|
| **诊断** | 找企业"重复最多、对成本利润影响最大"的板块，优先改造 | 不All in全板块，先切一个ROI最高的场景跑通 | 一上来想全面AI化，贪多嚼不烂 |
| **蒸馏** | 把企业最优经验提炼成"可描述的方法论"，把隐性经验显性化 | 能写清楚SOP的经验才值得蒸馏 | 只买工具不沉淀方法论，等于没改造 |
| **交付** | 方法论交给AI做成**专属技能（skill）**——skill本质=个人工作方法论的SOP封装 | 训练后确认输出达标，再封装存储到自有服务器 | 直接套通用AI，不贴合自己业务 |

> 企业AI化改造五步法（更细版）：诊断 → 内容化（选题/脚本/剪辑）→ 销售化（话术/跟进/成交）→ 交付化（SOP/培训/质检）→ 迭代化（数据驱动）。[·knowledge-base.md 第八章]

## 三、落地场景（用户最常问"AI能帮我干什么"）

### 场景1 · 内容场景（AI重构内容生产全流程）[·1905850400 ·1911045959 ·1907328207 ·1911939773]
- **闭环**：选题 → 文案 → 脚本 → 视频制作 → 数据复盘 → 持续迭代。
- **自动工作流（已跑通验证）**：Get笔记长期录制创始人日常工作语料 → API打通龙虾AI，定时任务每天抓取 → 自动生成短视频选题、文案、朋友圈图文 → 定时推送到微信 → 老板只做审核和发布。[·1905850400]
- **三层AI工作流（内容重构）**[·1911045959]：
  - 第一层：喂入客户日常录音→AI学习口吻→输出符合人设的内容（解决"没灵魂"）
  - 第二层：注入流量专业数据→AI理解算法逻辑→输出符合流量规则的内容（解决"没流量"）
  - 第三层：持续迭代调试→同一套提示词不同客户效果不同→人工介入校准
- **四维度选题（自动化）**[·1911939773]：工作日常抓取 + 行业热点蹭流量 + 同行爆款改编 + 历史数据复盘优化，四个维度都可设AI自动完成。
- **内容四类（一条视频直接获客）**[·1907328207]：流量型（刷到你）/人设型（信任）/专业型（认可专业）/营销型（引导咨询），一条同时含四类元素即直接获客。
- **分工铁律**：AI干重复性活（选题/文案/整理），人干把关判断的活。AI做重复活、人做判断，是AI时代内容生产最优分工。[·1905850400]
- **效率数据（框架，不报死数）**：团队人力成本优化——原来做IP至少两人，现在一个IP助理即可，一年至少省十万人力成本；IP本人有时间甚至能搞定全部。[·1907328207]
- **文案生成方法（教学）**：确定选题后让模型按"吸引人开头+核心观点+结尾钩子"结构生成；只教客户提要求的方法，不堆技术。[·1905850400]

### 场景2 · 销售场景（销冠能力复制）[·1912419525 ·1917723677 ·1911939773]
- **模型**：一个人出单 → 提取销冠话术逻辑 → 灌入智能体 → 所有人用销冠方式跟客户聊。[·1912419525]
- **解决痛点**：一个公司就1-2个销冠，他走能力就走，他忙别人等。智能体不是替代销冠，是把销冠能力复制给所有人。[·1912419525]
- **具体能力**：输入客户聊天记录 → 提取客户画像、诊断意向抗力、给评级 → 输出2-3条可直接使用的话术 + 下一步跟单SOP；还能"激活死客"——输入聊死的对话给激活方案。[·1912419525]
- **复制什么**：成交话术、成交SOP、异议处理能力（先梳理销冠工作流）。[·1911939773]
- **企微打通**：AI自动读客户消息给分风格话术建议，销售点发送即可；企业可直接在企微端用。[·1911939773]

### 场景3 · 交付场景（分身替专业岗答疑）[·1912419525 ·1911320446]
- **痛点**：交付老师答不上客户专业问题，以前等老板回消息，现在问AI分身3秒拿专业答案。[·1912419525]
- **一句话**："以前等老板回消息，现在3秒拿到答案。" 标准化问题AI答，人只处理特殊问题，降低对个人的依赖。[·1912419525]

### 场景4 · 老板数字分身（压轴大招）[·1912419525 ·1913599680 ·1911199089 ·1916410666]
- **是什么**：克隆的是你的**思维逻辑、语言风格、价值观**，不是数字人（数字人只是个壳子）。[·1912419525]

### 场景5 · 管理场景（CEO驾驶舱 / 团队管理）[·1917060015150265616 ·1918075840]（全量扫描新增）
- **CEO驾驶舱**[·1917060015150265616]：一块屏同时监控真人员工 + 数字人员工；看各部门（销售/客户成功/客户经理）在做什么；点部门→看员工→点员工→看单个客户跟进细节；一键还原跟进全流程，销售甩锅没用。
- **管理赋能（美业定制案例）**[·1918075840]：销售每人配AI后，所有通话沟通自动同步总部后台，AI自动总结每个客户跟进进度（不需销售手动汇报），并基于沟通内容自动生成跟进话术直接发给销售。
- **决策克隆（真实案例）**[·1918075840 ·1913599680]：把创始人决策逻辑训给AI；演示案例——10万元达人推广预算申请，克隆体给出"不批"，拆解花费占比/决策优先级，修改方案：砍掉达人预算换自制内容+自运营+本地推，分三阶段测试绑定转化目标，两周后复盘再决策，与真人逻辑完全一致。

## 五、决策铁律（AI化版）[·1912419525 ·1913599680 ·1916410666]

- **50%概率铁律**：思维克隆体现场演示——客户花100万谈区域合作，成功率仅25%→明确"不接"并给核心理由。企业经营本就是在不确定信息下决策；信息超过50%概率就干，低于就不干。[·1912419525 ·1913599680]
- **思维克隆体 vs 数字分身**：思维克隆体=复制本人思考决策逻辑，按本人方式做决策（两年前做一个要10万，现在很便宜）。能帮老板省大量时间：营销方案先让克隆体审、多项目先让克隆体分析、部门对接会先让两个克隆体沟通再给老板。[·1912419525]
- **快速决策快速修正**：概率>50%即行动，不等到100%；先做出来看效果再修正。[·knowledge-base.md 第二十二章]

## 六、工具选型原则（不堆技术，讲适配）[·1912594470 ·1913599680 ·knowledge-base.md 第十九章]

- **总原则**：不追求最好，追求最合适；先跑通一个场景再看工具；免费工具先跑通再付费。[·knowledge-base.md]
- **推荐矩阵**：内容创作（豆包/Kimi/Claude长文深度）；短视频（剪映AI/HeyGen数字人）；私域（企微+AI客服）；全栈（WorkBuddy）；自动化内容（龙虾AI·腾讯出品·沙箱安全）；可操作电脑的AI工具（给大模型加"手脚"，能力边界远大于仅输出文案的模型）。[·1912594470]
- **模型成本**：不同大模型价格不同，越贵能力越强；日常用性价比高的国产模型（如deepseek）就够，只有深度开发才需更贵模型。[·1913599680 ·1912594470]
- **龙虾AI计费（参考，对外不报死数）**：58元包月会员赠2000积分，新用户注册赠5000积分，每天还可领158免费积分；普通工作量每天免费积分基本够用；生成一个技能约耗十几积分（几毛钱）。[·1912594470]
- **安全红线**：国外开源无沙箱工具误操作风险高；腾讯出品小龙虾用沙箱，改文件前征得同意，数据安全更高。[·knowledge-base.md]
- **反面教材**：自己下载WorkBuddy、买录音卡折腾一个月，搭出来的智能体全是废话——自己折腾的人做不成。[·knowledge-base.md]

### 12.4 AI咨询转化三步法（成交/入企） [·1911216862]
- 让老板产生三个念头：**我要做 → 我自己做不了 → 这个老师能帮我做**。靠课上节奏推出来，不是靠说。
- "我要做"触发 = 痛点+效果对比（每环节先讲痛点再展示效果，老板对号入座）；"我做不了"= 展示AI/系统的门槛；"老师能帮我"= 展示交付与案例。
- 对应：入企诊断与产品体系——公开分享课只种草不逼单，所有成交动作放课后一对一；此三步法即课上转化节奏。

### 12.5 企业AI数据合规路径（工具选型/合规） [·1914607450]
- 红线：直接用 GPT 且不脱敏 → 经营数据传国外服务器，国内大中型企业基本不能用（数据出境红线）。
- 三条合规路：① 国产大模型直接用（文心一言/通义千问/智谱ChatGLM，数据不出境）② 私有化部署（银行/国企/大型制造业，数据全内网）③ 合规API服务（阿里云/腾讯云，数据不用于训练、签合规协议）。
- 对应：工具选型原则——不追求最好追求最合适；安全红线；补充"数据合规"维度（国企/医疗/教育等敏感行业首选国产/私有化）。
