## 第二章 IP定位方法论

### 一、人设三要素

| 要素 | 核心要求 | 错误示范 | 正确示范 |
|------|----------|----------|----------|
| 有结果 | 用数字说话 | "我们品牌很牛" | "我开了12家店，踩了800万的坑" |
| 有案例 | 加盟商赚到钱了才是真的 | "获得过XX大奖" | "95后小伙，用我的模式开了3家店，半年回本" |
| 有能力 | 你能帮别人避坑赚钱 | "我们家产品特别好" | "我能让你少走5年弯路，成功率比自己干高5倍" |

### 二、不同行业人设定位公式

| 行业 | 错误人设 | 正确人设 |
|------|----------|----------|
| 餐饮招商 | "我是开饭店的，菜好吃" | "我开了N家店，踩了N万的坑，现在把成功经验复制给你" |
| 美业连锁 | "我是做美容的，技术好" | "我帮助300个宝妈开了美容院，80%半年回本" |
| 教育加盟 | "我们课程很牛" | "我用这套方法，帮200个校区年赚百万" |
| 零售连锁 | "我们产品性价比高" | "县城100平小店，日赚5万，我教你怎么开" |

### 三、人设避坑指南

**绝对不要做的人设：**
- 不要做"成功学"人设——鸡血打完就跑，没人跟
- 不要做"完美老板"人设——太完美会招反噬

**一定要做的人设：**
- 踩过坑的过来人——"我当年比你还惨"
- 接地气的实干家——"我现在每天还在店里干活"
- 讲真话的明白人——"这个行业有很多人骗你，我不骗你"

## 新章 · 品牌商业定位与IP人设调研体系

> 本章内容基于保禄最新版「品牌商业+人设定位调研表」，用于在做IP定位前深度调研客户。核心逻辑：商业定位→人设定位→内容策略，三步递进，每一步基于上一步推导。

### 一、商业定位调研框架

#### 1. 核心产品与变现

| 调研项 | 关键问题 |
|--------|----------|
| 核心产品/服务 | 具体卖什么？实物/技术/培训/加盟/联营？ |
| 衍生产品 | 主营之外还能卖什么？周边、进阶课、会员制？ |
| 产品差异化 | 和同类相比最大不同？独家配方？专利技术？独特体系？ |
| 竞品弱点 | 主要竞争对手谁？他们哪里做得不好？ |

#### 2. 目标客户画像

- 年龄段：18-24 / 25-34 / 35-44 / 45+
- 性别：女性为主 / 男性为主 / 男女均有
- 职业/身份：宝妈、上班族、美业从业者、有创业意向的女性……
- 购买前状态：没有一技之长、想创业不知道做什么、对现状不满意
- 服务范围：全国 / 省份 / 本地

#### 3. 客单价与成交路径

- 核心客单价区间：500以下→500-2000→2000-5000→5000以上
- 成交步骤：刷到视频→发私信→加微信→沟通需求→签约付款
- 平均成交周期：当天/1-2天 → 3-7天 → 7-30天 → 1个月以上

#### 4. 客户决策分析

| 调研项 | 关键问题 |
|--------|----------|
| 最大顾虑 | 怕被骗/怕学不会/怕没效果/怕亏钱/怕家人不支持 |
| 如何打消顾虑 | 你的解决方案是什么 |
| 最终下单理由 | 什么让客户下定决心付款 |
| 为什么选你 | 与同行相比的优势 |

### 二、IP人设定位调研框架

#### 1. 出镜人基础信息

- 姓名/昵称
- 年龄
- 多重身份标签（最多5个，越具体越有说服力）
  - 例：美业10年资深从业者 / 2店联营创始人 / 素人逆袭创业导师 / 3个孩子的妈妈

#### 2. 性格与价值观

- 性格特点用3-5个词描述：直爽/温柔/犀利/接地气/理性/感性
- 核心价值观：你想传递什么？（女性不需要靠男人也能独立 / 普通人也有创业机会 / 踏实比聪明更重要）
- 你讨厌什么？反对什么？——强烈的立场更有记忆点

#### 3. 人设故事三要素

| 要素 | 说明 |
|------|------|
| 起点故事 | 从最低谷开始写——出身背景、困境、怎么转变、现在在哪 |
| 最大踩坑 | 失败故事是最强共情入口，观众会想"ta能走到今天，我也可以" |
| 反差点 | 强人设必须有反差——"看起来是XX，实际上是XX" |

#### 4. 信任背书（结构化）

| 背书要素 | 示例 |
|----------|------|
| 从业年限 | X年 |
| 累计培训/服务学员数 | 约X人 |
| 现有合作/直营门店数 | X家 |
| 代表性成功案例 | 至少2条学员变化故事 |
| 行业资质/荣誉/媒体背书 | 具体证书或报道 |
| 其他平台粉丝积累 | 微信/小红书/旧抖音号 |

#### 5. 人设记忆点与内容禁区

| 要素 | 说明 |
|------|------|
| 专属口号/Slogan | 一句话总结你是谁，每条视频里出现 |
| 标志性道具/场景/穿搭 | 让观众一眼认出你 |
| 内容禁区 | 不能说什么：竞品名、收益数字、政策相关词、本人不愿谈的话题 |
| 收益表达尺度 | 直接谈数字/只说范围/侧面表达 |
| 人设路线 | 行业专家+案例展示（引流快，转化直接）vs 陪伴分享+真实故事（信任强） |

### 三、内容策略定位

#### 1. 账号核心目标与发布节奏

- 主目标（只选一个）：私信咨询加微信 / 表单留资 / 涨粉 / 直接到店成交
- 发布频率：日更 / 3-5条/周 / 1-2条/周
- 拍摄资源：专业团队 / 兼职摄影 / 自己手机拍
- 剪辑资源：自己剪 / 外包 / 需要推荐

#### 2. 对标账号分析

- 找出5个做得好的同类账号
- 明确自己不喜欢的视频风格（规避用）

#### 3. 近期节点与素材库

- 近期有无活动/节点需要配合：招商会、促销、新品发布、节日营销
- 已有素材：过往视频、成功案例截图、客户好评、资质证书

## 第四章 短视频内容方法论

### 一、内容三板斧（招商加盟IP就拍这三类）

**第一斧：踩坑经历类（建立信任）**

公式："我开第一家店时，3个月亏了50万，就因为这3个错误..."

- 讲你踩过的坑，比讲你有多牛更让人信任
- 每个坑配一个具体的数字、具体的教训

爆款选题示例：
- "开奶茶店亏了80万，总结出3个必死的坑"
- "我开美容院，第一个月就倒闭，就因为信了加盟公司这3句话"

**第二斧：门店火爆类（展示结果）**

公式："县城80平小店，周末一天翻台8次，营业额破2万..."

- 排队、满座、收钱的画面，比什么都有说服力

爆款选题示例：
- "今天周六，我们店营业额32000，给大家算算账"
- "县城小店，中午12点已经排了30桌"

**第三斧：模式拆解类（展示可复制）**

公式："为什么我们的店3个月就能回本？核心就这3个标准化..."

- 讲你的供应链、培训、运营支持体系
- 讲"普通人也能做"的理由

爆款选题示例：
- "我们的加盟模式，为什么能让90%的店赚钱？"
- "为什么我们敢说，小白也能开我们的店"

### 二、内容发布策略

- 内容类型：流量型 + 人设型 + 获客型
- 发布频率：每天1-2条，固定时间发布
- 评论区必回，建立人设
- 内容形式：老板真人出镜，口播为主；门店实拍为辅

### 三、爆款视频风格公式

**公式：**[品牌名] + [震撼数据] + [成功秘诀是什么？] → 拆解3点 → 出人意表结论

**口吻：**
- 中年男声
- 语速中等，不激动但有力
- 短句断句，一口气一句
- 用数据说话，不用形容词

**情绪：**
- 好奇驱动力主
- 不打鸡血、不卖焦虑、不吹牛
- 让观众自己想看下去

**应用示例：**

> "保禄团队，3个月帮12家门店单量翻倍，秘诀是什么？就3点。第一，把创始人从幕后推到台前……第二……第三……最后说一个反常识的结论——"

### 一、黄金三秒开头话术公式

**警告式：** 奉劝大家一句，千万不要盲目搞XX行业，除非...

**揭秘式：** 只有干XX行业的人才知道这条路有多难走...

**圈人群式：** XX的模式千万不要再做了，XX行业一定要学的XX

**比较式：** 为什么这家店XX方法比头部连锁品牌更好用？

**说真话式：** 想干XX行业，搞懂四句话

**恐吓类：**

### 四、黄金三秒剪辑经验

1. **提取强烈情绪反应：** 视频开头尝试激发强烈情绪反应——快乐、惊讶、激动、吐槽等，吸引观众注意力。

2. **延长视频封面标题：** 开场显示标题作为钩子。眼睛看到文字会主动阅读，无意间增加用户停留，降低2秒跳出率。

3. **加画面信息密度：** 故意用不同颜色字增加信息密度，配合紧迫配乐。视频短，等你看清信息时已经在不知不觉中播放了很多遍。注意把控时长，避免烦躁。

4. **动态开场：** 运动比静止好！让视频开头动起来，或故意使画面摇晃配合悬念点。

5. **冲突前置：** 最精彩/惊心动魄的镜头放开头，爆点前置，金句放开头。

6. **视觉冲击：** 打乱时间顺序或前后语序制造歧义争论点，挑选合适网络素材添加至开头吸引留存。

7. **快闪剪辑：** 前两秒内展示多个快速剪辑片段激发好奇心。餐饮类可在片头添加美食混剪丰富感官。注意不过长不过于单调。

## 第六章 拍摄与剪辑全流程

### 一、拍摄前设备检查清单

**相机检查：** 电量、存储空间、镜头清洁、设置（分辨率/帧率/白平衡/ISO）、传感器对焦、声音输入、录制测试、配件检查

**手机检查：** 电量和存储、应用更新、设置调整、镜头清洁、外部麦克风连接、录制测试

**录音检查：** 麦克风工作状态、连接线完好、设备电量、录音测试、音量级别、备份设备、同步信号、录音格式、防风措施、环境声音

**灯光检查（22项）：** 设备清单、灯具数量、电量、色温设置、灯泡灯管、调光器、支架、反光板柔光设备、遮光设备、主灯定位、辅助灯背光测试、光线均匀性、阴影高光、测光表曝光、反光眩光排查、灯具安全、光线测试拍摄、兼容性、后期考虑、安全措施、备用设备

检查完毕→工作群反馈："设备已检查完毕，可随时开拍。"

### 二、拍摄过程要求

- 根据场景合理决定横竖版，画面清晰稳定，构图合理，光线得当
- 严格遵守进度安排，按时完成，保持专注，及时调整角度和位置
- 收音清晰无杂音，收音麦位置正确，避免放到桌子上
- 打光要求脸部不反光，商业质感强，助理扑粉去油
- 布置好后测试拍一条给IP和运营看，通过再正式拍

### 三、拍摄后整理与设备管理

**素材导出与命名规范：**
- 拍摄结束立即导出至剪辑电脑和移动硬盘
- 命名规范：流量/人设/痛点/营销-视频话题（例：流量-创业的16条铁律）

**储存与备份：**
- 三重备份：本地电脑 + 云端（网盘） + 移动硬盘

**设备维护：**
- 电池电量保持在20%-80%，避免过度充电放电
- 每月检查设备固件版本，及时更新
- 设备存放环境：温度15-25℃，湿度40-60%

### 四、剪辑六步精剪SOP

**第一步：素材整理**
- 按时间、话题等维度分类整理
- 补充画中画素材按使用频率单独分类或打包

**第二步：导入**
- 点击导入选中目标素材，拖入下方时间轴

**第三步：粗剪**
- 画面调整：确认画面状态，按需放大裁剪、移动构图
- 美颜美体：可保存预设，避免盲目套用，按需微调
- 音频优化：参考平台优质视频音量，不固定数值；噪音过大可降噪或分离人声
- 色彩校准：基础调整为主，色彩偏移用HSL面板微调；同批次素材可保存预设套用
- 智能剪口播：浏览删除无关/重复内容，筛选重点切除冗余气口；同话题用标记功能区分

**第四步：逻辑梳理与重构**
- 全选素材→右键识别字幕→选择清晰易读样式
- 明确核心三要素：视频主题是什么？想传达什么内容？目的是什么？
- 围绕主题梳理逻辑线，删除无关内容，整合相似表达片段
- 案例（热点流量型）：主题=豆包AI手机→传达=顺势推出AI获客服务→目的=热点圈粉筛选精准客户→逻辑=豆包AI手机→线上AI获客→服务介绍

**第五步：精剪**
- 风格统一：明确视频风格（科技感/商业化），特效音效贴合风格
- 字幕规范：统一字体与样式，取消"全部应用"避免格式混乱
- 开场留人：提取抓眼球内容（情绪/金句/悬念），开场加动态特效或视觉冲击
- 引导视线：突出核心信息，合理分配元素占比，提炼重点词句加特效
- 信息密度：按需添加标题副标题，不堆砌冗余信息
- 节奏把控：气口适中，避免过密（观众麻木）或过长（不耐烦）；特效音效张弛有度
- 情绪渲染：强化表情画面，特效贴纸放大情绪，音效烘托氛围；优质IP可留白增强共鸣

**第六步：收尾并导出**
- 配乐：选适配音乐，音量低于人声，突出主体
- 封面：适配平台3:4比例，注意画面裁剪范围
- 导出：1080P、MP4格式、30帧、推荐码率、H.264编码

### 五、剪辑工作标准

**内容方面：**
- 视频内容与文案紧密贴合，删减后逻辑通顺连贯自然
- 语气词仔细筛选后删除，语言简洁明了无错误
- 重点词通过花字强调，专业术语可添加注释解释

**节奏方面：**
- 节奏不拖沓，切口要短，适当加速增强节奏感
- 关键节点添加转场效果（淡入淡出、闪白、旋转）
- 注意规避违禁词，严格遵守平台规定

**画面方面：**
- 保持同一条视频色调、亮度、饱和度统一
- 美颜不可过度，效果应自然真实
- 引用网络素材去除水印

**音乐和封面：**
- 背景音乐与主题、氛围、节奏匹配，注意版权
- 封面文字不遮挡主体面部，简洁明了传达主题

**特效和字幕：**
- 合理运用特效动画增强视觉效果，不过度使用
- 字幕准确清晰，字体颜色大小合适，易于阅读

### 六、剪辑流程规范（完整6步详细版）

> 来源：保禄剪辑经验内部流程规范，2026年6月更新

#### 第一步：素材整理
- 将拍摄素材导入电脑，按「日期_项目名_拍摄场景」建立文件夹
- 对素材进行初步筛选——删除明显废片（对焦失败、严重抖动、NG多次的）
- 补拍素材单独标注，避免后期混乱

#### 第二步：导入
- 选择剪辑软件：推荐**剪映专业版**（效率高）或 DaVinci Resolve（色彩要求高时用）
- 将素材按「主镜头 / B-roll / 空镜」三类导入项目
- 建立时间线，设定项目参数（分辨率 1080×1920 竖屏，帧率 30fps）

#### 第三步：粗剪
**3.1 画面粗剪：** 按脚本顺序将主镜头拖入时间线，裁掉每段素材的头尾废话、停顿过长、明显口误，保留核心观点和逻辑完整

**3.2 美颜处理：** 在剪映中先对人物主镜头统一做磨皮/瘦脸/大眼（参数控制在30-50%，避免过度），肤色微提亮（+5~10），偏暖色调保持自然感

**3.3 音频处理：** 统一音量到-6dB至-3dB范围；降噪处理参数20-40%；去除环境杂音

**3.4 调色：** 基础调色亮度+5~10、对比度+10~15；同一场景使用相同调色参数保证视觉一致性；IP视频倾向简约高级感，避免过度饱和

**3.5 智能剪口播：** 使用剪映「智能剪口播」快速去除重复词/赘词（然后/就是/那个）；注意仅供粗剪参考，需人工复核

#### 第四步：逻辑梳理与重构
**4.1 识别字幕：** 推荐剪映/开拍自动生成字幕，逐帧检查纠错，特别注意专业术语和人名

**4.2 明确主题：** 回顾脚本核心主题，对照粗剪内容检查是否跑题，一句话总结这条视频的核心信息

**4.3 重组内容：** 根据逻辑重新排列素材顺序，删减与主题无关的内容，确保信息流清晰有递进感，检查是否有逻辑断层

#### 第五步：精剪
**5.1 风格定位：** IP视频用「简约高级感」，克制花哨转场；硬广视频用「营销型」，节奏更快信息更密集

**5.2 字幕优化：** 基础字幕用黑体/思源黑体，重点字用特黑体；主字幕8-10号，标题14-16号；重点字高亮（加大加粗或变色），禁用描边（IP视频）；位置统一底部偏上避免遮挡人脸

**5.3 开场留人：** 前3秒必须有视觉冲击或反差信息，配合音效/画面变化制造「忍不住往下看」效果（关键帧放大/快速闪切/冲击力BGM）

**5.4 引导视线：** 每3-5秒一个画面变化（切B-roll/加贴纸/字幕动画），用箭头/圈注标注重点，不要让观众盯着同一画面超过5秒

**5.5 信息密度：** 每句话信息量要足废话全砍，用B-roll填补口播节奏空隙，数据/案例/对比三类内容轮换出现

**5.6 节奏控制：** 口播节奏快→慢→快制造情绪起伏，观点转折处留0.5-1秒停顿，高潮段落加快剪辑节奏（0.5秒一切）

**5.7 情绪引导：** BGM匹配情绪线（开头抓人→中段铺垫→高潮爆发→结尾余韵），音效点缀关键点，在情绪最高点给出核心金句或CTA

#### 第六步：收尾并导出
**6.1 音乐检查：** 主BGM音量-25dB至-20dB确保不压人声，高潮段可略提升（-18dB），导出前用耳机+外放双重测试

**6.2 封面制作：** 画面比例3:4（抖音推荐），边角大字核心关键词40-60号字，小标题补全信息，颜色与画面主色调协调

**6.3 导出参数：** 分辨率1080×1920（竖屏），帧率30fps，码率推荐8-12 Mbps，格式MP4（H.264编码）

| 成熟期 | 再营销包：近30天私信/留资用户；相似包：以优质客户为种子生成1000-5000人。禁忌：不上传低意向/已拒绝客户 |

#### 8. 行为兴趣

| 阶段 | 设置 |
|------|------|
| 冷启动 | 全部置空。基础定向（地域+年龄+性别）已筛掉劣质流量，人工加标签反而限制系统探索 |
| 成熟期 | 仅选1个核心类目+少量关键词（如：美容美妆+美业创业/皮肤修复/开店/联营） |

#### 9-10. 过滤高活跃/高关注

| 阶段 | 高活跃 | 高关注 |
|------|--------|--------|
| 冷启动 | 不过滤 | 不过滤 |
| 成熟期 | 通常不过滤 | 通常不过滤，数据极差时可试>1000 |

原因：创业老板本身就是抖音高活跃/高关注人群，过滤等于错杀核心客户。

#### 11. 智能定向拓展

| 阶段 | 设置 |
|------|------|
| 冷启动 | 必须开启，解决本地流量池小、跑不动的问题，拓展严格遵循地域设置 |
| 成熟期 | 继续开启，放大优质人群 |

#### 12-13. 投放时间与时段

| 设置项 | 冷启动 | 成熟期 |
|--------|--------|--------|
| 投放时间 | 从今天起长期投放 | 维持，除非有限时活动 |
| 投放时段 | 24小时不限（预算紧张可8:00-24:00） | 只留高转化时段，关凌晨 |

#### 14. 出价方式

| 阶段 | 设置 | 原因 |
|------|------|------|
| 冷启动 | 最大转化 | 在出价上限内优先拿转化，快速建模 |
| 成熟期 | 稳定成本 | 严控获客成本，平稳放量 |

#### 15. 出价（核心公式）

**公式一（通用）**：冷启动初始出价 = 可接受目标成本 × 1.2~1.5倍

**公式二（安全线）**：最高出价 ≤ (单客户毛利 × 线索有效率 × 成交率) × 0.7
- 乘0.7是安全边际，预留30%防止亏损

**分阶段调价策略：**

| 阶段 | 时间 | 策略 |
|------|------|------|
| 冷启动 | 0-3天 | 固定溢价出价，不频繁调价。无曝光+5~10%，有曝光无转化换素材不涨价 |
| 过渡期 | 3-7天 | 成本<目标→提价放量；成本>目标→每次降5~10% |
| 成熟期 | 7天+ | 出价贴合实际成本，小幅浮动维稳 |

#### 16. 日预算

| 阶段 | 设置 |
|------|------|
| 冷启动 | 出价 × 10~20倍，保障系统足够探索空间 |
| 成熟期 | 效果好逐步加预算放量，成本超标维持现有预算 |

#### 17. 素材管理

| 阶段 | 设置 |
|------|------|
| 冷启动 | 同时上传3-5条，快速测试哪条跑出转化 |
| 成熟期 | 保留2-3条最优。预算不高时只留1-2条转化最好的 |

#### 18-19. AI优化与AIGC

| 设置项 | 冷启动 | 成熟期 |
|--------|--------|--------|

## 第十二章 短视频爆店方法论

### 一、核心认知：重新定义「爆店」

爆店三要素：必须同时满足「流量转化率 + 营销价值 + 沉淀口碑」
- 高播放量 ≠ 门店爆店，能爆流不一定能产生到店转化
- 95%达人数据是刷出来的，水分极大，对门店实际帮助极小
- 抖音不只是做低价，高客单产品一样能获得流量

### 二、爆款打造前置：选品与卖点挖掘

四步选品验证流程：
1. 关键词空白验证：搜索产品/核心卖点关键词，确认平台无大量同类内容再操作
2. 可拍摄性验证：文案和画面必须高度契合，卖点要在开场用画面直接论证
3. 盲测用户接受度：选品后拿给朋友/顾客盲测，确认接受度再上线
4. 增加品牌背书：给产品添加品牌故事/情怀背书，资质越清晰越容易做爆款

### 三、可复制爆款脚本模板

| 模板类型 | 适用场景 | 操作方法 |
|----------|----------|----------|
| 素人矩阵固定文案模板 | 全品类，尤其连锁品牌 | 全矩阵统一用一句好奇开头，批量产出爆款 |
| 顾客第一视角体验模板 | 差异化小众项目 | 一个顾客拍一条，一天能产出10条 |
| 话题制造型人设互动模板 | 旅游景区等 | 做NPC人设和游客互动，随手拍获流量 |

多平台复用：同一个爆款脚本同步发抖音、小红书、快手、视频号。视频号对中老年客群转化效果尤其好，医疗美业必须做视频号矩阵。

### 四、批量剪辑：低成本日产百条视频

- 原理：提前拍摄足够多画面、录制固定文案音频，搭建素材模板库，不同素材随机拼接，单条发布成本仅3元
- 多：拍摄前准备充足的画面素材，画面饱满更容易出爆款
- 近：多用大特写，镜头越近产品越大效果越好，搭配对应音效
- 真：用第一视角拍摄真实顾客体验，用顾客反馈替代商家自吹自擂
- 高效模型：一次拍摄做完1-2个月的所有素材，出镜人换几套衣服即可

### 五、门店矩阵搭建

- 绑员工抖音开通带货权限，让员工帮门店发视频
- 用员工身份证创建商家子账号，一个手机号可开通2个抖音账号
- 一个城市最少搭建3-5套账号，覆盖抖音、小红书、快手、视频号

### 六、投流筛选策略

- 核心：小预算测爆款，再放大盈利
- 给所有新视频批量投放100元左右测试筛选爆款
- 后台直接看每个视频的成交金额，优先放大能赚钱的视频
- 济南案例：投100块测试，三天出货51万

### 七、自运营 VS 达人推广

| 对比维度 | 达人推广 | 商家自运营 |
|----------|----------|-----------|
| 灵活性 | 绑定低价盘，难调整 | 灵活调整，想推什么就推什么 |
| 持续性 | 一次性投入，结束就没流量 | 持续输出内容，长期稳定获客 |
| 成本效果 | 成本高，数据水分大 | 1-2个固定人员，数据真实可控 |

### 八、多平台运营差异化

| 平台 | 平台属性 | 运营核心 |
|------|----------|----------|
| 美团 | 需求搜索平台 | 核心看性价比，主图优先级：活动>品牌力>特色产品>logo>环境 |
| 小红书 | 内容种草平台 | 占领搜索结果，核心玩法是「控屏改屏」 |
| 抖音 | 兴趣电商平台 | 前三秒抓住注意力，核心是开头抛出卖点 |

## 新章 · 投放数据指标详解与复盘体系

> 本章涵盖本地推投放的7大核心指标、计划好坏判定标准、学习期规则、单条素材管理、每日复盘模板

### 一、每日必看7大核心指标

#### 1. 消耗（花费）

| 维度 | 标准 |
|------|------|
| 学习期 | 日消耗≥500元 |
| 成熟期 | 日消耗≥800元 |
| 核心逻辑 | 不花钱=无曝光=模型休眠 |

**不消耗的排查优先级**：调出价（涨5-10%）→ 补预算（满足出价×10）→ 换封面/标题 → 放宽定向

#### 2. 展现量（曝光）

| 维度 | 标准 |
|------|------|
| 合格线 | 日展现≥10000次 |
| 危险线 | 日展现<5000次 |
| 转化比 | 1元=80-150次展现（招商赛道标准） |

数据判定：1元>200次→泛了，精准度低；1元<50次→人群过窄/太贵

#### 3. 点击率（CTR）— 第一核心指标

| 维度 | 标准 |
|------|------|
| 计算公式 | 点击量÷展现量 |
| 合格 | ≥3% |
| 优秀 | ≥4% |
| 极差 | <2%（直接关停优化） |

**核心结论**：点击率90%由封面+标题决定，与视频内容无关。点击率低→只换封面标题，不动视频。

#### 4. 点击量

用户主动点开广告视频的次数。点击≠看完，仅代表初步兴趣。

#### 5. 转化率（CVR）— 第二核心指标

| 维度 | 标准 |
|------|------|
| 计算公式 | 有效线索数÷点击量 |
| 合格 | ≥1.5% |
| 优秀 | ≥2.5% |
| 极差 | <1% |

**转化率低的原因**：视频后半段只讲技术不讲创业盈利；广告卡片卖点错位；人群混入无效流量。

**优化优先级**：视频后半段（突出开店/分红）→ 换卡片+标题 → 收紧定向

#### 6. 线索/私信数

| 维度 | 标准 |
|------|------|
| 合格 | 日线索≥8条 |
| 优秀 | 日线索≥15条 |

有效线索包含：主动私信咨询 + 表单留资 + 私信内发送联系方式

#### 7. 转化成本（CPA）— 最终结果指标

| 维度 | 标准 |
|------|------|
| 计算公式 | 总消耗÷有效线索数 |
| 优秀 | ≤80元 |
| 合格 | ≤100元 |
| 超标 | >120元（需优化） |

### 二、计划好坏判定（直接套用）

| 等级 | 标准 | 动作 |
|------|------|------|
| ✅ 合格计划 | 点击率≥3%+转化率≥1.5%+成本≤100+日线索≥8 | 稳定投放可放量 |
| ⚠️ 一般计划 | 点击率2-3%+转化率1-1.5%+成本100-120 | 观察1-2天优化 |
| ❌ 垃圾计划 | 点击率<2%+转化率<1%+成本>120 | 连续3天无改善直接删除 |

### 三、学习期规则

| 状态 | 含义 | 处理 |
|------|------|------|
| 🔵蓝 | 学习中，需4天积累20条有效线索 | 不大改，小涨出价，加新素材 |
| 🟢绿 | 学习期已过，模型稳定 | 不乱改定向，小幅降价5-10%，递增预算20% |
| ⚫灰 | 学习失败 | 保留2天不改动，仍失败则删除新建 |

**复制成熟计划**：可继承70%+精准标签，学习期大幅缩短至1-2天。

### 四、单条素材精细化管理

| 素材等级 | 标准 | 动作 |
|----------|------|------|
| ✅ 优质 | 完播率≥30%+点击率≥3%+日线索≥2 | 保留持续放量 |
| ⚠️ 普通 | 点击率2-3%+日线索1 | 观察1天无提升换 |
| ❌ 垃圾 | 点击率<2%+0线索 | 立即删除 |

**强制要求**：必须单条素材单独复盘！整体数据会被优质素材拉高，掩盖垃圾素材问题。

**运营标准**：每日优胜劣汰，保留2-3条最优，每日新增1-2条测试。

### 五、典型案例：高展现低转化

场景：展现5万、点击率4%（优秀）、点击2000、转化率0.5%（极差）、线索10条、成本200元

根因：封面标题引流强，但内容只讲技术、不讲创业盈利，吸引的是普通用户而非创业合伙人。

**分步修复**：
1. 优化视频后半段：弱化技术，突出开店/联营分红/低门槛
2. 更换广告卡片：标题卖点聚焦「联营开店、门店分红」
3. 优化广告标题：聚焦25-45岁女性创业赛道
4. 收紧定向：关闭25岁以下，过滤年轻小白

## 第十七章 IP账号运营风险治理

### 一、抖音平台主要风险位置

**评论区风险：**
- 评论过分引导：招商加盟类留言表述过于直接、引导留联系方式过于直白、互动引导过度
- 评论区存在不显示情况：发不出去或自己能看到别人看不到
- 应对：使用谐音替换词（"點我主耶纟我"替代"私信我"，"浙理ling"替代"这里领"）
- 负面评论：恶意攻击类直接删除拉黑；误解类礼貌回复澄清
- 执行标准：工作日回复时效≤30分钟，非工作日≤2小时，每条回复前关键词过滤

**私信风险：**
- 因过分获取用户信息被限制，客户投诉会封私信功能
- 敏感词替换："系联式方"替代"联系方式"，"话电"替代"电话"
- 禁止直接提及加盟费用、索要电话号码
- 每日主动私信不超过20条，同一用户间隔不少于24小时

**视频（剪辑环节）风险：**
- 敏感词使用不当→用拼音或谐音替换（"加盟"→"加M"）
- 引导性元素不当→贴片停留≤3秒，避免红色箭头手势等诱导元素
- 引流行为违规→避免"私信""加V咨询"等表述
- 肖像权问题→使用前签订授权协议并保留文件

**账号风险：**
- 每天进行账号风险排查，及时发现处理问题
- 修改前严格风险评估，不得自行修改，需先审核确认
- 姓名每月最多更改一次，简介无变动不修改
- 避免过度频繁引导，注意话术多样性

**企业号组件挂载：** 发布前检查组件和视频内容钩子结尾是否一致；更改投放方式前务必先修改对应组件

### 二、视频号平台风险治理要点

- 评论回复保持礼貌积极，严格避免敏感词汇，及时清理负面评论
- 私信回复时效5分钟以内，完善关键词自动回复内容
- 视频内容严格审查合法合规，避免数字类型文案被判违规
- 直播前审查脚本和预演内容，避免敏感话题和不当言论
- 封面简洁明了突出主题，不使用误导性夸大事实的封面

## 第二十七章 短视频创作全流程指南

### 一、短视频达人作品自检7问

发布前的"终极校验清单"，帮你快速排查内容问题：

1. **说人话** — 语气自然、避免刻意做作，用真实口语化表达，降低距离感
2. **不要自嗨** — 内容是否对用户有价值（谈资/知识/共鸣/欢乐），避免仅满足个人表达欲
3. **关键点** — 用户看完的最大感受和最深印象点是什么，明确核心信息确保用户接收
4. **不说废话** — 每一句话是否服务于内容推进、能否被删除，精简保持节奏紧凑
5. **用词准确** — 是否用了过多形容词、能否替换为动词和名词，增强画面感
6. **背书** — 内容是否有权威背书、事实佐证或亲身经历，增强可信度
7. **金句** — 是否有能让用户转发的金句，打造可传播的记忆点

   - 描述法：描述出带来感受的具体行动，让用户身临其境
   - 类比法：把抽象事物类比成具象事物，降低理解成本

2. **力量感打造**
   - 方言词汇：东北方言 > 其他北方方言 > 南方方言 > 普通话，增强表达张力
   - 强弱对比：通过反差放大情绪，对比维度：数量/时间/经历/身份

# 卷十：连锁老板招商短视频六大万能文案框架

## 第二十八章 六大文案框架完整写法

每一类选题都有一套可复用的写作公式，包含核心作用、开头、中间三段、结尾五个部分。

### 一、老板人设类框架

**核心作用：** 建立信任，让加盟商觉得「这个老板靠谱」

**开头（黄金3秒）：**
- 用反差金句开篇：「我做连锁XX年，踩过的坑比赚过的钱多」
- 或展示成果数据震撼：「XX家门店，XX%的存活率」

**中间（三段递进）：**
- 第一段：讲一个自己的失败/踩坑故事，展现真实
- 第二段：从这个故事中提炼出的商业认知/方法论
- 第三段：这个认知如何帮助现在的加盟商避免同样错误

**结尾（行动召唤）：**
- 暗示总部对加盟商的保护体系
- 「做连锁，经验可以教，坑必须替。这就是我们存在的意义」

---

### 二、模式拆解类框架

**核心作用：** 展示商业模式的独特性和盈利逻辑

**开头（黄金3秒）：**
- 直接抛出行业痛点：「餐饮加盟为什么80%都在亏？」
- 或对比数据：「我们XX家店，平均回本周期X个月」

**中间（三段递进）：**
- 第一段：拆解行业常见模式的问题（供应链、管理、获客三视角）
- 第二段：展示自己模式的差异化解决方案（配数据/图表）
- 第三段：用一个真实门店案例跑通数据验证

**结尾（行动召唤）：**
- 引导想要了解详情的加盟商留资
- 「想了解完整模式的，评论区扣1」

---

### 三、加盟商案例类框架

**核心作用：** 用真实成功案例激发加盟欲望

**开头（黄金3秒）：**
- 加盟商真实变化：「他的店，第一个月亏了XX万，现在月赚XX万」
- 或身份共鸣：「一个普通XX（职业），凭什么开出XX家店？」

**中间（三段递进）：**
- 第一段：加盟前的状态（普通身份/困境/犹豫）
- 第二段：加入后的关键转折点（总部给了什么支持/自己做了什么改变）
- 第三段：现在的成果（客流量/营业额/开店数/生活变化）

**结尾（行动召唤）：**
- 用这个案例引出总部赋能体系
- 「他可以的，你缺的只是一个好体系」

---

### 四、行业认知类框架

**核心作用：** 建立行业权威，让加盟商觉得「跟着你对」

**开头（黄金3秒）：**
- 抛出行业争议性观点：「202X年做XX（行业），最大的机会不在XX」
- 或趋势预判：「未来三年，这个行业会死掉一半人」

**中间（三段递进）：**
- 第一段：用数据/调研支撑观点（行业报告/自己调研/同行对比）
- 第二段：分析这个趋势背后的底层逻辑（消费者变化/政策/技术）
- 第三段：给出具体可操作的建议（加盟商该注意什么/总部在做什么准备）

**结尾（行动召唤）：**
- 强化认知差价值
- 「做对的选择，比努力重要一百倍。来找我聊聊」

---

### 五、总部扶持类框架

**核心作用：** 展示总部真实力，打消加盟顾虑

**开头（黄金3秒）：**
- 直接展示扶持动作：「我们给加盟商的扶持，不是嘴上说的」
- 或以加盟商痛点切入：「加盟后最大的坑，是总部的甩锅」

**中间（三段递进）：**
- 第一段：具体展示扶持体系（选址/装修/培训/供应链/营销/管理）
- 第二段：用具体案例+数据证明扶持效果（开业XX天回本/客流量提升XX%）
- 第三段：对比行业平均水平，展示差异

**结尾（行动召唤）：**
- 给出限时/限量信息
- 「这个月还有X个门店扶持名额，想了解的抓紧」

---

### 六、避坑警示类框架

**核心作用：** 用反面案例建立信任和紧迫感

**开头（黄金3秒）：**
- 直接抛出惨痛案例：「投了XX万的店，三个月就关门了」
- 或行业数据：「去年有XX%的新开店撑不过半年」

**中间（三段递进）：**
- 第一段：具体还原失败经过（从选址到关店的关键错误决策）
- 第二段：分析失败原因（外部因素 vs 内部决策失误）
- 第三段：对比——如果跟着我们/用对方法，结果会怎样

**结尾（行动召唤）：**
- 强化避险需求
- 「创业最大的成本不是钱，是试错。来找我们，先帮你避开这些坑」

## 第二十九章 实体门店引流——15个进店理由

进店理由的本质：**给消费者一个「不来就是你的损失」的理由。**

### 理由分类体系

| # | 理由类型 | 核心策略 | 适合行业 |
|---|---------|---------|---------|
| 1 | **效果好** | 效果承诺+案例背书，让消费者对结果有确定性期待 | 餐饮/美容/教育/服务 |
| 2 | **好评多** | 真实好评截图+点评平台高分，信任前置 | 全行业 |
| 3 | **性价比高** | 同品质价格更低/同价格品质更好，制造比价优势 | 零售/餐饮/服务 |
| 4 | **老板好** | 创始人IP+人格魅力，用人情味打动消费者 | 餐饮/服务/零售 |
| 5 | **便利性** | 离家近/停车方便/营业时间长，降低决策门槛 | 零售/餐饮 |
| 6 | **专业强** | 认证资质+专业背书+专家人设，建立技术信任 | 服务/医疗/教育 |
| 7 | **服务好** | 海底捞式服务+售后承诺，超越期待的体验 | 餐饮/服务/零售 |
| 8 | **有特色** | 独特产品/独家配方/沉浸体验，制造差异化吸引力 | 餐饮/零售/娱乐 |
| 9 | **选择多** | 品类丰富+套餐组合，满足不同需求 | 零售/餐饮 |
| 10 | **有面子** | 高端环境+网红属性+社交货币，让消费者愿意拍照分享 | 餐饮/酒店/娱乐 |
| 11 | **质量好** | 原材料/制作工艺/质检标准可视化，品质可视化 | 餐饮/制造/零售 |
| 12 | **生意好** | 排队效应+忙不过来，从众心理驱动进店 | 餐饮/零售 |
| 13 | **规模大** | 连锁品牌+门店数量+覆盖区域，品牌信任背书 | 连锁品牌 |
| 14 | **案例多** | 客户见证+合作品牌+服务数据，用成果说话 | B2B/服务/教育 |
| 15 | **颜值高** | 空间设计+产品外观+拍照打卡点，视觉驱动消费 | 餐饮/零售/酒店 |

### 使用原则

1. **选对不选多**：每家门店/品牌根据自身优势选取3-5个核心理由集中打透，不要贪多求全
2. **短视频化呈现**：每个理由都能拍成一条15-60秒的短视频（展示 + 证据 + CTA）
3. **组合使用**：「效果好 + 好评多 + 性价比高」三连击是最通用的信任组合
4. **因地制宜**：高端品牌侧重「有面子+质量好」，社区店侧重「便利性+老板好」
5. **持续迭代**：每月评估各理由的引流效果，淘汰无效理由，强化高效理由

### 短视频模板示例

以「效果好」为例：
- 开头：「XX家客人来了一次就再也不去别家了，为什么？」
- 中间：展示真实客户反馈截图+前后对比+具体效果数据
- 结尾：「想体验的，直接导航过来，报'XX'有优惠」

# 卷十二：AI做IP十二段提示词体系

## 第三十章 十二模块：IP的自动化流水线

### 核心理念

**为什么要用AI做IP？**

对个人：重要的不是每天焦虑粉丝数，而是修行、成长、幸福。你应该有时间冥想、读书、陪伴家人、锻炼身体，成为一个更完整的人。

对企业：重要的不是老板发多少条短视频，而是组织管理、产品优化、市场洞察。企业的核心竞争力，不在于流量短暂的爆点，而在于长期的战略、产品与格局。

AI做IP的价值，就是帮你从琐碎里解放出来，回到更重要的创造与修行。

**核心架构：** 把IP拆解为十二个模块，让AI接管重复劳动，形成自动化流水线。

---

### 模块一：定位诊断——AI帮你看清赛道与标签

**角色：** 定位诊断专家，兼具战略顾问、品牌教练和市场洞察者能力

**输入格式：**
1. 生命经历（关键节点、转折故事）
2. 核心技能（专业能力、隐性才华）
3. 长期兴趣（持续痴迷的方向）
4. 人格优势（气质、天赋、价值观）
5. 目标人群（年龄层、身份、主要痛点）

**工作流程：**
- Step 1：从输入中提炼3-5个核心关键词 → 等待用户确认
- Step 2：基于关键词，结合市场趋势和典型案例，生成三套定位方案（方案A/B/C）

每一套方案包含：定位名称、标签、定位语

---

### 模块二：人设塑造——基于人格与价值观，生成三套可传播的人设

**角色：** 人设塑造专家，融合心理学、叙事学与品牌传播智慧

**输入格式：**
1. 生命经历（关键故事、转折点）
2. 人格特质（外向/内向、敏感/理性等）
3. 价值观与信念
4. 目标人群（他们渴望的精神投射/情感需求）
5. 未来目标（希望通过人设达成的结果）

**工作流程：**
- Step 1：提炼人格关键词与核心价值观 → 等待确认
- Step 2：生成三套人设画像
- Step 3：为每套人设说明传播优势与潜在风险
- Step 4：推荐首选人设，阐述推荐理由

---

### 模块三：价值主张提炼——一句话打穿人心

**角色：** 价值主张提炼师，擅长将复杂经历与优势转化为直击人心的一句话核心价值

**输入格式：**
1. 核心优势（能力/经验/资源）
2. 能为目标人群解决的首要痛点
3. 所在领域或行业
4. 希望别人提到我时的第一印象
5. 想构建的长期影响力

**工作流程：**
- Step 1：提炼3-5个核心关键词 → 等待确认
- Step 2：生成三条差异化价值主张（每条含：主张核心、一句话金句、优势说明、潜在局限）
- Step 3：横向比较三条主张
- Step 4：推荐首选价值主张，说明推荐理由

---

### 模块四：故事资产挖掘——把生命经历提炼成可复用的故事库

**角色：** 故事资产挖掘师，擅长从个人经历中提炼能打动人心、可用于传播的叙事资源

**输入格式：**
1. 重要生命经历（转折、失败、成功、顿悟）
2. 与目标人群相似的处境或共鸣点
3. 在经历中展现的品质或能力
4. 想传递的核心价值观或理念
5. 未来希望长期讲述和放大的主题

**工作流程：**
- Step 1：提炼3-5个关键故事节点 → 等待确认
- Step 2：将故事划分为三类（挫折型、成长型、愿景型）
- Step 3：为每个故事生成叙事框架
- Step 4：汇总形成「故事资产清单」

### 模块五：内容选题生成——每天10-20个精准选题

**角色：** 内容选题策划师，具备市场敏锐度与叙事转化能力

**输入格式：**
1. 目标人群（身份、年龄层、痛点）
2. 核心领域（如AI、商业、身心灵等）
3. 核心优势（能力、故事、资源）
4. 希望长期强化的标签或印象
5. 近期内容目标（吸引流量/提升信任/带动成交）

**工作流程：**
- Step 1：提炼目标人群的高频问题与需求 → 等待确认
- Step 2：结合领域与优势，设计不少于15个具体选题
- Step 3：每个选题需包含主题、角度、目标受众、内容形式
- Step 4：对所有选题分类，形成「内容选题库」

### 模块六：文案与口播优化——生成三种风格口播稿

**角色：** 文案与口播优化专家，兼具广告创意人的敏锐和演讲教练的洞察

**输入格式：**
1. 主题内容（核心观点或信息）
2. 目标人群（他们是谁、渴望听到什么）
3. 身份设定（导师/布道者/创业者）
4. 传播目标（吸引流量/建立信任/引导成交）
5. 表达风格偏好（犀利/共情/震撼/幽默等）

**工作流程：**
- Step 1：生成三种不同风格口播文案（A共情型/B震撼型/C故事型）
- Step 2：每份文案标注适用场景和受众匹配度
- Step 3：逐条优化文案的节奏、情绪、记忆点
- Step 4：推荐最优版本，说明推荐理由

---

### 模块七：IP形象设计与表现

**角色：** IP形象设计师 + 影像导演

**操作流程（三步法）：**

**第一步——上传照片：**
- 正面清晰照（自然光下）
- 工作场景照（演讲/办公/日常）
- 半身或全身照（能看服装与体态）

**第二步——回答问题：**
- 希望在镜头里呈现什么气质？（亲和/威严/智慧/热情/极简/科技感）
- 希望观众看到的第一印象是什么？
- 最担心被误解成什么样子？
- 未来三年的人设关键词（如AI、修行、商业、东方气质）
- 应用场景（短视频/直播/课程/宣传片）

**第三步——AI输出逻辑：**
- 生成三套完整形象方案（外观、灯光、机位、妆造、表情与情绪）
- 每套方案匹配不同的传播场景

---

### 模块八：短视频脚本与分镜

**角色：** 短视频脚本与分镜策划师，既懂叙事节奏也懂视觉传播

**输入格式：**
1. 视频主题（核心观点或信息）
2. 目标受众（他们是谁、想看什么）
3. 表达风格（犀利/共情/励志/故事化）
4. 视频时长（30秒/60秒/90秒）
5. 视频目的（吸引流量/提升信任/促进成交）

**工作流程：**
- Step 1：生成三套不同风格脚本，每套包含：
  - 开头镜头（前3秒钩子）
  - 中段内容（逻辑清晰，情绪递进）
  - 结尾设计（留悬念/行动号召/金句收尾）

### 三、爆款视频三段式创作模型

> 来自2026年5月Top品牌实战案例提炼

```
开头 - 抓眼球（前3-5秒）
  → 价格反差："专柜千元品质，现在只要火锅价"
  → 痛点场景："月子餐样式单一、家人不会搭配"  
  → 情感导入："暖心婆媳故事开场"

中间 - 强种草（15-40秒）
  → 实物展示：面料细节/制作过程/使用演示
  → 数据佐证："63块裁片、高密缝线、四面弹力"
  → 功能包装设计：独立包装/30天不重样/即食操作

结尾 - 促转化（最后5-10秒）
  → 价值升华：从功能到情感（"化解婆媳矛盾"）
  → 性价比总结："火锅价买专柜品质"
  → 限时引导：简练话术催促下单
```

## 第三十一章 选题引擎（四来源三关）

**四来源配额**：Get笔记近期录音35%(3-4条) / 行业热点Web实时搜25%(2-3条) / 自身账号数据复盘20%(2条) / 同行爆款方向20%(2条) = 10条候选。

**三关筛选（不评分、贴标签）**：
- 第一关·一票否决：目标用户想不想看？同行同类视频有500赞+ / 自己或同行评论区有人问过 → 过；否则删。过了的都拍。
- 第二关·共识层级×客资准度：人性共识(百万级/拉流量) / 时代共识(几十万/建认知) / 利益共识(几万~十几万/主力内容) / 专业共识(几千~几万/收客资) / 热点共识(借势)。共识越高流量越大但客资越泛，每层各有使命。
- 第三关·按账号阶段配比：起号期(0-5000)人性5/时代2/利益2/专业1；增长期(5000-5万)各3；变现期(5万+)利益3专业3人性2时代2。

**核心原则**：先过门槛再排序；来源≠好坏；反常识优先；有数字有案例；可拍摄可落地；不满意就换一批。

## 第三十三章 投流体系精要（本地推+抖加+爆店）

**铁律**：投流是放大器不是起死回生药。自己拍+本地推 > 找达人(达人数据95%刷的)。

**前置判断**：完播率(DOU+≥25%/本地推≥30%)、互动率≥3%、自然播放(DOU+≥1000/本地推≥500)，不达标别投。

**本地推**：新店开业门店浏览200/天×7天3-5km；日常引流团购100/天3km；活动到店300/天×3天5km；招商获客线索200-300/天全国/目标城市。节奏：日常100稳定；活动前3天加300当天500；周五周六各200。时段早10-晚24。新户消耗2000-5000跑准，前3天不干预第4天优化。

**抖加六步**：自然跑流速放缓再投→有精准评论加投200→每条先100测→流速放缓时投→优先自然最好那条→新户消耗2000-5000投准。爆款流：发布→自然24h→投100测3h→追300-500→转本地推放大/追留资。禁12h以下/定向太窄/一步到位/未升级账户零营销容忍。

**爆店**：爆店=流量转化率×营销价值×沉淀口碑。流程：拍几条不同角度→每条100测→选最好加投500-2000→ROI稳放量→多平台同步(抖音+小红书+快手+视频号)。

**合规**：招商不承诺收益/不用极限词；本地推内容与落地页一致；禁诱导重复互动刷数据。

## 第三十四章 短视频复盘 V2 体系

**第零步 数据质量审计**：空值≠0；区分数据缺失与真实下降；交叉验证多源；比率加权平均。完播率覆盖<70%标红；评论全0功能关了；投流未区分则结论加⚠️。

**四步分析**：①数据分层(又爆又赚/有量无转/有转无量/没量没转) ②转化归因(精准度/信任/需求触发/门槛/时机，转化>流量) ③失败归因(5秒完播<30%开头弱/选题自嗨/人群跑偏/执行差/时机/限流) ④规律提炼(钩子/选题/形式/时间)。

**健康度与深层**：内容结构健康度(案例≥20%/人设≥15%/干货10-20%/入企证据10-15%/招商10-15%/知识≤10%/杂项≤5%)，(爆款+人设)/总>50%🟢/<30%🔴。完播率按时长×类型分桶找最佳配方。互动深度赞/分享比<2:1🟢传播力强/>4:1🔴。趋势预警历史中位数基线，连续2周降→预警，单条<7日均播×0.4查限流。

**选题建议**：又爆又赚→复制；有量无转→优化钩子；有转无量→投流放量；没量没转→归因。复盘数据本身就是选题来源3(数据复盘)出2条候选。

## 第三十五章 直播话术体系（带货+招商）

**场景隔离**：赚消费者→本地生活带货；赚创业者→招商加盟；赚学员→知识付费。判"赚谁的钱"。

**人货场**：人(主播练3遍/最低主播1+场控1)；货(带货主推1爆+1-2利润、团购≤7折、限50-100、券7-30天；招商留资工具+钩子物料+数据贴片+风险贴片)；场(餐饮后厨/门店、零售美业门店、招商工厂、知识书房；不在纯白墙)。设备手机≥1200万+领夹麦+补光+支架+电源必。开播前30分检查网络/画面/灯光/收音/链接/物料/置顶/违规监控。

**带货框架**：3秒钩子→痛点场景化→FABE→限时限量逼单→321上链接。
**招商框架**：痛点共鸣→品牌实力背书(量化)→单店盈利模型拆解→扶持保障具象化→留资钩子→风险提示(投资有风险加盟需谨慎)。

**应急12状况**：流量突来/人数少/高在线零互动/负面评论/忘词/团购零单/链接坏/音画故障/问价格(不报数字)/问能赚多少(不承诺+历史数据)/开播30分流失/收尾加单(≤10分)。

**合规**：禁极限词；带货禁医疗/虚假折扣；招商零容忍(包赚/稳赚/保底/零风险/回本/躺赚全禁)；口播风险提示；不报加盟费具体数字。

**全链路**：主产出=主播连续逐字稿(场控行内小注)，附属轮播节奏表+场控清单。核心话术每15-20分轮播；留资钩子每5-8分插；收尾前15分逼单关投流；前30+最后30留资最强。视频号每20分陌生用户全换单轮重复。

## 第三十六章 直播复盘六维诊断

**铁律零：先分轨再分析**。有投流必拆自然/付费：自然场观=总-付费；付费CPM=花费/付费场观×1000、付费ROI、单留资成本。高场观≠好(可能80%投的)、低停留≠差(付费流天然短)。

**六维**：①流量(停留>2分🟢/<1分🔴；进房率>8%；曲线平稳=好) ②转化(带货GPM≥500/1000+优、转化率≥1%/3%+；招商场观1000留资≥5/≥15、留资率≥0.5%/1.5%+、有效留资≥50%/80%+、到店≥10%/20%+、成交≥30%/50%+) ③互动(密度>5/分活跃；高意向问价🔴中意向问用法🟡低意向666🟢；互动高转化低=假热闹) ④话术执行(对照框架逐段看在线/互动/转化) ⑤人货场 ⑥方法论沉淀+下次调整清单(🔴🟡🟢×维度×问题×具体动作×负责人，动作具体到"把X改成Y")。

**迭代带**：现象→归因→下次(好保持放大/差怎么改)。无"下次怎么调"=废话。数据说话不用形容词；带货招商指标不混；投流缺失标⚠️。

**报告**：单场(核心速览→流量→转化→互动→话术执行→人货场→方法论→调整清单)；周/月(周期汇总+多场对比+趋势+话术版本+投流优化+下周计划)。

## 第三十七章 保禄真实案例库（脱敏）

> 本章为保禄本人真实服务记录脱敏稿（来源：Get笔记服务过程录音，2025-2026）。数字为真实口径，回答案例问题时以本章为准，不夸大、不另编。

### 一、贴膜小子（手机后市场连锁）
- 背景：北京300+门店的手机壳膜连锁，创始人从手机配件渠道商转型；做IP几年不得法，月客资仅1-2条，新店开不出来。
- 动作：入企调研→商业模式梳理→加盟政策→IP定位→内容体系→选题文案指导→自然表达引导→剪辑运营投流→赋能团队。
- 结果：第一条视频起每天稳定20+条精准客资，月500-600条；第4个月爆发，每月新增约20家加盟店，半年新增40家门店。

### 二、黑马汇老李（连锁培训）
- 背景：大连头部连锁培训机构（2025年营收5000万+），创始人老李为上市公司老板。
- 动作：创始人IP打造——以"上市公司老板"身份为原点，讲对连锁行业的理解与认知；抖音/视频号/快手/小红书多平台分发；内容→销售邀约→课程→后端服务，商业闭环。
- 结果：20多条视频半年获取1万+条客资。

### 三、某头部家庭教育IP（高度脱敏·不提姓名与品牌）
- 2021年在杭州操盘，全国家庭教育赛道排名前3，粉丝与变现第一梯队；7天GMV 2200万，全年GMV 1.5亿。

### 四、大崔（知识付费）
- 宝妈人设IP，年GMV约1000万。

### 五、耿叔朗诵（知识付费）

### 六、兰琪（美业·烟台）
- 背景：16年美业品牌，2万+技术学员/加盟商。

### 七、某中医馆连锁（高度脱敏·不提姓名与品牌）
- 背景：中医馆连锁，0-1起盘。
- 关键打法：医疗行业不能直接讲技术/疗效——公域用国学、孝道、养生等合规内容吸引中老年用户，再转私域推中医馆业务；以自然流为主（投放易违规）；内容侧重创始人创业故事与发心。
- 结果：首月80万。

### 八、枕水江南（中式快餐·沈阳）
- 背景：沈阳江浙菜品牌，创始人20万起家从无名小巷门店做到900平旗舰店；2026年布局外卖卫星店招商，规划三年东三省四城（沈阳/大连/长春/哈尔滨）。
- 动作：招商访谈内容（总部全链条帮扶：选址/装修/手续/平台搭建/开业带店；加盟商到沈阳门店学习4天-半月，开业带店3-5天，每月巡店1-2次）+创始人创业故事内容。
- 模型口径：总投入12-20万（不含房租10万可启动），加盟费品牌使用费29800+保证金1万+管理费3%（平台扣点后纯营业额），6-12个月回本，双重退出保障（折旧价回收门店+物料兜底回购）。

1. 回答"你做过什么案例"时，按用户行业挑最近案例，先讲结果数字再讲打法。
