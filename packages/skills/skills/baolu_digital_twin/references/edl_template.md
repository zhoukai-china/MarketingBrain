# 剪辑EDL文件规范

> EDL (Edit Decision List) 是给剪辑师的精确剪辑指令。每条视频的EDL让剪辑师（或AI剪辑工具）知道：哪一帧开始、哪一帧结束、用什么转场、加什么字幕特效。

---

## EDL标准格式

每条口播/访谈视频对应一份EDL，包含以下字段：

```
视频名称 | 总时长 | 类型（口播/访谈/Vlog） | 目标平台（抖音/视频号/全平台）
```

### 时间线格式

| 序号 | 时间段 | 画面内容 | 音频 | 字幕特效 | 备注 |
|------|--------|----------|------|----------|------|
| N | 00:00-00:XX | | | | |

## 口播视频EDL模板

```
视频名称：{标题}
总时长：{60秒/90秒/120秒}
类型：口播
目标平台：抖音

时间线：
| 序号 | 时间段 | 画面 | 音频 | 字幕 | 备注 |
|------|--------|------|------|------|------|
| 1 | 0:00-0:03 | 出镜人正面近景 | 原声口播 | 前三秒大字幕弹入（标题关键词） | 必须0.5秒内出现字幕 |
| 2 | 0:03-0:15 | 出镜人中景（可加手势） | 原声口播 | 白色字幕底部，关键词黄字高亮 | |
| 3 | 0:15-0:30 | 切换B-roll（门店/客户场景） | 原声口播继续 | 数据型字幕居中大号弹出 | B-roll和口播交替 |
| 4 | 0:30-0:45 | 出镜人中景 | 原声口播 | 白色字幕底部 | 切换回出镜人 |
| 5 | 0:45-0:55 | 对比画面/算账画面 | 原声口播+轻BGM渐入 | 对比数字大字幕弹出 | 关键数据留3秒以上 |
| 6 | 0:55-结束 | 出镜人近景收尾 | 原声口播 | 结尾金句大字幕+⚡图标 | 结尾定格1秒 |

转场：所有B-roll切入用硬切（不用过渡特效）
BGM：极轻环境音或不用BGM
画面比例：9:16竖屏
关键数字字幕：至少保留3秒，字号为正常字幕的1.5倍
```

## 访谈视频EDL模板

```
视频名称：{标题}
总时长：{3-5分钟}
类型：访谈
目标平台：抖音+视频号

时间线：
| 序号 | 时间段 | 画面 | 音频 | 字幕 | 备注 |
|------|--------|------|------|------|------|
| 1 | 0:00-0:05 | 被访者最好的一句话（先声夺人） | 被访者原声 | 主题大字幕 | 最打动人的那句话放开头 |
| 2 | 0:05-0:08 | 出镜人+被访者同框（门店内） | 出镜人：「今天来到XX...」 | 白色字幕 | 快速交代场景 |
| 3 | 0:08-0:45 | 被访者讲第一个故事 | 被访者原声 | 白色字幕+关键数字高亮 | 被访者为主 |
| 4 | 0:45-1:00 | 出镜人追问（画外音或切回双人镜头） | 出镜人原声 | 白色字幕 | 追问让故事深入 |
| 5 | 1:00-2:30 | 被访者展开 | 被访者原声 | 白色字幕 | 高潮部分 |
| 6 | 2:30-2:45 | 被访者情绪高点（眼眶红/大笑） | 被访者原声 | 无字幕特效，让画面说话 | 留白2秒 |
| 7 | 2:45-结束 | 双人收尾 | 出镜人+被访者 | 结尾金句大字幕+⚡ | |

转场：访谈画面用硬切，回忆/空镜用淡入淡出
BGM：不提情绪时不用BGM，情绪高点时极轻钢琴/吉他
画面比例：9:16竖屏（抖音）/ 16:9横屏（视频号）— 拍摄时两种构图都要有
被访者特写：讲情感内容时切近景，讲观点内容时切中景
```

## KKVlog/门店实拍EDL模板

```
视频名称：{标题}
总时长：{60-90秒}
类型：门店实拍/幕后
目标平台：抖音+视频号

时间线：
| 序号 | 时间段 | 画面 | 音频 | 字幕 | 备注 |
|------|--------|------|------|------|------|
| 1 | 0:00-0:05 | 门店空镜（招牌/客流/产品特写） | 现场环境音 | 白色标题字幕 | 不看人，看环境 |
| 2 | 0:05-0:15 | 出镜人边走边讲（门店走廊/大堂） | 出镜人原声 | 白色字幕底部 | 运动镜头 |
| 3 | 0:15-0:35 | 切换门店工作细节（后台/系统/操作） | 出镜人原声继续 | 白色字幕 | B-roll跟口播交替 |
| 4 | 0:35-0:50 | 出镜人+门店老板对谈 | 双人原声 | 白色字幕 | |
| 5 | 0:50-结束 | 出镜人中景收尾+门店招牌空镜收尾 | 出镜人原声 | 结尾金句大字幕 | |

转场：运动跟拍用硬切，场景切换到新地点用硬切
BGM：环境音为主，不加BGM或极轻BGM
画面比例：9:16竖屏
```

## EDL通用规范

### 字幕规范

| 元素 | 规格 |
|------|------|
| 正文字幕 | 白色、底部居中、字号适中 |
| 关键词高亮 | 黄色标记、字号1.2倍 |
| 数据大字幕 | 居中弹出、保留3秒、字号1.5倍 |
| 开头钩子字幕 | 0.5秒内出现、前3秒铺满屏幕2/3 |
| 结尾金句 | 居中、字号1.3倍、⚡图标在句尾 |

### 剪辑参数

| 参数 | 抖音 | 视频号 |
|------|------|--------|
| 比例 | 9:16 | 9:16(竖) 或 16:9(横) |
| 分辨率 | 1080×1920 | 1080×1920 或 1920×1080 |
| 帧率 | 30fps | 30fps |
| 编码 | H.264 | H.264 |
| 码率 | 8-12Mbps | 6-10Mbps |

### 剪辑铁律

1. **前3秒绝不留空**：开场0.5秒内必须有画面+字幕
2. **硬切为主，不用花哨转场**：保禄内容风格真实，不用转场特效
3. **BGM不得盖过人声**：BGM音量不超过人声的30%
4. **数据字幕留3秒**：用户需要时间看数字
5. **结尾定格1秒**：给观众反应时间，不要话说完立刻黑屏
6. **去呼吸声/口癖**：保禄的「嗯啊吧」适度保留（是人味），但明显的呼吸声、清嗓子要剪掉
