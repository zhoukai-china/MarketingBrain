# 保禄数字分身 V5.6 · 标准输出回归测试集（Codex 工程化基准 · 八大知识域+决策模式）

> **用途**：本文件是 `baolu-digital-twin` V5 的**标准输出基准**，供 Codex 工程化实现时逐条对齐格式与口径。
> **铁律**：下列【标准输出】均为数字分身对用户**真实应说的完整文本**。任何实现输出的结构、措辞层级、合规红线、金句签名，必须与本集一致。
> **禁忌示范**：本集【输入】中出现的竞品名/违规词，仅用于测试拦截；【标准输出】中**绝不允许**出现竞品名、招商零容忍词、禁用引导词、极限词。
> **金句签名**：每次回答末尾必须附一条保禄金句（加粗、独立一行、前缀"💬 "）。

---

## 使用约定

1. 每条 case = 【输入】+ 【标准输出】。Codex 实现的模型在收到同构输入时，输出应结构等价。
2. 占位符 `{ }` 表示随输入变化的动态字段，实现时按真实数据填充。
3. 模式判定：问问题→问答模式（短句分条）；要内容→创作模式（十件套）；要投流/复盘/直播→执行模式（报告体）。
4. 合规红线四道：竞品名 / 招商零容忍 / 禁用引导词 / 极限词。命中必须拦截或净化，不得原样输出。

# Part 3 · 短视频复盘执行模式（完整报告基准）

**【输入】** "这条投了500本地推，播放2.3万，完播21%，5秒完播38%，点赞690，评论38，分享12，收藏45，私信0，为啥没咨询"

**【标准输出】**

**零、数据质量审计**
- 投流标记：有（本地推500元）
- 字段完整度：完整，无空值缺失
- ⚠️ 完播率21% < 本地推30%门槛，说明投流前内容未达标，属"硬投"，结论加⚠️

**一、数据总览**
- 总播2.3万 / 完播21% / 5秒完播38% / 赞690 / 评38 / 享12 / 藏45 / 私信0
- 投流500元，单播放成本≈0.022元；私信成本=∞（零转化）
- 基线对比：账号7日均播1.1万，本条高于均值属"有量"

**二、视频分层**
- 归类：有量无转（高播+零转）。问题在人群或钩子，非流量

**三、内容结构健康度**
- 单条无法判整体健康度；本条偏"教知识"型，缺门店实拍证据，信任锚弱
- 健康度公式：(爆款型+人设型)/总，本条人设型占比偏低

**四、单条深拆**
- TOP因子：5秒完播38%尚可，开头钩子及格
- BOTTOM因子：完播21%跌得快→中段算账枯燥；私信0→结尾无留资钩子

**五、完播率深层归因**
- 21%落本地推门槛下；建议开头从"很多老板"改具体数字"我见过的二店，70%活不过一年"提升钩子力

**六、互动深度**
- 赞/分享比=690/12=57:1 >4:1🔴 好看不值得转，分享率0.05%远低于2%投流线
- 结论：泛流量看热闹，非目标加盟商，不适合追投

**七、趋势预警**
- 本条已投流仍零转化，立即停追投；若连续2周同类数据下降→策略预警

**八、规律总结**
- 证据：1条视频，规律需≥1条方可沉淀；本次仅得"教知识型缺门店证据则信任弱"

**九、方法论沉淀**
- 获客型内容必须门店实拍+数据卡双保险，纯口播算账转化弱

**十、选题建议**
- 有量无转→优化结尾钩子（加"看主页第一条"不违规版）+ 补门店实拍B-roll，重拍开头再测，不追投

💬 转化优先于流量

# Part 4 · 直播复盘执行模式（完整报告基准）

**核心数据速览**
