## 先定义生意问题

接到任务后先把“投流”翻译成可衡量的生意目标：

1. 交易：团购成交、支付 GMV、核销 GMV、到店毛利。
2. 门店：门店曝光、门店点击、到店客流、回头客。
3. 直播：进房、停留、商品点击、订单、支付与核销。
4. 线索：有效对话、表单、有效线索、预约、到店、成交。
5. 搜索：覆盖主动需求、品牌/品类词占位、搜索成交或搜索线索。

优先收集：行业、城市与门店数、客单价、毛利、团购/线索商品、核销周期、预算、历史消耗、目标成本、素材量、直播时段、回传能力、当前资质与违规情况。

信息不全时可以先给条件化方案，但必须标注假设，不能伪造账户结论。

## 选择产品与目标

### 交易型

- 有成熟团购、可直接支付：优先评估短视频推商品、直播交易和全域投放。
- 门店知名度低、需要先建立到店意愿：评估短视频推门店，再追踪门店访问与后续交易。
- 有稳定直播团队、货盘、主播和履约：使用直播加热或直播全域；先保证承接，再放大流量。
- 只想“涨播放”不是完整目标；必须说明播放如何连接到门店、商品或直播转化。

### 线索型

- 高客单、长决策、无法直接团购成交：使用线索产品。
- 新手或数据稀少：评估线索简单投等低门槛模式。
- 有稳定回传和足够深层事件：评估深度转化与 UBMax/周期稳投。
- 若只有“线索量”没有有效性和成交回传，算法会优化到便宜但低质的浅层事件。

### 搜索型

- 用户已有明确需求：使用搜索营销承接品牌词、品类词、场景词、地域词。
- 搜索不只是“加关键词”；要同时优化搜索流量选择、素材/封面相关性、出价与落地承接。
- “抢首位”“出价系数”“搜索通”“蓝海投放”等能力可能按账户开放，先核对当前产品手册。

## 账户与计划结构

遵循“一个单元只回答一个问题”：

- 不在同一测试单元混合目标、素材类型、门店区域、商品和人群变量。
- 连锁门店按经营半径、城市层级、门店成熟度或履约能力分组，不机械一店一计划。
- 交易、线索、搜索分开核算；短视频与直播分开观察承接链路。
- 测试期控制变量：一次只改变素材、出价、定向、商品或直播时段中的一个主要因素。
- 保留可复盘命名：日期-城市-目标-场景-商品/门店-素材批次-出价方式。

官方 PC 端创编资料显示，账户可能同时存在标准投放与全域投放；定向可涉及不限、行政区域、自定义、门店附近，以及智能推荐或自定义人群。实际可选项以账户实时界面为准。

## 短视频交易投放

### 素材组合

建立至少三类创意假设：

- 强利益：价格、套餐、限时权益，但价格与使用条件必须准确。
- 强场景：谁在什么场景下为什么来，突出本地感和距离感。
- 强证明：真实门店、环境、菜品/服务过程、顾客体验、可验证资质。

视频首段需要快速回答“是什么、适合谁、为什么现在行动”。挂载的门店、商品、地址与视频表达必须一致。

### 投放判断

- 曝光少：先查审核、余额、排期、定向范围、出价/成本目标、素材可投状态和商品状态。
- 点击低：优先改首屏、封面、卖点与人群匹配，不先归因于出价。
- 点击高但支付低：查价格、套餐理解、门店距离、评价、商品页、库存和优惠条件。
- 支付高但核销低：查履约、预约、有效期、门店承接、退款与核销周期；不能只报支付 ROI。

## 直播交易投放

流量前先检查直播承接：

- 货盘：主推品、价格锚点、库存、核销限制、引流品与利润品配合。
- 人：主播话术、节奏、场控、评论区、客服。
- 场：画面、声音、门店/商品证据、团购组件、福利节奏。
- 时：预热、开场、峰值、尾场；按时段看流量与转化，不用整场均值掩盖问题。

直播诊断漏斗：曝光 → 进房 → 停留/互动 → 商品点击 → 下单 → 支付 → 核销。

当进房差时优化封面、标题、素材与流量匹配；当进房好但停留差时优先修直播内容；当停留好但商品点击差时修货盘与讲解；当订单好但核销差时修履约。

## 线索投放

### 事件设计

从浅到深建立事件：咨询/表单 → 有效线索 → 预约 → 到店 → 成交。优先优化离真实收入更近、又有足够量和稳定回传的事件。

### 质量治理

- 统一“有效线索”定义：地域、需求、预算、时间、联系方式可用性。
- 记录无效原因，不把“未接通”全部归因于流量；同时检查跟进时效和话术。
- 分析有效率、预约率、到店率、成交率与回款，不只看线索成本。
- 对回传延迟、漏传、重复传、错误事件映射先做数据 QA，再调算法。

### 深度转化适配

满足以下条件再上深度事件：回传稳定、事件含义一致、样本不是极度稀疏、销售流程能及时更新状态。否则先用较浅事件积累，再逐步迁移。

## 搜索营销

把词分为：

- 品牌词：保护已有心智，检查竞品和自然结果协同。
- 品类词：规模大、竞争强，需要强卖点与承接。
- 场景词：聚会、约会、亲子、团建、周末等。
- 地域词：城市、商圈、地标、附近。
- 痛点/服务词：线索行业的明确需求表达。

搜索素材必须让标题、封面、正文、门店/商品/线索页与查询意图一致。先看搜索词和转化质量，再决定提价；“提价抢首位”不能替代素材和承接优化。

## 预算与放量

- 冷启动阶段避免频繁、大幅、多变量改动；先获得可解释样本。
- 放量前确认转化真实、回传稳定、核销/有效线索没有恶化。
- 每次只放大一个维度：预算、地域、人群、时段、素材或商品。
- 设止损与回退条件；不要把官方成本保障误解为无条件赔付。
- 预算按“探索、稳定、放量”分层；探索预算承担学习，稳定预算守住基本盘，放量预算追增量。

## 行业适配

- 餐饮/茶饮：商圈半径、用餐时段、套餐门槛、排队和核销体验。
- 休闲娱乐/丽人：场景感、环境证明、预约能力、淡旺季和复购。
- 酒旅/游玩：出行半径、日期库存、天气、节假日、退款与预约规则。
- 婚摄/家装/教育等线索：有效线索定义、销售跟进、深层回传、行业资质。
- 医疗健康、金融、房地产：先读最新准入、资质、素材与禁投规则，再谈策略。

官方案例用于提取结构：生意背景 → 问题 → 产品组合 → 素材/直播承接 → 结果 → 可迁移条件。不要直接复制案例中的 ROI 或 GMV 目标。
