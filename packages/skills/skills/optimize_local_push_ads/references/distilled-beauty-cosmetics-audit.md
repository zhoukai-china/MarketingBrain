## 一、违规禁投（准入红线）

### 1.1 私处护理类商品禁投

> 来源：文章ID 147926 / 144807 / 207679 / 144205

- 不得售卖作用于私处的护理类商品，高频产品如：私处香氛、私处润滑液、男士精油、男士喷雾、美乳仪、私处凝胶、私处香皂、私处湿巾、私处嫩红素、阴道凝胶、缩阴凝胶、阴道栓剂、乳头矫正类产品等。
- 女性私处洗液：【千川准入，AD 禁投】。女性私处洗液不得涉及赠送或配套医疗器械类清洁工具的宣传（如直接描述产品的医疗器械通用名称：内冲工具、入体清洁工具、阴道冲洗器；或在素材中展示医疗器械的画面或使用方式等）。
- 视频素材内整体暗示私处使用产品、且涉及两性关系中使用的，同样命中私处护理商品。

**违规案例（❌）**
- 投放私处护理凝胶，命中私处护理商品，不合规。（147926）
- 投放私处香水，属于禁止准入的产品，不合规。（147926）
- 素材"大姨妈后推入使用、老公变成粘人精"，整体指向私处使用产品，暗示私处润滑、养护功效，不合规。（144807）
- 素材明确指向产品用于夫妻性行为前润滑，属于私处润滑护理类产品，不合规。（144807）
- 投放男性私处护理产品（姨夫巾），属于禁止准入的产品，不合规。（207679）
- 素材"私处香皂/洗护涉及专门针对男性"，产品不接受投放。（144205）

### 1.2 医美/药品混淆类产品禁投

> 来源：文章ID 207679 / 144205

- 不得投放暗示医疗功效类产品，如煤焦油洗剂、雪莲护垫/雪莲红花护垫类商品等。
- 不得投放医美项目相关产品，如蛋白线、眉眼唇辅助剂、纹绣舒缓膏等。
- 不得投放名称含"臭"字或含"狐臭/腋臭"、且指向去除人体狐臭的日化美妆产品。
- 不得投放纤体塑形的日化美妆产品。
- 不得投放内置物理美鼻器/美鼻夹/美鼻神器（AD）。
- 不得投放玻璃修复液。
- 不得投放手机电池修复器。
- 不得投放风油精（属于 OTC 药品，医疗行业可投放，日化行业不接受投放）。

**违规案例（❌）**
- 投放雪莲贴，属于暗示医疗功效类产品，不合规。（207679）
- 投放降温喷雾，属于作用于人体/物体的降温产品，不合规。（207679）
- 素材"美鼻夹"产品不接受投放。（144205）
- 素材"玻璃修复液"产品不接受投放。（144205）
- 素材"风油精"类产品属于 OTC 药品，在日化行业不接受投放。（144205）

### 1.3 降温喷雾禁投

> 来源：文章ID 147926 / 144807 / 207679 / 144205

- 不得投放"迅速降温剂、降温喷雾、降温神器"等用于物体或人体的降温产品（如冰肌喷雾、清凉喷雾等）。

**违规案例（❌）**
- 投放降温喷雾，属于作用于人体/物体的降温产品，不合规。（147926 / 207679）
- 素材"清凉喷雾"类产品不接受投放。（144205）

### 1.4 其他禁投商品与服务

> 来源：文章ID 144807 / 144205

- 不得涉及情趣用品，如阴道凝胶、避孕套、情趣用品、书籍、外挂球（锁精环）等。
- 不得涉及破坏生态环境的产品或服务，如售卖动物捕杀设备（蚯蚓机/地龙仪/地笼、锚鱼器——包括可视/不可视锚鱼器、带有锚鱼功能的钓鱼类工具）、宠物标本类制作等。
- 不得涉及捕杀/诱杀动物的产品或服务，包括任何含有毒害、麻醉成分的诱捕、毒捕药剂及添加剂等。

**违规案例（❌）**
- 视频素材内整体暗示私处使用产品，且涉及两性关系中使用，命中私处护理商品，不合规。（144807）

### 1.5 禁投疾病类投放

> 来源：文章ID 147926 / 144807 / 207679

- 治疗皮肤疾病相关产品及服务禁投，如：头癣、手癣、足癣、股癣、甲癣、体癣、指甲癣、疱疹、酒渣鼻、脓疱疮、化脓菌感染、鱼鳞病、灰指甲、硬皮病、黄水病、神经性皮炎、疥疮、湿疹等（近期高频疾病补充：脚气、鸡眼、疣、鸡皮肤（或毛周角化综合征）等）。
- HPV 相关产品及服务禁投：HPV 检测试剂、HPV 体检服务等。

**违规案例（❌）**
- 投放汗疱膏，是皮肤病相关禁投产品，不合规。（147926）
- 投放灰甲净，指向灰指甲，属于皮肤病相关禁投产品，不合规。（147926）
- 产品外包装表述为"脚气净……喷雾"，明确指向禁投疾病相关，不合规。（144807）

## 二、功效虚假（美妆）

### 2.1 普通化妆品不得宣传特殊化妆品功效

> 来源：文章ID 147926 / 144807 / 207679 / 144205

依据《广告法》第四条、第二十八条（广告不得含有虚假或引人误解的内容）。

- 特殊化妆品：指用于染发、烫发、祛斑美白、防晒、防脱发的化妆品以及宣称新功效的化妆品。普通化妆品不得涉及相关功效。
- 非祛斑美白类化妆品，不得宣传产品可产生让皮肤本身变白的美白效果（如：美白、增白、变白、越来越白、白了一个度等）。
- 遮盖类化妆品可涉及符合产品特性的即时性变白效果，但不得宣称可：美白、增白。遮盖类产品范围：粉底液/霜/膏/棒、气垫、遮瑕液/膏、素颜霜、隔离霜、CC霜/BB霜、带物理遮盖效果的防晒/贵妇膏等。
- 普通化妆品不得涉及斑点、黑色素相关功效描述（除物理遮盖外）；非特化防晒类产品不得涉及隔离防护紫外线/UVA 等相关功效描述。
- 普通化妆品不得明示暗示具有「改善黑（黑变白）」的美白类特化功效，常见如：皮肤黑的人可以使用、黑的问题不用怕、脸黑黑的人快试试、"乌唇""乌肘"类的描述和展示（除物理遮盖外）。
- 普通化妆品不得涉及防掉发、防脱发、发际线后移/掉发人群可用、展示画面内有掉发等明示或暗示防脱功效的场景。
- 非染发类/遮盖类的化妆品：不得宣称具有「非即时性的白发转黑发」及「改善白发」类相关功效。
- 普化止汗露/走汗珠类产品不得涉及除臭、净味功效。

**违规案例（❌）**
- 投放普化眼贴膜，素材宣传淡化"黑眼圈"，涉及"改善黑"美白类特化功效，不合规。（147926）
- 投放普化面膜，宣传"淡斑""阻断黑色素"相关，涉及美白类特化功效宣传，不合规。（147926）
- 投放普化面霜，素材宣传"美白淡斑"，涉及美白类特化功效，不合规。（207679）
- 投放普通化妆品，演绎黑手肘变成白皙状态，暗示美白功效，涉及特殊化妆品功效，超出普通化妆品功效，不合规。（144807）
- 普通化妆品涉及特殊化妆品功效（淡化斑点），超出功效，不合规。（144205）

**合规案例（✅）**
- 投放美白精华霜，提供合规祛斑美白类特化资质，且素材宣传贴合相关功效信息，合规。（147926 / 207679）
- 投放普通化妆品贵妇膏，宣传"抗皱养颜 滋润保湿"相关，未涉及特殊化妆品功效范围，合规。（147926）
- 投放普化面膜，宣传"弹润透韧"，未涉及特殊化妆品功效范围，合规。（207679）

### 2.2 特殊化妆品功效需与报备一致

> 来源：文章ID 147926 / 144807 / 144205

- 产品批件无祛斑类功效则不可宣传"美白、淡斑"；防脱类产品不得宣传黑发等；育发类产品不得宣传黑发等。
- 祛斑美白（仅物理遮盖类）类特化不得宣传「去除/分解/告别/抑制/防止/解决/阻断黑色素等」等根源美白功效。
- 防晒类产品不得宣传具有美白功效。
- 防脱育发类特殊化妆品不得表述使用产品后发量增加。

**违规案例（❌）**
- 投放育发类特殊化妆品，表述使用完产品后发量增加（比别人多出来两倍的头发），命中促进头发生长类夸大功效，不合规。（144807）

### 2.3 不得涉及超出化妆品功效范围的词汇

> 来源：文章ID 147926 / 144807 / 144205

- 涂抹等外用产品/服用产品，不得描述可直接补充胶原蛋白、可食用（可食用、食品级）、防蓝光、抗疲劳、解码、数码、智能、红外线、助眠、破坏细胞、抗糖、提高肌肤抗刺激、化解死细胞、提高或保护记忆力、吸收胶原蛋白、可促进头发生长类夸大功效等。
- 不得涉及：根源黑发、破坏黑色素、破坏黑色素细胞、白发是络氨酸酶降低导致的、不节食等描述。
- 不得涉及可直接补充/吸收/促生胶原蛋白（Ⅲ人源蛋白/三型人源蛋白/重组人源Ⅲ型胶原蛋白）。
- 不得借助身体内部器官等暗示超脱化妆品功效。
- 【合理场景可支持】：产品报备名称中包含「助眠、抗糖」类描述，可支持作为完整的产品名称出现，但不得单独使用；素材宣传「助眠、抗糖」需要提供功效宣称的证明材料，其宣称需包含在药监部门注册或者备案的功效范围内。
- 即时性遮盖类商品，可涉及符合客观事实的即时性增发、密发功效描述。如提供「促进头发生长、增发」的功效证明，可涉及与之对应的功效描述；如涉及具体数值，需提供对应资质，并在素材中标记清楚数据来源。

**违规案例（❌）**
- 投放胶原蛋白精华面膜，宣称"补充胶原蛋白"，不合规。（147926）

**合规案例（✅）**
- 投放精华液，宣传成分具有"水解胶原""弹性蛋白"，未涉及可以补充胶原蛋白类宣传，合规。（147926）

### 2.4 不得夸大投放产品的效果（医美/不可逆状态/年龄/真皮层）

> 来源：文章ID 147926 / 144807 / 144205

- 不得宣传产品具有等同或超出医美项目的效果。常见医美项目包括但不限于：超声刀、各类美容美体针（美白针、黄金微针、童颜针、瘦脸针、瘦肩针、瘦腿针、营养针、填充针、除皱针、轮廓针等）、溶斑术/溶斑、热玛吉、线雕、激光、光子嫩肤、果酸焕（换）肤、肉毒素（针）、Fotona4Dpro、白瓷娃娃、皮秒、酷塑或深蓝射频、热拉提、提眉、做/切/填/割（动词穷举）+眼袋/法令纹/鱼尾纹等各种皱纹、拉皮、院线级相关功效等。
- 脱毛类产品不得宣称抑制毛发生长、不留小黑点/胡茬/胡青（含剃须工具）；不得涉及使用脱毛产品后，立刻一抹/一擦就实现脱毛效果的演绎。因化学类脱毛机理是软化毛囊脱毛，脱毛类化妆品可涉及减缓毛发生长类宣传。
- 不得宣传使用产品后，可解决不可逆转的肌肤状态问题等脱离实际的承诺表述。不可逆的肌肤状态包括：斑点、疤痕、黑眼圈、眼袋、皱纹、痘印、痘根、痘坑、痘肌、敏感肌、红血丝、白发等。
- 不可逆肌肤状态的禁词/禁句式：「祛/去、除/去除/消除、褪、克星/天敌、抑制、熨斗/橡皮擦、拜拜」+不可逆状态、减少细纹/皱纹等。
- 不得涉及利用夸张的年龄对比或利用年龄的夸大描述：五十岁看起来和三十岁一样、用完年轻X岁、50岁不长皱纹的秘密、用完都不认识自己等。年轻X岁，不区分即时非即时以及和自己对比还是和别人对比。
- 化妆品不得涉及：消包、止痒；不得涉及宣传产品或产品成分能直达真皮层，或对真皮层产生作用（如：直达真皮层、可使真皮脱落、在真皮层发挥作用等）。

**违规案例（❌）**
- 投放面膜，宣传"院线级注氧"，属于暗示产品具有医美项目功效，不合规。（147926）
- 投放修护皱纹类产品，表述"填充皱纹"相关，暗示护肤品可以达到医美项目功效，不合规。（144807）
- "60岁看起来像18岁"，利用夸张的年龄对比暗示产品效果，不合规。（144205）
- 投放抗皱精华液，提及"祛皱"，祛+不可逆皮肤状态，不合规。（144205）
- 投放修护皱纹类产品，表述"在俄罗斯从来就没有满脸皱纹的情况，什么法令纹、鱼尾纹、抬头纹，人家不费吹灰之力就处理好了"，是因为俄罗斯人使用了视频内投放的产品，命中受益人类场景，不合规。（144807）

**合规案例（✅）**
- 投放护肤品，宣传淡化细纹、舒缓肌肤相关，未涉及对细纹这类不可逆的肌肤状态问题做承诺表述，合规。（147926）

### 2.5 不得虚构产品的适用性

> 来源：文章ID 147926 / 207679 / 144205

- 不得虚构产品对任何严重的肌肤状态均有效果类表述。
- 严重肌肤状态句式：无论/不管/哪怕XX多严重/再厉害/多少年/大半辈子、越老、xx问题越多（如：不管是刚出现眼角纹，还是很多年的鱼尾纹；哪怕你的皱纹已经大半辈子了）。
- 有效果句式：越有效、都会改善、在它面前都是小儿科/小case、也怕他、都被拿捏。
- 即时性效果宣传可支持：不涉及严重肌肤状态表述（如仅表述皱纹比较明显时）可支持；仅表述可以尝试/试试/买两瓶回去看看等，非明确表述有效果类表述可支持。

**违规案例（❌）**
- 投放眼部精华，宣传"再厉害的眼袋也怕这个东西"，属于虚构产品的适用性，不合规。（147926）
- 投放祛斑霜，宣传"不管多少年的斑点都管用"，涉及虚构产品的有效性，不合规。（207679）

**合规案例（✅）**
- 投放眼霜，宣传"不管再严重的眼袋问题，都可以试试"，未涉及有效果类宣传，合规。（147926）

### 2.6 不得涉及使用前后的效果对比

> 来源：文章ID 147926 / 144807 / 207679 / 144205

- 产品效果因人而异，不可能所有人使用产品后都会有较为明显或翻天覆地的变化/改观；有些视频所展示的问题为病症，普通的日化用品无任何医疗能力，故无法达到任何效果。
- 非即时性效果产品不得涉及使用前后效果对比；不得涉及同一个体、同一部位（同时满足）的显著前后效果对比；不得以水果的形态变化，暗示人的使用产品前后状态/产品效果。
- 即时性效果产品不得涉及虚假的前后效果对比；遮盖类产品不得涉及巨大肤色差异的虚假功效；不得通过 ps/磨皮等手段使皮肤或水果皮的毛孔/纹路类消失。

**违规案例（❌）**
- 投放美白霜，展示眼袋、黑眼圈在使用产品后消失，涉及对比演绎，不合规。（147926）
- 投放祛痘洗面奶，展示脸部痘痘在使用产品后消失，涉及对比演绎，不合规。（147926）
- 投放去皱类护肤品，涉及同一人同一部位坏皮肤到好皮肤的对比，不合规。（144807）
- 投放素颜霜，演绎明显痘痘在涂抹产品后完全消失，属于无法实现的"一涂一抹变无瑕"的皮肤状态演绎，不合规。（144807）
- 投放颈霜，展示颈部皱纹对比，暗示承诺效果，不合规。（207679）
- 投放美白祛斑产品，展示脸部斑点前后对比，暗示承诺效果，不合规。（207679）
- 面霜涉及一个月前与现在皮肤对比，不合规。（144205）
- 护肤品涉及同一人同一部位，坏皮肤到好皮肤的对比，不合规。（144205）
- 遮盖类产品涉及夸张的磨皮，痘坑等都完全磨平，不合规。（144205）

**合规案例（✅）**
- 投放面膜，素材列举常见的肌肤问题，未涉及前后对比展示，合规。（147926）
- 投放眼贴膜，素材展示人物自身使用前眼部肌肤状态姣好，未涉及前后对比展示，合规。（147926）
- 投放素颜霜，人物本身肌肤状态较好，符合产品客观使用效果演绎，素材演绎合规。（144807）

### 2.7 染发类产品专项

> 来源：文章ID 147926 / 144807 / 144205

- 素材不得误导用户以为投放的产品非染发类产品，不得明示或暗示产品具有根源改变发色的功效等虚假效果宣传。常见违规场景：
  - 通过否定染发方式误导用户（如：不想再染发的可以来找我；用我的这个方法可以避免染发带来的伤害）。
  - 刻意宣传适用人群误导用户（染发类产品一般无特殊适用人群）。合理的适用宣传可支持：适用于非孕妇人群、适合皮肤不敏感的人群使用；为保证染发效果单次用量要增加。
  - 宣传不合常规的使用频次/方式（如：两天洗一次、连续用7天、黑了就不要再用了/黑了就可以停用了等）。
  - 宣传不合常规的见效时间/用量。
  - 通过非常规使用方式/场景宣传产品效果，包括但不限于将染发产品倒在脸上、涂抹到脸上。
  - 其他暗示根源黑发：宣传白发是体内X因素导致的、产生白发的身体原因；刻意宣传白发状态的不可逆性（明示暗示白发是好不了的/不可能自己好的、白发问题没法根本解决、攻克了白发问题等）；涉及人体皮下组织细胞、毛发的毛囊状态动画演绎；涉及内养性质的民间黑发方法对比（不会让你吃黑芝麻黑豆/以黑养黑、不需要乱用偏方、不需要按摩等）。
- 【注】不得涉及刻意宣传「白发量的多少/数量、白发问题的产生时长、白发问题是否拖延/拖延的程度、白发问题是否严重/严重的程度」。
- 染发类产品固色时间宣传：支持 ≤2个月（60天）；若大于该时间，脱离产品固色的客观事实，不合规。

**违规案例（❌）**
- 投放染发膏，宣传"不用再染发"，属于否定染发方式类宣传，不合规。（147926）
- 投放染发膏，宣传"连续用30天"，属于不符合常规的使用方式，不合规。（147926）

**合规案例（✅）**
- 投放染发膏，宣传"盖白发"，符合染发类效果宣传，合规。（147926）
- 投放染发膏，宣传"可多次使用易保存"，属于产品自身包装方式宣传，未涉及不符合常规的使用频次介绍，合规。（147926）

### 2.8 遮盖类产品：巨大肤色差异的虚假功效

> 来源：文章ID 147926 / 144807 / 144205

- 遮盖类产品可以达到修饰美化皮肤的作用，如遮盖、即时性亮白、匀称肤色等，但不得涉及巨大肤色差异的虚假功效。
- 巨大肤色差异场景：
  - 身体上写字/画画/划横线，使用商品可以完全遮盖隐形（注意：非常规的使用场景，常为口红、眉笔、彩笔等使用展示）。
  - 无法实现"一涂一抹变无瑕"的皮肤状态（特征：显著凸起/凹陷，比如眼袋、皱纹、疤痕、凸起型痘痘、痘坑等）。
- 底妆类产品（素颜霜、粉底液、妆前乳、毛孔打底棒）投放时，不得涉及在"关掉美颜/滤镜/瘦脸/变色类功能"下演绎使用产品后的磨皮/疑似磨皮状态；也不得涉及在参照物（如：手指就放在这里、笔就放在这里）对照下演绎使用产品后的磨皮/疑似磨皮状态。
- 【合理场景可支持】：本身皮肤有斑点、痘印、红血丝等瑕疵，涂抹遮盖后皮肤变好，属于可实现效果；本身肤质较好，没有明显瑕疵，涂抹后有肤色变化、肤感变好。

**违规案例（❌）**
- 投放粉底液，演绎明显眼袋问题在使用产品后变成无瑕肌肤状态，超出粉底液遮盖效果，不合规。（147926）
- 投放素颜霜，演绎明显痘痘在涂抹产品后完全消失，不合规。（144807）

**合规案例（✅）**
- 投放素颜霜，人物本身肌肤状态较好，素材展示提亮肤色效果，合规。（147926）

### 2.9 虚假实验 / 不符合常规使用场景

> 来源：文章ID 147926 / 144807 / 144205

依据《广告法》第四条、第二十八条（使用虚构、伪造或无法验证的科研成果、统计资料、调查结果、文摘、引用语等作证明材料的，构成虚假广告）。

- 不得通过虚假实验或不符合常规使用场景的素材展示，来过度夸大产品效果。
- 投放祛斑美白类化妆品，不得涉及将物品表面变成白色，或将浑浊/有颜色的液体变清澈场景（如黄水变白的净色效果）。
- 牙膏/祛斑产品，不得演示刷鹌鹑蛋去掉蛋壳表面色斑。
- 素颜霜/散粉类产品，不得演绎经水浸泡后仍完好无损、丝毫不影响使用效果。
- 洗面奶/清洁面膜/沐浴乳，不得演绎"油水变清"、上脸后"白变黄""类似污渍的黑点浮出""黑头浮起"等场景。
- 唇部/眼部彩妆不得展示过度夸张、不符合常规生活使用场景的防水不脱妆测试。夸张冲洗类：淋雨冲洗、水龙头冲洗、水盆冲洗、水桶类冲洗等；夸张使用类：水下使用口红展示防水效果、利用胶纸粘贴测试防脱妆效果等。
- 投放清洁/护肤类产品，不得涉及使用产品后析出黑点/黄渍类虚假场景。
- 不得使用超出常识范围的测试方式证明物品（商品或经商品修复后的物品）的坚韧度或质量，包括汽车碾压、尖锐坚硬物品刮划、锤子敲砸、火烧或超重量测试等。
- 展示食品/日化用品不合常理的溶解效果，不得涉及。
- 过滤装置净水类产品，不得将酱油/可乐/油/果汁/颜色异常的液体等过滤为清水。

**违规案例（❌）**
- 投放美白洗面奶，演绎产品可以将塑料袋上的黄色颜料清洁掉，涉及虚假的实验场景，不合规。（147926）
- 投放粉底液，演绎将产品在花洒下冲洗后仍旧可以正常使用，属于不符合常规生活使用场景的防水测试，不合规。（147926）
- 素颜霜展示防水不脱妆用油擦不掉，涉及化妆品虚假功效描述，不合规。（144205）
- 素材描述【洗面奶滴入杯子后，使"油水变清"】，涉及通过虚假实验过度夸大产品效果，不合规。（144205）
- 投放口红防水效果，通过夸张的演绎展示口红不脱妆，不合规。（144205）

**合规案例（✅）**
- 投放黑头粉刺贴，素材演绎正常在脸上使用产品的过程，未涉及虚假测试，案例合规。（147926）

## 三、绝对化用语与保证性承诺

### 3.1 不得承诺具体的见效时间/用量

> 来源：文章ID 147926 / 144807 / 207679 / 144205

- 不得宣传具体的见效时间或用量，如：1瓶搞定、一抹淡斑等。
- 不得宣传达到目标效果的使用时间或用量，间接暗示产品起效的时间或用量（如：要是你想要白的快一些，就一天用3次——仅限非即时性产品）。
- 不得强暗示处理某类非即时性问题的时间或用量（如：衰老型眼袋要多久？7天/两瓶；X问题，X天（瓶）就X天（瓶））。
- 时间/用量+停用类表述不得涉及：宣传使用了具体用时/用量就可以停止使用；暗示使用了一定周期或数量/次数后就可以永久解决对应问题，涉及效果保证，不合规（不区分可逆/不可逆肌肤、即时/非即时性产品）。
- 问答+否定式强暗示产品功效不得涉及（如：素材借用问答式结合否定使用时间，强暗示该产品至少在两三个星期即可达到非即时性改善的效果）。
- 非即时性效果产品不得承诺见效时间或用量；即时性效果产品不得涉及不符合常规的见效时间。
- 【合理场景可支持】：x月的试用期、x天的试用期/退换货时间等合理的售后服务时间，可支持。即时性商品在符合对应即时性效果的宣传中，可支持涉及1瓶搞定类描述（如：遮盖型美发笔宣称1瓶搞定发际线留白问题；素颜霜宣称1瓶搞定化妆）。

**违规案例（❌）**
- 投放祛斑霜，宣传"28天淡斑效果看得见"承诺产品具体的见效时间，未提供对应的功效证明，不合规。（147926）
- 投放美白祛斑抗皱霜，宣传斑点和皱纹问题仅需7天（"不管你是斑点暗沉还是法令纹，我说7天就7天"），暗示7天即可改善相关问题，涉及承诺效果宣传，不合规。（207679）
- 投放防脱洗发水，宣传"我才洗了两瓶就不敢再用了"，暗示使用2瓶后就可以永久解决对应问题，不合规。（207679）
- 素材表述"我真想再掉发一次"，涉及反转性承诺，暗示产品具有可以永久性改善某种皮肤问题的暗示，不合规。（144205）
- 内容中"轻松搞定"暗示承诺产品的效果，不合规。（144205）
- 内容中"最后就自然而然脱落"，承诺产品效果，不合规。（144205）

**合规案例（✅）**
- 投放护肤品，展示使用过程，未涉及承诺宣传，合规。（207679）
- 投放护肤品，宣传"一定要试试"属于正常的宣传介绍，未涉及功效的绝对化承诺，合规。（147926）

### 3.2 不得承诺产品维持时间

> 来源：文章ID 147926 / 144807 / 144205

- 不得承诺产品维持时间，如：一日洗头三日不油、素颜霜三天不脱妆；染发产品不得涉及大于2个月（60天）的固色时间宣传。
- 【合理场景可支持】：
  - 留香类产品：≤7天留香时间、持久/持续留香，可支持。
  - 持妆/定妆类产品：≤24小时持妆效果、持久/超长不脱妆，可支持；控油效果（含洗发水）可理解为持妆功效（≤24小时），如散粉宣传控油12小时，可支持。

**违规案例（❌）**
- 投放眼镜防雾剂，表述"喷一次持续防雾一星期"，涉及效果持续时间承诺，不合规。（147926）
- 投放留香喷剂，表述"留香长达33天"，涉及产品的使用效果做虚假性保证，不合规。（144807）

**合规案例（✅）**
- 投放洗衣凝珠，宣传留香72小时，且已提供数据证明文件，案例合规。（147926）

### 3.3 不得承诺永久性效果

> 来源：文章ID 147926 / 144807 / 207679 / 144205

- 不得承诺产品/服务的效果具有永久性，承诺永久解决某皮肤问题/烦恼。
- 常见承诺用语：告别、不再复发、彻底根除、不留痕、阻止、防止、阻断、解决、一生受益等。如：永久告别敏感肌、痘痘不再复发、彻底根除、防止痘痘再生、抑制色斑增生、解决青春痘等，均不合规。
- 反转性效果承诺不得涉及（"我真的想再XX一次"，如再脱一次发、头发再白一次等）。
- 不得宣传某一产品受众使用产品后，实现了非即时性的具体效果（如：同事用了这款修护霜，脸上的痘痘改善了好多）。

**违规案例（❌）**
- 投放护肤套装，宣传"告别草莓鼻"，涉及永久性效果宣传，不合规。（147926）
- 投放抗皱精华液，提及"和眼纹、眼袋说拜拜"，拜拜/告别+不可逆皮肤状态，不合规。（144807）
- 素材内容中"川字纹不再有""从根源解决出油问题""不再松松垮垮"，均涉及承诺产品效果描述，不合规。（144205）

### 3.4 绝对化描述与承诺类词汇

> 来源：文章ID 147926 / 207679 / 144205

- 不得利用绝对化描述与功效结合承诺产品功效。绝对化表述常见场景：一定/肯定/100%/绝对有效等；如祛斑美白类产品宣传一定可以美白/祛斑等。
- 日化&美妆行业通用：产品的使用效果因人而异，无法保证所有人使用投放的产品都能达到某种具体功效。此类绝对化描述包括但不限于：万能擦亮、万能清洗剂、100%清洁程度效果（去除每一点污渍、百分百去除、百分百变白、百分百去油、100%去除）、绝对不卡粉、绝对不脱妆、绝对不掉色、绝对不漏水等。
- 不得宣传产品在效果上能达到绝对、永久覆盖或解决：如驱蚊、驱鼠等动物驱逐类产品不得宣传"一晚上干掉全部蚊子"等100%解决、驱逐的效果；漂白剂、彩漂类等色彩改善产品不得宣传"万能去渍"等适用于所有色彩改善场景。
- 承诺类词汇注意：都、没有、天敌、克星、不再/不再有、告别、彻底、拯救、搞定、永别、说再见、说88等。
- 未对产品效果进行承诺，仅正常推荐产品或与产品无关时无需管控，如"一定要试试这款产品""氛围感的头发就一定要头顶特别的蓬松"等。

**违规案例（❌）**
- 投放祛斑精华液宣传一定可以美白/祛斑类，不合规（规则列举场景）。（147926）
- 驱鼠产品描述"永世没老鼠，三年不见老鼠"，涉及夸大产品功效的描述，不合规。（207679）
- 彩漂产品描述"万能去渍"，涉及夸大产品功效的描述，不合规。（207679）

**合规案例（✅）**
- 投放祛斑精华液，素材宣传"淡化斑点、改善暗沉"，未涉及具体承诺效果表述，合规。（147926）
- 驱鼠产品合规描述："老鼠见了都害怕，不敢靠近，专业驱鼠，还你清净家居"。（207679）
- 彩漂产品合规描述："去黄去渍不伤衣，彩衣鲜亮，白衣洁白，全家衣物都能漂"。（207679）

### 3.5 效果虚假保证（时间+效果）

> 来源：文章ID 147926 / 144807 / 144205

- 不得对产品的使用效果做虚假性保证（时间+效果），如：5秒上鱼、1分钟快速除螨、半小时爆竿、防雾剂XX天不起雾、28天见效、7天不再有、一星期就搞定等。
- 不得涉及虚假时效性保证，如：止漏十年、十年不漏、20年不补、补漏、一刷止漏/补漏、一贴止漏/补漏等。

**违规案例（❌）**
- 投放除螨喷雾，表述"螨虫不再有"，涉及直接的承诺表述，不合规。（147926）
- 投放驱鼠喷剂，表述"家里再也没有老鼠的踪影"，涉及过于绝对承诺的表述，不合规。（144807）
- 投放驱蚊凝珠，表述"一楼点二楼香，三楼蚊子全跑光"，涉及产品的使用效果做虚假性保证，不合规。（144807）

**合规案例（✅）**
- 投放除螨喷雾，宣传各个使用场景，未涉及承诺效果宣传，案例合规。（147926）
- 投放艾灸液，宣传"涂上挺舒服"，未涉及效果保证表述，案例合规。（147926）

### 3.6 数据虚假（需提供证明并标明来源）

> 来源：文章ID 147926 / 144807 / 144205

- 投放素材中如涉及具体数据展示或使用数据/统计资料/调查结果/文摘/引用语，需提供数据真实性证明并标明来源。如：2023、24年天猫面膜类销量第一、功效证明-书包减压70%。
- 使用自行取得的数据，需提供数据真实性证明。如：全网销量一亿件、工具软件下载量/安装量/玩家数量超过100万、累计已有50万人购买、成分含量-化妆品含99.6%高纯度烟酰胺等。

**违规案例（❌）**

- 素材展示"98%、97%、95%"等数据，无数据证明，不合规。（144205）
- 素材宣传"留香7天"，无数据证明，不合规。（144205）

## 四、非医疗广告涉及医疗（医疗用语）

### 4.1 化妆品行业医疗禁用词

> 来源：文章ID 147926 / 144807 / 144205

- 中医类禁用词：止血、活血、补血、血液循环、止痛、解毒、排毒、去除体内毒素、伤口愈合清除毒素、清热解毒、驱寒解毒、清热袪湿、祛风、理气、行气、益气、安神、养脑、通脉、胃胀蠕动、利尿、延缓更年期、吸附铅汞、失眠、延年益寿、青春永驻等。

- 其他：瘙痒、过敏（抗敏/抗敏感/改善过敏/防敏/脱敏/褪敏等）、医学护肤、药物化妆品、药物护肤、医疗术语。
- 化妆品投放中不得涉及医学名人暗示产品具有医疗功效，如：扁鹊、华佗、张仲景、孙思邈、李时珍等。
- 不得涉及狐臭及其变体「油耳型腋下异味」类相关描述，包括但不限于：油耳型腋下异味、油耳型、油耳朵、耳朵油油的、耳朵油腻等。

**合规案例（✅）**

- 正常展示眼部，未涉及医疗暗示，案例合规。（207679）
- 正常展示产品信息，未涉及医疗暗示，案例合规。（207679）

**违规案例（❌）**

**合规案例（✅）**
- 正常展示眼部，未涉及医疗暗示，案例合规。（207679）

### 4.5 防脱育发洗发水品类：暗示生发功效

> 来源：文章ID 147926 / 144807 / 144205

- 防脱育发洗发水品类（含日用皂类）投放，不得出现刻意突出展示小碎发、新生头发（不区分碎发位置）或利用异常发量（极少发量、超多发量）的画面或描述做效果的暗示，均属于暗示生发功效。
- 极少发量描述：哪怕就剩一根头发、哪怕一根头发都不剩、光头都能用；画面维度：出现光头画面（不合规）、秃头/头秃、秃瓢、头顶空了、地中海等「无发状态」仍可使用/有效。
- 超多发量：出现扎多根粗辫，或展示单根夸张发量的辫子。

**违规案例（❌）**
- 投放防脱洗发水，演绎秃顶画面，不合规。（147926）
- 素材展示异常发量、新生碎发，属于暗示生发功效，不合规。（144807）

**合规案例（✅）**
- 正常发量展示，未涉及暗示生发功效，案例合规。（147926）

### 4.6 医疗相关可支持投放场景

> 来源：文章ID 147926 / 144807 / 144205

- 牙膏类产品如能提供相关资质凭证，可涉及与之对应的防龋、抑牙菌斑、抗牙本质敏感、减轻牙龈问题等描述。
- 素材中可支持提示语形式体现医疗相关描述，如"糖尿病人不建议食用"、"孕妇食用请咨询医生"等。
- 化妆品类商品宣传物理遮盖胎记、红血丝、痤疮、蝴蝶斑、咖啡斑、红斑、紫斑、褐青色痣时，可支持。
- 素材中仅可以使用"暖宫"一词，不得宣传"暖宫"效果，如"缓解疼痛、改善宫寒"等医疗用语。
- 素材中仅在公司名称/集团名称/商标中客观含有医疗词汇，无不合规，如：XX药业出品、XX科技有限公司。
- 素材可涉及舒敏、柔敏、产品用了过后不过敏等相关内容。
- 如提供生发相关专利证明，可支持作为「专利名称」客观展示/描述涉及。
- 舒缓红痒/干痒可支持，如"缓解孩子肌肤泛红、发痒干裂"。
- 化妆品「成分名称」中包含的医疗相关词汇（单纯标识所使用的化学物质或天然提取物的具体名称）可支持，如"产品含药用层孔菌提取物"。
- 宣传"止痒""消包"时：如商品为痱子粉、洗发水、花露水、青草膏、驱蚊类商品，可支持；如化妆品产品名称中包含"止痒"、或提供相关化妆品功效评价报告，可支持。

## 五、儿童化妆品

### 5.1 非儿童化妆品不得宣传为儿童化妆品

> 来源：文章ID 147926 / 144807

依据《化妆品监督管理条例》第四十三条、《儿童化妆品监督管理规定》第七条、第十三条。

- 投放产品不是儿童化妆品时，不得涉及"儿童化妆品"或暗示产品使用人群包含儿童的表述或演绎。
- 若提供儿童化妆品资质证明，或素材内客观展示产品外包装的"小金盾"标识时，可认可为投放产品是儿童化妆品。

**违规案例（❌）**
- 投放儿童防晒乳，未提供资质证明或展示外包装小金盾标志（违规案例）。（147926）

**合规案例（✅）**
- 投放防晒霜，展示外包装小金盾标志，合规。（147926）

### 5.2 儿童化妆品的功效宣传范围

> 来源：文章ID 147926 / 144807

- 儿童化妆品是指适用于年龄在12岁以下（含12岁）儿童，具有清洁、保湿、爽身、防晒等功效的化妆品。
- 儿童化妆品的功效宣传不得超出以下范围：清洁、保湿、护发、防晒、舒缓、爽身、美容修饰、芳香、修护、卸妆。若使用人群指向或包含0-3周岁（含3周岁）的婴幼儿，则其功效宣称仅限于：清洁、保湿、护发、防晒、舒缓、爽身。
- 在儿童化妆品广告中不能使用"基因技术""纳米技术"等用语进行宣传，不得进行"祛斑美白""祛痘""脱毛""除臭""去屑""防脱发""染发""烫发"等与儿童化妆品使用目的不一致的功效宣传。
- 儿童化妆品标签不得标注"食品级""可食用"等词语或者食品有关图案。
- 若化妆品的产品包装印有「儿童化妆品标志」，或投放素材可明确判断产品受众为儿童或包含儿童，素材需按儿童化妆品审核规范执行。

**违规案例（❌）**
- 投放儿童洗发水，素材宣传防脱，超出儿童化妆品功效范围，不合规。（147926）
- 投放儿童面霜，素材演绎皮肤黑红到白嫩状态对比，超出儿童化妆品可宣传功效范围，不合规。（147926）
- 投放防脱育发类洗发水，描述涉及婴幼儿使用后体毛增长类场景，超出可宣传范围，不合规。（144807）
- 投放护肤膏类产品，素材演绎脸上疙疙瘩瘩使用产品后变成姣好肌肤状态，超出儿童化妆品可宣传功效范围，不合规。（144807）

**合规案例（✅）**
- 投放儿童滋润霜，素材宣传贴合功效范畴，合规。（147926）
- 投放儿童防晒霜，素材针对防晒宣传，其中"防晒"属于可宣传功效，合规。（147926 / 144807）

### 5.3 儿童使用成人彩妆禁投

> 来源：文章ID 144205

- 素材内容不得展示未成年人/儿童使用成人彩妆的画面（含眉笔、水眉笔、粉饼等）。

**违规案例（❌）**
- 素材内容展示儿童使用成人彩妆（眉笔）画面，不合规。（144205）
- 投放成人彩妆水眉笔，素材展示儿童使用上脸画面，不合规。（144205）
- 投放成人彩妆粉饼，素材展示儿童使用上脸画面，不合规。（144205）

## 六、素材表现规范

### 6.1 引人不适：大面积病症/污垢/分泌物

> 来源：文章ID 147926 / 207679

依据《广告法》第九条（广告不得有会对用户的感官和心理造成不良刺激、影响用户正常感受的内容）。

- 不得使用真人/动画或者其他逼真类道具展示大面积/密集的人体病症、身体污垢、分泌物；不得展示从人体清理出来的污垢/分泌物；不得展示易引人不适的作用于人体的非常规清洁方式；不得展示遗留在内裤表面的人体分泌物。
- 不得大面积或密集展示皮肤病症画面；因真菌感染导致的褪皮、溃烂画面；因烧/烫伤、过敏/治疗等情况引发的红肿、疤痕等画面；头皮屑、斑秃、油头等画面；不健康舌苔画面；因未注重口腔清洁而引发的牙齿问题画面。
- 投放本身具有颜色的清洁产品时，不得大面积或密集展示清洁皮肤后形成脏污泥垢的画面；不得大面积或密集展示擦拭皮肤或搓泥所产生的脏污泥垢画面；不得大面积/密集展示姨妈血等隐私部位的分泌物。

**违规案例（❌）**
- 画面特写展示大面积面部污垢/分泌物，影响用户感官体验，不合规。（147926 / 207679）
- 画面特写展示大面积、密集的痘痘画面，影响用户感官体验，不合规。（147926 / 207679）
- 特写展示内裤/裤子上的私处分泌物/姨妈血，影响用户感官体验，不合规。（207679）

**合规案例（✅）**
- 素材内展示的肌肤问题程度轻微，或展示无问题画面，未涉及影响用户感官体验内容，案例合规。（147926 / 207679）
- 客观展示投放产品并使用动画形式演绎产品使用方法，案例合规。（207679）

### 6.2 引人不适：脏污环境

> 来源：文章ID 147926

- 投放产品过程中不得出现引人不适的脏污/环境。

**违规案例（❌）**
- 演绎洗手池大量污垢泡沫溢出水池，属于影响用户感官的环境展示，不合规。（147926）
- 演绎下水道大量污垢，属于影响用户感官的环境展示，不合规。（147926）

**合规案例（✅）**
- 投放管道疏通剂，演绎疏通效果时展示小范围疏通效果，未涉及引人不适的脏污，案例合规。（147926）

### 6.3 低质文案

> 来源：文章ID 147926

- 素材不得涉及引人不适遐想类文案，如螨虫在痘痘里繁衍、螨虫啃食你的皮肤、百万螨虫陪你睡、蟑螂进入耳朵/嘴巴等。
- 素材不得涉及嘴巴里/身上有粪味/屎味/尿味/马桶味等系列描述臭味的同义词。
- 清洁相关产品投放，不得涉及利用马桶做程度更重的低质文案宣传。

**违规案例（❌）**
- 投放除螨喷雾，宣传"就像上百万只螨虫陪你睡觉"，属于引人不适遐想类文案，不合规。（147926）
- 投放洗衣机清洁剂，宣传洗衣机不清洁会比马桶还脏，涉及利用马桶做程度更重的低质文案宣传，不合规。（147926）

**合规案例（✅）**
- 投放除螨喷雾，宣传"有螨虫困扰的家庭"，未涉及引人不适的低质文案宣传，案例合规。（147926）

### 6.4 虚假情景演绎：悲情营销/弱势群体

> 来源：文章ID 147926 / 144807 / 207679 / 144205

- 不得利用弱势群体、自然灾害、热点新闻、动物进行悲情营销。
- 不得利用残障人士进行卖惨、悲情营销；不得利用儿童、残疾人（侏儒）、快递外卖人员、农民工、乞丐、贫困者、重症病患者等弱势群体形象，演绎其悲惨境遇，夸大产品/服务的必要性。
- 满足下述特征之一即属利用弱势群体悲情营销：
  - 展示悲惨环境与氛围：毛坯房、土房、简陋的居住环境、悲情音乐。
  - 展示悲惨行为：出现哭泣、哽咽、下跪、坐卧在地上、鞠躬弯腰等行为。
  - 祈求类话术和困境宣传：祈求话术"叔叔阿姨/哥哥姐姐先别划走"、困境宣传（为维持生计、筹钱看病、交赡养费、生活费、偿还欠款等进行商品投放）。
  - 渲染农民生活悲惨信息。
- 不得夸大自然灾害等造成的负面影响，通过编造悲情故事的方式博取同情。
- 不得利用热点新闻进行悲情营销：不得刻意借用某国悲惨国情营销；不得发布国际政治局势、国内外经济趋势的虚假新闻形式投放产品或服务。

**违规案例（❌）**
- 素材利用残疾人做悲情营销、投放商品，不合规。（147926）
- 素材利用重病弱势群体做悲情营销、投放商品，不合规。（207679）

**合规案例（✅）**
- 投放面霜，素材内正常进行宣传，未涉及弱势群体、自然灾害、热点新闻等场景进行编造夸大，案例合规。（147926 / 207679）

### 6.5 虚假情景演绎：虚假新闻/会议/暗访

> 来源：文章ID 147926 / 144807 / 207679

- 不得以虚假新闻报道形式、社会话题变相营销，包括虚假新闻、报纸、暗访、直播、发布会、记者招待会等形式。
- 不得涉及以发布社会保障相关话题（如"全民免费医疗""养老金补贴"等）的虚假新闻形式投放产品或服务。
- 素材不得涉及虚假会议形式。

**违规案例（❌）**
- 投放精华液，素材展示虚假新闻直播间形式，不合规。（147926 / 207679）
- 素材演绎虚假新闻报道形式，不合规。（144807）

**合规案例（✅）**
- 投放洗面奶，展示直播画面切片，未涉及虚假新闻形式，案例合规。（147926 / 207679）

### 6.6 虚假情景演绎：赌誓/竞争买卖关系

> 来源：文章ID 147926 / 144807 / 207679 / 144205

- 不得利用个人名誉或家庭成员的名义为营销内容发誓担保；不得展示使用个人身份证为产品做担保证明。
- 不得虚构违反常理的誓言、承诺、挑战等形式，如：如果卖假货就死全家；不好用我就嫁给你/把老婆送给你/送你兰博基尼；小说行业素材描述如果这本小说不好看你就来打我。
- 不得虚构演绎同行竞争关系，提高自身品牌优势。
- 不得虚构演绎买卖关系，传达产品效果很好、引导用户购买。
- 不得利用写承诺函/挑战书来做商品营销的内容保证。
- 不得利用人员通过演绎「拥抱、哭泣、下跪、送锦旗」等行为，表达激动、感激的情绪，以传达产品效果很好、引导用户购买的虚假情景演绎。
- 素材内容不得宣称「10个直播间，9个都是假的」「在直播间买东西的都是傻瓜」「直播间的主播都是骗子/都是剧本/买回去的东西都是智商税」等无事实依据的虚假误导性内容。
- 不得涉及退出直播了/停播了等虚假情景演绎内容。

**违规案例（❌）**
- 投放淡纹产品，素材宣传"向全国14亿人口发起挑战"，涉及以挑战书进行营销担保，不合规。（147926）
- 投放美白淡斑产品，素材宣传无法美白或淡斑将会"喝下水道水""退出互联网"，虚构违反常理的誓言，不合规。（147926）
- 素材展示使用个人身份证以为产品做担保证明，命中利用「个人名义」担保相关，不合规。（144807）
- 素材口播"我们两夫妻在这里实名呼吁"进行演绎，命中利用个人名誉为营销内容发誓担保，不合规。（144807）
- 投放腋下净味产品，演绎用个人名誉担保，不合规。（207679）
- 投放日用贴，素材宣传"因为成本太低了，所以可能动了某些人的利益，视频很快就会被下架"，涉及虚构演绎同行竞争关系，不合规。（207679）

**合规案例（✅）**
- 投放淡纹精华，宣传有各种纹路的可以试试产品，未涉及虚假赌誓宣传，案例合规。（147926）
- 投放淡斑面膜，宣传改善斑点等合规功效，未涉及虚假情景演绎，案例合规。（207679）

### 6.7 虚假情景演绎：虚构身份/背景

> 来源：文章ID 147926 / 144807 / 144205

- 不得涉及无事实依据的人物/企业负面经历现状，引出低价/便宜等虚假悲惨营销。
- 不得涉及无事实依据的人物/企业、产品/服务的身份、背景、价值，拔高产品/服务的效果。
- 不得通过杜撰背景抬高企业实力，暗示自身产品品质远高于市场，实际无事实依据的虚假演绎；如宣传研发经费花了几百万、几千万、上亿等，属于杜撰抬高企业实力的虚假演绎。
- 内容不得宣传某某人研发被奖励x万元/一夜暴富/一夜买车买房等无事实依据的虚假信息。

**违规案例（❌）**
- 投放护肤品，虚构企业家身份并做赌誓说明，拔高产品效果，不合规。（147926）
- 素材宣传研发经费花了几百万、几千万、上亿等，属于杜撰抬高企业实力的虚假演绎，不合规。（144205）

**合规案例（✅）**
- 投放精华油，素材涉及明星推荐（已提供授权备注），未涉及无事实依据的宣传介绍，案例合规。（147926）

### 6.8 有违社会主流价值观

> 来源：文章ID 207679 / 144205

- 不得涉及拜金现象，不得盲目崇拜金钱、把金钱价值看作重要评价指标，刻意宣扬金钱至上，如炫富、索取高额彩礼、嫌贫爱富、盲目消费奢侈品等。
- 常见的炫富行为：晒豪车；展示奢侈品（大量晒名牌包包、服装、首饰等）；强调高消费（晒高级餐厅用餐、豪华旅行等）；炫耀豪宅；提及巨额资产或收入。
- 素材中不得涉及传播错误价值导向的内容：
  - 散布错误事业观：不得涉及给教师/老师、医护人员等政府机关、国家企事业单位人员送礼的不良导向内容（送礼好办事儿、饭桌文化得到上司赏识、送礼投机才能得到赏识等）。
  - 散布错误婚恋观，故意制造性别对立（如：不能嫁给家里有2个儿子的，女人用钱试、男人用女人试等）。
  - 不得涉及未婚先孕等不符合大众认知的关系。
  - 不得涉及提倡、鼓励"躺平""摆烂"文化（如：现在工作太难做了，大家一起躺平吧；只要摆烂，生活都变好了）；不得利用"躺平、摆烂"进行营销投放，产生因果关系的内容（如：买了XX产品/下载了XX软件就可以直接躺平了）。
- 不得涉及有违中华民族传统美德和社会良好风尚的内容，比如不尊老爱幼、不孝敬父母、聚众闹事等情形。
- "小剧场"创意类型执行对齐：不得涉及明确的小三剧情、拜金素材（傍大款、羡慕豪车）、歧视特定群体（歧视蓝领打工人、嘲讽残疾人）、家庭关系伦理素材（老公小姨子、老婆小叔子等暧昧视频）、冲突视频（婆媳/夫妻动手搧耳光、黑社会街头斗殴）、不尊老爱幼类（孩子嫌弃父母、临终家产分割子女不赡养老人、不给老人饭吃、老人住院后子女不照顾）等。

**违规案例（❌）**
- 涉及结婚现场索要高价彩礼、嫌弃二婚拖油瓶等不合规描述。（207679）
- 涉及炫富类宣扬奢靡享乐炫富素材，不合规。（207679）
- 素材展示母子年龄差距非常小，易涉及未成年人生子、未婚先孕等问题，不符合正常的生育认知，不合规。（207679）
- "林业、水利、畜牧局"报考，描述"平时主要就是喝喝茶，钓钓鱼，一周只上三天班，事情很少……"，涉及错误价值导向宣传，不合规。（207679）

**合规案例（✅）**
- 未涉及嫌贫爱富和明确的言语侮辱，合规。（207679）
- 素材展示温馨和谐画面内容合规。（207679）

### 6.9 两性低俗内容

> 来源：文章ID 144205

- 不得通过突出身体敏感部位，或类敏感部位形状的动植物/景观/物品等暗示或令人产生低俗联想。画面主要人物露沟程度较深（足以看到胸部轮廓或乳房形状、乳房内侧、下侧沟线）或带有低俗倾向的露沟画面；类敏感部位指类两性生殖器形状的物品，包括但不限于：畸形茄子、象拔蚌、何首乌、畸形蚬子、蘑菇、类生殖器山峰等。
- 不得涉及明显性暗示的动作/表情/声音/场景/服务。如凌乱的室内、床、沙发、浴室、卫生间、玉米地、大量卫生纸的地板等场景；不得涉及暗示性动作/表情/场景演绎：摸胸、挤胸、ASMR 如娇喘、口腔音、黏糊糊的拍击音（有性暗示的啪啪声）、吮吸、模拟使用成人用品、偷窥、抚摸身体、舔舐食物、舔咬嘴唇、露舌头、宽衣解带、热吻、眼神迷离（高潮表情）、阿黑颜、鸭子坐、萝莉坐等；不得涉及不良暗示性的场景，比如演绎捂嘴、掐脖的同时演绎者表情潮红、迷离（演绎不区分性别）。

### 6.10 人物/版权授权

> 来源：文章ID 147926 / 144807 / 144205

依据《广告法》第三十三条（广告主或广告经营者在广告中使用他人名义或者形象的，应当事先取得其书面同意；使用无民事行为能力人、限制民事行为能力人的名义或形象的，应事先取得其监护人书面同意）。

- 人物授权：广告内容涉及明星、名人、大师等人物的名义、肖像等内容，需提供相应授权。
- 版权授权：广告内容涉及第三方影视/动漫/文学作品等，需提供版权授权。
- 肖像遮挡：指通过恶意遮挡等方式，对广告素材中的肖像面部进行二次加工。遮挡类型不得涉及：贴纸特效遮挡、文字遮挡、马赛克遮挡、滤镜遮挡等。
- 展示产品效果/演绎产品使用方式（例如涂口红、衣服展示等情况）只展示了局部肖像，或由于视频录制角度导致的文字遮挡肖像等情况，属于合理场景，可以支持。
- 如素材使用影视（含影视剧、综艺节目）片段或海报等物料进行投放，涉及明星/名人肖像，需同时收取明星/名人肖像授权，影视授权不可替代明星肖像授权。
- 化妆品外包装涉及明星等知名人物，可无需管控。

**违规案例（❌）**
- 投放淡斑精华，素材涉及文字遮挡脸部，不合规。（147926）
- 素材涉及打码遮挡人脸，不合规。（144807）
- 素材涉及卡通贴纸遮挡人脸、口罩贴纸挡脸，不合规。（144205）
- 素材涉及丁俊晖、韦雪、郝劭文投放介绍视频，需提供对应授权（未提供则不合规）。（144807）

**合规案例（✅）**
- 投放羊奶霜，素材演绎人物自身戴口罩宣传，非刻意遮挡，案例合规。（147926）
- 投放化妆品外包装涉及明星等知名人物，可无需管控。（144807）

## 七、日用清洁品类专项

### 7.1 不得夸大清洁功效（清洁动作要求）

> 来源：文章ID 147926 / 144807 / 207679 / 144205

- 日用清洁类产品不得夸大宣传产品或产品成分的功效，包括不限于不符合常理的清洗效果、清洗速度、清洗范围等。
- 素材若涉及效果展示，不允许展现脱离实际、不符合常识的清洁效果，不允许演示十分夸张、引人不适的画面（如喷上去车身的油漆直接掉落、清洁剂可清除掉物理划痕等）。
- 素材不得涉及溶解物品本身的搪瓷、塑料、油漆等及演绎；不得演绎使用产品后没有清洁动作时锅底污渍在物体表面剥离/溶解，或一擦立即大片脱落。
- 演绎清洁效果对比时，不得省略必要的清洁动作；水洗不作为必要清洁动作。
- 不得演绎清洁剂可清除掉物理划痕。
- 清洁工具类产品，不得涉及产品未添加清洁剂时仍可清洁/去除油污类演绎。

**违规案例（❌）**
- 投放清洁剂，宣传可以清除瓷砖金属划痕，属于脱离实际的清洁效果演绎，不合规。（147926 / 207679）
- 投放清洁剂，演绎浇上清洁剂之后物品本身的搪瓷剥脱，脱离实际的清洁效果演绎，不合规。（147926）
- 投放厨房清洁剂，演绎使用水枪直接清洁干净污渍，缺失了必要的清洁动作，不合规。（147926）
- 投放洗衣液类产品，展示衣服大量油污在盆里浸泡后拿出来就干净了，缺失了必要的清洁动作，不合规。（147926）
- 投放厨房清洁剂，演绎喷上污渍就滴落、燃气罐变干净了，未展示清洁动作和清洁过程，不合规。（207679）
- 素材演绎浇灌产品后油漆搪瓷等面层直接脱落的画面，超脱产品清洁功效，不合规。（144205）
- 素材借用高压水枪展示清洁效果，未体现合规清洁动作，易误导用户，不合规。（144205）
- 素材仅通过水洗达到清洁效果，未体现必要的清洁动作，不合规。（144205）
- 投放洗衣机清洁剂，演绎底盘清洁效果对比，不合规。（147926）

**合规案例（✅）**
- 投放浴室清洁剂，演绎清洁水垢，符合客观清洁场景，案例合规。（147926）
- 投放衣物清洁剂，演绎衣物油污，符合客观清洁场景，案例合规。（147926）
- 投放厨房清洁剂，演绎锅底清洁效果时明确展示了清洁动作，案例合规。（147926）
- 投放浴室清洁剂，演绎洗漱台清洁效果时明确展示了清洁动作，案例合规。（147926）
- 素材已体现「擦洗」的清洁动作，展示产品清洁效果，且玻璃水渍不属于顽固污渍，素材展示合规。（144205）

### 7.2 不得宣传极短时间内清除顽固污渍

> 来源：文章ID 147926 / 144807 / 207679

- 在有清洁动作展示的情况下，仍不得涉及宣传商品在"极短时间内"即可达到清除顽固污渍的效果。
- 顽固污渍类型参考：
  - 通用：油漆。
  - 服装鞋帽类：油渍、血渍、酱油渍、笔渍、果汁渍、霉渍、浓厚的汗渍、陈年黄渍/泛白等。
  - 家居类：锅底油污、锅底燃烧残留黑印、墙面上的大片涂鸦等。
  - 汽车类：生锈铁渍、陈年机油混合铁渍。
  - 常规污渍：除上述顽固污渍外的污渍类型。
- 视频内通过口播或文字标注等形式明确顽固污渍需要有清洁过程时（如下形式），可支持投放：
  - 视频清洁过程全程标注"计时、加速中"等提示语；
  - 明确表明需要泡洗X时间、静置X时间再搓洗等条件；
  - 口播或文字说明顽固污渍或难清洗污渍的处理方式（包括但不限于难洗的污渍多刷一刷）。

**违规案例（❌）**
- 投放厨房清洁剂，演绎极短时间清洁干净锅底油污、黑印，不符合常规的清洁过程，不合规。（147926）
- 投放洗衣膏，演绎极短时间清洁干净衣服的油污，不符合常规的清洁过程，不合规。（147926）

**合规案例（✅）**
- 投放厨房清洁剂，演绎极短时间内通过清洁动作实现清洁干净效果，并且展示"反复刷洗、加速中"相关过程提示语，案例合规。（147926）
- 投放鞋类清洁剂，演绎极短时间内通过清洁动作实现清洁干净效果，并且展示"反复刷洗、加速中"相关过程提示语，案例合规。（147926）
- 投放管道疏通剂，演绎疏通效果，已全程添加"反应静置1-2小时后"类反应过程提示语，合规。（144807 / 207679）

### 7.3 不得对清洁效果作虚假保证承诺

> 来源：文章ID 147926 / 144807 / 207679

- 不得以"秒"为时间单位承诺产品起效时间，如：3秒即净。
- 不得承诺清洁效果的不合理保持时间，如：清洁一次30天干干净净。
- 不得涉及对结果的绝对化描述：去除每一点污渍、100%去除/变白。
- 不得宣传使用商品后可使物品达到新品效果，如用完干净如新衣服/新鞋/新车一样（扩展至全行业管控）。
- 日用清洁类产品（含洗衣液、洗衣凝珠等）无功效证明场景下，不得涉及留香时间宣传。
- 日用清洁类产品，不得对产品功效进行绝对化的过度承诺宣传；不得宣传产品可以彻底解决某问题，如根除/告别/拜拜/不再复发/彻底根除等。
- 不得涉及虚构产品对任何严重污渍状态均有效果类表述。
- 不得涉及否定其他产品类表述，以暗示仅有投放产品有效果/效果最好。

**违规案例（❌）**
- 投放洗衣液，无功效证明下宣传留香30天，不合规。（147926）
- 投放鞋类清洁剂，宣传3秒即净，涉及以秒为单位的清洁时间承诺，不合规。（147926）
- 管道疏通剂宣传"用完没有改善堵塞臭味问题其他产品可丢进垃圾桶"，表达仅有投放的产品是有效的，否定其他产品类表述，以暗示仅有投放产品有效果/效果最好类宣传，不合规。（207679）
- 管道疏通剂宣传"再也没有异味小飞虫"，涉及彻底解决问题的过度承诺，不合规。（207679）

**合规案例（✅）**
- 投放洗衣凝珠，宣传留香72小时，且已提供数据证明文件，案例合规。（147926）
- 投放管道疏通剂，表达可以定期清洁，未涉及绝对化承诺或永久性承诺宣传，合规。（207679）

### 7.4 特殊品类：洗衣机清洁剂

> 来源：文章ID 147926 / 144807 / 207679 / 144205

- 不得涉及清洁洗衣机胶垫、盖子内壁、底盘、网兜的前后效果对比。
- 不得涉及洗衣机清洁剂素材中夸大演绎大量泡沫流出/溢出。

**违规案例（❌）**
- 投放洗衣机清洁剂，演绎底盘清洁效果对比，不合规。（147926）
- 素材投放洗衣机清洁类产品，涉及洗衣机网兜的前后效果对比，不合规。（144205）

**合规案例（✅）**
- 投放洗衣机清洁剂，演绎可以清洁各个部位，未涉及前后效果对比，案例合规。（147926）

### 7.5 特殊品类：管道疏通剂

> 来源：文章ID 147926 / 144807 / 207679

- 不得涉及腐蚀物体（如腐蚀金鱼、头发、西瓜等）的演绎；素材如果涉及腐蚀动物（如金鱼）等，不区分有没有加速中相关标注，均需管控。
- 不得涉及展示使用商品后可达到液体喷射或炸出的效果。
- 不得涉及无法被腐蚀的物体，如泥土、水泥块、塑料、石头、金属、纺织品、玻璃、陶瓷、猫砂、橡胶等。
- 若腐蚀毛发、厨余残渣等，在腐蚀过程中需标注"计时、加速中、静止等待"等信息，表达产品不是瞬间实现溶解效果。
- 不区分是否标注了"计时、加速中、静止等待"等信息，均不得涉及在社会性餐厅后厨管道（非家用厨房）、城市污水管道、公园蓄水池、室外大型排污管道等非日常家用场景做疏通的演绎。

**违规案例（❌）**
- 投放管道疏通剂，演绎腐蚀毛发效果，不合规。（147926）
- 管道疏通剂演绎疏通城市下水道，超出日常家用场景及超出功效范围，不合规。（207679）
- 管道疏通剂演绎清洁尿垢效果，未展示清洁动作，不合规。（207679）
- 素材演绎管道疏通剂类产品涉及腐蚀物体（鱼）类演绎，不合规。（144205）

**合规案例（✅）**
- 投放管道疏通剂，演绎腐蚀毛发效果，已全程添加"静置15分钟"类反应过程提示语，合规。（207679）
- 投放管道疏通剂，演绎疏通效果，已全程添加"反应静置1-2小时后"类反应过程提示语，合规。（144807 / 207679）

### 7.6 杀菌/除螨/除甲醛质检证明

> 来源：文章ID 147926

依据《广告法》第三十四条。

- 宣传涉及除甲醛/除菌/抑菌/杀菌等，但未涉及具体指数描述，提供对应类别（阻隔类/杀灭类）质检证明。
- 宣传涉及具体的除螨率/除菌率/杀菌率/抑菌率/灭菌率/除甲醛率等数据，需提供对应类别（阻隔类/杀灭类）及对应数据的质检证明。
- 符合客观事实的描述，如"植物除甲醛"，可支持。
- 除农药/消毒品外的商品外包装展示杀菌/抑菌/除菌，或展示具体的杀菌率/抑菌率/除菌率，可支持。
- 单独提及除螨/驱螨描述，无需收取质检证明。

**违规案例（❌）**
- 投放除味喷雾，宣传杀菌，未提供对应质检证明，不合规。（147926）
- 投放浴室清洁剂，宣传具有抑菌功效，未提供对应质检证明，不合规。（147926）
- 投放杯具除垢剂，素材宣传杀菌率99%以上，检测证明仅有96%，素材表述超出检测证明数值，不合规。（147926）
- 投放马桶清洁剂，素材宣传除菌率99.9%，检测证明仅有抑菌证明，类别不对应，不合规。（147926）

**合规案例（✅）**
- 投放除螨喷雾，宣传"除螨"，未涉及具体的除螨数据，案例合规。（147926）
- 投放洗衣机清洁剂，宣传"除菌"已提供对应质检证明，案例合规。（147926）
- 投放清洁剂，宣传"4个9的除菌率"并提供对应证明，案例合规。（147926）

### 7.7 口腔清洁品类

> 来源：文章ID 147926 / 144807

- 不得宣传有明示或暗示具有医疗效果的内容，不得涉及治疗效果。如："促长牙/补牙洞""修复蛀牙""闭合牙缝""稳固牙松动""牙龈出血"；牙龈萎缩、牙菌斑/牙斑、牙结石、黑三角、龋齿、口臭等。
- 牙膏类产品如能提供相关资质凭证，可涉及与之对应的防龋、抑牙菌斑、抗牙本质敏感、减轻牙龈问题、抗牙结石、减轻口臭等描述。
- 无功效证明情况下不得涉及虚假效果承诺；不得涉及牙齿美白清洁速度和效果的夸大描述；不得涉及医疗类清洁效果，如跟洗牙做效果对比。
- 口腔清洁品类宣传中，不得涉及明示或暗示承诺长期口腔问题（如口腔异味、牙齿色斑牙渍）可以解决。

**违规案例（❌）**
- 投放牙膏，表述"击退口气口臭"，属于效果承诺表述，不合规。（144807）
- 素材展示牙齿使用净白产品前后对比，大黄牙全部变白，整体效果夸张，不合规。（144205）

### 7.8 日化其他虚假宣传

> 来源：文章ID 147926 / 144807

- 除医疗类产品外，其他产品均不得涉及"助眠"功效宣传。若客观资质（如专利）已明确产品名字含"助眠"，可支持素材宣传与备注一致的内容。
- 眼部护理类日用品不得超出即时性滋润、养护眼部、缓解疲劳等范围进行宣传：不得涉及改善眼部不适问题（流泪、畏光、视物模糊/浑浊、疼痛、眼睛痒等）；不得涉及对眼部红血丝有功效类表述；不得涉及防止眼睛衰老、眼部问题的天敌/克星等断言夸大的表述；不得涉及使用状态的前后夸张对比；不得涉及给眼睛补充叶黄素类表述；不得暗示产品具有化妆品的功效（如淡化眼纹、眼袋、黑眼圈等）。
- 私处洗液类产品，不得涉及超出清洁/滋润功效宣传的内容。【仅千川执行细则，AD 仍会限制禁投】
- 素材宣称为食品级相关，需关注产品类型：投放食品相关产品，宣称商品为"食品级/食用级"相关，需提供第三方出具对应食品相关产品的食品安全国家标准的质检报告；投放非食品相关产品，不得宣称商品为"食品级/食用级"相关。
- 普通日用品等无特殊功效产品，不得宣传"去异味（腋下）、腋下净味、帮助睡眠"等清洁功效以外的其他特殊功效。
- 日用膏/液类产品，不得宣传"无复发、xx时间改善足部问题"等结果性描述表达产品具有特殊效果。
- 腋下净味类产品，不得涉及超出即时遮盖异味功效的宣传，以暗示可以根源改善异味。

**违规案例（❌）**
- 投放日化精油，涉及帮助睡眠、改善睡眠，不合规。（207679）
- 止汗喷雾描述"拒绝复发"，不合规。（207679）
- 投放润眼喷雾，宣传改善"视物模糊、眼睛疼痛"，超出润眼液功效范围，不合规。（207679）

**合规案例（✅）**
- 精油合规描述："一缕芬芳，舒缓日常疲惫和情绪"。（207679）
- 止汗喷雾合规描述："持久止汗，清新不黏腻"。（207679）

## 八、资质要求汇总

### 8.1 功效类资质

> 来源：文章ID 147926 / 144807 / 144205 / 207679

- 祛斑美白类等特殊化妆品功效宣传，需提供对应特化资质（批件/备案）；产品批件无对应功效则不可宣传。
- 儿童化妆品宣传需提供儿童化妆品资质证明，或素材内客观展示产品外包装的"小金盾"标识。
- 「助眠、抗糖」类宣传需提供功效宣称证明材料，且宣称需包含在药监部门注册或者备案的功效范围内（产品报备名称中包含时可作为完整产品名称出现，不得单独使用）。
- 涉及「促进头发生长、增发」功效描述，需提供功效证明；涉及具体数值需提供对应资质，并在素材中标记清楚数据来源。
- 牙膏类产品涉及防龋、抑牙菌斑、抗牙本质敏感、减轻牙龈问题等描述，需提供相关资质凭证。
- 化妆品产品名称中包含"止痒"，或提供相关化妆品功效评价报告，可支持。
- 生发相关专利证明，可支持作为「专利名称」客观展示/描述涉及。

### 8.2 数据/质检类证明

> 来源：文章ID 147926 / 144807 / 144205

- 素材涉及具体数据、统计资料、调查结果、文摘、引用语，需提供数据真实性证明并标明来源。
- 杀菌/抑菌/除菌/除甲醛等功效，需提供对应类别（阻隔类/杀灭类）质检证明；涉及具体率值（除螨率/除菌率/杀菌率/抑菌率/灭菌率/除甲醛率等）需提供对应类别及对应数据的质检证明，素材表述数值不得超出检测证明数值、类别不得不对应。
- 留香类时间表述需提供功效/数据证明（如留香72小时需提供数据证明文件）。
- 食品类产品宣称"食品级/食用级"，需提供第三方出具对应食品安全国家标准的质检报告。

### 8.3 授权类资质

> 来源：文章ID 147926 / 144807

- 涉及明星、名人、大师等人物名义/肖像，需提供相应人物肖像授权。
- 使用影视（含影视剧、综艺节目）片段或海报等物料，涉及明星/名人肖像，需同时收取明星/名人肖像授权，影视授权不可替代明星肖像授权。
- 涉及第三方影视/动漫/文学作品等，需提供版权授权。

  - 即时遮盖类产品演绎明显痘痘完全消失，属无法实现的"一涂一抹变无瑕"演绎，不合规。（144807）
