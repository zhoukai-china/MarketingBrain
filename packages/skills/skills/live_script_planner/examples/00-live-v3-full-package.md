# V3完整场次黄金样板

## 用户输入：

类型：招商加盟；品牌：示例品牌；行业：示例行业；时长：120分钟；目标客户：准备开店的创业者；真实资料：总投资口径、经营项目、供应链和培训动作均已提供；承接：私信“项目资料”领取已确认资料并预约沟通。

## 样板输出：

直播话术包

场景识别：招商加盟。直播目标：筛选真实意向并引导私信“项目资料”。所有数据只引用本轮输入。

一、直播总览

列出目标人群、真实卖点、唯一承接动作、合规边界和开播前检查。

二、开场话术

提供主播可直接照读的话术，并紧随运营配合动作。

三、四套核心轮播话术

依次覆盖创业痛点、真实实力证据、经营模式与投资边界、扶持与适配筛选。每套都有主播逐字稿和运营动作。

四、三种承接钩子

只围绕已确认的“项目资料+预约沟通”改写三个出现时机，不新增礼品、名额、报销或优惠。

五、高频问题应答

覆盖投资、回本边界、适合人群、总部支持和下一步。未知数据明确说以正式资料和评估为准。

六、收尾话术

自然总结并引导私信，不使用虚假倒计时、库存和名额。

七、120分钟轮播节奏表

时间段从0分钟连续覆盖到120分钟，包含模块、主播任务和场控动作，不重叠、不留空。

八、场控执行清单

按开播前、直播中、下播后列动作；包含“投资有风险，加盟需谨慎”、线索分层和复盘指标。

## 验收边界

- 样板品牌和数字不是用户事实。
- 没有输入的收益、回本、案例、库存、名额、福利和经营年限一律不写。
- 指定时长时必须完整覆盖；用户只要某一段时只交付该段。
