# WorkBuddy 样板库：直播话术

## 输入样例
我是西安一家儿童摄影店，今晚直播推 299 元儿童生日照套餐，想吸引 3-8 岁孩子家长，目标是预约到店。

## 样板输出骨架
直播目标：今晚不讲摄影技术大全，只让家长明确三件事：孩子生日照为什么现在拍、299 包含什么、怎么预约。

开场话术：
“家里有 3-8 岁孩子的家长可以停一下。孩子生日照最怕临时拍、赶时间、孩子状态不好。今晚我用 1 分钟讲清楚，怎么提前拍一套不折腾的生日照。”

留人话术：
“先别急着划走，我给你看三个家长最关心的点：服装怎么选、孩子不配合怎么办、299 到底包含什么。”

互动话术：
“评论区打孩子年龄，我按年龄告诉你适合拍可爱风、户外风还是成长记录风。”

转化话术：
“今天这套 299 不是让你立刻定风格，你先锁预约名额，到店再按孩子状态选方案。”

逼单话术：
“如果孩子生日在未来 30 天内，建议今天先约时间。越临近越容易赶不上孩子状态和档期。”

下播后跟进：给已咨询未预约、已预约未到店、老客转介绍三段私聊话术。

复盘指标：停留、评论年龄数、套餐点击、预约数、次日到店确认。

## 评分标准
- 主播能照着念，不是直播建议清单。
- 必须把产品、价格、目标客户、预约动作放进话术。
- 每段话术都有任务：留人、互动、转化、逼单、跟进。

## 失败案例
- 只有“多互动、多展示产品、多强调福利”。
- 没有下播后跟进。
- 输出成短视频脚本或朋友圈文案。

## IP语言声纹适配样例

输入附带语言声纹：本人习惯短句，常用“你看”“先别急”，观点推进顺序是“先判断—再解释—最后给动作”。

合格开场：“先别急着下单。你看这个套餐，先判断孩子适不适合，再看包含什么，最后我告诉你怎么预约不赶档期。”

边界：只复刻表达方式；价格、产品、福利和成交目标仍以本轮直播资料为准。
