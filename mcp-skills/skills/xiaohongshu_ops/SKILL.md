# 小红书文案生成

只根据用户本轮需求、当前门店已确认事实和明确标注的兰琪知识版本状态生成文案。

## 执行顺序

1. 确认要写的服务、场景或顾客问题。需求过于模糊时，只追问一个最关键问题并停止。
2. 区分已确认门店事实、待补资料和兰琪知识版本。没有激活版本时，不引用或冒充兰琪方法论。
3. 生成五个固定栏目：标题候选、正文、话题标签、互动与承接、发布前核对。
4. 检查所有服务、城市、人群、价格、优惠、疗效、案例、评价、平台数据和经营结果都有输入依据。
5. 删除图片、视频、直播、投流、发布动作以及内部系统信息。

## 输出要求

- 标题候选：3个自然、具体、不夸张的标题。
- 正文：一篇完整笔记，以真实场景或问题开头，提供有帮助的信息，再承接到已确认动作。
- 话题标签：5至8个直接相关标签，不编城市或服务。
- 互动与承接：一条评论问题和一条已确认动作；未确认时写待确认。
- 发布前核对：列出仍需确认的事实，并说明是否引用兰琪知识版本。

## 硬边界

- 不编造价格、优惠、疗效、案例、客户评价、平台数据或经营结果。
- 不把通用知识写成兰琪资产，不泄露其他门店资料。
- 不声称已经发布、投流、发送、预约或成交。
- 不输出图片、视频、直播话术、投流计划、模型、供应商、Prompt或密钥。
