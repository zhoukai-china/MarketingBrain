## 一、董十一 · 增长黑客方法论

### 1.1 个人概述

董十一，抖音短视频增长黑客，代表作《2022短视频底层实操课》（79节，标价7980元）。核心定位：用底层逻辑+用户思维做短视频增长。

### 1.2 课程体系（79节）

| 模块 | 节数 | 核心内容 |
|:---|:---|:---|
| 底层逻辑 | 39节 | 赛道→定位→商业模式→平台算法→用户思维→数据运营 |
| 爆款创作 | 4节 | 标题公式、选题方法、结构套路、内容公式 |
| 直播实战 | 36节 | 人货场模型、选品策略、直播脚本、巨量百应复盘 |

### 1.3 金字塔文案模型（SCQA）

董十一将《金字塔原理》的SCQA模型引入抖音文案创作：

```
⏐
⏐   模型1：背景 + 冲突 + 疑问 + 答案
⏐      背景：一个故事开头，交代场景
⏐      冲突：发生什么事了？产生矛盾
⏐      疑问：为什么会这样？引发好奇
⏐      答案：三段论式解答（第一、第二、第三）
⏐
⏐   模型2：结论先行 + 背景 + 冲突 + 疑问 + 答案
⏐      结论：先抛出结果（赚了100万）
⏐      然后按模型1展开
⏐
⏐   核心：重要的不是你讲了什么，而是用户讲完之后的状态
```

### 1.4 抖音影视结构（三幕剧）

```
第一幕（开头，0-10秒）：建立用户期待
  → 主人公出现了什么问题？交代背景

第二幕（中间，10-40秒）：制造冲突
  → 发生了这些事，带来什么变化？

第三幕（结尾，40-60秒）：给出答案
  → 通过变化升华主题，表达观点
```

### 1.5 用户留存三法

1. **讲故事** — 用故事情节勾住用户
2. **唤起疑问后顺应疑问** — 不要勾起了兴趣又不解决
3. **给违背直觉的知识** — 用户知道但不知道原理的东西

### 1.6 用户运营体系

- **赛道选择** → **账号定位** → **商业模式设计**
- **用户思维** → **需求挖掘** → **共情建立** → **生命周期管理**
- **拉新→留存→促活→转化** 四阶段运营

### 1.7 直播人货场模型

| 要素 | 核心 |
|:---|:---|
| **人** | 主播能力、用户互动、直播节奏 |
| **货** | 选品策略、产品布局逻辑、知识付费产品设计 |
| **场** | 直播间搭建、短视频导流、直播脚本 |

### 1.8 和保禄的差异

| 维度 | 董十一 | 保禄 |
|:---|:---|:---|
| 定位 | 泛短视频增长（全行业） | 连锁品牌招商加盟IP（垂直） |
| 文案 | SCQA金字塔模型 | 口语化短句+保禄味道 |
| 目标 | 抖音涨粉→变现 | 招商转化+IP信任 |

### 2.3 造课方法论

陈厂长抖音视频核心观点（758万点赞爆款）：

> **好课的核心标准：以「有用」为唯一指标**
> **好课的本质定义：让用户学完后真实发生改变**
> 经济状况改善（从穷到有钱）、技能提升（从无流量到有流量）

**造课五步法（推断）：**
1. 定位：明确解决谁的什么问题
2. 体系化：把碎片知识结构化
3. 案例化：每个观点配真实案例
4. 可交付：学完能立刻用
5. 持续迭代：每期更新，跟进行业变化

- **文案启蒙+认知升级** — 做IP先过文案关，再过认知关

## 三、润宇 · 微信生态IP方法论

### 3.1 个人概述

润宇，12年连续创业者（游戏→打车→音乐教育→K12→个体创业IP），「润宇创业笔记」主理人，视频号头部博主。芝课教育创始人CEO，团队教练/讲师/主播。从知识博主转型带货直播，累计成交近2000万。核心定位：微信生态公私域联动IP实操。

### 3.2 个人IP公式

> **个人IP = 价值 × 作品 × 流量**

- 价值是核心原点：你能帮什么人解决什么问题
- 不是因为做了IP所以有流量，是因为有价值、有作品所以有流量

### 3.3 微信「六道轮回」

润宇将微信生态六大场景串联为公私域运转闭环：

```
          视频号直播 ←——流量与内容的制高点，转化核心
               ↑
        视频号短视频 ←——长尾流量，涨粉引擎
               ↑
          公众号     ←——流量中转站，分发枢纽
        ↙  ↓  ↘
    群聊  朋友圈  私聊  ←——私域沉淀与互动
```

**各场景流量占比：**
- 公众号关注来源：10-20%来自文章，短视频和直播各占约40%

### 3.4 朋友圈四大能力

润宇坚持每天写5条朋友圈（已执行两年），提炼四大能力：

| 能力 | 说明 |
|:---|:---|
| **内容支撑结构** | 从哪里输入、怎么加工、怎么输出 |
| **网感** | 观察哪些内容火、哪些不火，挖背后原因 |
| **内容习惯** | 表达是一种习惯，经常表达就会习惯表达 |
| **内容链路** | 朋友圈→互动好的扩写公众号→适合视频的改脚本→反哺直播 |

### 3.5 私聊思维 vs 广播思维

润宇核心认知：短视频应从"广播思维"转向"私聊思维"

| 广播思维（错误） | 私聊思维（正确） |
|:---|:---|
| 泛化标题（"男人要成功的四个心法"） | 针对特定人群的具体问题 |
| 圈尽可能大的人群 | 精准解决一个群体的痛 |
| 数字/冲突套路化 | 像跟朋友私聊一样真诚 |

### 3.6 选品讲品五步法（女装专场案例）

| 步骤 | 做法 |
|:---|:---|
| 1. 品牌专场 | 品牌方提供专业助播 |
| 2. 研究品牌 | 看熟各平台直播间和主打品 |
| 3. 团队协作 | 懂行的人一起选品 |
| 4. 实地理解 | 去实地感受，理解情绪价值 |
| 5. 直播分工 | 助播介绍产品，自己把控节奏开价格 |

### 3.7 润宇核心金句

| 金句 | 应用场景 |
|:---|:---|
| "知识付费已死，IP资本化永生" | 行业趋势判断 |
| "内容是第一轮产品" | 内容策略定位 |
| "流量的本质是人心，人心的连接靠人格，人格的塑造靠内容" | 底层逻辑 |
| "个人IP不是割韭菜，不是过度包装。返璞归真，做好内容" | 价值观 |
| "阻止我们跨出舒适圈的最大敌人，不是困难本身，而是对他人眼光的畏惧" | 心理建设 |
| "天下哪有什么天赋，一切都是1万小时的刻意练习" | 行动号召 |

### 3.8 和保禄的差异

| 维度 | 润宇 | 保禄 |
|:---|:---|:---|
| 主平台 | 视频号+微信生态 | 抖音+全域 |
| 定位 | 泛创业IP（全行业） | 连锁品牌招商加盟（垂直） |
| 变现 | 知识付费+直播带货 | 诊断费+咨询费+内容服务 |
