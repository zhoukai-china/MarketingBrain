# 访谈提问方法论 · 基于杨澜《提问》体系

> 融合杨澜30年访谈经验，结合保禄「采访餐饮/美业老板」的短视频访谈场景，设计可直接应用的话术框架。

---

## 一、访谈的核心哲学

### 杨澜的三个访谈信条

1. **好奇心比技巧重要**：你不是在审问，你是在帮对方说出他心里想说的话。好的访谈者让被访者觉得「这个人是真的想了解我」
2. **提问是照亮，不是拷问**：好问题是手电筒——帮对方看到自己没意识到的闪光点。坏问题是聚光灯——照得对方不自在
3. **倾听比提问更重要**：对方的回答里藏着下一个好问题。70%精力用来听，30%用来问

### 保禄访谈场景的特殊性

保禄的访谈不是电视台专访，是**短视频人设访谈**——目的不是挖隐私，是帮被访者（餐饮/美业老板）**在镜头前展现他最打动人的一面**。所以：
- 提问要带「引导性」——帮对方找到闪光点
- 提问要有「故事性」——引导对方讲故事，不是讲观点
- 提问要有「共鸣性」——让对方说出观众也想说的话

## 二、五类核心提问

### 1. 情境式提问（打开话匣子）

**用途**：破冰，让对方放松。从具体、熟悉、好答的问题开始。

| 句式 | 保禄应用 |
|------|----------|
| 「你开第一家店的时候，还记得那天吗？」 | 餐饮/美业老板创业故事 |
| 「你印象最深的一个客人是谁？」 | 挖故事素材 |
| 「那时候最难的是什么？」 | 引出踩坑经历 |

**原则**：问具体时间、地点、人物。不要问「你的创业经历是什么」——太宽泛，对方不知道从哪讲。

### 2. 情感式提问（引发共鸣）

**用途**：让观众感受到「这个人跟我一样」。好的情感式提问能让对方说出心里话。

| 句式 | 保禄应用 |
|------|----------|
| 「那个时刻你心里在想什么？」 | 创业关键节点的内心戏 |
| 「你有没有想过放弃？什么时候？」 | 脆弱时刻，最打动人 |
| 「家人怎么看这件事？」 | 家庭话题，拉近跟观众距离 |

**原则**：问感受，不问评价。不说「你觉得XXX怎么样」，说「XXX的时候你什么感觉」。

### 3. 转折式提问（制造冲突感）

**用途**：让故事有起伏。平淡的故事加一个转折式提问就变成好故事。

| 句式 | 保禄应用 |
|------|----------|
| 「然后呢？发生了什么？」 | 推进故事节奏 |
| 「但是...后来怎么变的？」 | 引出转折点 |
| 「你那时候觉得完了，对吧？然后呢？」 | 先共鸣低谷，再引出反弹 |

**原则**：转折式提问是「顺藤→找到结→解结」。先顺着对方的话往下走，找到矛盾点，再深挖。

### 4. 引导式提问（帮对方表达）

**用途**：当对方说不清楚或不好意思说的时候，帮他找到表达方式。

| 句式 | 保禄应用 |
|------|----------|
| 「你是想说...？」 | 帮对方总结 |
| 「我理解你的意思是不是...？」 | 确认+引导 |
| 「如果用一个词来形容那段日子，你会用什么？」 | 帮对方提炼 |

**原则**：引导不是代替。你的话只是梯子，对方自己走上去。

### 5. 回顾式提问（升华主题）

**用途**：访谈收尾，让对方自己总结。最好的一句话往往在最后出现。

| 句式 | 保禄应用 |
|------|----------|
| 「回看这一路，你最大的改变是什么？」 | 收尾升华 |
| 「如果让你对当初的自己说一句话？」 | 金句制造机 |
| 「你觉得做对了什么，又做错了什么？」 | 反思+干货 |

**原则**：收尾问题要让对方有时间思考。问完后别急着接话，等。

## 三、访谈节奏控制

### 3.1 时间分配（以5分钟短视频访谈为例）

| 阶段 | 时长 | 内容 | 提问类型 |
|------|------|------|----------|
| 破冰 | 0-30秒 | 轻松开场，建立连接 | 情境式 |
| 展开 | 30秒-2分钟 | 引出核心故事 | 情境式+情感式 |
| 高潮 | 2分钟-4分钟 | 冲突/转折/高潮 | 转折式+引导式 |
| 收尾 | 4分钟-5分钟 | 提炼金句/升华 | 回顾式 |

### 3.2 沉默的价值

- 对方说完一个关键信息后，**停顿2秒**再问下一个问题
- 2秒的沉默会让对方觉得「你刚才说的很重要，我在消化」，同时给对方补充的机会
- 很多最好的素材出现在这2秒里——对方会自己补充细节

### 3.3 打断的艺术

- **允许打断**：对方跑题时用「所以你是说...」拉回来
- **不允许打断**：对方讲到情感细节时绝不打断
- **善意打断**：用点头+「对对对」+新问题 自然过渡

## 四、访谈提问话术模板

### 模板A：创业故事线（餐饮/美业老板）

```
【破冰 - 情境式】
「王总，你开第一家店那天还记得吗？」
「当时店里几个人？什么感觉？」

【展开 - 情感式】
「最难的时候是什么时候？」
「那时候有没有人跟你说别干了？」
「你心里怎么想的？」

【高潮 - 转折式】
「后来发生了什么变化？」
「是哪个事让你觉得'好像有戏'？」
「那时候做了什么关键决定？」

【收尾 - 回顾式】
「回看这几年，你最想对当初的自己说什么？」
「你觉得做餐饮/美业，最核心的是什么？」
```

### 模板B：AI改造故事线

```
【破冰 - 情境式】
「用AI之前，你们店里最头疼的是什么事？」
「一天接多少咨询？几个人在处理？」

【展开 - 情感式】
「试过什么方法？花了多少钱？」
「团队一开始什么反应？抵触吗？」

【高潮 - 转折式】
「后来怎么下定决心用AI的？」
「用了一个月之后，第一个变化是什么？」
「最让你意外的是什么？」

【收尾 - 回顾式】
「现在回头看，你觉得老板最该从哪个点开始用AI？」
「对还在犹豫的同行，你想说什么？」
```

### 模板C：反常识观点线

```
【破冰 - 情境式】
「行业里有个说法叫XXX，你同意吗？」
「我看到你在另一个采访里说XXX，能展开讲讲吗？」

【展开 - 引导式】
「你说这个的意思是不是...？」
「所以大部分人都在做的事，你觉得是错的？」

【高潮 - 转折式】
「那你觉得正确的方式是什么？」
「你这么说，不怕得罪人吗？」
「你有没有因为这个吃过亏？」

【收尾 - 回顾式】
「你觉得这个行业最需要改变的是什么？」
```

## 五、访谈者姿态

### 5.1 保禄的访谈人设

- **好奇心驱动**：不是来挖料的，是来了解这个人的
- **同行姿态**：跟被访者平视。不说「您太厉害了」，说「我也经历过类似的事」
- **真实反应**：对方说到好点时眼睛亮起来，说到苦点时跟着皱眉头

### 5.2 禁止的访谈姿态

- ❌ 主持人式：「那么请问...」「接下来我们聊聊...」
- ❌ 采访式：一个问题接一个问题，像在过清单
- ❌ 导师式：「你应该这样做」「我觉得你做得对」
- ❌ 吃瓜式：「真的吗？天哪！」——过度反应显得假

### 5.3 正确姿态

- ✅ 老友式：「哎那后来呢？」「对吧，我就说嘛」
- ✅ 同行式：「我也遇到过」「做咱们这行的都懂」
- ✅ 学徒式：「你当时是怎么想到的？」——真诚的好奇

## 六、访谈前准备清单

| 准备项 | 具体内容 |
|--------|----------|
| 被访者背景 | 行业/店名/规模/公开信息 |
| 核心故事线 | 确定今天访谈想走哪条线（创业/AI/观点） |
| 3个必问问题 | 不管聊到哪，这3个问题一定要问 |
| 1个可放弃的问题 | 如果节奏不对可以跳过的 |
| 关键词/主题 | 今天想让观众记住什么？ |

## 七、短视频访谈的黄金法则

1. **一条视频一个核心故事**：不要试图讲所有的事，5分钟讲一件事
2. **让被访者说，不是你说**：出镜频率不超过30%，把舞台给被访者
3. **情绪高于信息**：观众记不住你讲了什么数据，但记得住被访者说到某个点时眼眶红了
4. **金句是问出来的，不是准备好的**：好问题能引出对方自己都没想到的好回答
5. **结尾给一个行动暗示**：不是硬转化，是软引导——「如果你想了解XX，可以看看保禄的XX」
