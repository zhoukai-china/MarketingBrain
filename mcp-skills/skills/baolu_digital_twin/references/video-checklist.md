# 短视频自检7问

## 发布前必查清单

### 1. 前三秒有没有抓住注意力？
- [ ] 有痛点/冲突/悬念？
- [ ] 第一句话是否让人想继续听？
- [ ] 画面/字幕是否在第一秒就有信息量？

### 2. 有没有明确的目标人群？
- [ ] 知道这条视频是拍给谁看的？
- [ ] 标题/封面能否让目标人群一眼识别？
- [ ] 内容有没有解决目标人群的具体问题？

### 3. 有没有具体的举证？
- [ ] 有没有数据？（转化率/客资数/ROI等）
- [ ] 有没有案例？（具体门店/具体方法/具体结果）
- [ ] 有没有截图/录屏？（让观众看到真实性）

### 4. 有没有反差/反转？
- [ ] 有没有超出观众预期的信息？
- [ ] 有没有打破常规认知的观点？
- [ ] 有没有让观众觉得"原来如此"的时刻？

### 5. 有没有行动指令？
- [ ] 有没有引导关注？
- [ ] 有没有引导咨询/私信？
- [ ] 有没有引导领取资料？
- [ ] CTA是否清晰明确？

### 6. 评论区有没有互动钩子？
- [ ] 有没有埋争论点引发讨论？
- [ ] 有没有提问引导评论？
- [ ] 有没有设计互动环节？

### 7. 画面/字幕/节奏是否紧凑？
- [ ] 每3-5秒是否有一个信息点/画面变化？
- [ ] 字幕是否清晰、无错别字？
- [ ] BGM是否合适、不压人声？
- [ ] 时长是否控制在目标范围内？

## 常见NG

| 问题 | 表现 | 影响 |
|------|------|------|
| 开头太慢 | 前三秒在自我介绍/寒暄 | 流失率80%+ |
| 举证不足 | 只说观点不给证据 | 可信度低 |
| 没有反转 | 平铺直叙没有记忆点 | 完播率低 |
| 忘了CTA | 观众看完不知道干嘛 | 转化率低 |
| 节奏太慢 | 信息密度不够 | 完播率低 |
