## 这个skill解决什么

一家店做得好不叫本事。开到第10家、第100家，顾客闭着眼睛都知道会得到什么——这才叫本事。

这个skill把全球顶级企业的标准化方法论，拆成中小企业能直接用的体系。从一碗面的克重到一家店的开业流程，从一个人的操作习惯到一万人的行为统一。

## ⚠️ 第一步：先分体量（必做）

**同一句话在不同体量是两种需求。必须先判断客户在哪一层，再给方案。不给T1客户讲T4的东西。**

| 层级 | 体量 | 典型客户 | 一句话策略 |
|------|------|----------|-----------|
| **T1小微** | 1-10家/营收<1000万 | 社区店、单品类小店 | 不给体系，给一刀纸 |
| **T2中型** | 10-50家/1000万-1亿 | 区域连锁品牌 | 建体系，不再靠人盯 |
| **T3大型** | 50-500家/1亿-10亿 | 省域龙头/全国扩张 | 系统化+数字化，建壁垒 |
| **T4规模级** | 500家+/上市/>10亿 | 全国头部/上市公司 | 战略级，AI+合规+生态 |

**三步问清楚**：
1. 「多少家店？年营收多少？」→ 定T层级
2. 「标准化现在做到什么程度了？」→ 定该层内的起点
3. 「最痛的点是什么？」→ 定优先攻哪个模块

详细展开见 `references/tier-system.md`（含各模块按层级适配矩阵+跨级警告）。

## 使用方式

**核心流程**：先判体量（T1-T4）→ 再判成熟度（L1-L5）→ 再匹配框架 → 输出方案或文件。

告诉我要解决什么标准化问题，我会先问清楚体量和现状，然后自动匹配对应的框架和深度。

常见场景（按体量自动适配深度）：
- 「帮火锅店做出餐标准化」 → T1给标准卡，T3给数字化SOP体系
- 「连锁品牌怎么复制」 → T2给七步法，T4给生态输出方案
- 「加盟商培训体系怎么搭」 → T2给TWI试点，T3给企业大学
- 「怎么让服务统一」 → T1给服务卡，T4给全链路服务标准体系
- 「巡检怎么设计」 → T2给飞行检查，T3给三位一体+AI哨兵
- 「怎么用AI替代靠人盯」 → T2最多上客诉预警，T4六场景全上
- 「整个标准化体系从哪开始」 → 先分体量+成熟度评估

## 文件输出模式（直接出落地文件）

当客户说「给我出一个XX标准文件」时，直接输出能打印贴在墙上、拿在手上用的标准化文件。

### 输出规则

1. **格式**：一条条写清楚，客户拿了就能用。不用再解释。
2. **量化**：有克重用克重，有秒用秒，有℃用℃。没有数字不叫标准文件。
3. **一刀纸**：每份文件一张纸能写完。超过就是废话太多。
4. **客户信息**：用[XX]标注待填部分，客户填完就完整。

### 支持输出的标准文件类型

| 文件类型 | 触发词 | 用途 |
|----------|--------|------|
| 出品标准卡 | 「出个XX的标准卡」「XX怎么做才标准」 | 贴在灶台/操作台上 |
| 服务标准卡 | 「服务员怎么标准」「迎宾标准」 | 贴在收银/前厅 |
| 品控检查表 | 「品控怎么查」「后厨检查表」 | 店长/督导每日勾 |
| 培训过关卡 | 「培训怎么考核」「XX过关标准」 | TWI培训验收用 |
| 神秘顾客评分表 | 「神秘顾客怎么打分」 | 第三方暗访用 |
| 开店/打烊清单 | 「开店要检查什么」 | 早晚班交接用 |
| 供应商验收标准 | 「进货怎么验收」 | 收货区贴 |
| 加盟商交付手册 | 「加盟商流程」「给加盟商什么文件」 | 加盟商签约后交付 |

## 使用原则

1. **先分体量，再开药方**：T1别讲AI，T4别给一刀纸。看 `references/tier-system.md`。
2. **先测成熟度，再定深度**：L1口头化的店，目标是做到L2文档化，不是L4数字化。
3. **先固化再优化**：先做到「每次都一样」，再追求「每次都更好」。
4. **标准不是管人的，是帮人的**：好的标准让笨蛋也能做对，坏的标准让聪明人也想绕开。
5. **没有检查就没有标准**：写出来不检查=没写。
6. **标准必须能迭代**：三个月不改的标准是死的标准。
7. **文件不是做完就完了**：每个标准文件做完必须——贴到对应位置、培训到对应的人、纳入每日检查。
