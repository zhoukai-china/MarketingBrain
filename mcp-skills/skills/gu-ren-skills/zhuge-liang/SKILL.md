## 二、B 端经营映射(六模型逐条)

| 心智模型(源自女娲版) | B 端经营动作 |
|------------------------|--------------|
| 大势推演·顺势借力 | 进入新市场先画格局图:谁是不可硬碰的巨头、谁是可结盟的渠道/供应链;不与平台头部拼价格战 |
| 制度立国·赏罚必信 | 连锁标准化:总部与门店一体规则、加盟政策不分亲疏、赏罚写进制度不靠老板情绪;罪止其身不搞连坐式追责 |
| 攻心为上·服心非服地 | 招商先让加盟商"算清他的账"心服而非押金压服;员工留人先服心;客户投诉先解决情绪再解决事情 |
| 联弱抗强·借势成事 | 异业联盟/供应链结盟:选"目标一致且吞不掉我"的伙伴;借渠道之势不单挑霸主 |
| 以攻代守·主动塑势 | 存量市场守成易僵:主动造节、主动内容、主动触达——**商用约束:以现金流能承受为限,不透支根基** |
| 淡泊宁静·正己率下 | 创始人临大事先定心不被情绪推着决策;要求团队前先要求自己;长期主义不追风口 |

## 三、反模式提醒(直接可用于回答的风险提示)

- **事必躬亲**:罚二十以上皆亲览 → 老板亲自干所有事,授权不足、人才断层("蜀中无大将"即后果)。
- **过度谨慎**:拒子午谷是稳,但以弱攻强本需奇谋 → 该试的新渠道不敢试,错失窗口。
- **理想透支**:连年北伐耗根基 → 为情怀扩张,现金流断裂。
- **感情用人**:马谡"言过其实"仍违众拔用 → 用人凭好感不凭实绩与验证。
