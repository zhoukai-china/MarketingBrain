## 二、demo 要还原的核心交互(按优先级)

### P0:顾问对话页(核心页面)
每条回复必须是**四段结构**(从各 SKILL.md §三取):
1. **X子之见/兵法之见/商道之见/曾公之见/雪岩之鉴** —— 引用原则+原文出处
2. **经营映射** —— 翻译成商户场景
3. **可执行动作** —— 1-3 条,具体
4. **风险提示**
5. 底部固定**合规声明条**:"本回答由 AI 基于《XX》公开史料方法论生成,仅供经营参考,不构成专业意见。"——**每条回复都必须有,不可省略,这是《AI 生成合成内容标识办法》的合规要求,不是装饰**。UI 建议:浅灰小字+AI 标识图标,固定在气泡底部。

### P1:选人首页("智慧团"大厅)
- 6 顾问卡片,每个含:头像(建议水墨风古画意象)+一句话定位(从总览阵容表取)+适配场景标签(2-3 个)
- 场景路由入口(总览 §二的 10 条路由):"我遇到了什么问题"→ 按问题推荐顾问。示例:点"库存压货"→ 推荐范蠡+管子
- 演义校正的巧思展示位(差异化卖点):hover 顾问卡片出现"他真能打/他真说过"小知识,如诸葛亮卡:"草船借箭是小说,正史原型是孙权"

### P2:套餐定价页
从总览 §三取:四个双顾问包 ¥199/月、全席 ¥348/月、单次体验 ¥1-3/次。

### P3(可选):示例对话预置
demo 不接真模型,**对话内容直接用两份 QA 压测报告里的模拟应答**(那是人工打磨过的高质量样例)。建议每个顾问预置 2 条:
- 一条"典型场景"(如孙子对五折对抗题)
- 一条"边界展示"(如胡雪岩对挪用储值卡的严拒+以史为鉴)——**拒答场景恰恰是卖点:商户看到顾问"有原则"才信任**

## 三、设计风格参考

- 咨询公司级权威感 + 中式底蕴:深蓝+橙配色,或水墨+金;卡片玻璃质感
- 字体:正文黑体系,引文/古文用楷体或宋体区分(引文出处用小字标注——对应"一手/依托"分层,依托文献标灰字"后世托名")
- 引文出处 UI:原文引用右下角加来源标签,如《史记·货殖列传》(一手·绿) / 《范子计然》(辑佚·灰)——**分层标注是产品差异化,要在 UI 上可见**

## 四、红线(demo 也不能碰)

1. 不冒充真人:所有页面有"AI 蒸馏顾问,非真人"声明;不使用六位古人真实肖像做营销主视觉(用意象化插画)。
2. 每条对话必须带合规声明(demo 里也要,养成习惯)。
3. demo 中不放"必赚/保证盈利"类文案;拒答示例按压测报告里的措辞。
4. demo 完成后**不自动部署**,交付给保禄确认,上线走 chat-test 流程(见 HANDOFF.md)。
5. 曾国藩卡不用"曾剃头"、胡雪岩卡不主打"红顶商人官商"人设(合规观感风险)。
