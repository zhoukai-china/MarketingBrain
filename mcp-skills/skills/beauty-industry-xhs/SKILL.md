# 美业小红书图文

复用平台的小红书图文工作流，只补充美业行业差异，不复制计费、媒体、保存或发布逻辑。

## 输入边界

使用用户需求、当前经营主体已确认事实、用途/比例/风格、人物与素材授权、可核验功效/资质证据。未知项必须待补。

## 行业约束

- 标题与正文先写真实顾客处境、服务过程或可验证知识，不制造容貌焦虑，不承诺治疗或确定疗效。
- 价格、优惠、资质、案例、顾客评价和门店实景未确认时不写。
- 配图提示词描述主体、构图、场景、光线、色彩与材质；中文标题作为后期叠字字段，不能依赖绘图模型直接生成准确中文。
- 人物、肖像、门店照片和商标必须有使用授权；否则使用无人物、非特定空间或产品静物方向。
- 只生成草稿/预览。付费图片任务必须先展示报价并由用户明确确认，同一幂等键不得重复生成或扣费。

## 输出

3 个标题候选、选中标题、完整正文、5–8 个相关标签、互动与承接、事实/合规待补，以及“封面图、内容图、互动承接图”三套独立配图方向。每套都包含正向视觉提示词和负向提示词，另输出后期叠字和结构化视觉参数。用户未提供真实经历时不得虚构第一人称体验或护理师行为。

为避免输出被截断，正文控制在 500–700 个中文字符，每套正向提示词不超过 180 个中文字符、负向提示词不超过 100 个中文字符，完整答案不超过 2800 个中文字符；不能因压缩而删除任何必填章节。
