# 元神工厂 · 客户思维克隆体生产系统

## 概述

将思潼元神的五层思维模型方法论工业化——为每个客户老板创建属于他自己的「元神智能体」。

**思潼只做一件事：现场控场。其他全部自动化。**

---

## 现场流程（45-60分钟）

### 准备

1. 客户基本信息（姓名/行业/城市）**访谈前不需要**，生成skill时再给
2. 思潼打开Get笔记，开始**录音+全文转写**（不要只靠AI总结，要全文）
3. 客户可以坐在旁边看到问题文字（投屏或笔记本屏幕），知道聊什么方向

### 交互方式

```
WorkBuddy一次性出每层的全部问题
         ↓
思潼用聊天感提问（不是念题）→ 客户自然口述回答
         ↓
Get笔记全程录音 + 全文转写
         ↓
思潼现场控场：有案例/够细 → 继续；不够 → 追问一句
         ↓
答不出来 → 标记「待补充」→ 切下一题
         ↓
访谈结束 → AI抓Get笔记全文 → AI自己分析提炼（不依赖Get笔记AI总结）
```

### 思潼的控场规则

**不需要把客户回答转述给AI，不需要中途跟AI交互。**

现场只判断三件事：
- 有没有具体案例？→ 没有 → 追问「能举个实际的例子吗？」
- 有没有具体数字？→ 没有 → 追问「大概多少？具体几个？」
- 是不是太顺太圆（理想状态）？→ 是 → 追问「实际上有没有做不到的时候？」

答不出来不勉强，标个「待补充」，切下一题。强行追问破坏体验。

### 提问方式

**用聊天感，不要念题。**

- ❌ 「遇到一个完全没做过的事你怎么入手举个例子」
- ✅ 「我比较好奇，遇到一个完全没干过的事儿，你一般怎么入手？」

客户感觉就是跟思潼深度聊天，不知道背后有AI提炼这回事。

### 出题节奏

- 五层按顺序走，不跳
- 每层2-3个核心问题（见 `references/interview_questions.md`）
- 总时长控制在45-60分钟，第一层和第五层可以花多点时间
- 客户聊嗨了跑题 → 思潼拉回来：「这个有意思，我们后面聊，先回到这个——」

## 会后自动化

### Step 1: 获取Get笔记全文转写

Get笔记停止录音后，**抓取全文转写内容**（不是AI总结）。

> ⚠️ 关键：Get笔记的AI总结会丢细节，必须给我全文转写，我来做分析提炼。

### Step 2: 元神工厂分析提炼

加载Get笔记全文转写 → 按五层框架逐层提取：

| 层次 | 提取什么 | 关键信号 |
|:---|------|------|
| 第一层·元思维 | 怎么拆解问题、信息决策阈值、行动节奏 | 思考模式、决策习惯 |
| 第二层·决策框架 | 怎么选人/花钱/选客户、危机处理方式 | 优先级排序、底线 |
| 第三层·工作方法 | 怎么做方案、怎么学习、怎么验证想法 | 工作流程、学习偏好 |
| 第四层·品味判断 | 什么是好内容/IP/团队/生活 | 审美标准、喜恶 |
| 第五层·深层信念 | 为什么做、五年后、人生优先级 | 驱动力、核心价值观 |

**每个维度的提取遵循三条规则：**
1. 必须有客户原话或行为作为来源
2. 素材不够的标注 `[待补充]`
3. 客户说做不一致的，以做的为准，标注 `[自述]` vs `[实际]`

### Step 3: 生成客户元神skill

按 `references/output_skill_template.md` 模板生成，包含：
- `SKILL.md`：客户身份 + 触发场景 + 输出风格
- `references/mind-model.md`：客户五层思维模型

输出路径：`~/.workbuddy/skills/{client-name}-yuanshen/`

### Step 3.1（可选）: 外部知识增强模块

客户元神默认只含个人思维框架。如客户主动要求增强决策能力，可加载外部知识支持：

- **加载方式**：在客户 `mind-model.md` 末尾新增「外部知识处理原则」章节
- **输出标注规则**（必须遵守）：
  - `[思维框架]` = 来自五层思维模型，客户本人会这么判断
  - `[外部知识]` = 来自全球顶尖方法论/知识库，作为角度补全
  - 两条都有的内容，两个标签都标
- **重要**：结论必须用客户自己的框架得出，外部知识只做「角度补全」，不能替代客户判断
- **此模块必须客户主动选择**，不能默认开启；生成后需告知客户标注规则

## 交付与迭代

1. 思潼审核生成的mind-model，修改不准确的地方
2. 发送给客户确认（可选，看客户关系）
3. 后续客户有新录音/内容 → Get笔记更新 → 元神工厂自动增量补充
4. 渐进式构建：第一次不可能满分，50分就够了，后续迭代到80分

---

## 核心原则

- **不编造**：素材不够的标「待补充」，别替客户想
- **故事 > 自评**：问「你做了什么选择」不问「你是什么样的人」
- **做的 > 说的**：行为暴露真实思维
- **渐进式**：有多少素材建多少维度，不追求一次完美
- **思潼价值在控场**：Automate the process, humanize the follow-up
