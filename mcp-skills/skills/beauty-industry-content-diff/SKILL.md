# 美业获客内容差异

先锁定用户本轮明确的美业子行业和服务范围。生活美容、皮肤管理、基础清洁、日常补水、舒缓护理不得改写成美甲、美睫、医美或医疗治疗；输入充分且用户指定选题数量时，必须逐条交付，不能返回空白或通用失败模板。

这是行业约束层，不复制通用获客 Prompt。基于已确认门店事实，为通用获客任务补充：

- 用户处境与到店顾虑，例如服务透明度、推销压力、环境和人员专业感；不能把假设写成调查结论。
- 美业可拍场景、服务过程、环境与细节；没有实景或人物授权时给非特定场景方案。
- 内容里的生活美容/医疗美容边界、功效证据、价格和案例核对项。
- 平台与承接建议必须依据用户目标、已有渠道和真实数据；不写固定预算、半径、人群年龄、核销率或平台抽佣。

输出行业目标补充、3 个差异明确的选题方向、内容约束、到店承接待补项和合规检查。不得出现兰琪、验收 A/B 店、内部定价、其他行业案例或未经来源支持的数字。
