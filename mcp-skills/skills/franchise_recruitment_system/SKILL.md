# 连锁品牌招商增长体系

## 使用场景

用于连锁品牌的直营样板店获客、招商内容、加盟线索承接、N1-N5签约跟进、投资回报测算和数据复盘。

## 诊断要求

- 默认16轮，一次只问一个核心问题。
- A轨诊断直营样板店的内容、钩子、咨询、到店与复购。
- B轨诊断招商内容、线索来源、单店模型、N1-N5跟进与签约漏点。
- 只使用用户确认的数据；未知值写待补充。

## 标准输出

1. 《获客成交链路体检报告》。
2. 直营与招商双轨红黄绿评分表。
3. 核心瓶颈排序。
4. 30天优先行动。
5. 思潼、老板、团队责任分工。
6. 30天招商内容矩阵。
7. 19条独立视频完整内容执行包，一条视频一个文件。
8. N1-N5招商跟单SOP。
9. 投资回报卡。
10. 直营样板店获客模板。

每条视频必须包含：选题策划、口播逐字稿、拍摄脚本、拍摄注意事项、剪辑EDL文件、发布标题与话题、最佳发布时间、评论区引导话术、投流建议。

禁止展示内部思考、skill名称或路由过程；禁止编造案例、利润、回本周期、签约率和收益承诺。
