# AI短视频复盘引擎 V2

## 概述

本技能帮助企业/个人对短视频内容进行系统性复盘。核心逻辑：**不只分析数据，更沉淀方法论**。经过一段时间的持续复盘，企业能积累出自己的内容方法论和选题判断力。

```
数据输入 → 数据质量审计 → 多维分析 → 复盘报告 → 方法论沉淀 → 选题建议
                ↑                                                │
                └──────────── 持续迭代 ────────────────────────┘
```

---

## ⚡ 触发机制

> **「短视频复盘引擎」——所有平台、所有类型的短视频数据复盘都走本技能。涵盖自然流+付费流、单条诊断+批量分析+周期性复盘。**

**触发范围**：抖音/视频号/小红书/快手/B站等所有平台的短视频复盘。自然流量分析、付费流量(DOU+/本地推/千川)ROI分析、单条视频诊断、账号整体健康度诊断、周/月/季度复盘。
**排除范围**：IP定位/人设（ip-positioning）、内容创作/脚本/拍摄（baolu-content-creator）。
**两种模式**：简单模式（给链接快速看）→ 深度模式（导数据文件做完整报告）。

### 核心触发词（任一命中即触发）

**复盘/数据分析：**
- 复盘：短视频复盘、帮我复盘、复盘这条、这周复盘、月度复盘、季度复盘
- 数据：视频数据、数据怎么看、帮我分析数据、这条数据怎么样
- 诊断：为什么这条爆了、为什么没流量、帮我看看这条

**效果归因：**
- 转化：ROI怎么算、投了钱效果怎么样、投流有没有用
- 对比：这几条哪条好、A/B测试结果
- 趋势：最近播放一直掉、是不是限流了

**平台覆盖：**
- 全平台：抖音/视频号/小红书/快手/B站的视频数据，全部触发

### 两种复盘模式

| 模式 | 触发条件 | 输入 | 输出 |
|------|----------|------|------|
| 🚀 快速诊断 | 用户给链接/说“帮我看下这条” | 视频链接 + 用户可见的真实指标/口头描述 | 单条证据受控分析（3-5个要点） |
| 📊 深度复盘 | 用户给数据/说"帮我做周复盘" | Excel/CSV数据文件 | 完整复盘报告（含审计+健康度+归因+趋势+选题） |

### 深度复盘入口 → 引导数据上传

用户触发深度复盘后，先走「前置步骤：数据文件获取」引导，告诉客户怎么从创作者中心后台导出数据。

### 示例

✅ 触发本技能：
- "帮我复盘下这周的视频" — 周度深度复盘
- "这条视频 https://... 帮我看看" — 快速诊断
- "最近播放量一直掉什么原因" — 趋势诊断
- "投了5000块效果怎么样" — 投流ROI复盘
- "视频号和小红书数据对比一下" — 跨平台复盘

❌ 不触发本技能：
- "帮我写条口播稿" — baolu-content-creator
- "帮我做IP定位" — ip-positioning

### 升级点一览

| 升级模块 | V1 能力 | V2 新增 | 解决的问题 |

| 数据质量审计 | 无 | 第零步：数据完整性校验 | 完播率缺失/评论0异常等数据缺口导致误判 |
| 四层报告体系 | 单次复盘 | 日报/周报/月报/季报 | 不同周期看不同深度，日报不写长文、月报不只看数 |

| 账号基线系统 | 无 | 自动计算账号历史中位数做基线 | 不再用行业平均判断"好或坏"，用自己跟自己比 |

```

📊 必须包含的字段：

## 第零步：数据质量审计（V2新增——分析前必做）

**拿数据第一件事不是分析，是检查数据能不能用。** 数据缺了关键字段，分析结论可能完全反掉。

### 审计清单

| 检查项 | 审计方法 | 异常处理 |
|--------|----------|----------|
| 完播率覆盖率 | 有完播率的视频数/总数 | <70%：报告开头标红"⚠️ XX%视频完播率缺失，内容和留存分析受限" |
| 评论功能状态 | 是否全部为0 | 全为0：标注"⚠️ 评论数据全为0，无法做互动深度分析，请确认评论功能是否正常" |
| 数据时效性 | 最近更新时间 | 数据滞后超过48h：标注"数据可能存在延迟" |
| 字段完整性 | 必须字段（播放/互动/时间）是否都有 | 缺失：明确告知哪个维度分析受限 |
| 发布时间精度 | 是否包含时分 | 没有时分：跳过发布时间窗口分析 |
| 投流标记 | 是否区分自然/付费 | 没区分：所有流量分析结论加"⚠️ 未区分自然/付费" |

### 数据质量报告（每次分析开头输出）

```
## 数据质量审计
- 总记录数：XX条
- 完播率覆盖率：XX/XX = XX% {🟢健康/🟡偏低/🔴严重缺失}
- 评论数据：{正常/⚠️全为0}
- 发布时段精度：{有/无}
- 投流标记：{已区分/⚠️未区分}

本次分析受限维度：
- {列出所有因数据缺失而受限的分析维度}

如有🔴级别异常 → 优先建议用户补齐数据后再出完整报告
```

## 第一步：数据收集

### 需要收集的核心数据

视频复盘需要两类数据——**必须提供**的和**如有更准确**的。

| 数据类型 | 必须字段 | 推荐字段 | 用途 |
|----------|----------|----------|------|
| 播放数据 | 播放量 | 完播率、5秒完播率 | 判断内容吸引力 |
| 互动数据 | 点赞数 | 评论数、分享数、收藏数 | 判断内容价值感 |
| 转化数据 | 咨询量/留资数 | 成交数、客单价 | 判断商业价值（⭐最高权重） |
| 内容信息 | 视频链接/描述 | 选题、开头话术、时长、发布时段 | 归因分析 |
| 投流数据 | 是否投流 | 投流金额、投流ROI | 区分自然流量与付费流量 |

### 收集方式

1. 用户直接粘贴数据（播放1000/点赞50/评论10/咨询3）
2. 用户发送视频链接 + 口头描述效果
3. 用户提供截图（飞瓜/蝉妈妈/抖音后台）
4. 如果用户说「只知道播放量和点赞」，就用仅有的数据做分析，缺的维度标注「数据缺失」

## 第二步：四步分析法

### 第一步：数据分层——先把视频分档

拿到数据后，先不分析，先分类。按以下矩阵把视频分成四类：

```
              高转化（有咨询/成交）
              │
    有量无转  │  又爆又赚
   ──────────┼──────────
    没量没转  │  有转无量
              │
              低转化
```

| 类型 | 特征 | 核心分析角度 |
|------|------|------------|
| **又爆又赚** | 高播放+高转化 | 这条做对了什么？能否复制SOP？ |
| **有量无转** | 高播放+低/无转化 | 为什么看了但不行动？是人群不对还是钩子不对？ |
| **有转无量** | 低播放+有转化 | 怎么放大？投流？改开头？重发？ |
| **没量没转** | 低播放+无转化 | 快速诊断问题→优化 or 淘汰 |

### 第二步：转化归因——为什么这条能/不能转化

**这是复盘的核心。转化>流量。** 一条转化1个客户的视频比10万播放零转化的视频更有价值。

**如果有转化数据**，从以下维度归因：

| 维度 | 分析问题 | 判断标准 |
|------|----------|----------|
| 用户精准度 | 这条视频的受众是不是目标客户？ | 评论内容/咨询问题是否来自目标人群 |
| 信任感 | 视频建立了什么信任？ | 有没有真实案例/具体数字/身份展示 |
| 需求触发 | 用户为什么看完想行动？ | 视频有没有戳中一个具体痛点 |
| 行动门槛 | 用户行动方便吗？ | 有没有明确行动引导（不是违规引导，是内容层面的引导） |
| 时机匹配 | 用户在什么状态下看到？ | 发布时间/平台/场景是否匹配用户决策状态 |

**如果没有转化数据、但流量好**，从以下维度分析为什么流量好：

| 维度 | 分析问题 |
|------|----------|
| 钩子（前3秒） | 前3秒为什么能留住人？用了什么钩子？ |
| 内容价值 | 用户看完获得了什么？（信息/情绪/方法/共鸣） |
| 传播力 | 为什么用户想点赞/分享？触发什么情绪？ |
| 平台匹配 | 内容形式是否符合这个平台的推荐逻辑？ |

### 第三步：失败归因——这条为什么不行

| 可能原因 | 表现 | 诊断方法 |
|----------|------|----------|
| 开头没钩住 | 5秒完播率<30% | 看前三秒——有没有冲突/数字/反常识？ |
| 选题没兴趣 | 完播率低+互动低 | 选题是不是在自嗨？用户真的关心吗？ |
| 人群跑偏 | 播放不错但互动不匹配 | 评论是不是目标用户在说？ |
| 执行问题 | 画面/音质/节奏明显差 | 对比自己数据好的视频，画面差在哪？ |
| 发布时机 | 同时段其他视频数据正常 | 换发布时间测试 |
| 平台限流 | 突然降幅明显 | 检查是否有违规词/敏感内容 |

### 第四步：规律提炼——从单条到方法论

每次复盘结束后，从以下四个维度沉淀规律：

| 维度 | 沉淀什么 | 示例 |
|------|----------|------|
| 钩子规律 | 哪种类型的开头在你这最管用？ | 「数字冲击型开场，带具体金额的，比故事型开场流量高40%」 |
| 选题规律 | 哪类选题转化最好、流量最好？ | 「案例拆解类选题转化率最高，但流量低；反常识观点类流量高但转化一般」 |
| 形式规律 | 什么形式数据稳？ | 「口播+门店B-roll混合型完播率比纯口播高」 |
| 时间规律 | 什么时候发效果最好？ | 「周二/周四晚上8点发布，24小时播放量比周末高30%」 |

## V2新增分析维度

### 第五步：内容结构健康度诊断

**不只分析单条视频，更要看"内容组合拳"打得怎么样。**

#### 内容类型矩阵

| 类型 | 战略定位 | 判断标准 | 健康占比 |
|------|----------|----------|----------|
| 案例拆解（爆款型） | 拉新引流 | 高播放+高完播 | ≥20% |
| 创业故事/人设型 | 建信任 | 中播放+高互动 | ≥15% |
| 干货教学（专业型） | 秀专业 | 中播放+深互动 | 10-20% |
| 入企案例（证据型） | 促转化 | 播放不高但转化高 | 10-15% |
| 招商/引流（变现型） | 拿结果 | 有明确转化漏斗 | 10-15% |
| 知识分享（填充型） | 维持更新 | 播放/互动均垫底 | ≤10% |
| 杂项/无标签 | 定位不清 | 数据不稳定 | ≤5% |

#### 健康度评分

```
内容健康度 = (爆款型条数 + 人设型条数) / 总条数

> 50% → 🟢 健康
30-50% → 🟡 注意
< 30% → 🔴 危险：大部分内容在"假装日更"
```

#### 配比诊断输出

```
## 内容结构诊断
| 类型 | 占比 | 均播 | 互动率 | 完播率 | 判定 |
|------|------|------|--------|--------|------|

核心矛盾：
- 太少：数据显示最好的类型，占比最低
- 太多：数据最差的类型，占比最高

调整建议：增{类型N条} | 减{类型N条} | 改{标题/钩子/时长}
```

### 第六步：完播率深层归因

#### 按时长分桶

| 时长区间 | 平均完播率 | 平均播放 | 解读 |
|----------|------------|----------|------|
| <10秒 | X% | X | 碎片内容 |
| 10-20秒 | X% | X | 中等密度 |
| 20-40秒 | X% | X | 完整叙事 |

**核心判断**：如果20-40秒完播率高于<10秒 → 你的优势在完整叙事而非短平快。

#### 最佳配方发现

```
按时长×类型交叉 → 找到最高完播率+最高播放的组合
这就是该账号的"最佳视频配方" → 批量复制
```

### 第七步：互动深度分析

| 互动类型 | 含义 |
|----------|------|
| 浅层（赞） | "看着不错"，不一定传播 |
| 深层（分享+评论） | "值得转/值得讨论"，有裂变价值 |

```
赞/分享比：
< 2:1 → 🟢 传播力强，适合投流放大
2:1-4:1 → 🟡 正常
> 4:1 → 🔴 好看但不值得转
```

分享率>2%的视频 → 重点投流，利用裂变。

### 第八步：趋势分析与预警

#### 建立账号基线

用历史数据计算中位数作基准：

| 指标 | 中位数 | 警戒线 | 优秀线 |
|------|--------|--------|--------|
| 单条播放 | X | <0.6X | >1.5X |
| 互动率 | X% | <0.6X% | >1.5X% |

#### 趋势检测

分析过去4周数据趋势（上升/下降/平稳+斜率），连续2周下降→策略预警。

#### 异常告警

| 异常 | 阈值 | 行动 |
|------|------|------|
| 单条暴跌 | 播放 < 7日均播×0.4 | 立即检查限流 |
| 趋势反转 | 连续7天 < 前7天 | 策略调整 |
| 互动塌陷 | 互动率连降3天 | 检查选题疲劳 |

## 第三步：输出复盘报告

### 3.1 单次复盘报告结构（V2增强版）

```
# 短视频复盘报告 · {日期/周期}

## 零、数据质量审计
- 总记录：XX条 | 完播率覆盖：XX% | 评论状态：{正常/异常}
- 分析受限维度：{列出}

## 一、数据总览

## 第四步：方法论积累与迭代

### 4.1 方法论库

复盘规律应沉淀到当前企业知识库中的方法论档案（如已建立）；没有可写入的企业方法论档案时，只在本轮报告中输出“待沉淀规律”，不得声称已经持久化。

每次复盘后：
1. 对比本次发现的规律与历史上的规律——是否一致？是否更新？
2. 标注规律的置信度变化
3. 如果某个规律已经被10条以上视频反复验证 → 标记为「已验证黄金法则」

### 4.2 持续迭代原则

| 原则 | 说明 |
|------|------|
| 不重复发明 | 如果已有规律能解释，不再新创规律 |
| 置信度升级 | 单次发现→「疑似规律」；3次验证→「已确认」；10次以上→「黄金法则」 |
| 过期清理 | 如果某个规律连续3次被新数据推翻 → 标记「已失效」 |
| 平台隔离 | 抖音规律和视频号规律分开记录——不同平台算法逻辑不同 |

### 4.3 复盘节奏建议

| 频率 | 复盘内容 | 目标 |
|------|----------|------|
| 每条视频发布后72h | 快速看数据，记录印象 | 建立数据直觉 |
| 每周 | 7天数据汇总 + 分层分析 | 发现短期规律 |
| 每月 | 月度汇总 + 方法论更新 + 选题建议 | 沉淀方法论 |
| 每季度 | 季度对比 + 策略复盘 | 校准方向 |

## 第五步：选题建议

基于复盘结果，给出下个周期的选题方向。复盘不碰共识层级，只给行动方向。

### 5.1 四象限 → 下周期行动

| 复盘结果 | 下周期行动 |
|----------|-----------|
| 又爆又赚 | 🔥 **主力复制：** 换角度继续拍这个方向 |
| 有量无转 | 🔧 **优化钩子：** 保留选题，加强片尾引导和转化话术 |
| 有转无量 | 📢 **投流放大：** ROI正就加预算 + 改开头破播放 |
| 没量没转 | ⚡ **快速归因：** 方向对执行差→重做；方向错→放弃 |

**共识层级是选题系统的事，复盘只负责告诉你什么方向该继续、什么该放弃。**

### 5.2 复盘和选题系统的接口

复盘数据本身就是选题4大来源之一（来源3：数据复盘），直接出2条候选。加上其他3个来源合计10条，走三关筛选。**

**两个系统的接口不是"复盘告诉选题系统拍什么"，而是复盘数据直接进入选题池。**

### 5.3 选题建议输出格式

```
## 下个周期选题建议

### 主力复制（又爆又赚池）
基于{视频标题}：
- 换角度/换案例/换人群重做
- 为什么：已验证用户想看+能转化

### 优化重拍（有量无转池）
基于{视频标题}：
- 保留选题方向，重写片尾转化钩子
- 为什么：流量好但转化断了

### 投流放量（有转无量池）
基于{视频标题}：
- 改开头+投流放大
- 为什么：转化好但流量不够

### 放弃方向
{具体方向}：数据验证不行，不做
```

## 核心原则

1. **转化优先于流量**：能转化的视频 > 高播放视频。复盘以转化为第一权重
2. **规律需要证据**：每条规律必须有至少1条视频数据支撑
3. **积累才是壁垒**：单次复盘的价值有限。持续复盘积累出的方法论库才是真正的壁垒
4. **怀疑直觉、相信数据**：有数据冲突时，数据优先
5. **平台不可混**：不同平台（抖音/视频号/小红书）的复盘分开做
6. **复盘不碰共识层级**：共识层级是选题系统的判断，复盘只给行动方向——什么继续、什么优化、什么放弃
