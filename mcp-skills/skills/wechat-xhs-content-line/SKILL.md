# 公众号与小红书内容生产线

## 输入

用户需求、目标受众、当前经营主体已确认事实、冲突/缺失资料、素材与人物授权、平台、用途、画幅和风格。

## 小红书输出

1. `客户可复制成品`：标题候选（3 个）、完整正文、话题标签（5–8 个）、互动与承接；不得出现待补、核验、回执或制作术语。
2. `门店制作说明`：封面图、内容图、互动承接图三套独立图片方向；每套包含正向提示词、负向提示词、后期叠字和供应商无关视觉参数。
3. `质量与合规检查`：任务事实回执、缺失资料与风险边界，独立于客户复制内容。

没有输入时点时不得虚构季节；时点缺失只进入质量与合规检查。

任何输出层都不得出现“我做过”“亲测”“做完后”等未经输入事实支持的第一人称体验表述。没有可核验第一人称经历时，改用门店中性说明；不得把禁词转移到制作说明或审核回执。

## 边界

- 资料里有的才说，冲突和缺失必须标明，不虚构体验、疗效、价格、案例、门店或发布结果。
- 中文文字只进入后期叠字字段。
- 未确认人物、肖像、门店实景、商标或顾客素材授权时，改用无人物、非特定空间或静物。
- 不调用付费媒体、不发布、不投流、不付款。
