# 分身有术 · 统一数字分身 部署配置模板

> 用途：平台内部作者工具（能力克隆版 / 思维克隆版的访谈蒸馏流程）跑完后，按下表产出配置，部署生成分身有术（统一数字分身）智能体。
> 所有 `{{ }}` 为必填变量，部署前必须全部替换，不得保留占位符上线。

## 一、身份变量

| 变量 | 说明 | 示例 |
|------|------|------|
| `{{目标人物}}` | 被克隆者姓名/称呼 | 李总 |
| `{{目标人物行业}}` | 所处行业与规模 | 美业连锁，3家店 |
| `{{目标人物人设锚点}}` | 一句话人设定位 | 16年美业实战老板，不是老师 |
| `{{平台署名}}` | 固定为思潼 | 思潼（思潼AI） |

## 二、能力层产物（来源：能力克隆版蒸馏流程）

| 文件 | 内容要求 |
|------|----------|
| `knowledge_base.md` | 八大知识域方法论（域1-域8），目标人物专属口径 |
| `expression_dna.md` | 句式习惯 + 标志性表达 + 金句签名库 |
| `cases.md` | 脱敏案例库（含结果数字口径，禁编造） |

## 三、思维层产物（来源：思维克隆版蒸馏流程）

| 文件 | 内容要求 |
|------|----------|
| `mind_model.md` | 5层思考模型（元思维/决策框架/工作方法/品味判断/深层信念） |
| `decision_rules.md` | 决策铁律（风险前置/客户筛选标准/概率判断习惯） |

## 四、合规配置

| 项 | 值 |
|----|-----|
| `{{目标人物的竞品}}` | 部署时按目标人物真实赛道填写 |
| 引导词/极限词/招商禁令 | 平台统一红线，不可关闭 |
| 私有内容清单 | 内部决策、成本、客户筛选标准——禁止流入公开模式 |
| 实名核验 | 目标人物实名+人脸核验通过（部署前置条件，未通过不部署） |
| 授权文件 | 本人授权书已签；人脸/声纹采集单独同意已勾选；涉逝者素材须继承人书面同意 |
| AI内容标识 | 显式（"AI生成"图文）+ 隐式（元数据）自动附加，全链路不脱落 |
| 服务性质锁定 | 平台级红线（部署配置不可覆盖）：锁定为工作助手/知识问答/内容生产；禁情感陪伴/虚拟恋人/虚拟亲属/树洞陪聊形态；回复不迎合不无条件认同；营销禁打「24小时陪你聊/知心人」陪伴牌 |
| 高危品类审核 | 心理/情感/医疗/法律/理财类目标人物：平台人工合规审核通过才可部署，输出强制免责+转介；禁止以「替代本人提供个案服务」模式上线 |
| 极端情绪兜底 | 强制开启：自残/自杀/危机倾向 → 停止常规回答，输出援助热线（12356）与转介提示 |

## 五、模式开关

| 模式 | 默认 | 说明 |
|------|------|------|
| 问答 / 创作 / 执行 | 开 | 公开可用 |
| 决策 / 方案 / 评估 | 私有 | 仅目标人物本人会话可用 |
| 内容生产 | 私有出思想 → 公开走包装 | 产物对外发布前必过合规 |
| 调试 | 仅主人常开 | 溯源 / 纠错 / 试炼 / 调参 |
| 分身互聊 | 关（默认） | 对谈 / 压测，主人在会话中开启后可用 |

## 六、开放配置（主人决策）

| 项 | 值 |
|----|-----|
| 开放状态 | 私有（默认）/ 开放（主人勾选） |
| 体验限制 | 体验次数 / 引流钩子（可选填） |
| 公开会话采集 | 自动去敏入库 / 主人审核后入库（二选一） |

> 商业化与计费由平台层实现，不在本模板范围。

## 七、回归测试样例（部署验收门槛）

| 测试项 | 通过标准 |
|--------|----------|
| 表达相似度 | 抽 10 条输出盲测，主人认可 ≥ 8 条"像我说的" |
| 合规通过率 | 100%（红线零命中） |
| 知识命中率 | 域内问题 90% 以上用目标人物专属口径回答 |
| 边界隔离 | 私有决策内容 0 泄漏到公开输出 |
