# 减肥内容差异卡

> 本卡只写「减肥独有」，配合 `content-nine-piece` 使用。减肥是医疗功效/虚假宣传重灾区，合规是第一优先级。

---

## ① 合规红线（减肥第一优先级）

**红线"四不"**：不承诺效果、不制造焦虑、不碰违禁成分、不做医疗宣称。

| 禁用 | 替代 |
|------|------|
| "7 天瘦 10 斤""一个月减 20 斤" | 科学减重，健康第一，效果因人而异 |
| "永不反弹""根治肥胖" | 减重 + 生活方式干预，长期保持 |
| "减肥药/瘦身神药" | 营养干预 + 运动指导 + 心理支持 |
| 身材羞辱（"你这么胖还不减？"） | 健康体重，更好生活 |

**硬红线**：
- 违禁成分：西布曲明、酚酞。
- GLP-1 减重药（司美格鲁肽）为**处方药**，非医疗机构禁销、禁宣传。
- 普通食品（代餐/轻食）**禁宣"减肥/瘦身/燃脂"**。

**判断口诀**：不承诺数字效果、不制造身材焦虑、不碰药、不碰医疗宣称。

---

## ② 行业钩子

| 钩子 | 打法 |
|------|------|
| 免费体测 + 健康讲座 | 社区引流，用专业感立信任 |
| 按效果付费（EBC） | "有效果再付费"，头部企业收入占比 14.7% 且翻倍增长 |
| 社区服务站 | 150㎡ 以下，坪效比大店高 22% |

**核心**：钩子核心是"有效果再付费 + 科学不速效"，不是"7 天瘦 X 斤"。

---

## ③ 话术与选题库

**高频选题**：科普干货（"为什么越饿越胖？科学减重底层逻辑"）、真实案例（**脱敏、不夸大**）、避坑指南（"市面上 5 种减肥骗局"）、生活化记录（健康饮食/科学运动）。

**原则**：科学 + 可信 + 可持续，不速效夸张。

## ⑤ 案例与数据锚点

| 指标 | 数据 |
|------|------|
| 用户画像 | 女性 78.6%、25-35 岁 54.2%、本科及以上 67.3% |
| 复购率 | 43% |
| 短视频直播订单占比 | 37.2% |
| 行业警示 | 投诉 2.3 万条、闭店率 57%（合规差是行业顽疾） |

**可对外案例逻辑**：科学减重过程记录（脱敏）+ 免费体测引流。涉具体减重数字需脱敏且不承诺效果。

## ⑥ 选题库

**选题类型配比**：

| 类型 | 占比 | 作用 |
|------|------|------|
| 科普干货 | 40% | 科学减重逻辑，建立专业信任 |
| 真实案例（脱敏） | 30% | 减重记录，证明有效不夸大 |
| 避坑/生活化 | 30% | 骗局避坑 + 健康饮食记录 |

**高频选题清单**（可直接用）：
1. 为什么越饿越胖？科学减重底层逻辑
2. 市面上 5 种减肥骗局，别交智商税
3. 真实减重记录：3 个月健康减 12 斤（脱敏）
4. 减肥别踩这 3 个坑：节食、猛练、乱吃药
5. 一周健康饮食记录：不挨饿也能瘦
6. 为什么你总是反弹？问题出在这

**选题钩子公式**：反差钩子（越饿越胖 / 越减越肥）＋ 科学减重不速效。
