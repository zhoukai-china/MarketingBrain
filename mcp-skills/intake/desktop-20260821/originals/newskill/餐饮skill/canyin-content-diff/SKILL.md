# 餐饮内容差异卡

> 本卡只写「餐饮独有」，配合 `content-nine-piece` 使用：先用通用九件套出骨架，再把本卡五段回填进去。

---

## ① 合规红线（餐饮内容第一优先级）

**餐饮宣传翻车一次，比生意差更致命——最高罚 20 万，还罚到个人（1-10 倍年收入）。**

### 红线 1：广告法极限词

| 禁用 | 替代 |
|------|------|
| 最、最佳、最好、最高级、顶级、极品、第一、No.1 | 口碑之选、老顾客回头率最高的店（需有依据） |
| 国家级、世界级、顶尖 | 直接删掉 |
| 绝对、唯一、100%、根治、彻底 | 客观描述（"每日现做""当天采购"） |

### 红线 2：食品功效禁用（餐饮最容易被忽略的重灾区）

**普通食品（含菜品）不得宣传疾病预防、治疗、保健功能，不得用医疗术语。**

| 禁用 | 例子 |
|------|------|
| 疾病预防/治疗 | 抗炎、降血糖、降血脂、治疗便秘、增强免疫力 |
| 保健功能 | 排毒、养颜、减肥、瘦身、安神助眠 |
| 医疗术语 | 药膳（无资质）、疗效、疗程、根治 |

**典型翻车**："养生汤治失眠""轻食减肥餐""排毒火锅"——全是红线。普通菜品就是普通菜品，不能往疗效靠。

### 红线 3：特殊宣称需证明

"无糖、低脂、零添加、有机、绿色食品"必须符合国标 + 有有效证明，否则就是虚假宣传。

### 红线 4：虚假评价/刷单/价格

- ❌ 刷单炒信、虚构好评、伪造"必吃榜""网红打卡地"——属虚假广告。
- ❌ 虚构原价（"原价 299 现价 99"但原价从未卖过 = 违法）；折扣/满减限制条件须显著标明。
- 酒类广告不得诱导饮酒、不得暗示功效。

### 审查清单（写完跑一遍）

```
1 扫资质（证照/无堂食标识）→ 2 扫极限词 → 3 扫功效（治病/养生/减肥/排毒/抗炎）
→ 4 扫宣称（无糖/低脂/零添加有证明吗）→ 5 扫评价（刷单/伪造必吃榜）→ 6 扫价格（原价真实吗）
```

## ② 行业钩子

**引流款**：9.9 / 19.9 元低价团购（拉新到店，不是赚钱——前端亏钱、二转赚回来）。

**三大到店理由（递进，不是三选一）**：

| 类型 | 本质 | 怎么做 |
|------|------|--------|
| 种草 | 品牌引力场 | 挖差异化卖点、造话题（"这碗面凭什么天天排队"） |
| 品宣 | 品牌信任状 | 展示后厨卫生、食材品质、门店人气 |
| 营销 | 临门一脚 | 团购套餐、限时折扣、新客立减 |

**核销率是抖音死穴也是机会**：抖音团购核销率仅约 50%（美团 80%–90%）。谁把核销做上去（券设 24-48 小时有效 + 预约引导 + 到店提醒），谁就多拿一倍到店客流。

**买点思维（用户雇佣理论）**：顾客买的不是一顿饭，是"雇佣"这顿饭完成一件事——加班后一口热乎、约会体面、一个人也要好好吃饭的仪式感。**从顾客原话和下单前犹豫里挖买点，别拍脑袋自嗨"我家食材好"。**

## ③ 话术与选题库

**食欲感三感（餐饮图片/视频灵魂，提示词必写）**：
- 声音：滋滋作响、咕嘟冒泡、咔嚓脆响
- 动作：筷子夹起、汤汁浇下、芝士拉丝、勺子舀起
- 状态：冒着热气、油润光泽、流心、酥脆掉渣

**食欲色**：暖色调、高饱和、油润质感；避免冷色调灰暗（显得"不新鲜"）。

**高频选题方向**：招牌菜大特写（拉丝/流心/冒热气）、后厨实拍、食材溯源、环境打卡、避坑、点单攻略、隐藏吃法。

**爆款钩子公式**（15 秒同城）：
```
0-3秒   "XX 区的人注意，这家店这碗面天天排队是有原因的"
3-10秒 后厨实拍/招牌菜特写（拉丝、热气、浇汁）
10-14秒 团购价对比（原价 vs 线上专属价，标注限量）
结尾    点左下角定位团购，到店核销
```

## ④ 平台侧重

| 平台 | 定位 | 打法 |
|------|------|------|
| 点评/美团 | 需求驱动、搜索精准 | 拼评分口碑、性价比 |
| 抖音 | 兴趣驱动、放量引流 | 拼视觉话题、团购冲动下单 |
| 小红书 | 种草放大器 | 拼氛围打卡、收藏转发 |

**关键**：抖音是兴趣驱动（冲动下单）、美团是需求驱动（主动搜索），**两套打法不能混用**。餐饮主力成交平台 = 点评/美团（精准）+ 抖音（放量），小红书做种草放大。

**投流侧重**：本地推定向 3–15 公里，目标团购成交优先，止损——预算 50% 没下单就关停换素材。自己拍 + 本地推 > 找达人（达人数据 95% 是刷的）。

## ⑥ 选题库

**选题类型配比**：

| 类型 | 占比 | 作用 |
|------|------|------|
| 食欲特写 | 40% | 招牌菜拉丝/流心/冒热气，看饿就点进来 |
| 氛围打卡 | 30% | 环境/出片角落，让人想去 |
| 痛点共鸣 | 30% | 加班/约会/一人食场景，对上处境 |

**高频选题清单**（可直接用）：
1. 这碗面凭什么天天排队？后厨 3 个细节说清
2. 加班到凌晨，就为这口热乎的
3. 点单攻略：第一次来这样点不踩雷
4. 后厨实拍：你吃的食材是怎么处理的
5. 隐藏吃法：老板不写菜单上的 3 样
6. 这家店的招牌菜，为什么 10 个人 9 个回头

**选题钩子公式**：食欲钩子（拉丝/冒热气/流心）＋ 团购价对比。
