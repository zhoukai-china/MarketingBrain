# 产康内容差异卡

> 本卡只写「产康独有」，配合 `content-nine-piece` 使用。产康是医疗健康相关高监管行业，合规是第一优先级。

---

## ① 合规红线（产康第一优先级）

**医疗功效禁用（重灾区）**：

| 禁用 | 替代 |
|------|------|
| 治疗、消炎、康复治疗 | 护理、舒缓、改善 |
| 根治漏尿、彻底修复盆底、3 次见效 | 改善盆底肌功能，效果因人而异 |
| 医疗级、临床验证 | 专业设备、持证康复师操作（需真实资质） |

**广告法极限词**：最、第一、100%、根治、永久、彻底 → 口碑之选、专业、改善。

**资质线（硬红线）**：盆底康复、电刺激、医疗级设备属**医疗行为**，须有医疗资质 + 持证康复治疗师；普通按摩/塑形（手法）只需一般经营许可，但**不得宣传医疗功效**。内容里出现"盆底修复""电刺激"等，先问"有没有医疗资质"。

**判断口诀**：涉及「病、疗、医、药、根治、无创」一律替换；承诺效果一律加"因人而异"。

---

## ② 行业钩子

**核心反低价**：产康客单价年均 1.2 万，低价引流来的"只图便宜、难升单"——**别用 9.9 式低价钩子，用"专业感 + 信任"钩子**。

| 钩子 | 打法 |
|------|------|
| 免费检测/评估 | 先做体态/盆底评估，用专业感立信任 |
| 医疗级设备 + 个性化方案 | 用户愿为此付 30–50% 溢价 |

---

## ③ 话术与选题库

**高频选题**：科普干货（"产后漏尿是怎么回事？盆底肌修复到底有没有用？"）、真实康复前后案例（**脱敏**）、避坑指南（"产后康复的 5 个坑，别再交智商税了"）。

**核心话术逻辑**："产康是信任生意，靠专业种草和口碑，不是低价硬推"——内容专业感 > 营销感。

## ⑤ 案例与数据锚点

| 指标 | 数据 |
|------|------|
| 决策三渠道 | 种草 41% + 医生推荐 29% + 亲友口碑 18% |
| 复购率 | 45% |
| 持证康复治疗师占比 | 仅 14%（行业稀缺，是信任卖点） |
| 行业规范 | 《产后康复服务规范（试行）》2025 年发布 |

**可对外案例逻辑**：真实康复前后案例（脱敏）+ 持证治疗师专业背书。涉具体客户/效果数据需脱敏且不承诺疗效。

## ⑥ 选题库

**选题类型配比**：

| 类型 | 占比 | 作用 |
|------|------|------|
| 科普干货 | 40% | 盆底肌/腹直肌，专业感立信任 |
| 真实案例（脱敏） | 30% | 康复前后记录，证明有效 |
| 避坑指南 | 30% | 交智商税痛点，建立信任 |

**高频选题清单**（可直接用）：
1. 产后漏尿是怎么回事？盆底肌修复到底有没有用
2. 产后康复的 5 个坑，别再交智商税了
3. 真实康复记录：产后 3 个月的盆底肌变化（脱敏）
4. 腹直肌分离怎么判断？在家自查 3 步
5. 产后恢复黄金期是多久？别错过
6. 为什么说产康是信任生意

**选题钩子公式**：科普钩子（专业感 > 营销感）＋ 持证治疗师背书。

---

> **收尾大白话**：产康先不违法（不碰医疗功效），再谈种草；靠专业和口碑立信任，别靠低价——客单价 1.2 万的生意，低价只会引来难升单的人。
