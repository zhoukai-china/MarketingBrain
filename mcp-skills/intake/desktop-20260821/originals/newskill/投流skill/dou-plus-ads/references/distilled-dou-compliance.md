# DOU+ · 审核红线与内容规范 官方规则蒸馏

> 蒸馏时间：2026-08-16
> 来源：抖音 DOU+ 官方帮助中心「内容加热规范 + 高频规则详解」17 篇
> 用途：投流前快速自检，判断内容能否过审、命中哪条红线、后果有多重

---

## 一、DOU+ 审核机制

### 1. 审核流程
- DOU+ 下单后内容须先过审才能加热；普通内容须满足《抖音社区自律公约》，企业强营销场景还须满足《广告法》。
- 审核结果只影响加热，**不影响视频自然推荐分发**。
- 审核结果在订单详情页公布；审核不通过时披露具体拒绝理由。

### 2. 审核不通过怎么办
- 每条订单都可在订单详情页查看审核详情与拒绝理由。
- 不理解理由可「发起咨询」申诉；根据违规图修改视频后可再次发起。
- 申诉入口三处：订单详情页拒绝理由下方「发起咨询」、账号管理页「发起咨询」、点击右上角「小耳机」调起智投星（输入审核问题 / 发送「申诉」选订单）。
- 申诉结果在订单详情页「申诉复议结果」查看；仍有异议可再次「发起咨询」或转人工。
- 客服入口：「投放管理」「我的DOU+」页面右上角客服图标。

### 3. 违规分级与处置（P0 最严）
- 违规来源：他人举报、用户投诉、平台审核/主动巡查。
- 判罚等级 P0 > P1 > P2 > P3：

| 等级 | 处置 |
|------|------|
| **P0** | 立即下线 + 永久/30天限制投放；情节严重可主体封停、限制新开、限制账户资金权益、终止合作 |
| **P1** | 30天/7天限制投放；严重可永久/30天/7天封停 |
| **P2** | 7天限制投放；严重可 30天/7天封停 |
| **P3** | 一般不处置（用户体验类） |

- 触发升级处置的情形：引发争议/诉讼仲裁、遭投诉举报、被国家机关立案、产生舆论、平台对外赔偿、多次/持续违规等。

## 二、通用禁投红线（按类别）

> 每条 = 一句话红线 + 违规后果。后果按判罚等级标注。

### 涉政类（P0，最严红线）
- 不得涉及政治敏感话题/事件、诋毁政治人物/英雄/烈士、恶搞国徽国旗、使用错误地图、破坏国家统一 → P0 立即下线，永久/30天限制投放，可主体封停、终止合作。
- 不得泄露国家秘密、危害国家安全、宣扬恐怖/极端主义、破坏宗教政策、煽动民族仇恨 → P0 同上。
- 不得歪曲篡改历史、恶搞丑化革命烈士/民族英雄、不当模仿阅兵、军人负面内容 → 拒审下线，涉政最重处罚。
- 不得违规发布/转载时政新闻、不合规展示军人/国家机关形象 → 拒审下线。

### 淫秽色情类（P0）
- 不得展示性行为、性器官、传播色情资源、发布招嫖卖淫/约炮/援交信息、展示特殊性癖（SM、恋童等） → P0 立即下线 + 永久/30天限制投放，可封停。
- 不得涉及性器具、催情类产品（假阴茎、充气娃娃、迷情/催情药等） → P0 同上。

### 赌博类（P0）
- 不得明示或暗示赌博产品/服务：赌博场所、赌术、博彩、赌博工具、赌博网站、赌球、老虎机、六合彩、变牌器、赌石、预测体育赛事 → P0 立即下线 + 永久/30天限制投放。

### 毒品类（P0）
- 不得涉及各类毒品、易制毒化学品、毒品原料、制毒书籍等（冰毒、海洛因、大麻、罂粟、咔哇潮饮） → P0 立即下线 + 永久/30天限制投放。

### 非法宗教类（P0）
- 不得涉及邪教口号、邪教活动信息、利用封建迷信违法犯罪 → P0 立即下线。

### 非法医疗类（P0）
- 不得涉及国家明令禁止或侵害他人的医疗：代孕、胎儿性别鉴别等 → P0 立即下线。

### 非法金融类（P0）
- 不得涉及非法集资、股票配资、证券内幕、信用卡回收、代办流水、美容贷、首付贷/分期 → P0 立即下线。

### 非法服务类（P0）
- 不得提供虚假执照、代办户口、代取公积金、代写论文、征信修复、清债讨债等非法服务 → P0 立即下线。

### 严重对抗平台（P0）
- 不得重复投放大量同一/相似违规素材、审核通过率明显偏低、恶意规避审核 → P0 立即下线 + 封停。

### 色情低俗（P0/P1）
- 不得有性暗示声音/动作/姿势、性挑逗、激吻/抚摸敏感部位、抖臀抖胸等低俗内容 → 低俗判 P1（30天/7天限制投放），露骨判 P0。
- 不得着装暴露（臀部大面积裸露、仅穿内衣、露乳沟）、展示身体敏感部位轮廓、情趣服装/用品、脱贴身衣物等不良暗示 → P1 限制投放。
- 不得涉及 AV 女优人物、性服务人员/场所 → P0/P1 下线封停。

### 虚假误导（P2，严重可升）
- 不得虚构事实、凭空夸大（不存在的产品特性/优惠/名额）、仿冒官方界面诱导点击 → 拒审，P2 限制投放。
- 不得悲情营销：利用残疾人/老人/儿童/孕妇/退伍军人卖惨、渲染滞销/灾害博同情促销 → P2 限制投放，情节重升级。
- 不得保证性承诺与绝对化用语：包过、100%见效、永不反弹、0风险、月入过万、年入百万、国家级/最佳/顶级 → P2 限制投放。
- 不得标题党、挂羊头卖狗肉（用无关素材投其他品类）、伪装新闻形式推广理财投资、假借"官媒指定/教育部推荐"背书 → P2 限制投放。
- 不得发布与官方政策不符的信息、宣传虚假政府补贴 → P2 限制投放。

### 医疗健康（P0/P1）
- 不得推广任何药品（含 OTC、国药准字、祛疤化妆品、灵芝孢子粉）、针剂（减肥针/高潮针/助孕针）、保健品（蓝帽、钙片）、医疗器械（美瞳、避孕套、美容仪） → 非法医疗 P0，一般医疗管控拒审。
- 不得推广医美/植发/男科/妇科/不孕不育/慢性病/精神心理/近视手术等诊疗服务、在线问诊、陪诊、亲子鉴定、赴外生子 → P0/P1 限制投放。
- 不得科普任何具体疾病的病因/症状/治疗/预防，不得讲中医穴位/针灸/艾灸/拔罐疗效 → 拒审。
- 不得用前后对比暗示疗效、招募病患/试药/捐精献血志愿者 → 拒审下线。
- 减肥、丰胸、增高、壮阳功效类内容 → P1 限制投放。

### 引流行为（P2）
- 不得清晰完整展示手机号/微信/QQ/群号/二维码/社交账号，不得用谐音暗语（vx、v、君羊）导流，不得引导看主页/头像/签名找联系方式 → 拒审，强营销 P2 限制投放。
- 不得引导至站外网址、第三方小程序、下载外部 App（短视频/电商/交友/小说软件），不得用"搜xx领券/领福利"虚假话术引流 → 拒审。
- 豁免：110/119/反诈电话/官方400热线、寻人寻物公益联系方式、无意拍到的门头电话/条码、搬运视频自带水印。

### 商业营销推广（未升级账号，P2）
- 未升级账户严禁任何营销感内容：不得出现"推广/广告/品牌合作"标识、引导团购/挂小黄车/营销链接、自称店主、报价格/折扣/秒杀/包邮、引导到店/私信/进直播间橱窗 → 拒审，强营销 P2 限制投放。
- 未升级账户不得以明星/名人/网红形象背书带货、不得假冒专家/官方机构、不得用"CCTV上榜/央国企授权"等官方名义背书、不得卖惨营销 → 拒审。
- 已升级账户可在规则内投放营销内容，但营销推广视频另有独立禁投清单（见第三节）。

### 社交类（P2）
- 不得发起拼车/顺风车/驴友等高风险邀约、征婚相亲引导私信加群、推广社交交友 App、涉外婚恋 App、猫鼠游戏、引流搭子群 → 拒审，P2 限制投放。
- 豁免：客观讲述跨国婚姻事件、宠物征婚/配种（不涉及人身交友）。

### 招聘类 / 涉外劳务（P2）
- 不得发布任何人力资源招聘类内容（介绍岗位/晒薪资福利/留联系方式），哪怕顺带提一句"招人"也违规 → 拒审，P2 限制投放。
- 不得发布涉外劳务：菲佣/外籍保姆/菲佣培训、外国留学生校外兼职打工、外教持旅游/探亲/学生签证在华工作 → 拒审。
- 豁免：公司日常/工作环境、外籍人士合法在华生活、持合法文教签证外教的教学日常。

### 回收鉴定（P2）
- 不得以商业推广为主旨做回收/鉴定/售卖/培训，不得招揽生意（上门回收/估价）、引导私信加群到店、宣传收费鉴定/报价 → 拒审。
- 不得发布废电池/废机油等危险废物、报废机动车、金银铂钯铑贵金属、文物艺术品、储值卡/酒类/奢侈品/货币回收 → 拒审。
- 豁免：纯过程展示、剧情演绎、知识科普，无招揽、无导流、无收费宣传。

### 无资质（拒审，P1/P2）
- 核心原则"持证上岗"：有资质要求的行业必须提供对应许可证，缺资质一律拒绝投放 → 拒审，情节重 P1/P2 限制投放。
- 3C 商品缺《中国国家强制性产品认证证书》、新手机缺《入网许可证》、无备案网站、无证随身 WiFi → 拒审。
- 无证网吧/影院/按摩/无人机商业飞行/汽车检测/旅行社（含超范围经营出境游）/保安/公证/司法鉴定/快递/客运/影视制作/出版物销售 → 拒审。

### 封建迷信（P1）
- 不得看风水、请神、招财、辟邪、护平安、化解小人、算命改运等；不得以和尚/道士/宗教形象带货、以寺庙道观为背景卖货；不得宣传手机号/房产风水 → P1 限制投放。

### 未成年人保护（P1）
- 不得诱导未成年不当行为、未成年吸烟/赌博/喝酒/纹身/彩妆、与未成年人不当亲密、未成年成人化演绎、未成年危险行为、利用不满十周岁未成年人代言 → P1 限制投放，情节重升级。
- 不得涉"儿童邪典"类内容（SCP 基金会/档案等） → 拒审下线。

### 特殊人群保护（P1）
- 不得教唆未成年违法犯罪、侵犯未成年人隐私、丑化贬低老弱病残孕等弱势群体 → P1 限制投放。

### 违法产品/服务与其他禁投（P0-P2）
- 不得涉及枪支、管制刀具、易爆有毒腐蚀品、电子狗/雷达干扰器、窃听器/偷拍设备、有偿删帖、考试作弊器、代查开房记录等 → P0/P1 下线封停。
- 不得涉及烟草营销（品牌香烟/电子烟/戒烟产品）、0-18岁学科/素质教培、网赚兼职（刷单/打字员） → 拒审。
- 禁投特定品类：蜡瓶糖、俄罗斯蜂王浆/西藏乌梨/毛燕窝/织纹螺等高风险食品、猫狗肉产品、寻人启事、盲盒、动物活体售卖认养、数字人克隆、黑客培训、新能源燃料、代孕/试管、买卖微信红包封面、干细胞疗法、打捞尸体/文物、诱鱼类产品、无品牌摩托车 → 拒审。
- 禁投特定种苗菌类（鹿茸菌/红灵芝/铁皮石斛/棉花等）→ 拒审。
- 不得涉传销、非法持有枪支、偷逃税、非法社会组织 → P0/P1 下线封停。

### 危害交通安全 / 个人安全（P1/P2）
- 不得违规驾驶/危险驾驶/闯红灯/开车抽烟、电子狗、非机动车危险行为、汽车非法改装 → P1 限制投放。
- 不得自残自杀、高空抛物、加油站明火、无防护极限运动、易触电/窒息/烧伤/中毒行为、不良整蛊 → P2 限制投放。

### 侵权 / 不当竞争（P2）
- 不得使用未授权音视频/肖像/商标/专利，不得仿冒他人、不当对比竞品、恶意推广 → P2 限制投放。

### 违背价值观 / 公序良俗（P1/P2）
- 不得恐怖暴力、歧视丑化种族宗教地域、性别歧视、物化女性、浪费食物、出轨等 → P1/P2 限制投放。
- 不得制造容貌/经济/教育焦虑（股市崩盘、容貌焦虑等） → 拒审。
- 不得利用他人苦难玩梗、葬礼恶搞、歧视攻击、虐待动物、伤害弱势群体 → 拒审。

### 用户体验类（P3）
- 图片/文字不当、错别字/无意义符号/语句不通、弱营销（活动抽奖等） → P3 一般不处置，仅提示。

## 三、内容加热规范（按场景）

### 1. 视频场景（内容加热）
- 面向原生内容、无营销属性；有营销需求须先完成账号升级。
- 红线同第二节；另禁：赌石、预测体育赛事、文化艺术收藏品（错版币/虚假纪念币）、买卖书号刊号、未经申请群体活动、易燃易爆危险用品。
- 禁止借热点事件/人物蹭热度营销。
- 虚假宣传红线：绝对化用语、伪科学、仿冒官方界面、未经证实政策信息、保健与医疗混淆。

### 2. 直播场景
- 红线：涉政、黄赌毒、违法产品/服务、私服外挂、短信群发器/伪基站/网络水军、代查号码位置、流通货币推广、减肥丰胸增高壮阳。
- 不良导向：不当竞争（仿冒/恶意对比）、利用国家标志/英雄烈士商业宣传、低俗两性关系、暴力血腥/饮酒动作/危险行为、歧视攻击、幼童代言、制造健康/容貌焦虑、保健医疗混淆。
- 虚假宣传：绝对化用语、"驰名商标/国家免检"字样、低价换购、收益变现（游戏赚钱/现金回收）、受益者/专业人士推荐证明、新闻报道形式广告、服务保证性承诺、前后效果对比、国资背景/A股闪崩等误导。
- 平台限制禁投：开锁配钥、办证刻章、洗浴汗蒸、足疗按摩、刀具、回收买卖、房产中介、简历代投、1-2段奶粉/中药饮品、丧葬、动物养殖、代缴社保、招商加盟、情感调解、直播/电商/理财培训、黑户车/事故车、虚拟账号买卖、物联网卡、心理学培训、活体宠物。

### 3. 营销推广视频（已升级账号）
- 禁投行业/内容：高仿定制改装、第三方落地页短剧、医疗/金融类书籍、盲盒、猫狗肉、寻人启事、线下藏宝/手机掘金、黄金提炼/假黄金、蜡瓶糖、数字人克隆、黑客培训、新能源燃料、打捞尸体/危险品/文物、诱鱼剂、动物活体、特定种苗菌类。
- 政策法规红线：军功纪念章、红色收藏、政治军事书籍、展示领导人照片语录、地图/国旗国徽、人民币、红头文件、军人军队形象、"军用/军工级"描述、利用英雄烈士名义。
- 未成年：不得劝诱未成年要求家长购买、未成年喝酒买酒纹身彩妆美容、不满十周岁代言。
- 封建迷信：看风水/招财/辟邪/手机号影响运势/房产风水、以宗教形象或场所带货。
- 公司规定：不文明用语、非国家通用语言须加中文字幕、禁用繁体/异体/错别字/谐音拼音缩写；未经授权使用抖音/今日头条商标商号或公司名义宣传。

## 四、资质要求（营销推广视频场景）

### 核心原则
- 投放内容必须与平台认证的**营业执照经营范围相符**；涉及特定行业须提供主管部门颁发的专项许可或资质证明。
- 缺资质 → 一律拒绝投放（无资质不投）。

### 分行业资质清单（速查）

### 资质上传入口
- PC 端：DOU+网页版 - 资质认证 - 投放资质
- 移动端：DOU+ - 账号信息 - 投放资质

### 无资质后果
- 有资质要求行业必须"持证上岗"，缺资质内容**直接拒绝投放**；情节严重的按 P1/P2 限制账户投放权限。

## 附：一句话判断口诀

- **能不能投**：先看是否营销（未升级禁营销）、再看是否命中国家红线/黄赌毒/医疗/引流/社交/招聘/回收等禁投类别、再查资质是否齐全、最后看是否虚假夸大。
- **最严红线**：涉政类（P0）— 立即下线、永久/30天限制投放，可主体封停、终止合作、限制资金权益；淫秽色情、赌博、毒品同为 P0。
- **"擦边球"无效**：谐音/变体/暗语（如"游鱿游戏"）仍会被穿透式判定识别。
