# 微信豆官方规则蒸馏 — 直播加热

> 来源：腾讯微信官方文档《视频号直播加热帮助中心》《视频号直播加热FAQ》《视频号直播创作者流量包FAQ》等。抓取日期 2026-08-18。

## 一、直播加热是什么

为鼓励优秀直播内容被更多发现传播，视频号直播平台提供「直播加热」服务。创作者使用流量包加热后，直播间在直播期间被推荐给更多用户，提升观看人数、互动量（评论）、粉丝等目标。

**流量券**：加热过程中抵扣微信豆的优惠券，可能有多个额度。可于首页右上角"…"-"使用明细"查看使用明细。

**流量点**：流量包上的流量额度单位，不同场景含义不同，以页面说明为准。代表预计提升的传播效果幅度。

## 二、加热目标（5 种）

| 目标 | 优化方向 |
|------|---------|
| 直播间观众 | 优化观众进入直播间 |
| 直播间互动 | 优化评论等互动行为 |
| 直播间涨粉 | 优化点击关注视频号 |
| 直播间商品点击 | 优化点击商品行为 |
| 直播间成交订单量 | 优化购买商品行为 |

## 三、加热方式（2 种）

1. **系统智能推荐**：个性化推荐，把直播推给感兴趣用户
2. **自定义定向推荐**：按性别、年龄、城市、主播的观众等定向；选「主播的观众」时优先推给与主播观众/粉丝兴趣相近人群

## 四、使用方法

1. 扫描二维码 / 直播间右上角"更多"面板选"直播加热" / 创作者中心「加热工具」
2. 点击「新建订单」，选择期望加热的主播
3. 选择「快速加热」或「精准加热」
4. 设置加热选项后支付订单

**加热时长（14 档）**：0.5 / 1 / 1.5 / 2 / 2.5 / 3 / 3.5 / 4 / 4.5 / 5 / 5.5 / 6 / 12 / 24 小时

**网页端入口**：`channels.weixin.qq.com/promote/pages/platform/login`

## 五、关键 FAQ

### 使用与获取
- 流量券可通过参与活动、完成任务获得
- 加热需支付微信豆，流量券按比例抵扣
- 同一直播间可**多次、同时加热**

### 流量券规则
- 直播单次加热可用多张流量券
- 单张流量券可拆分使用

### 停止与结算
- 支持中途手动停止，立即结束加热，折算后剩余流量点退回原账户
- 已有一定观看量的直播可加热，不影响效果
- 新直播加热不影响同作者后续直播推荐分发

### 数据
- 「全部订单」查看数据，仅统计加热增量，不含自然流量
- 加热中实时数据可能有 10 分钟延迟
- 预计带来观看量为预估值，仅供参考，最终以实际展示为准
- 平台不对实际加热效果（观看/互动/涨粉）作承诺保证

### 审核
- 显示「审核未通过」表示直播不符合《微信视频号直播创作者流量包功能服务条款》或《微信视频号直播行为规范》
- 反馈邮箱：weixinlive@tencent.com（审核/数据疑惑/账号封禁申诉均可）

### 订单异常
- 加热会被判定为刷量吗？**不会**
- 订单关闭：超过 30 分钟未支付
- 预约失效：预约订单状态与开播时商品状态（是否挂购物车）不符
- 可预约加热的两种情况：①上一场未挂购物车且本场不挂；②上一场挂购物车且本场开播前先挂好
- 预约过期：主播 48 小时内未开播
- 数据变动：加热结束前已下发内容仍在曝光，电商数据持续更新到直播结束后 48 小时
- 结算中：消耗和退款金额结算中，订单在 2-48 小时完成结算退款
- 「再来一单」报错：当前直播间状态与订单状态不同（电商订单需挂购物车，非电商订单需不挂）

### 其他
- 人气卡：腾讯以流量包为基础的合集，可抵扣微信豆，可自用或赠与
- 改名后 2 小时内无法搜索自己直播间投流，2 小时后可搜新用户名

## 六、直播成长相关

**电商成长卡**：奖励优质创作者的流量加量扶持产品，通过参与平台任务或被定点邀请获得。适用于正在开播、内容健康的直播间，使用后直播间有机会推荐给更多用户。

**流量券查看**：直播结束后在「我的视频号-视频号私信」收到私信，点开查看奖励流量券及数据。
