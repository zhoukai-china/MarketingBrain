## 核心认知：微信豆是什么

微信豆是腾讯官方虚拟道具（安卓 1元=10豆，iOS 1元=7豆，网页充值可 1:10），仅限微信场景使用，不可退款、不可转赠、不可套现。用它给视频号短视频/直播「加热」，把内容推给更多兴趣用户，获得曝光、关注、互动、成交。

**微信豆 ≠ ADQ**：微信豆是内容加热（消耗上限低、定向弱、操作简单），ADQ 是专业广告投放（放量强、定向精准、需开户）。两者是「辅助军师」和「主力将军」的关系，不是替代关系。

## 保禄方法论（实战打法）

### 投放决策树

```
需求是什么？
├─ 个人创作者/小预算(50-500元/次)
│   └─ 微信豆加热（手机端操作）
│       ├─ 涨粉 → 选「关注数」
│       ├─ 互动 → 选「点赞评论数」
│       └─ 带货 → 选「商品成交数/ROI」
├─ 电商商家(视频号小店) → 小店投放（CPA结算，不转化不扣费）
└─ 企业正规投放(5000元+) → ADQ（精准定向、规模化放量）
```

### 三阶段投流场景

1. **起号阶段**：投流获取流量、增加账号权重
2. **补量阶段**：直播间承接能力稳定后，投流增加流量
3. **冲榜阶段**：借助投流冲刺更高 GMV 目标

### 出价核心原则（成交/ROI 目标）

- **成交出价**：按客单价利润倒推。例：10元客单价、5元利润的新号 → 初始出价 50 微信豆（=5元下单金额）。依客单价定预算：10元客单价选 2000-3000 豆，100元客单价至少 6000 豆起（计划最多消耗 30%-50%）。
- **ROI 出价**：保本 ROI 起步。例：10元客单价、5元利润 → 填 ROI=2 保本。
- **高开低走**：初始高出价让利跑量，让系统充分探索人群；跑量稳定后逐步降出价到目标成本（成交出价从 50 豆逐步降低，ROI 从 2 升到 2.5、3.0）。
- **官方建议**：自定义出价不要过低，商品加热建议 40-80 之间；初次建单预算 1000-2000 豆。

### 加热方式选择

- **控成本加热优先**（90% 情况选这个）：成本可控，有成本保障计划赔付，适合 ROI 导向。
- **放量加热**：控成本跑不动时再用。曝光高、系统自动优化，但成本波动大、可能吸低质流量。

### 素材策略

- **直投直播间 vs 跑短视频**：单价低、较泛、直播能力好 → 直投直播间；产品细分、单价高、直播间难呈现 → 跑短视频。**两者勿同时投**（直投流量泛、短视频流量精准，同投会承接矛盾）。
- **多素材加热测试**：勾选多条视频小额投放，系统按内容质量智能分配预算，测出有爆发潜力的再加大预算。
- **加热节点**：新作品付费流量冷启；有自然流量/成交数据后放大规模。

### 定向人群建议

- 投放时长 2.5-4 小时以上，越长流量越精准。
- 性别按产品受众；有对标达人填 5-20 个（商品加热最多 20 个兴趣领域/10 位作者/10 个群聊）。
- 视频号人群偏 40-50 岁，年龄按画像调整。
- 兴趣初跑选 5-8 个三级类目，别选太窄（会跑不出去）。

## 官方规则速查

### 短视频内容加热

- **门槛**：原创、优质；购物车加热还需购物车分享权益。
- **目标**：点赞评论数/关注数/播放数；带货视频仅可选「商品点击/成交数」。
- **下单金额**：500 豆起，500 的倍数，500-300000 之间。
- **出价方式**：智能出价（填消耗豆数）或自定义出价（填单价）。
- **加热方式**：智能加热（立即投放，最长 8 小时）或定向加热（自定义时间+人群）。
- **停止**：停止后约 20 分钟生效，返还剩余微信豆/流量券。

### 商品加热

- **硬门槛：DSR（带货评分）≥ 4.1 分**，低于 4.1 无法加热（带货中心查看）。
- **目标**：商品点击数/商品成交数/商品ROI数，每单只选一个。
- **浅层 vs 深层**：自然流量低 → 选「商品点击」探索人群；有自然流量积累 → 选「成交数/ROI」。
- **出价**：智能出价或自主出价，建议 40-80 之间，先高后稳；参考观众 UV 0.3-0.8 元、商品点击 12-18 元。
- **预算**：初次 1000-2000 豆，有效果再追投。
- **ROI 复盘**：ROI=商品成交金额/加热消耗金额，越高越适合追投。

### 直播加热

- **目标**：直播间观众/互动/涨粉/商品点击/成交订单量。
- **方式**：系统智能推荐 或 自定义定向（性别/年龄/城市/主播的观众）。
- **时长**：0.5/1/1.5/2/2.5/3/3.5/4/4.5/5/5.5/6/12/24 小时共 14 档。
- **可多次同时加热**，中途可手动停止。

## 工作规则

1. 先确认加热对象（短视频/商品视频/直播间）和目标（播放/涨粉/互动/商品点击/成交/ROI），不可用能力以当前微信豆页面为准。
2. 收集内容链接、自然数据、目标动作、预算上限、可承接人群、历史加热结果与审核状态。
3. 区分官方事实、账户数据结论、待验证假设和保禄经验建议；预算、出价、定向细则不能实时核验时，明确写「以微信豆当前页面为准」。
4. 一次只测一个主要变量。播放量/涨粉不等同于成交，目标是线索/成交时要写清承接缺口。
5. 不承诺上热门、涨粉、转化、ROI 或审核通过；不提供规避审核、刷量、虚假互动、非官方代充/折扣充值方案。
6. 网页/手机操作默认只到提交前预览；任何创建、付款、启动、暂停、预算或定向变更均需当前批次明确确认。
