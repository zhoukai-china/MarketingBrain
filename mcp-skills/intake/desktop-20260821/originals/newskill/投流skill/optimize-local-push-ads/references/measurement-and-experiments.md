## 统一口径

每份分析先声明：统计日期、时区、归因窗口、平台/门店/商品范围、是否含自然流量、GMV 口径、退款口径、核销成熟度、线索有效标准。

基础公式：

- CTR = 点击 / 展示
- CVR = 转化 / 点击，需注明转化事件
- CPM = 消耗 / 展示 × 1000
- CPC = 消耗 / 点击
- CPA = 消耗 / 转化，需注明浅层还是深层
- 支付 ROI = 支付 GMV / 消耗
- 核销 ROI = 核销 GMV / 消耗
- 有效线索成本 = 消耗 / 有效线索
- 到店成本 = 消耗 / 到店
- 成交获客成本 = 消耗 / 成交

## 交易指标

推荐漏斗：展示 → 点击/进店 → 商品访问 → 下单 → 支付 → 核销 → 净收入/毛利。

同时记录：客单价、退款率、核销率、核销等待天数、门店承接、自然流量占比。支付 ROI 高但核销和毛利差，不能判优。

对核销用 cohort：按支付日期分组，比较支付后 1/3/7/14/30 天核销，不用未成熟订单直接和成熟订单比。

## 直播指标

推荐漏斗：曝光 → 进房 → 有效停留 → 互动 → 商品点击 → 下单 → 支付 → 核销。

按 15/30 分钟或业务节奏分段，记录投流、自然流、主播/货盘/福利变化。整场均值会掩盖具体失效时段。

## 线索指标

推荐漏斗：展示 → 点击 → 咨询/表单 → 接通 → 有效 → 预约 → 到店 → 成交 → 回款。

必须建立无效原因枚举：不在服务区、空号、重复、无需求、预算不符、时间不符、无法联系、销售未跟进等。

媒体侧与销售侧分层：流量有效率反映媒体质量，首响/接通/跟进/报价/到店反映销售承接。

## 保本模型

### 交易保本 ROI

若用 GMV 口径，简化保本 ROI：

`保本 ROI = 1 / 可用于覆盖广告费的贡献毛利率`

贡献毛利率需扣除商品成本、平台/支付费用、履约成本、退款损耗、门店增量人工等。若只用毛利率，会低估真实保本门槛。

### 线索保本成本

`保本线索成本 = 客单收入 × 贡献毛利率 × 线索到成交率`

更严谨时继续乘以回款率并扣除销售/履约增量成本。使用稳定周期的成交率，不用最好销售员或短期峰值。

## 实验设计

### 最小实验单元

一次只检验一个主假设：素材、商品、地域、人群、出价、时段或直播脚本。

### 测试矩阵

- 创意：利益 × 场景 × 证明
- 人群：智能推荐 × 宽定向 × 有明确业务理由的自定义
- 地域：门店附近 × 行政区域 × 跨城需求
- 商品：引流品 × 主利润品 × 套餐组合
- 搜索：品牌 × 品类 × 场景 × 地域 × 痛点

### 观察与停止

- 用事先约定的最低样本和观察周期，避免看到一次转化就下结论。
- 止损不仅看消耗，还看下游质量、履约风险和素材违规风险。
- 胜出标准要在测试前确定：量、成本、ROI、核销、有效率或利润。
- 多重测试时避免“挑最好看的一个”；记录全部测试与失败。

### 放量实验

先在一组稳定计划上调整一个维度，保留对照；观察上游成本与下游质量；失败时回退并记录拐点。不给固定预算增幅，依据账户规模与转化密度决定。

## 数据需求清单

最小诊断表字段：日期、账户/项目/单元、目标、出价方式、预算、消耗、展示、点击、转化、支付 GMV、核销 GMV、退款、门店/商品、素材 ID、地域、时段。

直播增加：进房、停留、商品点击、主播/货盘/福利时间点。

线索增加：线索 ID 去重、有效状态、无效原因、首响、接通、预约、到店、成交、回款、回传时间。

若用户只提供截图，先转成结构化表，再核对口径；不从模糊截图猜精确数字。
