## 纳入标准

一门课程只有同时满足以下条件，才能标记为“已沉淀”：

1. 官方课程页或官方说明可验证标题、适用对象和主题。
2. 至少提炼一个可执行的规则、流程或诊断顺序。
3. 标明该规则的适用条件与不适用情形。
4. 能映射到仍在线的帮助中心产品/规则文章；冲突时以更新时间更晚的帮助中心为准。
5. 不复制课程原文、视频字幕或受限材料，而是写成简短的自主工作流。

仅有课程标题、课程封面或第三方转述时，状态只能是“已建档待学习”。

状态只按以下顺序流转：`已建档待学习 → 正文已核验 → 已映射现行规则 → 已沉淀可执行工作流`。课程下线或与新版规则冲突时改为 `历史参考`，不得继续用于当前界面或政策判断。

## 从课程到策略的使用规则

1. 课程用于理解产品意图和方法论；当前能力、计费、赔付、审核和界面路径必须回到帮助中心或账户界面核验。
2. 对课程案例，只提取“背景—动作—适用条件”，不得复制其结果数字来承诺客户。
3. 每个课程结论必须标为“官方事实”“经验建议”或“待验证假设”，避免把讲师建议伪装成平台规则。
4. 发现课程与新版帮助中心冲突时，记录冲突，并采用新版帮助中心；不要静默覆盖。
