# PC 网页执行与确认规范

## 执行面选择

优先使用 `browser:control-in-app-browser` 的结构化页面能力读取文本、定位控件、填写字段和验证状态；使用前遵循其工具发现、浏览器选择和完整文档要求。只有结构化定位失败且页面视觉状态明确时，才使用 `computer-use` 或浏览器坐标能力兜底；坐标操作后必须重新读取页面确认结果。

## 允许直接执行

- 打开页面、读取账户与报表、截图、计算指标。
- 生成计划草案、ChangeOrder 和执行前预览。
- 在用户已授权的真实账户中填写到最终提交前，但不得点击提交。

## 必须即时确认

- 创建或提交计划。
- 修改预算、出价、优化事件、地域、定向或素材。
- 暂停、启用、删除或复制计划。
- 任何可能产生消耗、改变账户状态或影响客户数据的操作。

确认内容必须显示：客户、账户、计划、字段原值、新值、预算影响、原因、风险、止损和回退。确认只适用于当前批次；页面或字段发生变化后重新确认。

## 页面执行流程

1. 从官方入口 <https://ad.oceanengine.com/> 或抖音来客 PC 进入；不要使用搜索结果中携带陌生 `advid` 的深链接。
2. 读取当前客户、账户 ID/名称、主体、门店和抖音号。
3. 与 ClientBrief 和 ChangeOrder 比对；不一致立即停止。
4. 读取余额、账户状态、产品开关、归因口径和异常提示。
5. 使用角色、标签、字段名或稳定 DOM 属性定位；不要猜测“第几个按钮”。
6. 每完成一个关键区块就重新读取值，防止页面自动重置。
7. 到最终提交前生成预览；未获得确认不得继续。
8. 提交后重新读取成功提示、计划列表和关键字段，生成 ExecutionReceipt。

## 立即停止条件

- 登录失效、验证码、权限不足、账户切换失败。
- 客户或账户身份不匹配。
- 页面结构变化导致目标字段不唯一。
- 预算、出价、地域、优化事件或素材与 ChangeOrder 不一致。
- 页面出现未在预览中的额外收费、协议或高风险提示。
- 提交结果无法确认、重复提交风险或页面状态不明。

验证码必须交给用户处理；不读取浏览器密码、Cookie、本地存储或其他账户秘密。

## 多客户隔离

每次任务只绑定一个 `client_id + account_id`。切换客户后重新读取身份、清空未提交草稿并生成新的 ChangeOrder。禁止跨客户复制预算、素材、门店、抖音号、表单、转化事件或经验阈值。

## 失败与恢复

- 结构化定位失败：保存页面证据，尝试一次基于当前可见状态的重新定位。
- 坐标兜底仍不确定：停止并请求用户接管，不连续盲点。
- 部分字段已填写但未提交：报告草稿状态，不声称已执行。
- 提交后验证失败：回执标为 `UNVERIFIED`，不要重复提交。
