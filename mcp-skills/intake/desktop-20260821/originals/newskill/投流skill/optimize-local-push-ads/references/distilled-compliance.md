# 巨量本地推 · 行业素材审核红线 官方规则蒸馏

> 蒸馏时间：2026-08-16
> 数据来源：巨量本地推官方帮助中心「行业素材审核规则」46 篇（含 618/双11/暑期大促专项、案例解读、风险专项）
> 说明：本文为聚合蒸馏稿，非逐篇罗列。同一红线在多个行业/多篇文档反复出现时已合并。实际审核以官方实时反馈为准（各文均提示"不同案例违规情节存在差异，请以具体反馈结果为准"）。

## 一、通用审核红线（所有行业适用）

### 1. 绝对化用语
- 红线：禁用「国家级、最高级、最佳、顶级、极品、第一品牌、最…之一」及同义变体（"最/一/级极/首"四大类，如 NO.1、唯一、独家、首选、世界级、史无前例、绝无仅有等）。**后果：素材驳回，需删除或提供权威证明。**
- 红线：领导品牌/销量领先/遥遥领先须提供国家级行业协会资质或第三方调研报告并标注来源。**后果：无证明一律驳回。**
- 红线：「金标准」仅限医疗行业（仍需资质），其他行业禁用。**后果：非医疗行业使用直接驳回。**
- 豁免：明示自我比较（最大户型/顶配车型）、客观事实/分级（国家标准生产、最佳饮用时间）、企业理念（安全第一）、表演者主观情感（"我最喜欢"）、玩梗（秋天的第一杯）。

### 2. 效果承诺 / 保证性承诺
- 红线：不得对产品/服务效果做明示或暗示保证性承诺（起效时间、有效率、安全性、永久性、一定达到某程度）。**后果：驳回；涉及严重虚假宣传可封停账户并限制新开账户。**
- 红线：禁用承诺类词汇——告别、不再复发、彻底根除、不留痕、阻止/防止/阻断/解决、一生受益、克星/天敌、说再见、搞定、拯救、100%、绝对。
- 红线：不得以"时间+具体效果/用量+效果"变相承诺（X天祛痘、1瓶搞定、淡化95%妊娠纹、用了3瓶）。

### 3. 非医疗广告涉及医疗
- 红线：非医疗行业（食品/日化/美妆/服饰/洗浴按摩/母婴/3C等）不得出现疾病名称、医疗术语、医疗过程、医美项目，不得以养生科普变相发布医疗广告。**后果：驳回。**
- 红线：高危疾病词（三高、痛风、乙肝、灰指甲、肿瘤、性病、癫痫、艾滋病、HPV、黄褐斑、斑秃等）+ 医疗器械标识（OTC、械字号、红底白字【外】）一律禁用。
- 红线：禁用医学名人背书（扁鹊、华佗、李时珍等）与"医生推荐、药房有售"。

### 4. 数据虚假
- 红线：宣传销量/客户量/评价数/评分/调查结果，须提供真实性证明并标注来源。**后果：无证明驳回。**
- 红线：评价数据若同时展示对应平台评分截图可豁免；平台系统自带销量数据可豁免。
- 红线：引用第三方/市场数据（万亿市场、销量第一）来源须具体有指向性。

### 5. 价格虚假 / 活动虚假
- 红线：「原价/原售价/成交价/特价/划线价」+具体数字，须提供促销前7日内成交证明。**后果：无证明驳回。**
- 红线：禁用「清仓价、出厂价、零利润、全网最低价」等无依据价格描述。
- 红线：禁用「仅限今日、今日特惠、明天涨价」虚假时间范围。
- 红线：商品/服务本身不得为 0 元/免费（仅赠品、附加项可为 0）。
- 红线：禁用饥饿营销/倒计时/最后一次类活动描述（仅剩X件、最后X天、最后一波、就这一次）。
- 红线：禁用「万元档次/千元档次」等抬高预期的低实价诱导；禁用承诺赚取价格（一套只挣5块）、用手势模糊价格、"一天工资/一杯奶茶钱"类比。

### 6. 虚假情景演绎
- 红线：不得利用弱势群体（老人/儿童/残疾人/农民工/重症患者等）悲情营销。**后果：驳回。**
- 红线：不得夸大自然灾害、热点新闻负面营销；不得以虚假新闻/报纸/暗访/发布会/记者招待会形式变相发布。
- 红线：不得利用个人/家庭成员名誉赌誓担保（死全家、不好用跪下、实名呼吁）；不得写承诺函/挑战书营销担保；不得虚构同行竞争/拉踩、虚构买卖关系、虚构人设（xx老师/董事长/钟老）。
- 红线：不得杜撰研发经费、一夜暴富、停播退出等虚假信息抬高实力。

### 7. 人物肖像 / 商标 / 专利 / 第三方授权
- 红线：使用明星/名人/达人肖像须提供授权，影视授权不可替代明星肖像授权；肖像不得打码/贴纸遮挡。**后果：无授权驳回。**
- 红线：使用他人商标须提供商标证+授权（非持有方）；未经授权不得使用"抖音/头条推荐"等平台名义。**后果：侵权驳回。**
- 红线：涉及专利须标明专利号+专利种类并上传证书。
- 红线：涉及第三方公司/产品（官方授权、合作）须提供合作协议或关系证明。

### 8. 影响感官体验 / 引人不适
- 红线：不得大面积/密集展示病症、伤口特写、污垢、分泌物、密集痘痘、疤痕、妊娠纹、耳屎、姨妈血等。**后果：驳回。**（轻微/动画贴纸展示可豁免）

### 9. 有违社会主流价值观
- 红线：不得炫富、拜金、嫌贫爱富、婚恋对立、躺平摆烂、错误事业观（送礼办事）、歧视特定群体。**后果：驳回。**
- 红线：不得涉及国家标志/国家机关/军事装备（国旗国徽、天安门、军徽、警察法院、庭审场景、现役武器装备）。

### 10. 伪科技
- 红线：未提供专利/证明时，不得使用「富氢、富氧、脱糖、纳米、石墨烯、量子、暗物质、恒温、自发热、地震预警」等伪科技词。**后果：驳回。**（纳米作计量单位、通电/耗能产品恒温、蒸汽眼罩自发热可豁免）

### 11. 诱导点击 / 留资虚假 / 履约违规
- 红线：不得宣传"点击领报价/一键估价/X秒得方案"实际跳转后需留资才提供，且实际未提供。**后果：虚假宣传判罚，可封停账户。**
- 红线：宣传价格有隐性条件（拼团/置换）必须明示；折扣力度不得与实际不符。
- 红线：履约须按承诺交付，不得退款难、拉黑辱骂、付费后48小时不回复。

### 12. 资质缺失
- 红线：行业准入资质缺失一律驳回（医疗广审文号、装修报价单、高危体育许可证、演出许可、加盟资质、商标证等，见各行业条款）。

## 二、分行业审核红线

### 医疗 / 医药 / 健康（含口腔、医美、孕产、宠物医院）
1. 医疗机构广告须全程标注「医疗机构第一名称 + 医疗广告批准文号」，且与报备一致、清晰可见。**后果：缺失/不一致驳回。**
2. 不得涉及药物、疾病、医疗器械、医疗技术、诊疗方法（含真人注射、手术过程演绎）。**后果：驳回。**
3. 不得使用医生/专家/患者真人形象（白大褂、胸牌、病号服、X光片解读均算），漫画/局部/素人可。**后果：驳回。**
4. 不得承诺功效有效性/起效时间/安全性（治愈率XX%、根治、不反弹、当天种牙当天啃硬物、无痛、0伤害、无依赖）。**后果：驳回。**
5. 药品/器械/保健食品/特医食品宣传须与说明书/注册证书范围一致，不得超范围。**后果：驳回。**
6. 禁投处方药；禁投两性/私密整形（私密种植、乳晕漂红）、畸形修复（精灵耳、高颅顶、O/X型腿）、肉毒素及针剂类（瘦脸针、溶脂针、美白针）、干细胞。**后果：中危禁投。**
7. 禁投国家暂停医疗营销疾病（三叉神经、尖锐湿疣/HPV、梅毒、淋病、艾滋病、癌症、癫痫、乙肝、白癜风、红斑狼疮、精神疾病等）。**后果：高危禁投。**
8. 不得制造健康焦虑（日常现象→重大疾病、夸大患病后果、病症关联寿命）。**后果：驳回。**

### 丽人 / 医美 / 洗浴按摩 / 生活美容
1. 生活美容不得承诺效果（永久告别敏感肌、7天改善法令纹、淡化95%妊娠纹、前后对比）。**后果：驳回。**
2. 不可逆肌肤状态（斑点/疤痕/皱纹/黑眼圈/眼袋/白发）禁用"祛/除/褪/克星/修复+状态"表述。**后果：驳回。**
3. 不得涉及医疗项目/医美（光子嫩肤、水光针、热玛吉、线雕、超声刀、植发/生发、做双眼皮、纹绣除纹眉外的美瞳线、产后康复/腹直肌/骨盆修复、刮痧拔罐正骨中医推拿）。**后果：驳回或中危禁投。**
4. 禁投上门按摩、陪伴服务、两性服务（私处护理/脱毛）、纹身/肤色重构、纤体塑形日化品。**后果：中危禁投。**
5. 不得涉及减壮丰增（减肥、壮阳、丰胸、增高）。
6. 严禁低俗两性暗示（鸭子坐、露沟、侧乳/臀部暴露、敏感部位特写、行业黑话暗示特殊服务如"男士专属/懂得都懂"、蕾丝面具氛围）。
7. 生活美容不得使用未成年人形象营销。
8. 口腔机构（类医疗）：不得诱导报价（在线测算/领取报价），仅"名额/方案"或电话短信回访报价可豁免。

### 教育 / 培训
1. 禁投 0-18 岁未成年人学科类、素质类、综合能力培养类培训（线上+线下、含品牌形象投放）。**后果：高危禁投。**
2. 禁投青少年网瘾/叛逆矫正非正规学校、特殊儿童托管、国内升学规划、已取消资格证培训（ACI心理咨询师等）、两性技巧培训、理财培训、中医养生/医疗资格培训。
3. 不得效果承诺（保过、包过、包拿证、保就业、一战成硕、通过率XX%、考不过退款、无学历升本科、毕业双证、1年本科、高薪承诺）。**后果：驳回。**
4. 不得制造教育焦虑（批判家长、攀比成绩、否定孩子未来、"中考考不好一生毁了"、强调寒暑假/年级决定性、贬低职业）。
5. 不得虚构人设（xx老师、首席讲师、创始人）与利用未成年人营销（<10岁不得代言，10岁以上需监护人书面授权）。

### 招商加盟
1. 禁投特定品类：手机/面膜/林木/鱼类/畜禽养殖/微商/手工加工/养蟑螂苍蝇/游戏代理陪玩/旅游/机顶盒/路由器/流动摊/电瓶电池修复/能量舱/本地未准入行业加盟。**后果：中危禁投。**
2. 不得收益承诺（开店即回本、生意爆满、四季畅销、永久收益、投资小利润高、轻投资回本快、利润空间大、翻台快）。**后果：驳回。**
3. 资质要求：品牌商标注册证 + 至少三份加盟代理合同或三家加盟店面照片。**后果：缺资质驳回。**
4. 内部数据（加盟商XX家）须标注【数据来源于官网】；第三方市场数据来源须具体。
5. 不得涉及医疗保健功效（如小儿推拿加盟"治疗体虚"）。

### 商务服务 / 法律 / 回收
1. 法律：不得胜诉承诺/宣示胜诉率/赔偿额；不得为金融机构网贷债务提供法律服务；禁收账追债讨债、拆迁维权、退费维权咨询、受骗咨询。**后果：驳回或中危禁投。**
2. 法律：不得受理条件虚假（无需材料/无借条也能立案）、服务过程虚假（先打官司再收费）、离婚"无需冷静期/无需对方同意"、低于同行收费、律所担保。
3. 法律：不得有罪辩护（刑事申诉、减刑、二审上诉）、封存刑期记录、暴力催收暗示、过度渲染还款焦虑、贬低法律途径、庭审场景/突出警察法院。
4. 商务服务禁投：非法网络公关（水军/删帖/短信群发/呼死你）、社保代缴补缴/公积金代办、海外劳务、虚假证件、公司转让注销、资质代办（医疗/金融/三甲/烟草/国企央企）、图书出版、证书制作、获客/拓客系统、殡葬、发票代开、债务优化/停息挂账、资质挂靠、跨境电商运营及培训、多级分销、爆店码。
5. 招聘 APP：薪资表述须加提示语"各岗位/城市薪资可能存在差异，具体以app内岗位详情为准"（视频全程、不得置顶置底、清晰可见），且须明确工作地点。
6. 回收：禁投黄金/贵金属废料回收、酒类回收、药品保健品医疗器械回收、旧衣旧书回收；不得宣传回收价高于市场/公价。

### 房地产 / 家居建材
1. 禁投公租房/小产权房等特定住房、北京六区民宿、首付贷/首付分期、售后包租/返本销售、酒店尾房、农村建别墅、加装电梯、国内土地/宅基地买卖流转、个人中介新房、无资质中介单一新盘。**后果：中危禁投。**
2. 新房售卖须全程标明开发企业名称 + 预售/销售许可证号（中介代理加标中介名称）；3个及以上楼盘可豁免。
3. 涉及面积须标明"建筑面积/套内建筑面积"提示语。
4. 装修/全屋定制/家具整装：提及价格须提供报价单（主体+价格+定制单位），素材须标明平米数并与报价单一致，且加"具体价格以实际装修方案为准"提示语（视频全程）。**后果：缺一驳回。**
5. 家居禁投：家用房屋防水补漏维修、轻钢/重钢别墅、二手红木家具转让、瓷砖空鼓翘边修复。
6. 菜刀/胶类/净水器不得暴力测试、夸大功效（30年不用磨、代替焊接、出水直饮）。
7. 广告来源名称须含公司/品牌核心词，不得用通用词或无关第三方名称。

### 汽车 / 汽车后市场
1. 新车一口价+具体金额须标明车系、款型年份、置换条件、贷款条件（首付+利息政策）。**后果：缺失驳回。**
2. 旧车置换补贴不得超国补标准（新能源≤8%最高1.5万、燃油≤6%最高1.3万）；不得"不看车型/品牌统一抵价"；补贴金额/补贴后价格须全程字幕。
3. 不得"不摇号/包上牌/包过户"（限购城市）、"仅一张身份证提车"、解决征信贷款（不看征信/黑户可贷）、0成本置换/换车倒拿钱。
4. 不得"无人驾驶/自动驾驶/高阶智驾"（仅可"辅助驾驶"）；不得包运营证办证。
5. 二手车：未明确车辆信息不得报具体价；3年内≥指导价5折、4-10年≥2折；须承诺函。
6. 燃油宝：仅可宣传清理积碳/除碳，节油/扭矩须质检报告并完整表述数值；禁"一桶油变2桶"、液体喷射炸出；加提示语。
7. 禁投：事故车/抵押车/叉车/老年代步车/车牌代办出售/车漆修复液/补漆笔/补胎液/提神车载香薰/带安防功能车载产品。
8. 汽车清洁剂不得省略清洁动作、不得"秒"级起效、不得非常规极端场景测试。

### 食品 / 饮料 / 酒 / 餐饮 / 酒旅
1. 不得涉及果腹之外功效（美容养颜、改善睡眠、助孕、壮阳、减肥、降糖降压、补脑益智、防脱育发）。**后果：驳回。**
2. 禁"0添加/无添加"未指明成分；"0糖0脂0卡"须检测证明（"0蔗糖/不添加XX成分"可豁免）。
3. 禁投：动物器官酒（三鞭/鹿鞭/虎骨/鹿血酒）、解酒产品、灵芝孢子粉、药食同源高危品（人参/山茱萸/芡实/葛根等）、中药材/中药饮片、槟榔、0-12月婴幼儿奶粉、代母乳产品、长江流域水产、国家保护野生动植物、野生蜂蜜/驼奶（量产伪野生）。
4. 酒类/酒吧：须加"未成年人不得饮酒"提示语；禁诱导怂恿饮酒、饮酒动作、驾驶场景。**后果：缺提示语驳回。**
5. 餐饮禁投：猫狗肉、流动摊贩、无资质演唱会/音乐节、定制酒/贴牌酒/散装酒、国家批准名单外出境游、高危体育项目（游泳/滑雪/潜水/攀岩）无《高危体育项目经营许可证》。
6. 旅行社/邮轮：禁投以转化为目标的销售线索收集。**后果：限投。**

### 服装 / 配饰 / 鞋包
1. 不得虚构耐用程度（三年不变形、十年穿不烂）、抗寒超范围（内穿低于零度、外穿低于零下30度）、"显瘦+具体斤数"。
2. 美肤衣不得宣传润肤/养肤/保湿（可表述添加玻尿酸等客观成分）；塑身衣不得虚假塑形/P图对比/永久塑形暗示。
3. 内衣类入口图/视频不得用真人素材（三角裤/平角裤/文胸/抹胸）；情趣内衣、原味内衣、丁字裤、开裆袜、渔网袜（膝盖以上）禁投。
4. 不得两性低俗（露沟、胸部下缘、鸭子坐、歧义视角、斩男/流鼻血等词汇、户外试穿私密衣物）。
5. 特殊材质（真皮/羽绒/蚕丝/动物毛/金/银/珠宝）须质检报告/鉴定证书。
6. 不得暴力测试（小刀划包、鞋子踩钉、钢丝球刷衣、丝袜装菠萝）、伪科技（自发热、纳米防臭）。
7. 品牌侵权：未授权商标（迪卡侬、CK、babycare 等）须商标证+授权；禁高仿、山寨、低价名表。

### 3C / 数码 / 家电
1. 禁投：信号增强贴/破解道闸/汽车功能破解、偷电节电设备、震楼器、生鲜灯、聚能环/燃气防风罩、老年代步车、pos机（刷单零扣率等）、手机租赁、手机违规售卖引流线下、烟草/电子烟、罗马仕充电宝、盗版出版物、私服外挂、刷粉刷赞。
2. 不得夸大功效（手机散热器结冰、电风扇"3秒降温/空调效果/制冷"、果蔬清洗机去农残激素、虚假实验点火器敲瓶/汽车碾压手机）。
3. 智能手表不得宣传测血氧/血糖/尿酸（测血压/心率可）。
4. 除菌/除螨/除醛率须对应类别质检证明，数值不得超证明；特殊工艺（防水/防尘/防火/阻燃等级如IPX7）须鉴定证书。
5. 禁伪科技（富氢/石墨烯/纳米）无证明；禁第三方无授权（美团员工作为主要角色出镜）。

### 母婴 / 宠物
1. 禁投 0-12 月婴儿配方乳制品、代母乳产品、pre段奶粉；禁医疗器械（开塞露、胎心仪）。
2. 禁投宠物活体、动物种苗、活体鸡仔赠送。
3. 奶粉/纸尿裤/儿童化妆品不得医疗暗示（提高免疫力、通脉养脑、避免湿疹、医护级、儿科医生推荐）。
4. 儿童化妆品功效限于清洁/保湿/护发/防晒/舒缓/爽身/美容修饰/芳香/修护/卸妆；0-3岁更窄；禁"食品级/可食用"。
5. 宠物用品不得宣传治病（心肌缺氧、眼睛看不见）；饲料功效限于美毛/化毛/发腮/淡化泪痕/改善软便等营养可实现项。
6. 未成年人不得身着泳装/内衣，不得聚焦特殊部位误导视角。
7. 专利须标明专利号种类并上传证书。

## 三、大促专项审核

### 618 / 双11（含双旦）/ 暑期 通用大促要求
- **大促并未放松红线**：各行业大促文档是"日常规则 + 大促热点场景"的强化版，通用红线（绝对化、虚假宣传、医疗擦边、价格虚假）全部照常适用。
- **价格/活动类高发**：大促期间"原价/划线价/清仓价/出厂价/仅限今日/最后一波/限时特价"是重点稽查对象，必须提供 7 日内成交证明，否则驳回。
- **"年货节/大促做活动"可正常描述**：单纯"趁着XX节做活动、新年冲销量、直播间搞活动"未提具体虚假价格，合规。
- **促销折扣须有活动证明**（装修半价/X折、换购抵价均需资质证明：活动时间+内容+对象+公章）。
- **促销价格隐性条件必须明示**（拼团、旧车置换、邀请好友等条件未体现即虚假）。

### 暑期专项（餐饮酒旅/家居/丽人/医疗/教育）
- 暑期教育培训：严禁强调"寒暑假是黄金期/决定期/弯道超车"制造焦虑，禁中高考倒计时。
- 暑期餐饮酒旅：禁流动摊贩/摆摊、无资质演唱会音乐节；高危体育项目须许可证；酒类须"未成年人不得饮酒"提示语。
- 暑期家居建材：防水补漏维修、轻钢别墅、二手红木家具仍为禁投重点。
- 暑期丽人/医疗：上门按摩、私密项目、肉毒素、畸形修复等禁投项与日常一致。

### 风险专项（汽车/虚假宣传）
- 汽车风险专项：新车一口价条件披露、国补上限、征信贷款、无人驾驶表述、二手车低价是重点稽查方向。
- 虚假宣传专项：留资虚假、价格活动虚假、产品服务信息不一致、履约违规（退款难/失联/辱骂）将触发**封停账户 + 限制新开账户**的判罚。

## 四、高频违规点（案例教训）

1. **"原价/特价/清仓价/出厂价/仅限今日"**：全行业最高频，缺 7 日成交证明即驳回。教训：报优惠只讲折扣力度、给活动证明，勿用无依据价格词。
2. **效果承诺与"告别/根治/不再复发/克星"**：美妆祛斑、丽人、医疗、食品是重灾区。教训：用"改善/淡化/舒缓/缓解"过程词，勿用结果词。
3. **前后对比 + 时间承诺**（"7天祛斑""淡化95%妊娠纹""10次改善痘痘"）：几乎每篇案例解读都出现。教训：不演绎同一人同一部位前后对比。
4. **非医疗擦边医疗**：食品讲"药膳/药方/降糖/助眠"、日化讲"消炎/牙结石/脚气"、服饰讲"老寒腿/富贵包"。教训：只讲口感/成分/材质/基础功效。
5. **虚假情景演绎**：下跪/哭/送锦旗/手持身份证实名/赌誓（死全家、喝下水道水、退出互联网）/挑战全网/拉踩同行/虚假新闻直播。教训：正常展示产品与售后即可。
6. **拉踩对比**：口香糖香臭对比、酥肉粉对比、大米饭对比、"动了某些人利益视频快下架"。教训：不得无事实依据贬低同类。
7. **绝对化用语**："国家级""销量第一""宝宝辅食首选""最专业""不二之选"。教训：销量领先须数据证明，主观情感表达可豁免。
8. **伪科技**：纳米银/石墨烯/自发热/富氢/恒温，无专利证明全驳回。教训：纳米作计量单位、通电耗能才可提恒温。
9. **诱导报价（医疗/口腔）**："在线测算/一键报价"被禁，改为"名额/方案"或"电话短信回访报价"。
10. **内衣物料/敏感部位**：露沟、胸部下缘、鸭子坐、户外试穿私密衣物、原味内衣、情趣品类全禁。
11. **未成年人**：教育投未成年人课程、生活美容用儿童形象、儿童成人彩妆、儿童泳装内衣、<10岁代言，均为高危。
12. **引人不适画面**：密集痘痘、分泌物、耳屎、姨妈血、妊娠纹、牙结石特写，改动画贴纸或轻微展示。
13. **资质缺失**：装修报价单、医疗广审文号、加盟三店/合同、商标证+授权、高危体育许可证、专利证书，缺一即驳回。
