# 本地服务内容差异卡

> 本卡是「本地生活服务」通用差异卡，配合 `content-nine-piece` 使用。⚠️ 本行业无专门 compliance skill，① 合规红线为通用参考 + 行业特有风险，建议后续补 `bendi-compliance`。

---

## ① 合规红线

**通用广告法极限词**：最/第一/100%/绝对/唯一 → 用客观描述替代。

**行业特有风险**：

| 风险 | 红线 | 合规写法 |
|------|------|---------|
| 夸大虚假 | 别虚构"月销万单""排队王" | 用真实数据、真实门店实拍 |
| 达人虚假流量 | "达人数据 95% 是刷的"——别依赖达人虚流量 | 自己拍 + 本地推，数据真实可控 |

## ② 行业钩子

| 钩子 | 打法 |
|------|------|
| 到店钩子 | 团购、限时、新客立减 |
| 三大到店理由 | 种草（引力场）/ 品宣（信任状）/ 营销（临门一脚）三层递进 |

**成本对比**：找达人 3000–10 万 vs 自运营职人号 0 成本——自运营攒资产是正解。

---

## ③ 话术与选题库

**核心手法**：
- 卖点转买点：把"产品特征"转成"顾客场景收益"
- 场景化：场景 = 时间 + 原因 + 人物 + 情境 + 情绪
- 痛点 / 痒点 / 爽点三选一
- 蹭热点 4 手法：谐音双关 / 场景代入 / 反差反转 / 夸张比喻

**平台差异话术**：小红书用场景共鸣型（"加班到凌晨就为这口热乎的"）胜过功能型（"招牌牛肉面"）；短视频前 3 秒 = 冲突感 / 食欲感 / 痛点场景。

## ⑥ 选题库

**选题类型配比**：

| 类型 | 占比 | 作用 |
|------|------|------|
| 场景共鸣 | 40% | 时间+原因+人物+情境+情绪，对上处境 |
| 卖点转买点 | 30% | 把产品特征翻成顾客收益 |
| 蹭热点 | 30% | 谐音双关/场景代入/反差反转/夸张比喻 |

**高频选题清单**（可直接用）：
1. 加班到凌晨，就为这口热乎的
2. 第一次来这样点不踩雷
3. 店里最真实的 3 个细节，为什么老顾客回头
4. 明码标价不推销，为什么这么难找
5. 周末限定：这个隐藏项目只有熟客知道

**选题钩子公式**：场景化（时间 + 原因 + 人物 + 情境 + 情绪）＋ 到店理由。
