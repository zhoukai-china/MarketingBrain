# 新疆特产内容差异卡

> 本卡只写「新疆特产独有」，配合 `content-nine-piece` 使用。⚠️ 本行业无专门 compliance skill，① 合规红线参考餐饮食品合规 + 行业特有风险，建议后续补 `xjtc-compliance`。

---

## ① 合规红线

**通用广告法极限词**：最/第一/100%/绝对/唯一 → 用客观描述替代。

**食品相关（特产是食品，重点）**：

| 风险 | 红线 | 合规写法 |
|------|------|---------|
| 食品功效 | 普通食品不得宣传疾病预防/治疗/保健（"降三高""养胃""补血"） | 客观描述口感/产地/工艺 |
| 产地宣称 | "正宗新疆""产地直发"需真实可溯 | "新疆 XX 产地直发"（可验证） |
| 有机/绿色 | "有机""绿色食品"需有认证证明 | 无证不宣称 |

## ③ 话术与选题库

**创始人 IP 四类内容**（特产招商核心）：
- 流量型（拉新曝光）→ 人设型（获取信任）→ 专业型（证明专业）→ 营销型（引导咨询）

**高频选题**：创业故事 + 全产业链实力（产地/加工/物流）+ 加盟政策。

## ⑥ 选题库

**选题类型配比**（创始人 IP 四类）：
- 流量型（拉新曝光）→ 人设型（获取信任）→ 专业型（证明专业）→ 营销型（引导咨询）

**高频选题清单**（可直接用）：
1. 创业故事：从新疆产地到全国餐桌
2. 带你走进产地：这颗红枣是怎么到你手里的
3. 全产业链实拍：从种植到加工到物流
4. 为什么新疆的干果甜？3 个产地秘密
5. 加盟政策解读：怎么和我们一起做
6. 先尝后买：到店免费品尝，好吃再买

**选题钩子公式**：产地 + 创业故事（信任型），C 端卖货 B 端招商分两条线。
