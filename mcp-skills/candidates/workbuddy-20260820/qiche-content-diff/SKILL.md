# 汽车后市场内容差异卡

> 本卡只写「汽车后市场独有」，配合 `content-nine-piece` 使用。⚠️ 本行业无专门 compliance skill，① 合规红线为通用参考 + 行业特有风险，建议后续补 `qiche-compliance`。

---

## ① 合规红线

**通用广告法极限词**：最/第一/100%/绝对/唯一/国家级 → 用客观描述替代。

**行业特有风险（重点）**：

| 风险 | 红线 | 合规写法 |
|------|------|---------|
| 对比贬低同行 | "4S 店报价 5000 的毛病，其实 800 就能修"——易踩贬低同行红线 | 只报自家透明价，不点名贬低 4S/同行 |
| 终身承诺 | "终身技术指导 19800"需有真实服务条款支撑 | 明确服务内容、期限、边界 |
| 疗效/维修承诺 | 别承诺"修好""包好"（车况不同） | "先免费检测，报明细价，修不修您自己定" |

---

## ② 行业钩子

| 钩子 | 打法 |
|------|------|
| 免费检测 | "先免费帮您检测，有问题报明细价，修不修您自己定" |
| 透明报价 | 材料费 + 工时费分开列，消除"被宰"顾虑 |
| 保养引流 | 小保养 200-500 元（利润率<10%，纯引流） |
| 老带新 | 双方各得免费保养一次 |

**核心**：汽修是信任生意，透明报价 + 免费检测是最高转化的钩子。

---

## ③ 话术与选题库

**高频选题**：故障诊断（"故障灯亮了别慌，90% 是这个问题"）、避坑指南、维修案例（"修好一台别人都修不了的特斯拉"）。

**升单话术**：刹车片检测转化——"现在换 8 折，等报警再换伤刹车盘更贵"（用后续成本倒逼当下成交）。

---

## ④ 平台侧重

**抖音 + 快手双平台**（O+O 深度融合，总部赋能加盟商共同获客）+ POI 挂载。门店实拍维修过程、故障诊断是最强内容。

---

## ⑤ 案例与数据锚点

| 指标 | 数据 |
|------|------|
| 后市场规模 | 1.3 万亿 |
| 汽修门店 | 38.2 万家，3 个月减 4.7 万家（日均倒闭 522 家） |
| 维修类毛利 | 47%–54%（刹车片 50%/冷却液 54%） |
| 新能源维保产值 | 91 亿(2020) → 904 亿(2025)，6 年涨 9 倍 |
| 新能源渗透率 | 52.9% |

**可对外案例逻辑**：透明报价 + 免费检测建立信任、维修案例展示技术实力。涉具体品牌/门店数据需确认可对外再引用。

## ⑥ 选题库

**选题类型配比**：

| 类型 | 占比 | 作用 |
|------|------|------|
| 故障诊断 | 40% | 故障灯/异响，建立专业信任 |
| 避坑指南 | 30% | 保养避坑、4S 店对比 |
| 维修案例 | 30% | 高难度案例，证明实力 |

**高频选题清单**（可直接用）：
1. 故障灯亮了别慌，90% 是这个问题
2. 4S 店报价 5000 的毛病，透明报价后多少钱
3. 刹车片什么时候换？3 个信号别等报警
4. 修好一台别人都修不了的特斯拉
5. 保养避坑：这 3 个项目根本不用做
6. 新能源车保养，比油车省在哪

**选题钩子公式**：诊断钩子（故障灯 / 异响 / 报警）＋ 透明报价信任。

---

> **收尾大白话**：汽修是信任生意，先免费检测、报透明价，再谈修不修；靠技术案例立人设，别靠贬低同行。
