## ① 合规红线（美业内容第一优先级）

**美业是重监管行业，内容第一优先级不是"写得好"，是"不违法"。**

### 红线 1：广告法极限词

| 禁用 | 替代 |
|------|------|
| 第一、No.1、首选、唯一 | 口碑之选、深受顾客信赖 |
| 最好、最佳、最有效 | 效果不错、顾客反馈好 |
| 顶级、顶尖、极致 | 高端、专业 |
| 100%、绝对、彻底、根治、根除 | 有效改善、帮助缓解 |
| 无创、零风险、无副作用、绝对安全 | 温和、低刺激（仍须谨慎） |
| 立竿见影、一次见效、秒变、永久 | 逐渐改善、坚持护理 |
| 国家级、世界级、全球领先 | 直接删掉 |

### 红线 2：医疗/功效禁用（生活美容 vs 医疗美容）

| 场景 | 能不能说 |
|------|---------|
| 宣传"注射、水光针、激光祛斑、微针、溶脂" | ❌ 医疗美容，生活美容无资质宣传即违法 |
| 宣称"治疗痘痘、治愈皮炎、消炎杀菌、排毒" | ❌ 医疗术语，生活美容/化妆品禁用 |
| 宣称"祛斑、美白、防晒、防脱、祛痘"特殊功效 | ⚠️ 需特证/功效依据，普通品不能直接说 |
| "抗皱、紧致、提亮、舒缓、补水、控油" | ✅ 可宣称，仍需产品功效依据 |

**判断口诀**：涉及「病、疗、医、药、根治、无创」的字眼一律替换；涉及「祛斑美白防晒」先问"有没有特证"。

### 红线 3：功效证据链

每个功效必须能答"凭什么"：成分 / 仪器 / 数据 / 资质 四选一，选不出就划掉或改弱。**禁止编效果数据、虚构顾客证言、AI 生成"前后对比图"当真实案例。**

### 禁用词速查表（写完直接跑一遍替换扫描）

```
禁用：治疗 治愈 根治 根除 消炎 杀菌 排毒 药妆 医用级(无证) 无创 微创
     永久 彻底 绝对 100% 第一 最 顶级 极致 秒变 立竿见影 零风险 无副作用
     祛斑 美白(无特证) 抗衰老 逆龄 瘦脸 溶脂 水光针 玻尿酸注射(无资质)
替代：改善 缓解 帮助 舒缓 修护 呵护 水润 柔嫩 提亮 紧致(需依据)
     温和 亲肤 口碑 顾客反馈 逐渐 坚持使用
```

## ② 行业钩子

| 店型 | 引流款 | 作用 |
|------|--------|------|
| 快消型（美甲美睫） | 9.9 元美甲、39.9 元基础清洁（限新客 1 次） | 低门槛拉新 |
| 中高端（抗衰/SPA） | 199 元体验券（皮肤检测 + 局部护理） | 避免低价拉低调性 |

**核心逻辑**：引流款只是"请客人进门"的钩子，**别用引流款成交**；到店后先用免费/低价解决具体问题，认可后再推王牌项目（高阶项目/疗程）——**前端拓客亏钱、二转盈利**。

**核销率生死线**：团购券设 24/72 小时有效 + 下单后微信约时间 + 到店前 1 小时提醒；核销率守 80% 以上，系统标"优质商家"流量倾斜。

**爆款钩子公式**（15 秒同城）：
```
0-3秒   "XX 区想做美甲的姐妹，纯色美甲只要 29.9！"
3-10秒  门店实景/服务特写（操作细节、环境、顾客实拍）
10-14秒 团购价对比（原价 vs 线上专属价，标注限量）
结尾    点左下角定位团购，预约直接到店核销
```

## ③ 话术与选题库

**痛点钩子**：
- "想做美甲的姐妹先别划走，纯色美甲只要 9.9"
- "敏感肌/问题肌看过来，先别乱买"
- "被美容院推销到怕的人，终于找到一家明码标价不推销的店"

**高频选题方向**：问题肌护理、抗衰、换季敏感、美甲款式、皮肤检测、避坑指南、仪器科普。

**差异化卖点**：**明码标价 + 零推销**是美业最安全也最有效的差异点（典型封面：被推销到怕 → 找到一家不推销的店）。信任状优先于效果承诺：资质、真人案例（经授权）、顾客口碑、明码标价，比"效果多牛"更打动客群也更合规。

## ④ 平台侧重

| 店型 | 主攻平台 |
|------|---------|
| 中高端（抗衰/SPA） | 小红书（种草）+ 大众点评（搜索转化） |
| 快消型（美甲美睫） | 抖音（同城团购）+ 美团（搜索） |
| 社区便民店 | 社群 + 本地生活 |

**投流侧重**：本地推定向门店 3–15 公里、25–45 岁女性、早 10 点–晚 24 点跑量；止损——预算烧到 50% 没团购下单就关停换素材。功效类（祛痘）直接投线索易审核不通过，改用"加热投放"更稳。

## ⑥ 选题库

**选题类型配比**：

| 类型 | 占比 | 作用 |
|------|------|------|
| 痛点共鸣 | 40% | 问题肌/被推销恐惧，0.5 秒对上处境 |
| 干货科普 | 30% | 建立专业人设 |
| 氛围向往 | 30% | 做完的松弛感、素颜好状态 |

**高频选题清单**（可直接用）：
1. 敏感肌别乱买，先搞清楚你是屏障受损还是真的过敏
2. 被美容院推销到怕的人，找到一家明码标价不推销的店
3. 换季皮肤闹脾气？3 个信号说明该换护理了
4. 美甲避坑：99 块的纯色和 39 块的差别在哪
5. 皮肤检测到底测什么？一次说清
6. 抗衰不是越贵越好，先做对这 3 件事

**选题钩子公式**：痛点钩子「XX 区的姐妹 / 敏感肌看过来，先别乱买」＋ 到店理由。
